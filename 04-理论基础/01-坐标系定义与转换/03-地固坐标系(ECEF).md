# 地固坐标系（ECEF）

## 概述

地固坐标系（Earth-Centered Earth-Fixed，ECEF）是以地球质心为原点，随地球一同转动的坐标系。ECEF坐标系与地球表面固定相连，适用于描述地面站位置、卫星相对地面位置、大地测量等应用场景。

## 定义

### 基本定义

ECEF坐标系的定义如下：

- **原点**：地球质量中心
- **Z轴**：指向地球北极（CTP方向）
- **X轴**：指向赤道面与格林尼治子午线的交点
- **Y轴**：与X、Z轴构成右手坐标系（$Y = Z \times X$，在赤道面上东经90°方向）

### 坐标表示

ECEF坐标系下，任意位置用三维坐标 $(x, y, z)$ 表示：

- $x$：沿格林尼治子午线方向
- $y$：沿东经90°子午线方向
- $z$：指向北极方向

### 与经纬高的关系

对于大地坐标系（经度 $\lambda$、纬度 $\phi$、高度 $h$），转换为ECEF坐标的公式为：

$$
\begin{aligned}
x &= (N + h) \cos\phi \cos\lambda \\
y &= (N + h) \cos\phi \sin\lambda \\
z &= \left[N(1-e^2) + h\right] \sin\phi
\end{aligned}
$$

其中：
- $N = \frac{a}{\sqrt{1 - e^2 \sin^2\phi}}$ 为卯酉圈曲率半径
- $a$ 为地球椭球长半轴
- $e$ 为地球椭球第一偏心率

## 主要类型

| 坐标系 | 全称 | 说明 |
|--------|------|------|
| **ITRF** | 国际地球参考框架 | IERS定义的精确框架 |
| **WGS84** | 世界大地测量系统1984 | GPS使用的标准 |
| **PZ90** | 参数Z坐标系1990 | GLONASS使用的标准 |
| **CGCS2000** | 2000国家大地坐标系 | 中国大地测量标准 |

### ITRF与WGS84的关系

ITRF是国际高精度参考框架，WGS84是GPS导航使用的框架。在当前精度水平下，两者可以认为是等价的（差异小于1厘米）。

## 特点

1. **地球固连**：坐标轴随地球一同旋转，地面点坐标恒定
2. **直观性**：便于表示地面站、卫星地面轨迹等与地球相关的信息
3. **实用性**：测控、通信、导航等领域广泛使用
4. **时变性**：坐标值不随时间变化（忽略极移等微小变化）

## 应用场景

| 应用领域 | 具体用途 |
|----------|----------|
| **测控系统** | 地面站位置、跟踪弧段计算 |
| **卫星导航** | GPS、GLONASS、北斗定位 |
| **通信** | 卫星通信覆盖区计算 |
| **大地测量** | 坐标系统转换 |
| **气象** | 星下点轨迹 |

### 典型计算

1. **星下点计算**：卫星在地球表面的投影位置
2. **覆盖分析**：地面站对卫星的可见性判断
3. **距离计算**：地面站到卫星的几何距离
4. **多普勒计算**：相对运动引起的多普勒频移

## 在ATK中的使用

### 配置方法

在ATK中设置地固坐标系：

```
参考框架：ECEF / ITRF / WGS84
```

### 常见配置

| 应用场景 | 推荐坐标系 | 说明 |
|----------|------------|------|
| 地面站分析 | WGS84 | 测控标准框架 |
| GPS数据 | WGS84 | GPS导航标准 |
| 大地测量 | ITRF | 高精度测量 |
| 国内应用 | CGCS2000 | 中国标准 |

### 坐标转换

ECEF是ECI与地面之间的桥梁：

```
ECEF坐标 = R(GAST) × ECI坐标
ECI坐标  = R(-GAST) × ECEF坐标
```

### ATK配置示例

```python
# 设置地面站坐标系为ECEF
station.SetLocation(ECEF, x=−1230404.0, y=4822381.0, z=3748770.0)

# 设置卫星位置输出为ECEF
satellite.TrackData.OutputFrame = ECEF
```

## 注意事项

1. **极移效应**：地极位置有微小摆动，高精度需考虑极移修正
2. **框架差异**：不同ECEF框架存在微小差异（厘米级）
3. **时间基准**：ECEF坐标转换需要精确的UT1时间
4. **一致性检查**：不同来源的位置数据需确认坐标系一致性
