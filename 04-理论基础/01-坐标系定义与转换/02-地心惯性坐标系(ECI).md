# 地心惯性坐标系（ECI）

## 概述

地心惯性坐标系（Earth-Centered Inertial，ECI）是以地球质心为原点，不随地球自转的坐标系。它是航天任务分析中最常用的坐标系之一，特别适用于描述卫星轨道运动、天体位置等不随地球自转变化的物理量。

## 定义

### 基本定义

ECI坐标系的定义如下：

- **原点**：地球质量中心
- **X轴**：指向春分点（J2000历元的平均春分点）
- **Z轴**：垂直于地球平均赤道面，指向北极
- **Y轴**：与X、Z轴构成右手坐标系（$Y = Z \times X$）

### 常用ECI坐标系变体

| 坐标系 | 说明 | 基准历元 |
|--------|------|----------|
| **J2000** | 美国国防部定义的惯性系 | 2000年1月1日 12:00 TT |
| **GCRF** | 地心天体参考框架 | IERS规范 |
| **MOD** | 平均平赤道坐标系 | 当前时刻 |
| **TOD** | 真赤道真春分点坐标系 | 当前时刻 |

### J2000坐标系详细定义

J2000是应用最广泛的惯性坐标系，其定义为：

- **历元时刻**：JD = 2451545.0 TT（即2000年1月1日12:00 TT）
- **基准平面**：J2000历元的平均赤道面
- **X轴指向**：J2000历元的平均春分点
- **参考框架**：ICRF（国际 Celestial Reference Frame）

## 特点

1. **惯性特性**：ECI坐标系不随地球自转，方向固定在惯性空间中
2. **数学简洁性**：轨道方程在惯性系中形式简洁，便于推导和计算
3. **时间独立性**：坐标轴方向固定，不随时间变化
4. **高精度**：配合IAU岁差章动模型可达亚毫角秒精度

## 应用场景

### 主要应用

| 应用领域 | 具体用途 |
|----------|----------|
| **轨道力学** | 轨道根数定义、轨道预报、轨道转移计算 |
| **星历计算** | 行星、卫星位置计算 |
| **任务规划** | 轨道设计、星座构型分析 |
| **导航** | 惯性导航基准 |
| **测控** | 遥测数据处理 |

### 典型使用场景

1. **轨道根数表示**：开普勒轨道要素（半长轴、偏心率、倾角等）基于ECI定义
2. **星历数据生成**：DE系列星历、SPK文件中的位置数据
3. **轨道预报**：二体运动、高精度轨道积分
4. **相对运动分析**：卫星编队飞行、交会对接

## 在ATK中的使用

### 配置方法

在ATK中设置惯性坐标系时，需要指定具体的惯性框架类型：

```
参考框架：J2000 / GCRF / MOD / TOD
```

### 常见配置

| 对象类型 | 推荐坐标系 | 说明 |
|----------|------------|------|
| 卫星轨道 | J2000 | 标准轨道计算框架 |
| 星历数据 | GCRF | IERS标准框架 |
| 姿态基准 | TOD | 精确姿态计算 |

### 坐标转换

ECI与其他坐标系的转换关系：

```
ECEF = R(GAST) × ECI          # ECI转ECEF，需考虑地球自转角
ECI  = R(-GAST) × ECEF        # ECEF转ECI
```

其中 $R(GAST)$ 是绕地轴旋转格林尼治视恒星时（GAST）的旋转矩阵。

## 注意事项

1. **岁差章动效应**：长时间积分需考虑岁差和章动修正
2. **框架一致性**：不同来源的轨道数据需确认坐标系一致性
3. **精度匹配**：高精度任务需使用IAU 2006/2000A岁差章动模型
4. **时间系统**：惯性坐标系与具体的时间系统（TT、UT1等）无关，但转换时需注意
