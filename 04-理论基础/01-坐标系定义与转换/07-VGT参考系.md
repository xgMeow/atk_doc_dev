# VGT参考系

## 概述

VGT（Virtual Ground Track）参考系是一种虚拟参考坐标系，主要用于描述卫星相对于地球表面的运动轨迹。VGT坐标系在地中海区域分析、区域导航和特定区域覆盖分析中有重要应用价值。

## 定义

### 基本概念

VGT参考系是一种"虚拟"的地面轨迹坐标系，它将卫星星下点的地理坐标（经度、纬度）作为坐标变量：

- **第一坐标**：地面轨迹的经度
- **第二坐标**：地面轨迹的纬度
- **第三坐标**：卫星高度

### 坐标系特性

| 特性 | 说明 |
|------|------|
| 原点 | 随时间变化的星下点 |
| 运动性 | 随卫星运动而移动 |
| 投影性 | 始终在地球表面参考 |
| 虚拟性 | 非物理坐标系，是数学映射 |

### 与ECEF的关系

VGT坐标系的原点（星下点）在地固坐标系（ECEF）中的位置为：

$$
\begin{aligned}
\lambda &= \arctan2(y_{ECEF}, x_{ECEF}) \\
\phi &= \arcsin\left(\frac{z_{ECEF}}{r}\right) \\
h &= r - R_{\text{地球}}
\end{aligned}
$$

## 特点

1. **区域针对性**：特别适合分析特定地理区域的覆盖
2. **直观性**：直接给出经纬度信息，便于理解
3. **动态性**：坐标原点随星下点移动
4. **简化分析**：便于计算区域停留时间、重复周期

## 应用场景

| 应用领域 | 具体用途 |
|----------|----------|
| **区域覆盖** | 特定国家/地区的卫星覆盖分析 |
| **重复轨迹** | 卫星回归特性分析 |
| **星下点轨迹** | 地面轨迹绘图 |
| **区域通信** | 特定区域的服务窗口 |
| **遥感应用** | 区域成像规划 |

### 典型应用

1. **区域通信卫星**：保证特定区域的通信覆盖
2. **气象卫星**：对特定区域的连续观测
3. **遥感卫星**：区域数据采集优化

### 回归轨道分析

对于回归轨道卫星，VGT坐标系可以分析：

- 回归周期：星下点重复轨迹的时间间隔
- 覆盖带宽度：相邻轨迹间的覆盖区域
- 区域覆盖时间：特定点的可见时长

## 在ATK中的使用

### 配置方法

在ATK中设置VGT参考系：

```
参考框架：VGT
关联对象：卫星名称
```

### ATK配置示例

```python
# 创建VGT参考框架
vgt_frame = sat.ReferenceFrame.Create("VGT_Frame")
vgt_frame.Type = "VGT"
vgt_frame.Origin = "Satellite"

# 获取VGT轨迹数据
vgt_data = sat.GroundTrack(VGT)

# 区域覆盖分析
region = Analysis.Coverage.Region("China")
region.AccessConstraint = Access.MinElevation(10)
```

### 典型输出参数

| 参数 | 说明 | 单位 |
|------|------|------|
| GroundTrack.Longitude | 星下点经度 | 度 |
| GroundTrack.Latitude | 星下点纬度 | 度 |
| GroundTrack.LocalTime | 星下点地方时 | 小时 |

## 注意事项

1. **极轨道特性**：极轨道卫星的VGT轨迹覆盖全球
2. **倾斜轨道**：倾斜轨道的VGT轨迹受纬度限制
3. **坐标系非惯性**：VGT随地球自转而变化
4. **边界处理**：经度的周期性（±180°）需特殊处理
