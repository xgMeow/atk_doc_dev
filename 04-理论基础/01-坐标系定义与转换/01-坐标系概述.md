# 坐标系概述

## 什么是坐标系

坐标系是描述空间中点、向量或物体位置和方向的数学框架。在航天任务分析与设计中，坐标系是表达轨道状态、姿态、相对几何关系的基础工具。

一个完整的坐标系包含两个核心要素：
- **原点（Origin）**：坐标系的参考起点，通常选取天体质心、航天器质心或地表某一点
- **坐标轴（Axes）**：一组相互正交的单位向量，定义了空间方向的基准

## 坐标系的分类

在 ATK 中，坐标系按照应用场景可分为以下几大类：

### 1. 惯性坐标系（Inertial Frames）

惯性坐标系是不随时间旋转的坐标系（在牛顿力学意义下），通常以太阳系质心或地球质心为原点，用于描述天体的绝对运动。

常见惯性坐标系包括：
- **ICRF**（国际天球参考架）
- **J2000**（J2000历元平赤道平春分点坐标系）
- **各中心天体的 Inertial 坐标系**

### 2. 中心天体固定坐标系（Body-Fixed Frames）

与中心天体固连的坐标系，随天体一起旋转，用于描述相对于天体表面的位置和方向。

常见固定坐标系包括：
- **Fixed**（固定坐标系）
- **TrueOfDate**（真赤道坐标系）
- **MeanOfDate**（平赤道坐标系）

### 3. 轨道局部坐标系（Trajectory-Based Frames）

以航天器轨道运动为基础定义的坐标系，常用于描述轨道相对几何、编队飞行、交会对接等场景。

常见轨道局部坐标系包括：
- **LVLH**（当地垂当地平坐标系）
- **RIC**（径向-迹向-法向坐标系）
- **VNC**（速度-法向-共法向坐标系）
- **ICR**（迹向-法向-径向坐标系）
- **VVLH**（飞行器速度当地水平坐标系）

### 4. 表面局部坐标系（Surface-Based Frames）

以中心天体表面某参考点为基础定义的坐标系，常用于描述地面站、着陆点、目标点等局部几何关系。

常见表面局部坐标系包括：
- **NorthEastDown**（北东下坐标系）
- **NorthWestUp**（西北上坐标系）
- **TopoCentric**（站心坐标系）
- **RadialCentric**（径向中心坐标系）

### 5. 历元坐标系（Epoch-Based Frames）

在特定历元时刻定义的坐标系，该坐标系在该历元时刻与对应的时变坐标系对齐，但之后不随时间旋转。

常见历元坐标系包括：
- **AlignmentAtEpoch**
- **MeanOfEpoch**
- **TrueOfEpoch**
- **TEMEOfEpoch**

### 6. 黄道坐标系（Ecliptic Frames）

以黄道面为基准定义的坐标系，常用于行星际任务和深空探测。

常见黄道坐标系包括：
- **MeanEclpJ2000**
- **TrueEclpDate**
- **J2000_Ecliptic**

## 坐标系的命名规则

在 ATK 中，坐标系名称通常遵循以下命名模式：

```
[中心天体].[坐标系类型]
```

例如：
- `Earth.Fixed` — 地球固定坐标系
- `Moon.MeanEarth` — 月球平均地球坐标系
- `Satellite1.LVLH` — 卫星1的LVLH轨道坐标系

## 坐标系选择指南

在实际任务分析中，选择合适的坐标系至关重要：

| 应用场景 | 推荐坐标系 |
|---------|-----------|
| 描述绝对轨道状态 | ICRF 或 J2000 |
| 描述相对于地球表面的位置 | Earth.Fixed |
| 编队飞行相对运动分析 | LVLH 或 RIC |
| 交会对接相对导航 | LVLH 或 VVLH |
| 地面站观测几何 | NorthEastDown 或 TopoCentric |
| 行星际转移轨道 | MeanEclpJ2000 或 ICRF |
| 月球表面任务 | Moon.MeanEarth 或 Moon.Fixed_IAU2003 |

## 常用坐标系关系概览

```
ICRF（惯性基准）
  ├── J2000（地球惯性，历元固定）
  ├── 各中心天体 Inertial（常量旋转自ICRF）
  │     └── Fixed（随天体旋转）
  │           ├── TrueOfDate
  │           ├── MeanOfDate
  │           └── ...
  ├── 轨道局部坐标系（与具体对象绑定）
  │     ├── LVLH
  │     ├── RIC
  │     └── VNC
  └── 历元坐标系（特定时刻冻结）
        ├── TrueOfEpoch
        ├── MeanOfEpoch
        └── AlignmentAtEpoch
```

> **注意**：上述层次关系仅表示概念上的推导关系，实际的数学转换可能涉及多个中间步骤。具体转换方法参见 [坐标转换方法](./06-坐标转换方法.md)。
