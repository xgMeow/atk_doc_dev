# 坐标系概述

## 概述

坐标系是描述物体位置和运动状态的数学参照系。在航天任务分析中，正确选择和使用坐标系是保证计算准确性的基础。不同应用场景需要使用不同的坐标系，例如轨道计算通常在惯性坐标系中进行，而地面站定位则在地球固连坐标系中进行。

## 定义

坐标系由以下要素定义：

- **原点**：坐标系的参考点
- **轴向**：定义坐标轴的方向
- **基准平面**：用于定义角度的参考平面
- **度量单位**：长度的单位（通常为米）

## 常用坐标系分类

### 按原点位置分类

| 类别 | 说明 | 典型坐标系 |
|------|------|------------|
| 地心坐标系 | 原点在地心 | ECI、ECEF |
| 站心坐标系 | 原点在地面站或观测点 | ENU、NED |
| 星心坐标系 | 原点在恒星或行星中心 | J2000、GCRF |
| 本体系 | 原点在飞行器中心 | 飞行器体坐标系 |

### 按是否随地球转动分类

| 类别 | 说明 | 典型坐标系 |
|------|------|------------|
| 惯性坐标系 | 不随地球自转 | J2000、GCRF |
| 固连坐标系 | 随地球自转 | ECEF、ITRF |

### 按应用领域分类

| 领域 | 坐标系 |
|------|--------|
| 轨道力学 | ECI、J2000、GCRF |
| 大地测量 | ECEF、WGS84 |
| 导航 | NED、ENU |
| 姿态控制 | 体坐标系、轨道坐标系 |

## ATK支持的坐标系列表

ATK软件支持的坐标系包括：

### 惯性坐标系
- **J2000**：美国国防部定义的惯性坐标系，epoch为2000年1月1日12:00 TT
- **GCRF**：地心惯性参考系，与J2000几乎等价
- **MOD**：J2000到当前时刻的平均平赤道面坐标系
- **TOD**：真赤道面坐标系

### 地球固连坐标系
- **ECEF (ITRF)**：地球中心地球固定坐标系
- **WGS84**：用于GPS的大地测量坐标系
- **PZ90**：俄罗斯GLONASS使用的坐标系

### 站心坐标系
- **ENU (East-North-Up)**：东北天坐标系
- **NED (North-East-Down)**：北东下坐标系

### 轨道坐标系
- **VVLH**：速度垂线局部水平坐标系
- **LVLH**：局部垂线局部水平坐标系
- **VNC**：速度-法向-叉乘坐标系

### 专用坐标系
- **Spacecraft Body**：航天器本体坐标系
- **VGT**：虚拟地面轨迹参考系
- **VNC_Sat**：卫星VNC坐标系

## 应用场景

| 应用场景 | 推荐坐标系 |
|----------|------------|
| 轨道预报与计算 | J2000、ECI |
| 地面站测控 | ENU、NED |
| 姿态控制 | 体坐标系 |
| 星历数据处理 | GCRF |
| 大地测量 | ECEF、WGS84 |

## 在ATK中的使用

在ATK中进行任务分析时，需要注意以下几点：

1. **统一坐标系**：在进行多对象分析时，确保所有对象使用相同的坐标系
2. **时变坐标系**：惯性坐标系是固定的，但固连坐标系会随时间变化
3. **坐标转换**：ATK提供自动坐标转换功能，但需注意转换精度和适用条件
4. **输出格式**：根据下游应用选择合适的坐标系输出

## 注意事项

- 不同软件对同一坐标系的定义可能略有差异
- 坐标系的基准历元（epoch）会影响计算精度
- 进行高精度任务分析时，需明确坐标系的定义来源和精度要求
