# LVLH坐标系

## 概述

LVLH（Local Vertical Local Horizontal）坐标系是另一种以航天器为中心的局部轨道坐标系。与VVLH类似，LVLH也用于描述航天器的相对运动和姿态控制，但轴向定义有所不同。LVLH在卫星姿态控制、对地观测等应用中使用更为广泛。

## 定义

### 轴向定义

LVLH坐标系的定义如下：

| 轴 | 名称 | 方向 |
|----|------|------|
| Z轴 | 垂线向（Local Vertical） | 指向地心（向下） |
| X轴 | 水平向（Local Horizontal） | 垂直于Z轴，指向运动方向 |
| Y轴 | 轨道法向（Cross-Track） | 垂直于ZX平面 |

### 几何解释

```
            Y (正法向)
             ↑
             |
             |
    ● ←——————————→ X (水平向，速度方向)
   /
  /
 ↓
 Z (垂向，指向地心)

      地心
```

### 与VVLH的比较

| 特性 | LVLH | VVLH |
|------|------|------|
| 第一轴 | Z轴指向地心 | X轴指向地心 |
| 第二轴 | X轴沿速度方向 | Y轴沿速度方向 |
| 第三轴 | Y轴为法向 | Z轴为法向 |

**主要区别**：VVLH和LVLH的轴向定义互换了径向和法向轴的位置。

### 数学定义

假设航天器在地心惯性坐标系中的位置向量为 $\vec{r}$，速度向量为 $\vec{v}$：

$$
\begin{aligned}
\hat{Z}_{LVLH} &= -\frac{\vec{r}}{|\vec{r}|} \quad \text{（指向地心）} \\
\hat{X}_{LVLH} &= \frac{\vec{v}_\perp}{|\vec{v}_\perp|} \quad \text{（切向速度方向）} \\
\hat{Y}_{LVLH} &= \hat{Z}_{LVLH} \times \hat{X}_{LVLH} \quad \text{（轨道面正法向）}
\end{aligned}
$$

## 特点

1. **坐标系形式**：与地心地固坐标系形式一致，便于坐标转换
2. **对地观测友好**：X轴指向运动方向，便于对地观测载荷指向
3. **姿态基准**：卫星姿态控制的常用基准坐标系
4. **一致性**：与地球观测卫星的任务规划系统兼容性好

## 应用场景

| 应用领域 | 具体用途 |
|----------|----------|
| **对地观测** | 相机指向、条带扫描 |
| **姿态控制** | 姿态角定义、对日定向 |
| **卫星通信** | 天线指向地球 |
| **编队飞行** | 相对运动描述 |
| **空间环境探测** | 局部门槛测量 |

### 对地观测中的应用

卫星对地观测时，载荷坐标系通常定义为：

```
X轴：指向运动方向（顺轨）
Z轴：指向星下点（垂轨）
Y轴：垂直于轨道面（法向）
```

### 姿态控制中的典型应用

三轴稳定卫星的姿态控制模式：

- **对地定向模式**：卫星X轴指向地心，Y轴沿轨道法向
- **对日定向模式**：太阳帆板始终垂直于太阳方向
- **惯性定向模式**：姿态相对于惯性空间固定

## 在ATK中的使用

### 配置方法

在ATK中设置LVLH坐标系：

```
参考框架：LVLH
关联对象：卫星名称
```

### ATK配置示例

```python
# 创建LVLH参考框架
lvlh_frame = sat.ReferenceFrame.Create("LVLH_Frame")
lvlh_frame.Type = "LVLH"
lvlh_frame.Origin = "Satellite"

# 获取LVLH坐标系下的姿态
att_lvlh = sat.Attitude(LVLH)

# 定义相对运动
sat2.Locator = [0, 1.0, 0] @ LVLH(Sat1)  # 在主星顺轨方向1km
```

### 典型应用场景配置

| 场景 | 推荐坐标系 | 说明 |
|------|------------|------|
| 对地成像 | LVLH | 与地面轨迹对齐 |
| 轨道控制 | VVLH | 与速度矢量对齐 |
| 编队飞行 | VVLH/LVLH | 根据具体分析选择 |

## 坐标转换

### LVLH到ECI的转换

给定LVLH坐标系中的位置 $(x_l, y_l, z_l)$：

$$
\vec{r}_{ECI} = \vec{r}_{sat} + R_{LVLH\to ECI} \cdot \begin{pmatrix} x_l \\ y_l \\ z_l \end{pmatrix}
$$

其中 $R_{LVLH\to ECI}$ 是从LVLH到ECI的旋转矩阵。

## 注意事项

1. **轨道依赖**：LVLH坐标系完全依赖于轨道位置
2. **长时间累积**：绕轨道一圈，X轴会旋转360°
3. **极轨道问题**：极轨道附近坐标系变化剧烈
4. **与VVLH选择**：根据具体应用选择合适的坐标系
