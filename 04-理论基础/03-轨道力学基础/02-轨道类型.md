# 轨道类型

## 概述

根据轨道高度、倾角、偏心率等参数，卫星轨道可分为多种类型。不同类型的轨道具有不同的特点和应用场景，理解这些轨道类型对于卫星任务设计至关重要。

## 按高度分类

### 低地球轨道（LEO）

| 参数 | 典型值 |
|------|--------|
| 高度范围 | 200 - 2000 km |
| 周期 | 90 - 120 分钟 |
| 速度 | 7.8 - 6.9 km/s |

**特点**：
- 轨道周期短，重访时间快
- 大气阻力显著，需轨道维持
- 通信延迟小（<20 ms）
- 覆盖范围有限（单星~40°仰角覆盖约3000 km）

**应用**：
- 对地观测（遥感、气象）
- 国际空间站
- 星链星座
- 军事侦察

### 中地球轨道（MEO）

| 参数 | 典型值 |
|------|--------|
| 高度范围 | 2000 - 35786 km |
| 周期 | 2 - 12 小时 |
| 速度 | 6.9 - 3.1 km/s |

**特点**：
- 介于LEO和GEO之间
- 覆盖范围较大
- 轨道维持需求较低
- GPS、GLONASS导航星座常用

**应用**：
- 卫星导航（GPS：20200 km）
- 通信增强
- 监测预警

### 地球同步轨道（GEO）

| 参数 | 典型值 |
|------|--------|
| 高度范围 | 35786 km（精确） |
| 周期 | 23小时56分（恒星时） |
| 速度 | 3.07 km/s |

**特点**：
- 与地球自转周期同步
- 相对地球表面静止
- 全球覆盖（三颗即可）
- 通信延迟中等（~250 ms）

**应用**：
- 通信卫星
- 气象卫星（风云二号/四号）
- 电视广播
- 数据中继

### 高地球轨道（HEO）

| 参数 | 典型值 |
|------|--------|
| 高度范围 | > 35786 km |
| 周期 | > 24 小时 |
| 轨道形状 | 椭圆 |

**特点**：
- 偏心率大，远地点和近地点差异显著
- 可覆盖高纬度地区
- 轨道维持复杂

**应用**：
- 闪电轨道（MOLNIYA）
- 准地球同步轨道
- 深空通信

## 按倾角分类

### 赤道轨道

| 倾角 | 说明 |
|------|------|
| $i = 0°$ | 与赤道面重合 |
| $i = 180°$ | 与赤道面重合（逆向） |

**特点**：
- 星下点轨迹在赤道上
- 高纬度覆盖差

### 极轨道

| 倾角 | 说明 |
|------|------|
| $i = 90°$ | 垂直于赤道面 |

**特点**：
- 全球覆盖
- 星下点轨迹覆盖所有纬度
- 气象、遥感卫星常用

### 临界倾角轨道

| 倾角 | 说明 |
|------|------|
| $i \approx 63.4°$ | 无升交点漂移 |

**特点**：
- J2摄动引起的升交点漂移为零
- 轨道面相对地球稳定

## 特殊轨道类型

### 太阳同步轨道（SSO）

| 参数 | 典型值 |
|------|--------|
| 倾角范围 | 97° - 99° |
| 高度范围 | 500 - 1500 km |
| 特点 | 地方时不变 |

**特点**：
- 轨道面相对于太阳方向固定
- 卫星每天在同一地方时经过同一纬度
- 适合光学遥感

### 回归轨道

| 参数 | 说明 |
|------|------|
| 回归周期 | N天重复 |
| 特点 | 星下点轨迹重复 |

**特点**：
- 定期重访固定地点
- 便于多星编队
- 遥感卫星常用

### 冻结轨道

| 参数 | 说明 |
|------|------|
| 偏心率 | ~0.001 |
| 近地点幅角 | 90°或270° |
| 特点 | 保持偏心率冻结 |

**特点**：
- 补偿J2摄动的影响
- 轨道参数保持稳定
- 导航卫星常用

### 拉格朗日点轨道

| 点位 | 说明 |
|------|------|
| L1 | 日地连线内侧 |
| L2 | 日地连线外侧 |
| L3 | 太阳另一侧 |
| L4 | 地球轨道前60° |
| L5 | 地球轨道后60° |

**特点**：
- 周期与地球相同
- 燃料消耗低
- 需偏差控制

**应用**：
- L1：太阳观测（SOHO）
- L2：深空观测（JWST）
- L4/L5：未来预警系统

### 闪电轨道（MOLNIYA）

| 参数 | 典型值 |
|------|--------|
| 倾角 | 63.4° |
| 偏心率 | ~0.7 |
| 周期 | 12小时 |
| 远地点高度 | ~40000 km |

**特点**：
- 高纬度地区停留时间长
- 苏联/俄罗斯通信和预警常用

## 轨道比较

| 类型 | 高度 | 周期 | 覆盖 | 延迟 | 典型应用 |
|------|------|------|------|------|----------|
| LEO | 400-2000 km | 90-120 min | ~3000 km | <20 ms | 对地观测 |
| MEO | 2000-20000 km | 2-12 h | ~10000 km | ~100 ms | 导航 |
| GEO | 35786 km | 24 h | ~1/3地球 | ~250 ms | 通信 |
| HEO | 可变 | 可变 | 可变 | 可变 | 高纬覆盖 |

## 在ATK中的使用

### 创建标准轨道

```python
# LEO轨道
leo = sat.Orbit
leo.Type = "Keplerian"
leo.SemiMajorAxis = 6778  # km (约500 km高度)
leo.Eccentricity = 0
leo.Inclination = 97.5

# GEO轨道
geo = sat.Orbit
geo.Type = "Keplerian"
geo.SemiMajorAxis = 42164  # km
geo.Eccentricity = 0
geo.Inclination = 0

# 太阳同步轨道
sso = sat.Orbit
sso.Type = "SunSynchronous"
sso.Altitude = 800  # km
sso.LTAN = "10:30"  # 地方时
```

### 特殊轨道

```python
# 冻结轨道
frozen = sat.Orbit
frozen.Type = "Frozen"
frozen.SemiMajorAxis = 26558  # km
frozen.Inclination = 63.4

# 拉格朗日点轨道
lpoint = sat.Orbit
lpoint.Type = "Lagrangian"
lpoint.Point = "L2"
lpoint.Trail = 0  # km，偏移距离
```

## 注意事项

1. **轨道高度选择**：需权衡覆盖范围、通信延迟、大气阻力
2. **倾角选择**：需考虑服务区域纬度
3. **多星组网**：需选择相互兼容的轨道构型
4. **轨道寿命**：大气阻力影响低轨卫星寿命
