# 轨道摄动

## 概述

轨道摄动是指卫星在轨道运动中受到的除中心天体引力以外的其他力作用。摄动导致卫星轨道偏离理想的开普勒轨道，研究和精确计算各种摄动对于轨道确定和轨道预报至关重要。

## 摄动来源分类

### 自然摄动

| 摄动类型 | 来源 | 量级（LEO） | 量级（GEO） |
|----------|------|-------------|-------------|
| J2摄动 | 地球非球形 | 10⁻³ km/s² | 10⁻⁶ km/s² |
| 大气阻力 | 大气残余 | 10⁻⁷ km/s² | 可忽略 |
| 太阳光压 | 太阳辐射 | 10⁻⁸ km/s² | 10⁻⁶ km/s² |
| 月球引力 | 月球 | 10⁻⁶ km/s² | 10⁻⁵ km/s² |
| 太阳引力 | 太阳 | 10⁻⁷ km/s² | 10⁻⁶ km/s² |

### 人为摄动

| 摄动类型 | 来源 | 量级 |
|----------|------|------|

## 地球非球形摄动

### J2摄动

地球非球形的主要摄动来源是J2项（二阶带谐系数）：

$$
V_{J2} = -\frac{GMm}{r^3} J_2 R_E^2 \left(\frac{3}{2}\sin^2\phi - \frac{1}{2}\right)
$$

其中：
- $J_2 = 1.08263 \times 10^{-3}$
- $R_E = 6378.137$ km（地球赤道半径）
- $\phi$ 为纬度

### J2引起的长期变化

长半轴变化（无）：

$$
\dot{a} = 0
$$

偏心率变化：

$$
\dot{e} = 0
$$

升交点赤经变化：

$$
\dot{\Omega} = -\frac{3}{2} J_2 n \left(\frac{R_E}{a}\right)^2 \cos i
$$

近地点幅角变化：

$$
\dot{\omega} = \frac{3}{4} J_2 n \left(\frac{R_E}{a}\right)^2 (5\cos^2 i - 1)
$$

### J3、J4摄动

高阶带谐系数：

| 系数 | 值 | 主要影响 |
|------|-----|----------|
| J2 | 1.08263×10⁻³ | 升交点进动、近地点幅角变化 |
| J3 | -2.54×10⁻⁶ | 轨道面不对称 |
| J4 | -1.61×10⁻⁶ | 扁率修正 |

## 大气阻力

### 大气密度模型

大气密度随高度指数衰减：

$$
\rho(h) = \rho_0 e^{-(h-h_0)/H}
$$

其中 $H$ 为标高，约5-10 km（取决于温度）。

### 阻力加速度

$$
\vec{a}_D = -\frac{1}{2} \rho \frac{C_D A}{m} v_{rel}^2 \hat{v}_{rel}
$$

其中：
- $\rho$：大气密度
- $C_D$：阻力系数（约2.2）
- $A/m$：面积质量比
- $v_{rel}$：相对大气速度

### 大气阻力效应

- 轨道衰减：高度持续降低
- 周期缩短
- 近地点高度下降快于远地点

## 太阳光压

### 光压强度

太阳常数在日心距离为1 AU时：

$$
P = \frac{L_\odot}{4\pi c r^2} \approx 4.57 \times 10^{-6} \text{ N/m}^2
$$

### 光压加速度

$$
\vec{a}_{SRP} = -\nu P \frac{C_R A}{m} \hat{S}
$$

其中：
- $\nu$：阴影因子（0-1）
- $C_R$：反射系数（1-1.4）
- $\hat{S}$：太阳方向单位矢量

### 阴影模型

| 模型 | 说明 |
|------|------|
| 圆锥阴影 | 简化圆柱/圆锥 |
| 双圆锥 | 更精确的阴影边界 |
| 数值阴影 | 精确考虑地球遮挡 |

## 第三体引力

### 月球引力

月球引力加速度量级：

$$
a_{Moon} \approx 4.7 \times 10^{-6} \times \frac{M_{sat}}{M_{Moon}} \times \left(\frac{r}{r_{Moon}}\right)^2
$$

### 太阳引力

太阳引力加速度量级：

$$
a_{Sun} \approx 0.6 \times 10^{-6} \times \left(\frac{r}{1 AU}\right)^2
$$

### 第三体效应

- 长期效应：轨道参数周期性变化
- 共振效应：与太阳/月球轨道周期相关
- GEO卫星：需考虑太阳/月球引力

## 潮汐摄动

### 固体潮

地球固体部分对卫星的引力：

$$
\dot{a} \propto k_2 \left(\frac{R_E}{r}\right)^5
$$

其中 $k_2 \approx 0.3$ 为 Love数。

### 海洋潮

海洋潮汐引起的附加引力：

| 分潮 | 周期 | 主要影响 |
|------|------|----------|
| M2 | 12.42 h | 升交点漂移 |
| S2 | 12.00 h | 周期变化 |
| O1 | 25.82 h | 轨道共振 |

## 在ATK中的配置

### 摄动模型选择

```python
# 二体运动（无摄动）
sat.Propagator.Type = "TwoBody"
sat.Propagator.PointMass = True

# J2摄动
sat.Propagator.PointMass = True
sat.Propagator.J2 = True
sat.Propagator.J2Order = 4  # J2-J4

# HPOP高精度
sat.Propagator.Type = "HPOP"
sat.Propagator.GravityOrder = 20  # 重力场阶数
sat.Propagator.Drag = True
sat.Propagator.SolarPressure = True
sat.Propagator.ThirdBody = ["Moon", "Sun"]
```

### 详细配置

```python
# 大气阻力配置
sat.Drag.Model = "NRLMSISE-00"
sat.Drag.CD = 2.2
sat.Drag.AreaMassRatio = 0.01

# 太阳光压配置
sat.SolarPressure.Model = "Spherical"
sat.SolarPressure.CR = 1.3
sat.SolarPressure.Area = 10  # m²

# 第三体配置
sat.ThirdBody.Moon = True
sat.ThirdBody.Sun = True
sat.ThirdBody.Ephemeris = "DE430"
```

## 注意事项

1. **模型精度**：不同任务需选择适当精度的摄动模型
2. **轨道类型**：GEO主要考虑J2和第三体；LEO主要考虑大气阻力
3. **积分方法**：高精度需使用数值积分方法
4. **实时更新**：大气模型需实时获取太阳活动指数
