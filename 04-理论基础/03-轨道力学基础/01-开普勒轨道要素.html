开普勒轨道要素

概述

开普勒轨道要素（Keplerian Orbital Elements）是描述卫星轨道状态的标准参数集。六要素完全定义了卫星在惯性空间中的轨道位置和运动状态，是轨道力学中最基本、最重要的概念。

六要素定义

开普勒轨道要素包括六个参数，可以分为两类：形状参数和定向参数。

形状参数

参数符号单位说明
半长轴akm轨道椭圆长半轴
偏心率e无量纲轨道椭圆扁平程度

定向参数

参数符号单位说明
轨道倾角ideg轨道平面与赤道面夹角
升交点赤经Ωdeg升交点相对春分点角度
近地点幅角ωdeg近地点到升交点角度
真近点角νdeg卫星当前位置与近地点夹角

各参数详解

半长轴（a）

轨道椭圆长半轴，决定轨道大小：

  • 圆形轨道：r=a
  • 椭圆轨道：r=a(1−e2)/(1+ecos⁡ν)
  • 平均半径：r¯=a

半长轴与轨道周期的关系（开普勒第三定律）：

(1)T=2πa3μ

其中 μ=GM≈398600.4418 km³/s² 为地球引力常数。

偏心率（e）

轨道椭圆的偏心程度：

轨道类型偏心率
圆轨道e=0
近圆轨道0<e<0.1
椭圆轨道0.1≤e<1

近地点和远地点距离：

(2)rp=a(1−e)（近地点）ra=a(1+e)（远地点）

轨道倾角（i）

轨道平面与地球赤道面的夹角：

轨道类型倾角范围
赤道轨道i=0° 或 i=180°
极轨道i=90°
顺行轨道0°<i<90°
逆行轨道90°<i<180°

升交点赤经（Ω）

升交点（卫星从南向北穿过赤道的点）相对于春分点的经度：

  • 范围：0°≤Ω<360°
  • 顺行轨道：Ω 向东增加
  • 逆行轨道：Ω 向西增加

近地点幅角（ω）

近地点相对于升交点的角度：

  • 范围：0°≤ω<360°
  • ω=0°：近地点在升交点
  • ω=90°：近地点在北极方向
  • ω=180°：近地点在降交点

真近点角（ν）

卫星当前位置与近地点的连线相对于近地点方向的角度：

  • 范围：0°≤ν<360°
  • ν=0°：卫星在近地点
  • ν=180°：卫星在远地点

轨道六面体

六个开普勒要素确定了轨道在惯性空间中的完整定向：

           ★ 春分点
            |
            |
   Ω ----→ ★------------→ X轴
           |
           |\
           | \
           |  \ 轨道平面
           |   \
           |    \
           |     ●--------→ 升交点方向
           |    /
           |   /
           |  /
           | /
           |/
          ★
         近地点

计算公式

位置计算

在轨道坐标系中：

(3)r=a(1−e2)1+ecos⁡νx=rcos⁡νy=rsin⁡ν

转换到惯性坐标系：

(4)(XYZ)=Rz(−Ω)⋅Rx(−i)⋅Rz(−ω)⋅(xyz)

速度计算

真近点角对应的速度大小：

(5)v=μ(2r−1a)

速度分量：

(6)r˙=μa(1−e2)esin⁡νν˙=μa3(1−e2)3(1+ecos⁡ν)2

辅助参数

平近点角（M）

(7)M=n(t−τ)=E−esin⁡E

其中 n=2π/T 是平均角速度，E 是偏近点角，τ 是过近地点时间。

偏近点角（E）

与真近点角的关系：

(8)tan⁡ν2=1+e1−etan⁡E2

在ATK中的使用

配置方法

# 设置开普勒轨道要素
sat.Orbit.Type = "Keplerian"
sat.Orbit.Elements.SemiMajorAxis = 7153.2  # km
sat.Orbit.Elements.Eccentricity = 0.0001
sat.Orbit.Elements.Inclination = 97.5  # deg
sat.Orbit.Elements.RAAN = 250.0  # deg
sat.Orbit.Elements.ArgOfPerapsis = 90.0  # deg
sat.Orbit.Elements.TrueAnomaly = 45.0  # deg

从六面体创建

kep = KeplerianElements(
    SemiMajorAxis=7153.2,
    Eccentricity=0.0001,
    Inclination=97.5,
    RAAN=250.0,
    ArgOfPerapsis=90.0,
    TrueAnomaly=45.0
)
sat.Orbit.SetElements(kep)

输出开普勒要素

# 获取当前时刻的开普勒要素
kep_elements = sat.Orbit.GetElements()
print(f"半长轴: {kep_elements.SemiMajorAxis} km")
print(f"偏心率: {kep_elements.Eccentricity}")
print(f"倾角: {kep_elements.Inclination} deg")

注意事项

  1. 近圆轨道：e<0.001 时近地点定义可能不明确
  2. 赤道轨道：i≈0 时升交点位置不确定
  3. 极轨道：Ω 的变化不影响轨道形状
  4. 圆轨道：e=0 时近地点位置无意义
