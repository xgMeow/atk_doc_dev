# 轨道预报模型

## 概述

轨道预报模型是用于计算卫星在未来时刻位置和速度的数学模型。不同精度和复杂度的模型适用于不同的应用场景，从简单的二体运动到高精度的数值积分模型，需要根据任务需求选择合适的模型。

## 模型分类

| 模型类型 | 精度 | 计算速度 | 适用场景 |
|----------|------|----------|----------|
| 二体模型 | 低 | 快 | 概念设计 |
| J2模型 | 中 | 快 | 初轨计算 |
| SGP4/SDP4 | 中-高 | 快 | TLE预报 |
| HPOP | 高 | 慢 | 精密预报 |

## 二体运动模型

### 基本方程

在只考虑中心天体引力的情况下，卫星运动满足二体运动方程：

$$
\ddot{\vec{r}} = -\frac{\mu}{r^3}\vec{r}
$$

### 解析解

对于理想二体运动，轨道参数保持不变：

- 半长轴 $a$：恒定
- 偏心率 $e$：恒定
- 角动量 $\vec{h}$：恒定

### 适用范围

- 概念设计阶段
- 粗略轨道计算
- 初步任务分析

## J2-J4摄动模型

### 模型方程

$$
\ddot{\vec{r}} = -\frac{\mu}{r^3}\vec{r} + \vec{a}_{J2} + \vec{a}_{J3} + \vec{a}_{J4}
$$

### J2摄动加速度

$$
\vec{a}_{J2} = \frac{3}{2} J_2 \mu \frac{R_E^2}{r^5} \begin{pmatrix} x(5z^2/r^2 - 1) \\ y(5z^2/r^2 - 1) \\ z(5z^2/r^2 - 3) \end{pmatrix}
$$

### J2长期效应

| 参数 | 变化率公式 |
|------|------------|
| $\dot{\Omega}$ | $-\frac{3}{2} J_2 n \left(\frac{R_E}{a}\right)^2 \cos i$ |
| $\dot{\omega}$ | $\frac{3}{4} J_2 n \left(\frac{R_E}{a}\right)^2 (5\cos^2 i - 1)$ |

### 适用范围

- 初轨计算
- 轨道维持分析
- 中等精度需求

## SGP4/SDP4模型

### 模型概述

SGP4（Simplified General Perturbations）和SDP4（Simplified Deep-space Perturbations）是美国空军开发的轨道预报模型，专门用于处理TLE（Two-Line Element）格式的轨道数据。

### SGP4与SDP4的区别

| 模型 | 适用轨道 | 周期 |
|------|----------|------|
| SGP4 | 近地轨道（周期 < 225 min） | 短周期 |
| SDP4 | 深空轨道（周期 ≥ 225 min） | 长周期 |

### 模型精度

- 短期精度（1-3天）：~1 km
- 中期精度（1-2周）：~10 km
- 长期精度（数周）：数十公里

### TLE输入参数

```python
# TLE格式
tle_line1 = "1 25544U 98067A   24015.50000000  .00016744  00000-0  30000-3 0  9002"
tle_line2 = "2 25544  51.6400 250.0000 0006700  80.0000 280.0000 15.50000000350000"

# ATK导入TLE
sat.Orbit.Source = "TLE"
sat.Orbit.TLE = tle_line1 + "\n" + tle_line2
```

## HPOP高精度轨道预报

### 模型概述

HPOP（High Precision Orbit Propagator）使用数值积分方法，综合考虑多种摄动力，提供最高精度的轨道预报。

### 考虑的主要摄动

| 摄动类型 | 模型 | 说明 |
|----------|------|------|
| 地球引力 | EGM96/EGM2008 | 球谐系数展开 |
| 大气阻力 | NRLMSISE-00 | 大气密度模型 |
| 太阳光压 | 球形/面板模型 | 考虑地影 |
| 第三体 | DE星历 | 月球、太阳 |
| 潮汐 | IERS | 固体潮、海洋潮 |

### 积分方法

| 方法 | 精度 | 速度 |
|------|------|------|
| RK4 | 中 | 快 |
| RKF78 | 高 | 中 |
| Adams | 高 | 快 |
| PECE | 高 | 快 |

### 配置示例

```python
# HPOP配置
sat.Propagator.Type = "HPOP"
sat.Propagator.StepSize = 60  # 秒
sat.Propagator.EphemerisTimeStep = 60  # 输出步长

# 重力场模型
sat.Gravity.Type = "EGM2008"
sat.Gravity.Order = 70  # 球谐阶数
sat.Gravity.Degree = 70

# 大气阻力
sat.Drag.Type = "NRLMSISE-00"
sat.Drag.SolarFlux = 150  # F10.7指数
sat.Drag.Geomagnetic = "WMM"  # 地磁指数

# 太阳光压
sat.SolarPressure.Type = "Cannonball"
sat.SolarPressure.CR = 1.3
sat.SolarPressure.Area = 20  # m²

# 第三体
sat.ThirdBody.Moon = True
sat.ThirdBody.Sun = True
sat.ThirdBody.Ephemeris = "DE430"
```

## 模型比较

| 特性 | 二体 | J2-J4 | SGP4 | HPOP |
|------|------|-------|------|------|
| 计算速度 | 最快 | 快 | 快 | 慢 |
| 精度 | 最低 | 中 | 中-高 | 最高 |
| 内存需求 | 低 | 低 | 低 | 高 |
| 大气阻力 | 无 | 无 | 有 | 有 |
| 第三体 | 无 | 无 | 有 | 有 |
| TLE兼容 | 否 | 否 | 是 | 否 |

## 在ATK中的使用

### 基本配置

```python
# 选择轨道预报模型
sat.Propagator.Type = "HPOP"

# 设置积分参数
sat.Propagator.MaxStep = 300
sat.Propagator.InitialStep = 1
sat.Propagator.AccTol = 1e-10
sat.Propagator.RelTol = 1e-10

# 运行仿真
mission.Start()
```

### 批量仿真

```python
# 长时间预报
mission.Duration = "30 days"
mission.Propagator = "HPOP"

# 生成星历
ephemeris = sat.Orbit.GenerateEphemeris("30d.pt", Format="SPK")
```

## 注意事项

1. **计算资源**：HPOP计算量大，需考虑硬件性能
2. **TLE有效期**：SGP4模型精度随时间降低
3. **摄动选择**：根据任务精度要求选择适当摄动
4. **积分稳定性**：步长选择影响计算稳定性和精度
