四元数

概述

四元数（Quaternion）是描述三维旋转的数学工具，由William Rowan Hamilton于1843年提出。四元数在航天器姿态控制、计算机图形学、机器人等领域广泛使用，是欧拉角的理想替代方案。

数学定义

四元数表示

四元数由一个标量分量和三个矢量分量组成：

(1)q=[q0,q1,q2,q3]=[q0,q→]

其中：

  • q0：标量部分
  • q→=[q1,q2,q3]：矢量部分

四元数乘法

两个四元数的乘积：

(2)q1⊗q2=[q10q20−q→1⋅q→2q10q→2+q20q→1+q→1×q→2]

单位四元数

用于表示旋转的四元数必须归一化：

(3)|q|=q02+q12+q22+q32=1

与旋转矩阵的转换

四元数到旋转矩阵

(4)C=[1−2(q22+q32)2(q1q2−q0q3)2(q1q3+q0q2)2(q1q2+q0q3)1−2(q12+q32)2(q2q3−q0q1)2(q1q3−q0q2)2(q2q3+q0q1)1−2(q12+q22)]

旋转矩阵到四元数

从旋转矩阵提取四元数：

(5)q0=121+c11+c22+c33q1=c32−c234q0q2=c13−c314q0q3=c21−c124q0

与欧拉角的转换

Z-Y-X欧拉角到四元数

给定偏航(ψ)、俯仰(θ)、滚转(φ)：

(6)q0=cos⁡ϕ2cos⁡θ2cos⁡ψ2+sin⁡ϕ2sin⁡θ2sin⁡ψ2q1=sin⁡ϕ2cos⁡θ2cos⁡ψ2−cos⁡ϕ2sin⁡θ2sin⁡ψ2q2=cos⁡ϕ2sin⁡θ2cos⁡ψ2+sin⁡ϕ2cos⁡θ2sin⁡ψ2q3=cos⁡ϕ2cos⁡θ2sin⁡ψ2−sin⁡ϕ2sin⁡θ2cos⁡ψ2

四元数的优点

特性说明
无奇异性全姿态表示，无万向锁
计算效率乘法比矩阵乘法更快
数值稳定归一化简单
插值方便Slerp插值自然
存储紧凑4个参数 vs 9个矩阵元素

共轭与逆

共轭四元数

(7)q∗=[q0,−q1,−q2,−q3]

逆四元数

对于单位四元数：

(8)q−1=q∗=q∗|q|

旋转连续

连续旋转：

(9)Cfinal=C(v→)=C(qfinal⊗qinitial)

姿态运动学

四元数微分方程

(10)q˙=12q⊗ω

其中 ω=[0,ωx,ωy,ωz] 是角速度四元数。

展开形式

(11)q˙0=−12(q1ωx+q2ωy+q3ωz)q˙1=12(q0ωx+q2ωz−q3ωy)q˙2=12(q0ωy+q3ωx−q1ωz)q˙3=12(q0ωz+q1ωy−q2ωx)

在ATK中的使用

配置方法

# 设置四元数姿态
sat.Attitude.Type = "Quaternion"
sat.Attitude.Quaternion = [0.966, 0.259, 0, 0]  # [q0, q1, q2, q3]

# 或使用标量-矢量格式
q = Quaternion(scalar=0.966, vector=[0.259, 0, 0])
sat.Attitude.Quaternion = q

从欧拉角创建四元数

# 欧拉角转四元数
from Attitude import Quaternion
q = Quaternion.FromEulerAngles(yaw=45, pitch=30, roll=15, order="ZYX")
sat.Attitude.Quaternion = q

获取当前姿态

# 获取四元数
q = sat.Attitude.GetQuaternion()
print(f"q0: {q.scalar:.6f}")
print(f"qv: [{q.vector[0]:.6f}, {q.vector[1]:.6f}, {q.vector[2]:.6f}]")

# 获取旋转矩阵
C = q.To DCM()
print(f"C = \n{C}")

# 获取欧拉角
euler = q.ToEulerAngles(order="ZYX")
print(f"Yaw: {euler[0]:.2f} deg")

四元数插值

# Slerp插值
from Attitude import Quaternion, Slerp
q1 = Quaternion(scalar=1, vector=[0, 0, 0])
q2 = Quaternion(scalar=0.966, vector=[0.259, 0, 0])
q_interp = Slerp(q1, q2, t=0.5)  # t从0到1

姿态轨迹生成

# 姿态传播
mission.AttitudeStep = 60  # 秒
mission.Propagate()

# 导出四元数数据
attitude_data = sat.Attitude.ToDataFrame()
print(attitude_data[['Time', 'Q0', 'Q1', 'Q2', 'Q3']])

注意事项

  1. 归一化：四元数必须保持单位长度
  2. 双覆盖：q 和 −q 表示同一姿态
  3. 插值方法：使用Slerp而非线性插值
  4. 数值精度：长期积分需定期归一化
  5. 坐标系定义：确保旋转方向定义一致
