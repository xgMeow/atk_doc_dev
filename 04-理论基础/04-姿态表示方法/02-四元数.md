# 四元数

## 概述

四元数（Quaternion）是描述三维旋转的数学工具，由William Rowan Hamilton于1843年提出。四元数在航天器姿态控制、计算机图形学、机器人等领域广泛使用，是欧拉角的理想替代方案。

## 数学定义

### 四元数表示

四元数由一个标量分量和三个矢量分量组成：

$$
q = [q_0, q_1, q_2, q_3] = [q_0, \vec{q}]
$$

其中：
- $q_0$：标量部分
- $\vec{q} = [q_1, q_2, q_3]$：矢量部分

### 四元数乘法

两个四元数的乘积：

$$
q_1 \otimes q_2 = \begin{bmatrix}
q_1^0 q_2^0 - \vec{q}_1 \cdot \vec{q}_2 \\
q_1^0 \vec{q}_2 + q_2^0 \vec{q}_1 + \vec{q}_1 \times \vec{q}_2
\end{bmatrix}
$$

### 单位四元数

用于表示旋转的四元数必须归一化：

$$
|q| = \sqrt{q_0^2 + q_1^2 + q_2^2 + q_3^2} = 1
$$

## 与旋转矩阵的转换

### 四元数到旋转矩阵

$$
C = \begin{bmatrix}
1-2(q_2^2+q_3^2) & 2(q_1q_2-q_0q_3) & 2(q_1q_3+q_0q_2) \\
2(q_1q_2+q_0q_3) & 1-2(q_1^2+q_3^2) & 2(q_2q_3-q_0q_1) \\
2(q_1q_3-q_0q_2) & 2(q_2q_3+q_0q_1) & 1-2(q_1^2+q_2^2)
\end{bmatrix}
$$

### 旋转矩阵到四元数

从旋转矩阵提取四元数：

$$
\begin{aligned}
q_0 &= \frac{1}{2}\sqrt{1 + c_{11} + c_{22} + c_{33}} \\
q_1 &= \frac{c_{32} - c_{23}}{4q_0} \\
q_2 &= \frac{c_{13} - c_{31}}{4q_0} \\
q_3 &= \frac{c_{21} - c_{12}}{4q_0}
\end{aligned}
$$

## 与欧拉角的转换

### Z-Y-X欧拉角到四元数

给定偏航(ψ)、俯仰(θ)、滚转(φ)：

$$
\begin{aligned}
q_0 &= \cos\frac{\phi}{2}\cos\frac{\theta}{2}\cos\frac{\psi}{2} + \sin\frac{\phi}{2}\sin\frac{\theta}{2}\sin\frac{\psi}{2} \\
q_1 &= \sin\frac{\phi}{2}\cos\frac{\theta}{2}\cos\frac{\psi}{2} - \cos\frac{\phi}{2}\sin\frac{\theta}{2}\sin\frac{\psi}{2} \\
q_2 &= \cos\frac{\phi}{2}\sin\frac{\theta}{2}\cos\frac{\psi}{2} + \sin\frac{\phi}{2}\cos\frac{\theta}{2}\sin\frac{\psi}{2} \\
q_3 &= \cos\frac{\phi}{2}\cos\frac{\theta}{2}\sin\frac{\psi}{2} - \sin\frac{\phi}{2}\sin\frac{\theta}{2}\cos\frac{\psi}{2}
\end{aligned}
$$

## 四元数的优点

| 特性 | 说明 |
|------|------|
| 无奇异性 | 全姿态表示，无万向锁 |
| 计算效率 | 乘法比矩阵乘法更快 |
| 数值稳定 | 归一化简单 |
| 插值方便 | Slerp插值自然 |
| 存储紧凑 | 4个参数 vs 9个矩阵元素 |

## 共轭与逆

### 共轭四元数

$$
q^* = [q_0, -q_1, -q_2, -q_3]
$$

### 逆四元数

对于单位四元数：

$$
q^{-1} = q^* = \frac{q^*}{|q|}
$$

### 旋转连续

连续旋转：

$$
C_{final} = C(\vec{v}) = C(q_{final} \otimes q_{initial})
$$

## 姿态运动学

### 四元数微分方程

$$
\dot{q} = \frac{1}{2} q \otimes \omega
$$

其中 $\omega = [0, \omega_x, \omega_y, \omega_z]$ 是角速度四元数。

### 展开形式

$$
\begin{aligned}
\dot{q}_0 &= -\frac{1}{2}(q_1\omega_x + q_2\omega_y + q_3\omega_z) \\
\dot{q}_1 &= \frac{1}{2}(q_0\omega_x + q_2\omega_z - q_3\omega_y) \\
\dot{q}_2 &= \frac{1}{2}(q_0\omega_y + q_3\omega_x - q_1\omega_z) \\
\dot{q}_3 &= \frac{1}{2}(q_0\omega_z + q_1\omega_y - q_2\omega_x)
\end{aligned}
$$

## 在ATK中的使用

### 配置方法

```python
# 设置四元数姿态
sat.Attitude.Type = "Quaternion"
sat.Attitude.Quaternion = [0.966, 0.259, 0, 0]  # [q0, q1, q2, q3]

# 或使用标量-矢量格式
q = Quaternion(scalar=0.966, vector=[0.259, 0, 0])
sat.Attitude.Quaternion = q
```

### 从欧拉角创建四元数

```python
# 欧拉角转四元数
from Attitude import Quaternion
q = Quaternion.FromEulerAngles(yaw=45, pitch=30, roll=15, order="ZYX")
sat.Attitude.Quaternion = q
```

### 获取当前姿态

```python
# 获取四元数
q = sat.Attitude.GetQuaternion()
print(f"q0: {q.scalar:.6f}")
print(f"qv: [{q.vector[0]:.6f}, {q.vector[1]:.6f}, {q.vector[2]:.6f}]")

# 获取旋转矩阵
C = q.To DCM()
print(f"C = \n{C}")

# 获取欧拉角
euler = q.ToEulerAngles(order="ZYX")
print(f"Yaw: {euler[0]:.2f} deg")
```

### 四元数插值

```python
# Slerp插值
from Attitude import Quaternion, Slerp
q1 = Quaternion(scalar=1, vector=[0, 0, 0])
q2 = Quaternion(scalar=0.966, vector=[0.259, 0, 0])
q_interp = Slerp(q1, q2, t=0.5)  # t从0到1
```

### 姿态轨迹生成

```python
# 姿态传播
mission.AttitudeStep = 60  # 秒
mission.Propagate()

# 导出四元数数据
attitude_data = sat.Attitude.ToDataFrame()
print(attitude_data[['Time', 'Q0', 'Q1', 'Q2', 'Q3']])
```

## 注意事项

1. **归一化**：四元数必须保持单位长度
2. **双覆盖**：$q$ 和 $-q$ 表示同一姿态
3. **插值方法**：使用Slerp而非线性插值
4. **数值精度**：长期积分需定期归一化
5. **坐标系定义**：确保旋转方向定义一致
