# 姿态插值与微分

## 概述

姿态插值和微分是姿态数据处理的关键技术。插值用于生成平滑的姿态轨迹，微分用于从姿态角速度计算姿态变化。正确使用这些技术对于姿态仿真、数据处理和控制律设计至关重要。

## 姿态插值

### 线性插值的问题

对欧拉角直接线性插值（LERP）可能导致：

- 旋转路径不唯一
- 在万向锁附近产生奇异性
- 姿态跳变

### 四元数球面线性插值（Slerp）

#### 公式

对于单位四元数 $q_1$ 和 $q_2$：

$$
q(t) = \frac{\sin((1-t)\Omega)}{\sin\Omega} q_1 + \frac{\sin(t\Omega)}{\sin\Omega} q_2
$$

其中：

$$
\cos\Omega = q_1 \cdot q_2 = q_1^0 q_2^0 + \vec{q}_1 \cdot \vec{q}_2
$$

#### 注意事项

- 选择角度较小的路径（$\Omega < 90°$）
- 必要时取 $-q_2$ 代替 $q_2$

#### 实现代码

```python
def slerp(q1, q2, t):
    """球面线性插值"""
    # 确保插值角度最小
    dot = q1[0]*q2[0] + q1[1]*q2[1] + q1[2]*q2[2] + q1[3]*q2[3]
    if dot < 0:
        q2 = [-q2[i] for i in range(4)]
        dot = -dot
    
    if dot > 0.9995:
        # 线性近似
        q = [q1[i] + t*(q2[i]-q1[i]) for i in range(4)]
        return normalize(q)
    
    Omega = arccos(dot)
    q = [(sin((1-t)*Omega)*q1[i] + sin(t*Omega)*q2[i])/sin(Omega) for i in range(4)]
    return q
```

### Slerp的替代方案

#### Squad（四元数样条）

对于多关键帧的姿态插值：

$$
S(q_a, q_b, q_c, q_d, t) = \text{Slerp}(S(q_a, q_b, q_c, t), S(q_b, q_c, q_d, t), 2t(1-t))
$$

其中 $S(q_a, q_b, q_c, t)$ 是三次样条。

### 欧拉角插值

#### 最小角差插值

```python
def lerp_euler(e1, e2, t):
    """欧拉角线性插值（修正）"""
    delta = e2 - e1
    
    # 修正角度差到[-180, 180]
    for i in range(3):
        while delta[i] > 180:
            delta[i] -= 360
        while delta[i] < -180:
            delta[i] += 360
    
    return [e1[i] + t*delta[i] for i in range(3)]
```

## 姿态微分

### 四元数微分

#### 运动学方程

$$
\dot{q} = \frac{1}{2} \Omega \otimes q
$$

其中 $\Omega = [0, \omega_x, \omega_y, \omega_z]$ 是角速度四元数。

#### 矩阵形式

$$
\begin{pmatrix} \dot{q}_0 \\ \dot{q}_1 \\ \dot{q}_2 \\ \dot{q}_3 \end{pmatrix} = 
\frac{1}{2} \begin{bmatrix}
0 & -\omega_x & -\omega_y & -\omega_z \\
\omega_x & 0 & \omega_z & -\omega_y \\
\omega_y & -\omega_z & 0 & \omega_x \\
\omega_z & \omega_y & -\omega_x & 0
\end{bmatrix}
\begin{pmatrix} q_0 \\ q_1 \\ q_2 \\ q_3 \end{pmatrix}
$$

### DCM微分

$$
\dot{C} = [\omega_\times] C
$$

其中 $[\omega_\times]$ 是角速度的反对称矩阵：

$$
[\omega_\times] = \begin{bmatrix}
0 & -\omega_z & \omega_y \\
\omega_z & 0 & -\omega_x \\
-\omega_y & \omega_x & 0
\end{bmatrix}
$$

### 欧拉角微分

#### Z-Y-X顺序

$$
\begin{pmatrix} \dot{\phi} \\ \dot{\theta} \\ \dot{\psi} \end{pmatrix} = 
\frac{1}{\cos\theta} \begin{bmatrix}
1 & \sin\phi\tan\theta & \cos\phi\tan\theta \\
0 & \cos\phi & -\sin\phi \\
0 & \sin\phi/\cos\theta & \cos\phi/\cos\theta
\end{bmatrix}
\begin{pmatrix} \omega_x \\ \omega_y \\ \omega_z \end{pmatrix}
$$

注意：当 $\theta = \pm 90°$ 时，$\cos\theta = 0$，方程奇异。

from Attitude import Interpolator

class CustomInterpolator(Interpolator):

### 姿态微分

```python
from Attitude import Quaternion

# 从角速度计算四元数增量
def propagate_quaternion(q, omega, dt):
    """四元数积分"""
    omega_quat = [0, omega[0]*dt/2, omega[1]*dt/2, omega[2]*dt/2]
    q_dot = quaternion_multiply(omega_quat, q)
    q_new = [q[i] + q_dot[i] for i in range(4)]
    return normalize(q_new)

# 使用ATK内置积分器
integrator = sat.Attitude.CreateIntegrator()
integrator.StepSize = 0.1  # 秒
integrator.Propagate(3600)  # 传播1小时
```

## 数值积分方法

### 四阶龙格库塔（RK4）

```python
def rk4_quaternion(q, omega, dt):
    """四阶龙格库塔积分"""
    def q_dot(q):
        omega_quat = [0, omega[0]/2, omega[1]/2, omega[2]/2]
        return quaternion_multiply(omega_quat, q)
    
    k1 = q_dot(q)
    k2 = q_dot([q[i] + dt*k1[i]/2 for i in range(4)])
    k3 = q_dot([q[i] + dt*k2[i]/2 for i in range(4)])
    k4 = q_dot([q[i] + dt*k3[i] for i in range(4)])
    
    return normalize([q[i] + dt*(k1[i] + 2*k2[i] + 2*k3[i] + k4[i])/6 for i in range(4)])
```

## 注意事项

1. **归一化**：四元数积分后必须归一化
2. **奇异性**：欧拉角在特定角度奇异
3. **插值路径**：选择旋转角度较小的路径
4. **数值稳定性**：使用高阶积分方法
5. **时间同步**：确保姿态和时间数据同步
