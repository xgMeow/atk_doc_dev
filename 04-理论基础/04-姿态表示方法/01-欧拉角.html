欧拉角

概述

欧拉角（Euler Angles）是描述刚体三维旋转的经典方法，通过三次顺序旋转将两个坐标系重合。欧拉角直观易懂，在航空航天、机器人、游戏等领域广泛应用。

基本原理

旋转定义

欧拉角通过三次基本旋转实现坐标系的定向。每次旋转绕固定轴或旋转后的轴进行：

(1)C=R轴3(θ3)⋅R轴2(θ2)⋅R轴1(θ1)

旋转轴定义

轴名称旋转正方向
X轴滚转轴右手法则
Y轴俯仰轴右手法则
Z轴偏航轴右手法则

常用旋转顺序

Z-Y-X旋转（航空顺序）

绕Z轴偏航（ψ）、绕Y轴俯仰（θ）、绕X轴滚转（φ）：

(2)CZYX=Rz(ψ)⋅Ry(θ)⋅Rx(ϕ)

Z-X-Z旋转（天文顺序）

两次绕Z轴旋转，中间绕X轴旋转：

(3)CZXZ=Rz(ψ)⋅Rx(θ)⋅Rz(ϕ)

X-Y-Z旋转（欧拉角标准）

(4)CXYZ=Rx(ϕ)⋅Ry(θ)⋅Rz(ψ)

基本旋转矩阵

绕X轴旋转

(5)Rx(ϕ)=[1000cos⁡ϕsin⁡ϕ0−sin⁡ϕcos⁡ϕ]

绕Y轴旋转

(6)Ry(θ)=[cos⁡θ0−sin⁡θ010sin⁡θ0cos⁡θ]

绕Z轴旋转

(7)Rz(ψ)=[cos⁡ψsin⁡ψ0−sin⁡ψcos⁡ψ0001]

Z-Y-X旋转矩阵

完整旋转矩阵（航空顺序）：

(8)C=[cos⁡θcos⁡ψcos⁡θsin⁡ψ−sin⁡θsin⁡ϕsin⁡θcos⁡ψ−cos⁡ϕsin⁡ψsin⁡ϕsin⁡θsin⁡ψ+cos⁡ϕcos⁡ψsin⁡ϕcos⁡θcos⁡ϕsin⁡θcos⁡ψ+sin⁡ϕsin⁡ψcos⁡ϕsin⁡θsin⁡ψ−sin⁡ϕcos⁡ψcos⁡ϕcos⁡θ]

欧拉角提取

从旋转矩阵提取Z-Y-X

给定旋转矩阵 C=[cij]：

(9)ϕ=arctan⁡2(c23,c33)θ=−arcsin⁡(c13)ψ=arctan⁡2(c12,c11)

特殊情况

条件姿态解决方法
cos⁡θ=1万向锁设 ψ=0，ϕ=arctan⁡2(c21,c22)
cos⁡θ=−1万向锁设 ψ=0，ϕ=arctan⁡2(−c21,c22)

万向锁问题

问题描述

当第二次旋转角度 θ=±90° 时，第一轴和第三轴平行，导致失去一个自由度：

  • θ=+90°：Z轴和X轴重合
  • θ=−90°：Z轴和-X轴重合

数学表现

(10)C(ψ,90°,ϕ)=Rz(ψ)⋅Ry(90°)⋅Rx(ϕ)

此时 ψ+ϕ 和 ψ−ϕ 不可区分。

在ATK中的使用

配置方法

# 设置欧拉角姿态
sat.Attitude.Type = "Euler"
sat.Attitude.Style = "Yaw_Pitch_Roll"  # Z-Y-X顺序
sat.Attitude.Yaw = 45  # deg
sat.Attitude.Pitch = 30  # deg
sat.Attitude.Roll = 15  # deg

# 或使用数组
euler_angles = [45, 30, 15]  # deg, Z-Y-X
sat.Attitude.SetEulerAngles(euler_angles)

旋转顺序选项

ATK选项旋转顺序轴定义
Yaw_Pitch_RollZ-Y-X偏航-俯仰-滚转
Roll_Pitch_YawX-Y-Z滚转-俯仰-偏航
Quaternion-四元数（避免万向锁）

获取当前姿态

# 获取欧拉角
euler = sat.Attitude.GetEulerAngles(style="Yaw_Pitch_Roll")
print(f"Yaw: {euler[0]} deg")
print(f"Pitch: {euler[1]} deg")
print(f"Roll: {euler[2]} deg")

欧拉角轨迹

# 生成姿态轨迹
mission.AttitudeTimeStep = 60  # 秒
mission.Propagate()

# 导出欧拉角数据
attitude_data = sat.Attitude.ToDataFrame()
print(attitude_data[['Time', 'Yaw', 'Pitch', 'Roll']])

注意事项

  1. 旋转顺序：不同旋转顺序会得到不同的欧拉角值
  2. 万向锁：特定角度组合导致自由度丢失
  3. 角度范围：通常 ϕ,θ,ψ∈[−180°,180°] 或 [0°,360°]
  4. 插值问题：直接对欧拉角插值可能产生奇异结果
  5. 一致性：确保坐标系定义与旋转方向一致
