地球形状模型

概述

地球形状模型是描述地球几何形状的数学模型。由于地球并非完美的球体，而是略微扁平的椭球体，准确描述地球形状对于卫星轨道计算、大地测量和导航定位至关重要。

地球几何形状

基本参数

参数值说明
赤道半径 a6378.137 km长半轴
极半径 b6356.752 km短半轴
扁率 f1/298.257223563(a−b)/a
第一偏心率 e0.0818191908(a2−b2)/a2

WGS84参考椭球

WGS84（World Geodetic System 1984）是GPS使用的全球参考系统：

参数WGS84值
长半轴 a6378137.0 m
扁率 f1/298.257223563
地球引力常数 GM3986004.418×10⁸ m³/s²
角速度 ω7292115.0×10⁻¹¹ rad/s

椭球方程

标准方程

在椭球坐标系中：

(1)x2+y2a2+z2b2=1

子午面椭圆

地球子午面（包含极轴的平面）上的椭圆方程：

(2)x2a2+z2b2=1

大地坐标系

大地坐标定义

坐标定义
大地纬度 ϕ参考椭球法线与赤道面夹角
大地经度 λ参考椭球子午面与格林尼治子午面夹角
大地高度 h沿法线到椭球面的距离

大地坐标转空间坐标

(3)N=a1−e2sin2⁡ϕx=(N+h)cos⁡ϕcos⁡λy=(N+h)cos⁡ϕsin⁡λz=[N(1−e2)+h]sin⁡ϕ

空间坐标转大地坐标

\begin{aligned} \lambda &= \arctan2(y, x) \\ p &= \sqrt{x^2 + y^2} \\ \theta &= \arctan2(z a}{p b}) \\ \phi &= \arctan2(z + e'^2 b \sin^3\theta, p - e^2 a \cos^3\theta) \\ h &= \frac{p}{\cos\phi} - N \end{aligned}

其中 e′2=(a2−b2)/b2。

曲率半径

子午曲率半径 M

(4)M=a(1−e2)(1−e2sin2⁡ϕ)3/2

卯酉曲率半径 N

(5)N=a1−e2sin2⁡ϕ

平均曲率半径

(6)R=MN

在ATK中的使用

椭球模型配置

# 设置地球椭球模型
Earth.Shape = "WGS84"

# 或选择其他模型
Earth.Shape = "GRS80"
Earth.Shape = "Krasovsky"

位置计算

# 获取地球椭球参数
a = Earth.SemiMajorAxis  # 6378137.0 m
b = Earth.SemiMinorAxis  # 6356752.314 m
f = Earth.Flattening      # 1/298.257223563

# 计算曲率半径
M = Earth.MeridianRadius(lat)  # 子午曲率半径
N = Earth.PrimeVerticalRadius(lat)  # 卯酉曲率半径

大地坐标转换

# ECEF到大地坐标
lat, lon, alt = Earth.ECEFToGeodetic(x, y, z)

# 大地坐标到ECEF
x, y, z = Earth.GeodeticToECEF(lat, lon, alt)

# ENU坐标系
enu = Earth.CreateLocalFrame(lat, lon, "ENU")

地形模型

# 设置高程模型
Earth.Terrain = "SRTM30"

# 获取地形高度
height = Earth.GetTerrainHeight(lat, lon)

# 考虑地形的影响
sat.MinAltitude = 150 + height  # km

注意事项

  1. 模型选择：不同应用需选择合适的参考椭球
  2. 高程基准：大地高与正高、正常高的差异
  3. 极移：地球极点的微小移动
  4. 潮汐变形：固体潮和海潮引起的形变
  5. 局部偏差：各国有自己的大地参考框架
