# 地球引力场模型

## 概述

地球引力场模型通过球谐系数展开描述地球引力位的空间变化。精确的引力场模型对于卫星轨道预报、轨道确定和地球物理研究具有重要意义。

## 引力位展开

### 球谐展开

地球引力位在地心惯性坐标系中的展开：

$$
V(r, \phi, \lambda) = \frac{GM}{r} \sum_{n=0}^{\infty} \left(\frac{R_E}{r}\right)^n \sum_{m=0}^{n} P_{nm}(\sin\phi)(C_{nm}\cos m\lambda + S_{nm}\sin m\lambda)
$$

其中：
- $P_{nm}$：缩合勒让德多项式
- $C_{nm}, S_{nm}$：球谐系数
- $R_E$：参考半径

### 正常位

正常引力位由参考椭球和引力常数确定：

$$
U = \frac{GM}{r} + \text{离心力位}
$$

## 带谐系数

### J_n系数

轴对称项的带谐系数：

| 系数 | 值 | 说明 |
|------|-----|------|
| $J_2$ | 1.08263×10⁻³ | 地球扁率 |
| $J_3$ | -2.54×10⁻⁶ | 梨形不对称 |
| $J_4$ | -1.61×10⁻⁶ | 四极矩 |
| $J_5$ | -2.29×10⁻⁷ | 五极矩 |
| $J_6$ | 5.41×10⁻⁷ | 六极矩 |

### J2的物理意义

$J_2$ 描述地球的赤道鼓起：

$$
J_2 = -\frac{A - C}{MR_E^2}
$$

其中 $A$ 为赤道转动惯量，$C$ 为极转动惯量。

## 引力加速度

### 球谐系数计算

引力加速度分量：

$$
\begin{aligned}
a_r &= -\frac{GM}{r^2} \sum_{n=0}^{N} (n+1)\left(\frac{R_E}{r}\right)^n \sum_{m=0}^{n} P_{nm}(\sin\phi)(C_{nm}\cos m\lambda + S_{nm}\sin m\lambda) \\
a_\phi &= \frac{GM}{r^2} \sum_{n=0}^{N} \left(\frac{R_E}{r}\right)^n \sum_{m=0}^{n} \frac{\partial P_{nm}}{\partial \phi}(C_{nm}\cos m\lambda + S_{nm}\sin m\lambda) \\
a_\lambda &= \frac{GM}{r^2 \cos\phi} \sum_{n=0}^{N} \left(\frac{R_E}{r}\right)^n \sum_{m=0}^{n} m P_{nm}(\sin\phi)(-C_{nm}\sin m\lambda + S_{nm}\cos m\lambda)
\end{aligned}
$$

## J2摄动的长期效应

### 升交点赤经变化

$$
\dot{\Omega} = -\frac{3}{2} J_2 n \left(\frac{R_E}{a}\right)^2 \cos i
$$

### 近地点幅角变化

$$
\dot{\omega} = \frac{3}{4} J_2 n \left(\frac{R_E}{a}\right)^2 (5\cos^2 i - 1)
$$

## 在ATK中的使用

### 引力场模型配置

```python
# 选择引力场模型
Earth.Gravity.Type = "EGM2008"
Earth.Gravity.Order = 70  # 展开阶数
Earth.Gravity.Degree = 70

# 简化模型
Earth.Gravity.Type = "J2"
Earth.Gravity.J2Order = 4  # 包含J2-J4
```

### 模型参数

```python
# 设置GM
Earth.GM = 398600.4418  # km³/s²

# 设置参考半径
Earth.ReferenceRadius = 6378.137  # km
```

### 高精度配置

```python
# HPOP高精度轨道预报
sat.Propagator.Type = "HPOP"
sat.Propagator.Gravity.Type = "EGM2008"
sat.Propagator.Gravity.Order = 120  # 高阶
sat.Propagator.Gravity.Degree = 120
```

### 自定义模型

```python
# 导入外部引力场模型
Earth.Gravity.LoadModel("my_gravity.gfc")

# 或使用简化模型加速计算
Earth.Gravity.Type = "PointMass"  # 仅考虑中心引力
```

## 注意事项

1. **阶数选择**：高精度需要高阶展开，计算量大
2. **模型时效**：引力场模型会随观测数据更新
3. **轨道匹配**：不同轨道高度需要不同的展开阶数
4. **计算效率**：全阶模型计算非常耗时
5. **数值精度**：高阶展开的数值稳定性
