# 地磁模型

## 概述

地磁模型描述地球磁场的空间分布和时变特性。精确的地磁场模型对于磁强计校准、姿态确定、轨道计算和空间天气研究具有重要意义。

## 地磁场组成

### 内源场

| 分量 | 来源 | 贡献 |
|------|------|------|
| 偶极子场 | 液态外核 | ~80% |
| 非偶极子场 | 核幔边界 | ~15% |
| 地壳场 | 地壳磁化 | ~5% |

### 外源场

| 分量 | 来源 | 变化 |
|------|------|------|
| 环电流 | 范艾伦带粒子 | 小时-天 |
| 场向电流 | 极光电射流 | 分钟-小时 |
| 磁层顶电流 | 太阳风相互作用 | 分钟-小时 |

## IGRF模型

### 概述

IGRF（International Geomagnetic Reference Field）是国际地磁参考场模型，是最广泛使用的全球地磁场模型。

### 模型发展

| 模型 | 年份 | 最大阶数 | 说明 |
|------|------|----------|------|
| IGRF-13 | 2020 | 15 | 当前最新 |
| IGRF-12 | 2015 | 13 | 广泛使用 |
| IGRF-11 | 2010 | 13 | 历史版本 |

### 球谐展开

$$
V = a \sum_{n=1}^{N} \sum_{m=0}^{n} \left(\frac{a}{r}\right)^{n+1} (g_n^m \cos m\phi + h_n^m \sin m\phi) P_n^m(\cos\theta)
$$

其中 $g_n^m, h_n^m$ 是IGRF系数。

## WMM模型

### 概述

WMM（World Magnetic Model）是美国国家地球物理数据中心（NGDC）和英国地质调查局（BGS）联合开发的地磁场模型，专门用于导航用途。

### 特性

| 参数 | 说明 |
|------|------|
| 更新周期 | 5年 |
| 最大阶数 | 12 |
| 精度 | <500 nT |
| 应用 | 导航、姿态确定 |

## 地磁场分量

### 坐标分量

| 分量 | 说明 | 正方向 |
|------|------|--------|
| X | 北向分量 | 地理北 |
| Y | 东向分量 | 地理东 |
| Z | 垂直分量 | 向下 |
| H | 水平分量 | 水平北 |
| F | 总强度 | 总场强 |
| I | 磁倾角 | 向下为正 |
| D | 磁偏角 | 东偏为正 |

### 换算关系

$$
\begin{aligned}
H &= \sqrt{X^2 + Y^2} \\
F &= \sqrt{H^2 + Z^2} \\
D &= \arctan2(Y, X) \\
I &= \arctan2(Z, H)
\end{aligned}
$$

## 地磁场变化

### 主磁场长期变化

| 变化 | 周期 | 量级 |
|------|------|------|
| 西向漂移 | ~1000年 | ~0.1°/年 |
| 偶极子衰减 | 持续 | ~5%/世纪 |
| 磁极漂移 | 持续 | ~10 km/年 |

### 外源场变化

| 现象 | 周期 | 幅值 |
|------|------|------|
| 地磁宁静 | - | ~30 nT |
| 地磁亚暴 | 1-3小时 | ~1000 nT |
| 地磁风暴 | 1-3天 | ~3000 nT |

## 在ATK中的使用

### 地磁模型配置

```python
# 设置地磁模型
Earth.Magnetic.Type = "IGRF-13"

# 或使用WMM
Earth.Magnetic.Type = "WMM-2020"
```

### 获取磁场强度

```python
# 在指定位置计算磁场
B = Earth.Magnetic.GetField(lat=40, lon=116, alt=500, time="2024-01-01")
print(f"Bx: {B.X} nT")
print(f"By: {B.Y} nT")
print(f"Bz: {B.Z} nT")
print(f"F: {B.Total} nT")
```

### 磁强计仿真

```python
# 配置磁强计
sensor = sat.Payload.Create("Magnetometer")
sensor.Type = "VectorMagnetometer"
sensor.Orientation = [0, 0, 1]  # z轴指向

# 计算磁场测量值
B_measurement = sensor.Measure(Earth.Magnetic)
print(f"测量磁场: {B_measurement} nT")
```

### 姿态确定

```python
# 使用磁强计进行姿态确定
from Attitude import MagnetometerEstimator
estimator = MagnetometerEstimator()
estimator.AddMeasurement(magnetometer_data)
estimator.AddModel(Earth.Magnetic)
attitude = estimator.Estimate()
```

## 地磁场应用

### 轨道力矩

磁场对磁棒或线圈产生力矩：

$$
\vec{M} = \vec{m} \times \vec{B}
$$

其中 $\vec{m}$ 是磁矩。

### 磁阻力

运动导体在磁场中产生感应电流，产生阻力：

$$
\vec{a}_{mag} \propto \vec{v} \times \vec{B}
$$

## 注意事项

1. **模型时效**：地磁模型需定期更新
2. **外源场**：风暴期间误差增大
3. **地壳场**：局部磁异常可能很大
4. **测量噪声**：磁强计校准很重要
5. **卫星姿态**：姿态确定需要精确的磁场模型
