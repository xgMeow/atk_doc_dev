天体星历模型

概述

天体星历模型（Ephemeris Model）提供太阳系天体（太阳、行星、月球等）的精确位置和运动状态。星历模型是天体测量、轨道设计和深空任务规划的基础。

DE系列星历

概述

DE（Development Ephemeris）系列是由NASA喷气推进实验室（JPL）开发的高精度行星星历。DE系列是目前最广泛使用的星历模型。

主要版本

版本年份说明
DE4051998经典版本，广泛使用
DE4061998与DE405相同，低精度插值
DE4212009改进月球模型
DE4302014当前推荐版本
DE4402021最新版本

DE430特性

参数值
时间范围1550-2650年
精度厘米级
天体数量8大行星+月球+冥王星
插值Chebyshev多项式

星历数据结构

Chebyshev多项式

星历数据使用Chebyshev多项式存储：

(1)P(t)=∑k=0nckTk(2t−TmaxTmax)

其中 Tk 是Chebyshev多项式。

数据格式

JPL星历数据文件（.dat）包含：

  • 标题记录：常数信息
  • 数据块：Chebyshev系数
  • 插值信息：块大小、时间步长

SPK文件格式

概述

SPK（Spacecraft Planet Kernel）是JPL开发的星历数据文件格式，是NAIF（Navigation and Ancillary Information Facility）系统的一部分。

数据类型

类型说明
Type 1状态矢量（Chebyshev）
Type 2Chebyshev位置
Type 3分离Chebyshev
Type 5离散状态
Type 9二体轨道

文件结构

SPK File
├── File ID
├── Descriptive comment
├── Segment table
│   ├── Segment 1
│   │   ├── Target body
│   │   ├── Center body
│   │   ├── Time bounds
│   │   └── Chebyshev coefficients
│   └── Segment 2
└── ...

在ATK中的使用

星历配置

# 设置星历模型
Space.SolarSystem.Ephemeris = "DE430"

# 或指定星历文件
Space.SolarSystem.EphemerisFile = "path/to/de430.bsp"

获取天体位置

# 获取太阳位置
sun_pos = Space.Sun.Position(time, frame="J2000")
print(f"太阳位置: {sun_pos} km")

# 获取月球位置
moon_pos = Space.Moon.Position(time, frame="J2000")
print(f"月球位置: {moon_pos} km")

# 获取行星位置
mars_pos = Space.Mars.Position(time, frame="J2000")
print(f"火星位置: {mars_pos} km")

深空任务仿真

# 创建星际转移轨道
probe = Scenario.Create("DeepSpaceProbe")
probe.Orbit.Type = "Trajectory"
probe.Orbit.Ephemeris = "DE430"

# 添加星际段
probe.AddSegment("EarthDeparture", start_time, end_time)

自定义星历

# 导入外部星历
Space.SolarSystem.LoadEphemeris("my_ephemeris.bsp")

# 创建自定义天体
Space.SolarSystem.AddBody("Asteroid_X")
Space.SolarSystem.Body("Asteroid_X").Ephemeris = "my_asteroid.bsp"

与地心星历的转换

J2000坐标系

星历通常在地心J2000坐标系中：

(2)r→J2000=r→GEOCENTRIC

ECEF坐标系

需要考虑地球自转：

(3)r→ECEF=Rz(GAST)⋅r→J2000

注意事项

  1. 星历时效：确保使用最新版本的星历
  2. 时间范围：检查目标时间是否在星历有效范围内
  3. 精度需求：不同任务需要不同精度的星历
  4. 文件大小：高精度星历文件较大
  5. 插值精度：使用正确的插值方法
