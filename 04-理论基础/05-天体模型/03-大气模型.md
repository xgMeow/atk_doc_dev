# 大气模型

## 概述

大气模型描述地球大气层的密度、温度和成分分布。大气阻力是低地球轨道（LEO）卫星的主要摄动源之一，精确的大气模型对于轨道预报和轨道寿命估计至关重要。

## 大气层结构

### 分层结构

| 层级 | 高度范围 | 温度特性 |
|------|----------|----------|
| 对流层 | 0-12 km | 随高度下降 |
| 平流层 | 12-50 km | 随高度上升 |
| 中间层 | 50-85 km | 随高度下降 |
| 热层 | 85-600 km | 随高度上升 |
| 外逸层 | >600 km | 逐渐稀疏 |

### 热层特征

| 参数 | 典型值 |
|------|--------|
| 温度 | 500-2000 K |
| 主要成分 | O, O₂, N₂ |
| 密度 | 10⁻¹³-10⁻⁹ kg/m³ |
| 太阳活动依赖 | 强 |

## NRLMSISE-00模型

### 概述

NRLMSISE-00（Mass Spectrometer and Incoherent Scatter Radar Exosphere 2000）是美国海军研究实验室开发的高精度大气模型，被广泛用于卫星轨道计算。

### 输入参数

| 参数 | 说明 | 单位 |
|------|------|------|
| 年 | 年份 | - |
| 日 | 年内天数 | day |
| 秒 | 日内秒数 | s |
| 纬度 | 地理纬度 | deg |
| 经度 | 地理经度 | deg |
| 高度 | 大地高度 | km |
| F10.7 | 太阳10.7cm射电通量 | SFU |
| F10.7A | 81天平均F10.7 | SFU |
| Ap | 地磁指数 | - |

### 主要输出

| 输出 | 说明 |
|------|------|
| rho | 总质量密度 kg/m³ |
| Tn | 温度 K |
| He, O, O₂, N₂, Ar, H, N | 各成分数密度 |

### 太阳活动指数

| 指数 | 说明 | 影响 |
|------|------|------|
| F10.7 | 当日太阳射电通量 | 热层密度 |
| F10.7A | 81天滑动平均 | 热层长期变化 |
| Ap | 地磁指数 | 热层短期变化 |
| Kp | Kp指数 | 极区密度增加 |

## Jacchia系列模型

### Jacchia-70

经典的氧主导热层模型：

$$
\rho(h) = \rho_0 \exp\left(-\frac{h-h_0}{H}\right)
$$

其中 $H$ 为标高。

### Jacchia-77

改进了温度和成分分布：

| 特点 | 说明 |
|------|------|
| 温度分布 | 基于卫星轨道数据 |
| 成分模型 | O, O₂, N₂, Ar |
| 太阳活动 | F10.7依赖 |

### Jacchia-71

主要用于极轨道卫星的大气计算。

## MSIS系列模型

### MSIS-86

Mass Spectrometer Incoherent Scatter Extended模型：

- 扩展的温度-密度关系
- 极光区域处理

### MSIS-90

MSIS-86的改进版本：

- 更好的日变化模型
- 极光加热模型

### NRLMSISE-00

MSIS-90的改进版本：

- 更精确的氧密度
- 极光效应改进
- 地球辐射带电子加热

## 指数大气模型

### 简化模型

对于精度要求不高的应用：

$$
\rho(h) = \rho_0 \exp\left(-\frac{h-h_0}{H}\right)
$$

### 常用参数

| 高度(km) | 密度(kg/m³) | 标高(km) |
|----------|-------------|----------|
| 120 | 5.0×10⁻⁹ | 10 |
| 200 | 2.5×10⁻¹¹ | 30 |
| 400 | 5.0×10⁻¹³ | 50 |
| 600 | 2.0×10⁻¹⁴ | 80 |

## 大气阻力计算

### 阻力加速度

$$
\vec{a}_D = -\frac{1}{2} \rho \frac{C_D A}{m} v_{rel}^2 \hat{v}_{rel}
$$

其中：
- $\rho$：大气密度
- $C_D$：阻力系数（1.5-2.5）
- $A$：迎风面积
- $m$：卫星质量
- $v_{rel}$：相对大气速度

### 阻力系数

| 表面类型 | $C_D$ |
|----------|-------|
| 漫反射 | 2.2 |
| 镜反射 | 2.0 |
| 漫反射+吸收 | 2.5 |

## 在ATK中的使用

### 大气模型配置

```python
# 设置大气模型
Earth.Atmosphere.Type = "NRLMSISE-00"

# 设置太阳活动指数
Earth.Atmosphere.F107 = 150  # 当日F10.7
Earth.Atmosphere.F107A = 140  # 81天平均
Earth.Atmosphere.Ap = 15  # 地磁指数
```

### Jacchia模型

```python
Earth.Atmosphere.Type = "Jacchia-77"
Earth.Atmosphere.F107 = 150
Earth.Atmosphere.Ap = 15
```

### 指数大气

```python
Earth.Atmosphere.Type = "Exponential"
Earth.Atmosphere.Density0 = 1.0e-12  # km³/s²
Earth.Atmosphere.ScaleHeight = 50  # km
```

### 实时太阳活动

```python
# 从数据库获取太阳活动指数
from SolarActivity import GetSolarIndices
indices = GetSolarIndices(date="2024-01-01")

Earth.Atmosphere.F107 = indices.F107
Earth.Atmosphere.F107A = indices.F107A
Earth.Atmosphere.Ap = indices.ApDaily
```

### 轨道衰减分析

```python
# 设置大气阻力
sat.Drag.Type = "NRLMSISE-00"
sat.Drag.CD = 2.2
sat.Drag.AreaMassRatio = 0.01  # m²/kg

# 运行轨道衰减仿真
mission.Duration = "365 days"
mission.Propagate()

# 获取轨道高度变化
height = sat.Orbit.SMA - Earth.SemiMajorAxis
print(f"年度高度衰减: {-height:.2f} km")
```

## 注意事项

1. **太阳活动**：F10.7对热层密度影响巨大
2. **地磁活动**：Ap指数影响极区热层
3. **极光加热**：高纬度地区的额外加热效应
4. **模型时效**：大气模型需定期更新
5. **卫星朝向**：姿态影响有效迎风面积
