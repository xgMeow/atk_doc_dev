# 天体指向模型

## 概述

天体指向模型描述天体（太阳、月球、行星等）在惯性空间中的指向和姿态。这些信息对于太阳帆定向、太阳能电池板对日指向、恒星跟踪器和天文观测至关重要。

## 太阳指向

### 太阳在J2000坐标系中的位置

太阳赤道坐标（IAU 2009）：

$$
\begin{aligned}
\lambda_\odot &= 280.46646° + 36000.76989° T + 0.00030372° T^2 \\
\beta_\odot &= 0° \\
\epsilon &= 23.439291° - 0.013004° T - 0.00000016° T^2
\end{aligned}
$$

其中 $T$ 是儒略世纪数。

### 日心距

$$
r_\odot = 1.000001018 \text{ AU}
$$

### 太阳常量

在1 AU处的太阳辐射强度：

$$
S_0 = 1361 \text{ W/m}^2
$$

### ATK中的太阳指向

```python
# 获取太阳指向矢量
sun_vec = Space.Sun.Vector(time, frame="J2000")
print(f"太阳方向: {sun_vec}")

# 获取太阳距离
sun_dist = Space.Sun.Distance(time)
print(f"日心距: {sun_dist} AU")

# 计算太阳辐照度
solar_constant = 1361  # W/m²
irradiance = solar_constant / (sun_dist ** 2)
```

## 月球指向

### 月球姿态

月球自转周期等于公转周期（潮汐锁定）：

$$
T_{spin} = T_{orbit} = 27.321661 \text{ 天}
$$

### 月球坐标系

| 轴 | 方向 |
|----|------|
| X | 指向地球 |
| Z | 垂直于白道面 |
| Y | 与X、Z构成右手系 |

### 月球指向计算

```python
# 获取月球指向
moon_att = Space.Moon.Attitude(time, frame="J2000")
print(f"月球姿态四元数: {moon_att.Quaternion}")

# 获取月心距
moon_dist = Space.Moon.Distance(time)
```

## 恒星指向

### 恒星在天球上的位置

恒星位置用赤经（α）和赤纬（δ）表示：

$$
\begin{aligned}
\alpha &: 0° \sim 360° \text{（赤经）} \\
\delta &: -90° \sim +90° \text{（赤纬）}
\end{aligned}
$$

### 岁差修正

恒星位置需修正岁差：

$$
\alpha_{J2000} \rightarrow \alpha_{epoch}
$$

### ATK中的恒星指向

```python
# 创建恒星目录
star_catalog = Space.CreateStarCatalog("Hipparcos")
star_catalog.LoadFile("hip_main.dat")

# 获取恒星指向
star = star_catalog.GetStar("Sirius")
star_vec = star.Vector(time, frame="J2000")
print(f"天狼星方向: {star_vec}")
```

## 地月指向关系

### 地月连线方向

地球指向月球的方向：

$$
\hat{r}_{EM} = \frac{\vec{r}_{Moon} - \vec{r}_{Earth}}{|\vec{r}_{Moon} - \vec{r}_{Earth}|}
$$

### 月球相位角

$$
\cos E = -\frac{\vec{r}_{EM} \cdot \vec{r}_{ES}}{|\vec{r}_{ES}|}
$$

其中 $E$ 是月球相位角（新月时 $E=0°$，满月时 $E=180°$）。

## 太阳指向计算

```python
# ATK太阳指向计算
sun_vector = Space.Sun.Vector(time, frame="J2000")
sun_distance = Space.Sun.Distance(time)

# 对日定向姿态
def sun_pointing_attitude(sun_vector):
    """计算太阳帆板对日定向姿态"""
    z_axis = -sun_vector / norm(sun_vector)
    x_axis = [0, 0, 1]  # 定义参考轴
    y_axis = cross(z_axis, x_axis)
    x_axis = cross(y_axis, z_axis)
    return [x_axis, y_axis, z_axis]
```

## 在ATK中的使用

### 太阳敏感器仿真

```python
# 配置太阳敏感器
sun_sensor = sat.Payload.Create("SunSensor")
sun_sensor.Type = "DigitalSunSensor"
sun_sensor.FieldOfView = 128  # deg
sun_sensor.Alignment = [0, 0, 1]  # z轴指向

# 获取太阳在敏感器中的测量
sun_in_body = sun_sensor.Measure(Space.Sun)
print(f"太阳在本体坐标系: {sun_in_body}")
```

### 太阳帆板对日定向

```python
# 配置太阳帆板
solar_array = sat.Payload.Create("SolarArray")
solar_array.Type = "SolarPanel"
solar_array.Area = 20  # m²

# 设置对日定向模式
solar_array.AttitudeControl = "SunPointing"
solar_array.SunReference = Space.Sun
```

### 恒星跟踪器

```python
# 配置恒星跟踪器
star_tracker = sat.Payload.Create("StarTracker")
star_tracker.Type = "Basestar"
star_tracker.Alignment = [0, 1, 0]  # y轴指向
star_tracker.StarCatalog = "Hipparcos"

# 获取星图
star_image = star_tracker.Measure(time)
```

### 地球/月球指向

```python
# 获取地球指向
earth_vec = Space.Earth.Vector(time, frame="Body")
```

## 应用场景

| 应用 | 天体 | 说明 |
|------|------|------|
| 太阳能 | 太阳 | 对日定向 |
| 热控 | 太阳+地球 | 辐射热管理 |
| 姿态确定 | 恒星 | 星敏感器 |
| 导航 | 恒星 | 星光导航 |
| 通信 | 地球 | 对地定向 |

## 注意事项

1. **光行差**：恒星位置的相对论效应
2. **大气折射**：地面观测需修正
3. **指向精度**：高精度任务需完整岁差章动模型
4. **时间同步**：指向计算需要精确时间
5. **姿态抖动**：星敏感器需考虑卫星姿态稳定度
