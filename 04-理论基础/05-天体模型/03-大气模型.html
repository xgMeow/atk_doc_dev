大气模型

概述

大气模型描述地球大气层的密度、温度和成分分布。大气阻力是低地球轨道（LEO）卫星的主要摄动源之一，精确的大气模型对于轨道预报和轨道寿命估计至关重要。

大气层结构

分层结构

层级高度范围温度特性
对流层0-12 km随高度下降
平流层12-50 km随高度上升
中间层50-85 km随高度下降
热层85-600 km随高度上升
外逸层>600 km逐渐稀疏

热层特征

参数典型值
温度500-2000 K
主要成分O, O₂, N₂
密度10⁻¹³-10⁻⁹ kg/m³
太阳活动依赖强

NRLMSISE-00模型

概述

NRLMSISE-00（Mass Spectrometer and Incoherent Scatter Radar Exosphere 2000）是美国海军研究实验室开发的高精度大气模型，被广泛用于卫星轨道计算。

输入参数

参数说明单位
年年份-
日年内天数day
秒日内秒数s
纬度地理纬度deg
经度地理经度deg
高度大地高度km
F10.7太阳10.7cm射电通量SFU
F10.7A81天平均F10.7SFU
Ap地磁指数-

主要输出

输出说明
rho总质量密度 kg/m³
Tn温度 K
He, O, O₂, N₂, Ar, H, N各成分数密度

太阳活动指数

指数说明影响
F10.7当日太阳射电通量热层密度
F10.7A81天滑动平均热层长期变化
Ap地磁指数热层短期变化
KpKp指数极区密度增加

Jacchia系列模型

Jacchia-70

经典的氧主导热层模型：

(1)ρ(h)=ρ0exp⁡(−h−h0H)

其中 H 为标高。

Jacchia-77

改进了温度和成分分布：

特点说明
温度分布基于卫星轨道数据
成分模型O, O₂, N₂, Ar
太阳活动F10.7依赖

Jacchia-71

主要用于极轨道卫星的大气计算。

MSIS系列模型

MSIS-86

Mass Spectrometer Incoherent Scatter Extended模型：

  • 扩展的温度-密度关系
  • 极光区域处理

MSIS-90

MSIS-86的改进版本：

  • 更好的日变化模型
  • 极光加热模型

NRLMSISE-00

MSIS-90的改进版本：

  • 更精确的氧密度
  • 极光效应改进
  • 地球辐射带电子加热

指数大气模型

简化模型

对于精度要求不高的应用：

(2)ρ(h)=ρ0exp⁡(−h−h0H)

常用参数

高度(km)密度(kg/m³)标高(km)
1205.0×10⁻⁹10
2002.5×10⁻¹¹30
4005.0×10⁻¹³50
6002.0×10⁻¹⁴80

大气阻力计算

阻力加速度

(3)a→D=−12ρCDAmvrel2v^rel

其中：

  • ρ：大气密度
  • CD：阻力系数（1.5-2.5）
  • A：迎风面积
  • m：卫星质量
  • vrel：相对大气速度

阻力系数

表面类型CD
漫反射2.2
镜反射2.0
漫反射+吸收2.5

在ATK中的使用

大气模型配置

# 设置大气模型
Earth.Atmosphere.Type = "NRLMSISE-00"

# 设置太阳活动指数
Earth.Atmosphere.F107 = 150  # 当日F10.7
Earth.Atmosphere.F107A = 140  # 81天平均
Earth.Atmosphere.Ap = 15  # 地磁指数

Jacchia模型

Earth.Atmosphere.Type = "Jacchia-77"
Earth.Atmosphere.F107 = 150
Earth.Atmosphere.Ap = 15

指数大气

Earth.Atmosphere.Type = "Exponential"
Earth.Atmosphere.Density0 = 1.0e-12  # km³/s²
Earth.Atmosphere.ScaleHeight = 50  # km

实时太阳活动

# 从数据库获取太阳活动指数
from SolarActivity import GetSolarIndices
indices = GetSolarIndices(date="2024-01-01")

Earth.Atmosphere.F107 = indices.F107
Earth.Atmosphere.F107A = indices.F107A
Earth.Atmosphere.Ap = indices.ApDaily

轨道衰减分析

# 设置大气阻力
sat.Drag.Type = "NRLMSISE-00"
sat.Drag.CD = 2.2
sat.Drag.AreaMassRatio = 0.01  # m²/kg

# 运行轨道衰减仿真
mission.Duration = "365 days"
mission.Propagate()

# 获取轨道高度变化
height = sat.Orbit.SMA - Earth.SemiMajorAxis
print(f"年度高度衰减: {-height:.2f} km")

注意事项

  1. 太阳活动：F10.7对热层密度影响巨大
  2. 地磁活动：Ap指数影响极区热层
  3. 极光加热：高纬度地区的额外加热效应
  4. 模型时效：大气模型需定期更新
  5. 卫星朝向：姿态影响有效迎风面积
