# 光照条件计算

## 概述

光照条件计算用于确定卫星或目标在空间中的光照状态，包括日光照射、地球阴影（月食）和光照强度等。光照条件对于太阳能发电、热控、遥感成像和通信等任务至关重要。

## 基本概念

### 光照区域

| 区域 | 说明 | 特征 |
|------|------|------|
| 日照区 | 阳光直射区域 | 太阳能发电 |
| 地球阴影 | 被地球遮挡 | 无阳光照射 |
| 半影区 | 部分遮挡 | 过渡区域 |
| 地影锥 | 地球阴影锥形区域 | 月食发生区 |

### 太阳常数

在日心距1 AU处的太阳辐射强度：

$$
S_0 = 1361 \text{ W/m}^2
$$

### 阴影因子

描述太阳照射程度的因子：

$$
\eta = \begin{cases}
1 & \text{完全日照} \\
0 < \eta < 1 & \text{半影} \\
0 & \text{完全阴影}
\end{cases}
$$

## 地球阴影模型

### 圆锥阴影模型

简化假设：太阳和地球都是球体：

#### 半影角

$$
\tan\gamma = \frac{R_\odot - R_E}{D_{SE}}
$$

其中 $D_{SE}$ 是日地距离。

#### 本影角

$$
\tan\beta = \frac{R_\odot + R_E}{D_{SE}}
$$

### 圆柱阴影模型

忽略太阳角直径的简化模型：

$$
\theta_{shadow} = \arcsin\frac{R_E}{r}
$$

### 数值阴影计算

精确计算考虑地球不规则形状：

```python
def in_umbra(position, sun_direction, earth_radius=6378.137):
    """判断位置是否在地球本影中"""
    r_proj = position - sun_direction * np.dot(position, sun_direction)
    r_perp = np.linalg.norm(r_proj)
    
    # 地球视半径
    theta_e = np.arcsin(earth_radius / np.linalg.norm(position))
    
    return r_perp < earth_radius * np.cos(theta_e)
```

## 日食计算

### 月食条件

月食发生在卫星进入地球本影时：

$$
\cos\theta = \frac{\vec{r}_{sat} \cdot \vec{r}_{sun}}{|\vec{r}_{sat}||\vec{r}_{sun}|}
$$

### 月食持续时间

$$
T_{eclipse} = 2\sqrt{\frac{(R_E + R_{moon})^2 - d^2}{|\vec{v}_{sat}|}}
$$

其中 $d$ 是卫星到地月连线的垂直距离。

## 在ATK中的使用

### 光照分析配置

```python
# 启用光照计算
sat.Analysis.Lighting = True
sat.Analysis.Eclipse = True

# 设置阴影模型
Earth.Shadow.Model = "Cylindrical"
Earth.Shadow.SunRadius = 696340  # km
Earth.Shadow.EarthRadius = 6378  # km
```

### 获取光照状态

```python
# 获取阴影状态
eclipse_state = sat.Lighting.Eclipse(time)
print(f"阴影状态: {eclipse_state}")  # Sunlight, Umbra, Penumbra

# 获取日照比例
illumination_ratio = sat.Lighting.IlluminationRatio(time)
print(f"日照比例: {illumination_ratio:.2%}")
```

### 光伏功率计算

```python
# 配置太阳能电池板
solar_panel = sat.Payload.Create("SolarArray")
solar_panel.Area = 20  # m²
solar_panel.Efficiency = 0.30
solar_panel.SunTracking = True

# 计算发电功率
power = solar_panel.Power(time)
print(f"太阳能发电: {power:.1f} W")
```

### 阴影窗口分析

```python
# 计算阴影进入和离开时间
eclipse_intervals = sat.Lighting.GetEclipseIntervals(
    start_time="2024-01-01 00:00:00",
    end_time="2024-01-02 00:00:00"
)

for interval in eclipse_intervals:
    print(f"进入阴影: {interval.Start}")
    print(f"离开阴影: {interval.End}")
    print(f"持续时间: {(interval.End - interval.Start).total_seconds():.0f} s")
```

## 太阳仰角计算

### 地平坐标系

太阳在地平坐标系中的高度角：

$$
\sin h_\odot = \sin\phi\sin\delta + \cos\phi\cos\delta\cos H
$$

其中 $\phi$ 是纬度，$\delta$ 是太阳赤纬，$H$ 是时角。

### 日出日落

当太阳高度 $h_\odot = 0$ 时：

$$
\cos H_0 = -\tan\phi\tan\delta
$$

### 在ATK中的计算

```python
# 计算太阳仰角
sun_elevation = GroundStation.SunElevation(time)
print(f"太阳仰角: {sun_elevation:.2f}°")

# 计算日照窗口
daylight_windows = GroundStation.GetDaylightWindows(
    start_time="2024-01-01",
    end_time="2024-01-02"
)
```

## 光照强度计算

### 距离衰减

$$
E = E_0 \left(\frac{1 \text{ AU}}{r}\right)^2
$$

### 表面光照

$$
E_{surface} = E \cdot \cos\theta \cdot \alpha
$$

其中 $\theta$ 是入射角，$\alpha$ 是表面反射率。

### 在ATK中的计算

```python
# 计算表面光照
surface_irradiance = Analysis.SurfaceIrradiance(
    point=ground_point,
    time=time,
    source="Sun"
)
print(f"表面辐照度: {surface_irradiance:.1f} W/m²")
```

## 应用场景

| 应用 | 光照条件 | 说明 |
|------|----------|------|
| 太阳能 | 日照比例 | 发电功率 |
| 热控 | 日照/阴影 | 热输入 |
| 成像 | 太阳仰角 | 图像质量 |
| 通信 | 阴影状态 | 链路质量 |
| 电池管理 | 阴影周期 | 充放电策略 |

## 注意事项

1. **阴影模型**：高精度应用需使用数值阴影
2. **太阳指向**：需使用精确的太阳星历
3. **地形影响**：地面站需考虑地形遮挡
4. **大气折射**：地面观测需修正
5. **多阴影体**：深空任务需考虑多天体遮挡
