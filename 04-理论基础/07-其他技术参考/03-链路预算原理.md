# 链路预算原理

## 概述

链路预算（Link Budget）是卫星通信系统设计的基础，用于计算信号从发射端到接收端的功率平衡。完整的链路预算分析确保通信链路的可靠性和性能满足任务需求。

## 链路方程

### 自由空间链路方程

接收功率：

$$
P_r = P_t + G_t + G_r - L_{fs} - L_{total}
$$

其中：
- $P_t$：发射功率 (dBW)
- $G_t$：发射天线增益 (dBi)
- $G_r$：接收天线增益 (dBi)
- $L_{fs}$：自由空间损耗 (dB)
- $L_{total}$：其他损耗总和 (dB)

### 自由空间损耗

$$
L_{fs} = 20\log_{10}d + 20\log_{10}f + 92.45
$$

其中：
- $d$：距离 (km)
- $f$：频率 (GHz)

简化形式：

$$
L_{fs} = 32.44 + 20\log_{10}d + 20\log_{10}f
$$

## 链路分量

### 发射端

| 参数 | 符号 | 单位 | 典型值 |
|------|------|------|--------|
| 发射功率 | $P_t$ | dBW | 10-50 |
| 发射天线增益 | $G_t$ | dBi | 10-60 |
| 发射损耗 | $L_{t}$ | dB | 1-3 |

### 传播损耗

| 损耗类型 | 符号 | 说明 |
|----------|------|------|
| 自由空间损耗 | $L_{fs}$ | 距离衰减 |
| 大气损耗 | $L_{atm}$ | 0.5-2 dB |
| 雨衰损耗 | $L_{rain}$ | 0-10 dB |
| 云损耗 | $L_{cloud}$ | 0-2 dB |
| 极化损耗 | $L_{pol}$ | 0-3 dB |

### 接收端

| 参数 | 符号 | 单位 | 典型值 |
|------|------|------|--------|
| 接收天线增益 | $G_r$ | dBi | 20-60 |
| 系统噪声温度 | $T_s$ | K | 50-500 |
| 接收损耗 | $L_{r}$ | dB | 1-3 |
| 图腾 | $P_r$ | dBW | -150至-100 |

## 链路余量

### 信噪比

$$
\frac{E_b}{N_0} = P_r + 228.6 - 10\log_{10}T_s - 10\log_{10}R_b
$$

其中：
- $E_b$：每比特能量
- $N_0$：噪声功率谱密度
- $R_b$：比特率

### 载噪比

$$
\frac{C}{N_0} = P_r - 10\log_{10}(kT_s)
$$

其中 $k = 1.38\times10^{-23}$ J/K 是玻尔兹曼常数。

### 链路余量

$$
M = \left(\frac{C}{N_0}\right)_{actual} - \left(\frac{C}{N_0}\right)_{required}
$$

典型设计余量：3-6 dB

## 在ATK中的使用

### 创建通信链路

```python
# 创建地面站
ground_station = Network.CreateGroundStation("Beijing")

# 创建卫星链路
link = Analysis.Communication.Link(Satellite, ground_station)

# 设置载波参数
link.Frequency = 14.0  # GHz
link.Bandwidth = 100  # MHz
link.Modulation = "QPSK"
link.Coding = "LDPC 3/4"
```

### 配置发射机

```python
# 发射机参数
transmitter = Satellite.Payload.Create("Transmitter")
transmitter.Power = 10  # W
transmitter.Frequency = 14.0  # GHz
transmitter.DataRate = 100  # Mbps
transmitter.Modulation = "QPSK"
transmitter.FEC = 0.75
```

### 配置天线

```python
# 卫星天线
sat_antenna = Satellite.Payload.Create("Antenna")
sat_antenna.Type = "Parabolic"
sat_antenna.Diameter = 1.0  # m
sat_antenna.Efficiency = 0.55
sat_antenna.Pointing = "EarthPointing"

# 计算天线增益
gain = sat_antenna.Gain
print(f"天线增益: {gain:.1f} dBi")
```

### 配置接收机

```python
# 接收机参数
receiver = GroundStation.Receiver
receiver.Frequency = 12.0  # GHz
receiver.SystemTemperature = 150  # K
receiver.NoiseFigure = 0.5  # dB
```

### 运行链路分析

```python
# 分析链路性能
link_analysis = Analysis.Communication(link)

# 计算链路参数
results = link_analysis.Compute(time="2024-01-01 12:00:00")

print(f"发射功率: {results.TransmitPower:.1f} dBW")
print(f"发射增益: {results.TransmitGain:.1f} dBi")
print(f"自由空间损耗: {results.FreeSpaceLoss:.1f} dB")
print(f"接收功率: {results.ReceivePower:.1f} dBW")
print(f"E_b/N_0: {results.EbN0:.1f} dB")
print(f"链路余量: {results.Margin:.1f} dB")
```

### 链路扫描

```python
# 扫描链路性能随时间变化
scan = link_analysis.Scan(
    start_time="2024-01-01 00:00:00",
    end_time="2024-01-02 00:00:00",
    step="00:01:00"
)

# 绘制链路余量
plot(scan.Time, scan.Margin)
```

## 雨衰计算

### ITU-R模型

$$
L_{rain} = k R^\alpha \cdot d / \sin\theta
$$

其中：
- $R$：降雨率 (mm/h)
- $d$：路径长度 (km)
- $\theta$：仰角

### ATK雨衰计算

```python
# 雨衰分析
rain_analysis = Analysis.Communication.RainAttenuation(link)
rain_analysis.Location = "Beijing"
rain_analysis.RainRate = 50  # mm/h (年平均最大)
rain_analysis.TimePercentage = 0.01  # 99.99%可用性

# 计算雨衰
rain_loss = rain_analysis.Compute()
print(f"雨衰: {rain_loss:.1f} dB")
```

## 注意事项

1. **气象数据**：雨衰计算需要准确的当地气象数据
2. **系统余量**：确保设计余量满足可用性要求
3. **频率选择**：不同频段的大气特性差异显著
4. **极化方式**：线极化/圆极化的选择与跟踪能力相关
5. **干扰考虑**：实际系统中需考虑同频干扰
