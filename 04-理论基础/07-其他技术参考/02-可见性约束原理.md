# 可见性约束原理

## 概述

可见性约束（Visibility Constraint）是航天任务分析中的核心概念，用于判断卫星与地面站、卫星与卫星之间是否存在视线（Line of Sight）连接。可见性分析是通信、导航、遥感等任务规划的基础。

## 基本定义

### 视线条件

两个目标可见的充要条件：

$$
\theta < 90° \quad \text{且} \quad \text{视线未被遮挡}
$$

其中 $\theta$ 是目标相对观测点的仰角。

### 最小仰角

考虑地球曲率和障碍物的影响：

$$
\sin E_{min} = \frac{R_E}{R_E + h}
$$

其中 $E_{min}$ 是最小可观测仰角。

| 最低点高度(km) | 最小仰角=0°时的地平距离 |
|----------------|------------------------|
| 0 | 0 km |
| 200 | 1595 km |
| 400 | 2255 km |
| 500 | 2525 km |
| 35786 | ~90° |

## 可见性计算

### 地心角计算

观测点A到目标B的地心角：

$$
\cos\gamma = \frac{\vec{r}_A \cdot \vec{r}_B}{r_A r_B}
$$

### 仰角计算

在站心坐标系中：

$$
\sin E = \frac{\vec{r}_{AB} \cdot \hat{z}}{|\vec{r}_{AB}|}
$$

其中 $\hat{z}$ 是当地垂线方向。

### 距离计算

$$
d = |\vec{r}_B - \vec{r}_A|
$$

### 距离变化率（多普勒）

$$
\dot{d} = \frac{(\vec{v}_B - \vec{v}_A) \cdot \vec{r}_{AB}}{d}
$$

## 遮挡类型

### 地球遮挡

最常见的遮挡类型：

```python
def is_earth_obscured(observer, target):
    """判断地球是否遮挡视线"""
    # 视线向量
    los = target.position - observer.position
    los_unit = los / np.linalg.norm(los)
    
    # 检查地球表面交点
    r_obs = np.linalg.norm(observer.position)
    r_tgt = np.linalg.norm(target.position)
    
    # 视线与地球的最近距离
    d_closest = r_obs * np.sqrt(1 - (np.dot(los_unit, observer.position)/r_obs)**2)
    
    return d_closest < EARTH_RADIUS
```

### 地形遮挡

地面站观测时的地形遮挡：

```python
def is_terrain_obscured(observer, target, terrain):
    """判断地形是否遮挡视线"""
    # 视线上的采样点
    n_samples = 100
    los = target.position - observer.position
    
    for i in range(n_samples):
        point = observer.position + (i/n_samples) * los
        terrain_h = terrain.GetHeight(point)
        point_h = np.linalg.norm(point) - EARTH_RADIUS
        
        if point_h < terrain_h:
            return True
    return False
```

## 在ATK中的使用

### 基本可见性分析

```python
# 创建可见性分析
access = Analysis.Access(GroundStation, Satellite)

# 设置最小仰角约束
access.Constraint.MinElevation = 10  # deg

# 计算可见弧段
access.StartTime = "2024-01-01 00:00:00"
access.EndTime = "2024-01-02 00:00:00"
access.Compute()
```

### 多约束条件

```python
# 创建复合约束
from Analysis import Constraint

# 仰角约束
elev_constraint = Constraint.MinElevation(10)

# 距离约束
range_constraint = Constraint.Range(500, 40000)  # km

# 方位角约束
az_constraint = Constraint.Azimuth(0, 180)  # deg

# 组合约束
access.Constraint = elev_constraint & range_constraint & az_constraint
```

### 可见性窗口

```python
# 获取可见窗口列表
windows = access.GetAccessWindows()

for window in windows:
    print(f"开始: {window.Start}")
    print(f"结束: {window.End}")
    print(f"持续: {window.Duration}")
    print(f"最大仰角: {window.MaxElevation:.2f}°")
    print(f"最大距离: {window.MaxRange:.0f} km")
```

### 统计分析

```python
# 可见性统计
stats = access.GetStatistics()

print(f"可见次数: {stats.AccessCount}")
print(f"总可见时间: {stats.TotalAccessTime:.1f} min")
print(f"平均可见时间: {stats.AverageAccessTime:.1f} min")
print(f"最大可见时间: {stats.MaxAccessTime:.1f} min")
print(f"最小可见时间: {stats.MinAccessTime:.1f} min")
print(f"可见率: {stats.AccessPercentage:.1f}%")
```

## 特殊可见性问题

### 星蚀期

地球进入太阳与卫星之间：

$$
\text{星蚀} = \text{地影} \cap \text{通信窗口}
$$

### 日凌

太阳进入地面站与卫星之间：

$$
\text{日凌} = \text{太阳仰角} < 5° \cap \text{通信窗口}
$$

### 极区盲区

高纬度地面站的特殊约束。

## 注意事项

1. **精度需求**：高精度任务需考虑大气折射修正
2. **实时计算**：轨道预报误差影响可见性预测
3. **地形数据**：复杂地形需高精度地形模型
4. **多路径效应**：低仰角时存在多路径干扰
5. **时间系统**：确保所有时间使用统一的时间系统
