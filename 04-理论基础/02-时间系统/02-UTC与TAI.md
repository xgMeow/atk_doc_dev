# UTC与TAI

## 概述

UTC（Coordinated Universal Time，协调世界时）和TAI（International Atomic Time，国际原子时）是航天和日常生活中最常用的时间系统。UTC通过闰秒机制与地球自转保持同步，而TAI提供绝对均匀的时间尺度。理解两者之间的关系对于卫星导航、通信和测控至关重要。

## TAI（国际原子时）

### 定义

TAI是以全球分布的原子钟数据为基础，通过加权平均得到的时间尺度。TAI的秒长定义为铯-133原子基态的两个超精细能级之间跃迁所对应的辐射的9192631770个周期的时间。

### 基本特性

| 特性 | 值 |
|------|-----|
| 秒长定义 | 铯原子秒（SI秒） |
| 起点 | 1958年1月1日 00:00:00 |
| 连续性 | 连续，无闰秒 |
| 精度 | 10^-15 秒/天 |

### 物理意义

TAI是理想的均匀时间尺度，适用于需要精确时间间隔的计算：

$$
\Delta T_{TAI} = t_2 - t_1
$$

## UTC（协调世界时）

### 定义

UTC是TAI与地球自转（UT1）协调的产物。UTC保持与TAI仅相差整数秒，同时通过闰秒与UT1的偏差保持在0.9秒以内。

### 闰秒机制

$$
\text{UTC} = \text{TAI} - \Delta \text{AT}
$$

其中 $\Delta \text{AT}$ 是累积的闰秒数。

### 历史数据

| 日期 | ΔAT (s) |
|------|---------|
| 1972-01-01 | 10 |
| 1972-07-01 | 11 |
| 1980-01-01 | 19 |
| 2000-01-01 | 32 |
| 2017-01-01 | 37 |
| 2024-01-01 | 37 |

### 闰秒插入规则

1. 在6月30日或12月31日最后一天插入
2. 在23:59:59之后插入23:59:60，然后跳到00:00:00
3. 由IERS（国际地球自转服务）提前6个月公告

## 转换关系

### UTC与TAI

$$
\begin{aligned}
\text{TAI} &= \text{UTC} + \Delta \text{AT} \\
\text{UTC} &= \text{TAI} - \Delta \text{AT}
\end{aligned}
$$

### 示例计算

```python
# 2024年1月1日 00:00:00 UTC
TAI = UTC + 37秒 = 2024年1月1日 00:00:37 TAI
```

## UTC与导航系统

### GPS时间与UTC

GPS时间系统与UTC的关系：

$$
\text{GPS} = \text{UTC} - \Delta t_{GPS}
$$

其中 $\Delta t_{GPS} = 19$ 秒（截至当前）。

### 闰秒公告

GPS导航电文会广播UTC-GPS时间偏移和未来闰秒预告。

## 应用场景

| 应用 | 使用UTC还是TAI | 原因 |
|------|---------------|------|
| 日常计时 | UTC | 与地球同步 |
| 卫星通信 | UTC | 与用户时间一致 |
| 轨道计算 | TAI/TT | 时间均匀 |
| 导航定位 | UTC | 国际标准 |
| 科学实验 | TAI | 时间均匀 |

## 在ATK中的使用

### 配置方法

ATK中可设置UTC或TAI作为时间系统：

```
时间系统：UTC / TAI
```

### ATK配置示例

```python
# 使用UTC时间系统
mission.TimeSystem = UTC
mission.StartTime = "2024-01-01 12:00:00 UTC"

# 时间转换
time_utc = Time("2024-01-01 12:00:00 UTC")
time_tai = time_utc.Convert(TAI)

# 获取当前闰秒
leap_seconds = Time.GetLeapSeconds(time_utc)
```

### 时间格式

```python
# ISO格式（UTC）
time_iso = "2024-01-01T12:00:00"

# 带时区
time_tz = "2024-01-01T12:00:00+08:00"

# 相对时间
time_rel = "+0001:00:00"  # 相对起始时间1小时
```

## 注意事项

1. **闰秒不可预测**：闰秒由地球自转决定，无法精确长期预测
2. **计算机时间**：多数计算机系统使用UTC，内部忽略闰秒
3. **GPS周计数**：GPS使用周计数+周内秒，跳秒时可能有歧义
4. **长期存档**：科学数据存档应使用TAI或带有闰秒标注的UTC
