# 北斗时（BDT）

## 概述

北斗时（BeiDou Time，BDT）是中国北斗卫星导航系统（BDS）内部使用的时间系统。BDT采用原子时秒长，与TAI保持固定偏移，是中国卫星导航、定位和授时服务的时间基准。

## 定义

### 基本特性

| 特性 | 值 |
|------|-----|
| 秒长定义 | SI秒（与TAI相同） |
| 起点 | 2006年1月1日 00:00:00 UTC |
| 参考历元 | 2006-01-01 00:00:00 BDT |
| 与TAI偏移 | 33秒（截至当前） |
| 周计数 | 13位，起点2006年1月1日 |

### 时间表达

BDT采用以下格式表达：

$$
T_{BDT} = \text{Week} \times 604800 + \text{SOW}
$$

其中：
- **Week**：北斗周计数（0起始）
- **SOW**：周内秒（Seconds of Week，0-604799）

### 完整表达

$$
T = \text{BDT周} + \frac{\text{周内秒}}{604800}
$$

## 与其他时间系统的关系

### 与TAI的关系

$$
\text{BDT} = \text{TAI} + \Delta t_{BDT}
$$

其中 $\Delta t_{BDT} = -33$ 秒。

### 与UTC的关系

$$
\text{UTC} = \text{BDT} - \Delta t_{UTC-BDT}
$$

当前 $\Delta t_{UTC-BDT} = 37 - 33 = 4$ 秒（取决于闰秒数量）。

### 时间转换链

```
BDT → TAI → UTC
```

转换公式：

$$
\begin{aligned}
\text{TAI} &= \text{BDT} + 33 \text{ s} \\
\text{UTC} &= \text{TAI} - \Delta \text{AT} \\
          &= \text{BDT} + 33 - \Delta \text{AT} \text{ s}
\end{aligned}
$$

### 历元转换

| BDT | UTC | 说明 |
|-----|-----|------|
| 2006-01-01 00:00:00 | 2005-12-31 23:59:56 | 起点 |
| 2012-01-01 00:00:00 | 2011-12-31 23:59:56 | 运行中 |
| 2024-01-01 00:00:00 | 2023-12-31 23:59:37 | 当前 |

## 在卫星导航中的应用

### 导航电文

北斗导航电文包含以下时间信息：

| 参数 | 说明 | 单位 |
|------|------|------|
| WN | 北斗周数 | 周 |
| TOW | 周内秒 | 秒 |
| Δt_UTC | BDT-UTC偏移 | 秒 |
| ΔT_GPS | BDT-GPS偏移 | 秒 |

### 定位解算

用户接收机通过以下步骤使用BDT：

1. 接收BDT时间信息
2. 转换为UTC进行日常使用
3. 使用UTC计算伪距
4. 解算用户位置

### 与GPS时间的对比

| 特性 | BDT | GPS |
|------|-----|-----|
| 起点 | 2006-01-01 | 1980-01-06 |
| 与TAI偏移 | 33秒 | 19秒 |
| 周计数 | 13位 | 10位 |
| 闰秒处理 | 是 | 是 |

## 在ATK中的使用

### 配置方法

ATK支持北斗时间系统：

```
时间系统：BDT
```

### ATK配置示例

```python
# 设置北斗时间系统
mission.TimeSystem = BDT
mission.StartTime = "2024-01-01 00:00:00 BDT"

# 北斗卫星轨道数据
bds_sat.Orbit.TimeSystem = BDT

# 时间转换
time_bdt = Time("2024-01-01 12:00:00 BDT")
time_utc = time_bdt.Convert(UTC)
time_tai = time_bdt.Convert(TAI)
```

### 北斗星座分析

```python
# 创建北斗星座
bds_constellation = Constellation.Create("BeiDou")
bds_constellation.Type = "BeiDou"
bds_constellation.TimeSystem = BDT

# 可见性分析
access = Coverage.Access(GroundStation, bds_constellation)
access.TimeSystem = BDT
```

## 注意事项

1. **闰秒更新**：当UTC增加闰秒后，BDT-UTC偏移需相应更新
2. **周溢出**：13位周计数可表示到2160年左右
3. **互操作性**：BDT与GPS、Galileo时间系统需保持同步
4. **广播参数**：用户需从导航电文获取最新的Δt_UTC参数
