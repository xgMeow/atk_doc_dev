# 时间转换

## 概述

时间转换是航天任务分析中的基础技术，涉及不同时间系统之间的精确转换。掌握时间转换方法对于轨道计算、星历处理、数据分析和任务规划至关重要。

## 常用转换公式

### TAI为中介

TAI是均匀时间系统，适合作为转换中介：

$$
\begin{aligned}
\text{UTC} &= \text{TAI} - \Delta \text{AT} \\
\text{TT} &= \text{TAI} + 32.184 \text{ s} \\
\text{GPS} &= \text{TAI} - 19 \text{ s} \\
\text{BDT} &= \text{TAI} - 33 \text{ s}
\end{aligned}
$$

### 闰秒表

| 生效日期 | ΔAT (UTC-TAI) |
|----------|---------------|
| 1972-01-01 | -10 |
| 1972-07-01 | -11 |
| 1980-01-01 | -19 |
| 2000-01-01 | -32 |
| 2017-01-01 | -37 |

### JD与常用时间的转换

| 时间系统 | 与JD的关系 |
|----------|------------|
| TT | JD(TT) = JD(TAI) |
| TAI | JD(TAI) = JD |
| UTC | JD(UTC) = JD(TAI) - ΔAT/86400 |
| GPS | JD(GPS) = JD(TAI) - 19/86400 |

## 实现代码

### Python实现

```python
from datetime import datetime, timedelta

# 闰秒表
LEAP_SECONDS = {
    datetime(1972, 1, 1): 10,
    datetime(1972, 7, 1): 11,
    datetime(1980, 1, 1): 19,
    datetime(2000, 1, 1): 32,
    datetime(2017, 1, 1): 37,
}

def utc_to_tai(dt_utc):
    """UTC转TAI"""
    delta_at = get_leap_seconds(dt_utc)
    dt_tai = dt_utc + timedelta(seconds=delta_at)
    return dt_tai

def tai_to_utc(dt_tai):
    """TAI转UTC"""
    delta_at = get_leap_seconds(dt_tai - timedelta(seconds=get_approx_leap(dt_tai)))
    dt_utc = dt_tai - timedelta(seconds=delta_at)
    return dt_utc

def get_leap_seconds(dt):
    """获取指定日期的闰秒数"""
    tai_minus_utc = 0
    for date, offset in sorted(LEAP_SECONDS.items()):
        if dt >= date:
            tai_minus_utc = offset
    return tai_minus_utc

def utc_to_jd(dt_utc):
    """UTC转儒略日"""
    delta_at = get_leap_seconds(dt_utc)
    dt_tai = dt_utc + timedelta(seconds=delta_at)
    
    # 儒略日计算
    y = dt_tai.year
    m = dt_tai.month
    d = dt_tai.day + dt_tai.hour/24 + dt_tai.minute/1440 + dt_tai.second/86400
    
    if m <= 2:
        y -= 1
        m += 12
    
    A = int(y / 100)
    B = 2 - A + int(A / 4)
    
    JD = int(365.25 * (y + 4716)) + int(30.6001 * (m + 1)) + d + B - 1524.5
    return JD

def jd_to_mjd(jd):
    """JD转MJD"""
    return jd - 2400000.5

def mjd_to_jd(mjd):
    """MJD转JD"""
    return mjd + 2400000.5
```

## 地球自转相关转换

### GMST计算

格林尼治平恒星时（GMST）的计算：

对于UTC日期：

$$
\begin{aligned}
T_u &= \frac{JD_{UTC} - 2451545.0}{36525} \\
GMST_0^h &= 280.46061837 + 360.98564736629 \times (JD_0^h - 2451545.0) \\
         &+ 0.000387933 \times T_u^2 - \frac{T_u^3}{38710000}
\end{aligned}
$$

GMST化为360度或24小时制。

### GAST计算

格林尼治视恒星时（GAST）：

$$
GAST = GMST + \Delta \psi \cos \epsilon
$$

其中：
- $\Delta \psi$：黄经章动
- $\epsilon$：平黄赤交角

### ECEF与ECI转换

地球固连系与惯性系之间通过GAST转换：

$$
\vec{r}_{ECEF} = R_z(GAST) \cdot \vec{r}_{ECI}
$$

## 在ATK中的实现

### ATK时间转换函数

```python
from Time import Time, Convert

# 创建时间对象
time_utc = Time("2024-01-01 12:00:00 UTC")
time_tai = Time("2024-01-01 12:00:19 TAI")
time_gps = Time("2024-01-01 12:00:00 GPS")

# 系统间转换
t_utc = time_tai.Convert(UTC)
t_tai = time_utc.Convert(TAI)
t_gps = time_utc.Convert(GPS)
t_tt = time_utc.Convert(TT)
t_bdt = time_utc.Convert(BDT)

# 儒略日转换
t_jd = time_utc.Convert(JD)
t_mjd = time_utc.Convert(MJD)

# 从儒略日创建时间
t_from_jd = Time(2460310.5, JD)
t_from_mjd = Time(60310.0, MJD)
```

### 批量转换

```python
# 时间序列转换
times = [Time(t) for t in range(2460300, 2460320)]
times_utc = [t.Convert(UTC) for t in times]

# 格式化输出
for t in times_utc:
    print(f"JD: {t.Convert(JD):.5f}  MJD: {t.Convert(MJD):.3f}  UTC: {t.Format('ISO')}")
```

### 时区处理

```python
# 本地时间转UTC
local_time = Time("2024-01-01 20:00:00+08:00")
utc_time = local_time.Convert(UTC)

# UTC转本地时间
from TimeZone import TimeZone
beijing = TimeZone("Asia/Shanghai")
local = utc_time.Convert(beijing)
```

## 特殊时间转换

### GPS周计数

```python
def jd_to_gps_week(jd):
    """JD转GPS周和周内秒"""
    GPS_EPOCH_JD = 2444244.5  # 1980-01-06 00:00:00 UTC
    days_since_epoch = jd - GPS_EPOCH_JD
    week = int(days_since_epoch / 7)
    sow = (days_since_epoch % 7) * 86400
    return week, sow

def gps_week_to_jd(week, sow):
    """GPS周和周内秒转JD"""
    GPS_EPOCH_JD = 2444244.5
    days = week * 7 + sow / 86400
    return GPS_EPOCH_JD + days
```

### 儒略世纪

$$
T = \frac{JD - 2451545.0}{36525}
$$

儒略世纪常用于岁差章动计算。

## 注意事项

1. **闰秒处理**：UTC的闰秒会导致时间不连续
2. **日期边界**：儒略日中午12:00的特殊约定
3. **相对论效应**：TT与TDB的差异约为毫秒级
4. **精度要求**：高精度计算需使用完整的时间模型
