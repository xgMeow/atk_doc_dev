# 时间系统概述

## 概述

时间系统是航天任务分析的基础，正确理解和使用各种时间系统对于轨道计算、任务规划、数据处理至关重要。不同应用场景需要使用不同的时间系统，而时间系统之间的精确转换是保证计算准确性的前提。

## 时间系统的基本概念

### 时间尺度

时间尺度（Time Scale）是量化时间流逝的标准。航天领域常用的时间尺度包括：

| 时间尺度 | 说明 | 基准 |
|----------|------|------|
| 原子时 | 基于原子跃迁 | TAI |
| 力学时 | 基于地球轨道运动 | TT/TDB |
| 世界时 | 基于地球自转 | UT1 |

### 时间框架

时间框架（Time Frame）由时间尺度和参考历元组成：

$$
T = t_0 + \Delta t
$$

其中 $t_0$ 是参考历元，$\Delta t$ 是从该历元开始的时间间隔。

## 常用时间系统分类

### 原子时系统

| 时间系统 | 全称 | 说明 |
|----------|------|------|
| **TAI** | 国际原子时 | 铯原子秒定义，均匀时间尺度 |
| **UTC** | 协调世界时 | TAI+闰秒，与地球定向同步 |
| **GPS** | GPS时间 | GPS系统内部时间 |

### 力学时系统

| 时间系统 | 全称 | 说明 |
|----------|------|------|
| **TT** | 大地时 | 地球表面时间的理论基准 |
| **TDT** | 地球动力学时 | TT的旧称，与TT等价 |
| **TDB** | 质心动力学时 | 太阳系质心参考的力学时 |
| **TCG** | 地心坐标时 | 相对论效应修正后的TT |
| **TCB** | 质心坐标时 | 相对论效应修正后的TDB |

### 世界时系统

| 时间系统 | 全称 | 说明 |
|----------|------|------|
| **UT0** | 世界时0 | 原始地球自转时间 |
| **UT1** | 世界时1 | 极移修正后的世界时 |
| **GMST** | 格林尼治视恒星时 | UT1对应的恒星时 |
| **GAST** | 格林尼治视恒星时 | 考虑章动修正的GMST |

### 专用时间系统

| 时间系统 | 说明 | 应用 |
|----------|------|------|
| **BDT** | 北斗时 | 中国北斗卫星导航系统 |
| **GST** | Galileo系统时 | 欧洲伽利略系统 |
| **GLONASS** | GLONASS时间 | 俄罗斯GLONASS系统 |

## 时间系统之间的关系

### TAI是基础

TAI是所有其他时间系统的基础，通过常数偏移建立关系：

$$
\begin{aligned}
\text{UTC} &= \text{TAI} - \Delta \text{AT} \\
\text{GPS} &= \text{TAI} - 19 \text{ s} \\
\text{TT} &= \text{TAI} + 32.184 \text{ s} \\
\text{BDT} &= \text{TAI} - 33 \text{ s}
\end{aligned}
$$

### UTC与闰秒

UTC通过闰秒保持与UT1的同步：

$$
|\text{UTC} - \text{UT1}| < 0.9 \text{ s}
$$

闰秒通常在6月30日或12月31日的23:59:59之后插入。

|----------|-------------|

## 在ATK中的使用

### 时间系统配置

ATK中可配置的时间系统：

```
时间系统：UTC / TAI / TT / TDB / GPS / JD / MJD
```

### 时间格式

ATK支持多种时间格式输入：

| 格式 | 示例 |
|------|------|
| ISO格式 | 2024-01-15 12:00:00.000 |
| 儒略日 | 2460315.0 |
| 修改儒略日 | 60314.5 |
| 相对格式 | 2024-01-15T12:00:00 |

### ATK配置示例

```python
# 设置仿真时间
mission.TimeSystem = UTC
mission.StartTime = "2024-01-01 00:00:00 UTC"
mission.EndTime = "2024-01-02 00:00:00 UTC"

# 时间系统转换
time_utc = Time("2024-01-01 12:00:00 UTC")
time_tt = time_utc.Convert(TT)
time_jd = time_utc.Convert(MJD)

# 轨道输出时间系统
sat.Orbit.TimeSystem = TT
```

### 时间窗口分析

```python
# 创建时间窗口
window = Access.Interval("Coverage_Window")
window.TimeSystem = UTC

# 时间相关约束
constraint = Access.MinElevation(10)
constraint.TimeSystem = UTC
```

## 注意事项

1. **闰秒处理**：进行长期轨道积分时需注意闰秒影响
2. **相对论效应**：深空任务需使用TDB/TCB
3. **时间一致性**：确保所有输入数据使用相同时间系统
4. **精度要求**：高精度任务需使用TT/TDB而非UTC
