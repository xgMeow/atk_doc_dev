# 儒略日与修改儒略日

## 概述

儒略日（Julian Day，JD）和修改儒略日（Modified Julian Day，MJD）是天文和航天领域广泛使用的连续时间计数系统。儒略日以公元前4713年1月1日正午为起点，提供了一种不间断的天数计数方法，特别适用于轨道计算、星历生成和历史天文事件记录。

## 儒略日（JD）

### 定义

儒略日是从公元前4713年1月1日格林尼治正午（12:00 UT）开始计算的连续天数。JD是整数部分表示天数，小数部分表示从正午开始的时间。

### 基本特性

| 特性 | 值 |
|------|-----|
| 起点 | 公元前4713年1月1日 12:00 UT |
| 1天长度 | 86400 SI秒 |
| 连续性 | 连续，无间断 |
| 类型 | 实数 |

### 儒略日的计算

#### 从公历日期计算

对于格里高利历日期（1582年10月15日之后）：

$$
\begin{aligned}
a &= \left\lfloor \frac{14 - \text{month}}{12} \right\rfloor \\
y &= \text{year} + 4800 - a \\
m &= \text{month} + 12a - 3 \\
J &= \text{day} + \left\lfloor \frac{153m + 2}{5} \right\rfloor + 365y \\
  &+ \left\lfloor \frac{y}{4} \right\rfloor - \left\lfloor \frac{y}{100} \right\rfloor + \left\lfloor \frac{y}{400} \right\rfloor - 32045
\end{aligned}
$$

儒略日：

$$
JD = J + \frac{\text{hour} - 12}{24} + \frac{\text{minute}}{1440} + \frac{\text{second}}{86400}
$$

| 1950-01-01 00:00 UT | 2433281.5 |
| 1970-01-01 00:00 UT | 2440587.5 |
| 2024-01-01 00:00 UT | 2460310.5 |

## 修改儒略日（MJD）

### 定义

修改儒略日是为了简化计算，将儒略日减去2400000.5天：

$$
MJD = JD - 2400000.5
$$

### 基本特性

| 特性 | 值 |
|------|-----|
| 起点 | 1858-11-17 00:00 UT |
| 与JD关系 | MJD = JD - 2400000.5 |
| 1天长度 | 86400 SI秒 |
| 日从午夜开始 | 更直观 |

### 常用历元的修改儒略日

| 历元 | MJD |
|------|-----|
| 2000-01-01 12:00 TT | 51544.5 |
| 1950-01-01 00:00 UT | 33281.5 |
| 1970-01-01 00:00 UT | 40587.5 |
| 2024-01-01 00:00 UT | 60310.0 |

## 分秒儒略日

### 约定

不同领域对儒略日的小数起点有不同约定：

| 类型 | 起点 | 说明 |
|------|------|------|
| JD | 中午12:00 | 天文传统 |
| MJD | 午夜00:00 | 便于日常使用 |
| RJD | 午夜00:00 | 美国海军天文台 |
| DJD | 1858-11-04 | Dubna MJD |

### 日期时间转换

```
JD = MJD + 2400000.5
MJD = JD - 2400000.5
```

## 应用场景

### 轨道力学

儒略日是轨道计算的标准时间格式：

```python
# 轨道元素常用MJD表示历元
 kep = [7153.2, 0.0001, 97.5, 250.0, 90.0, 45.0]  # km, -, deg, deg, deg, deg
 kep[0] = 2460310.5  # MJD
```

### 星历数据

DE系列星历使用儒略日作为时间变量：

```python
# JPL星历数据格式
state =ephemeris(position, time=2460310.5, frame='J2000')
```

### 航天任务规划

```python
# 任务时间窗口
window_start = 2460310.0  # MJD
window_end = 2460311.0    # MJD
```

## 在ATK中的使用

### 配置方法

ATK支持儒略日和修改儒略日：

```
时间系统：JD / MJD
```

### ATK配置示例

```python
# 使用儒略日
mission.TimeSystem = JD
mission.StartTime = "2460310.5 JD"

# 使用修改儒略日
mission.TimeSystem = MJD
mission.StartTime = "60310.5 MJD"

# 时间转换
time_jd = Time(2460310.5, JD)
time_mjd = time_jd.Convert(MJD)  # 60310.0

# 从日期字符串创建
time_from_date = Time("2024-01-01 12:00:00 UTC")
jd_value = time_from_date.Convert(JD)
```

### 批量数据处理

```python
# 生成时间序列
times = Time.Generate("2024-01-01 00:00:00", "2024-01-02 00:00:00", step="00:01:00")

# 转换为MJD数组
mjd_array = [t.Convert(MJD) for t in times]

# 轨道数据导出
sat.Orbit.Export("trajectory.csv", TimeFormat="MJD")
```

### 常用转换

```python
# 公历到儒略日
def date_to_jd(year, month, day, hour=0, minute=0, second=0):
    """公历日期转儒略日"""
    import math
    if month <= 2:
        year -= 1
        month += 12
    A = int(year / 100)
    B = 2 - A + int(A / 4)
    JD = int(365.25 * (year + 4716)) + int(30.6001 * (month + 1)) + day + B - 1524.5
    JD += (hour + minute/60 + second/3600) / 24
    return JD

# 儒略日到公历
def jd_to_date(jd):
    """儒略日转公历日期"""
    import math
    jd += 0.5
    Z = int(jd)
    F = jd - Z
    if Z < 2299161:
        A = Z
    else:
        alpha = int((Z - 1867216.25) / 36524.25)
        A = Z + 1 + alpha - int(alpha / 4)
    B = A + 1524
    C = int((B - 122.1) / 365.25)
    D = int(365.25 * C)
    E = int((B - D) / 30.6001)
    day = B - D - int(30.6001 * E) + F
    if E < 14:
        month = E - 1
    else:
        month = E - 13
    if month > 2:
        year = C - 4716
    else:
        year = C - 4715
    hour = (day % 1) * 24
    minute = (hour % 1) * 60
    second = (minute % 1) * 60
    return year, month, int(day), int(hour), int(minute), int(second)
```

## 注意事项

1. **闰年规则**：格里高利历从1582年10月15日开始
2. **夏令时**：儒略日基于UTC，避免夏令时混淆
3. **精度**：浮点数精度足够表示毫秒级时间
4. **历元约定**：J2000历元为JD 2451545.0 TT
