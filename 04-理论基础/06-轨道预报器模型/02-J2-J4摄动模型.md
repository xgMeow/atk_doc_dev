# J2-J4摄动模型

## 概述

J2-J4摄动模型考虑地球非球形引力位中的二阶、三阶和四阶带谐系数，是二体模型的自然扩展。J2摄动是最主要的地球非球形摄动源，它解释了地球赤道鼓起对轨道的长期影响。

## 地球引力位

### 球谐展开

地球引力位的球谐展开：

$$
V = \frac{GM}{r}\left[1 + \sum_{n=2}^{\infty} \left(\frac{R_E}{r}\right)^n \sum_{m=0}^{n} P_{nm}(\sin\phi)(C_{nm}\cos m\lambda + S_{nm}\sin m\lambda)\right]
$$

### 主要系数

| 系数 | 值 | 说明 |
|------|-----|------|
| $J_2$ | 1.08263×10⁻³ | 地球扁率 |
| $J_3$ | -2.54×10⁻⁶ | 梨形不对称 |
| $J_4$ | -1.61×10⁻⁶ | 四极矩 |

## J2摄动加速度

### 加速度公式

$$
\vec{a}_{J2} = \frac{3}{2}J_2\frac{\mu R_E^2}{r^5}\begin{pmatrix}x(5z^2/r^2-1)\\y(5z^2/r^2-1)\\z(5z^2/r^2-3)\end{pmatrix}
$$

### 分量形式

$$
\begin{aligned}
a_x &= \frac{3}{2}J_2\frac{\mu R_E^2}{r^5}x(5z^2/r^2-1) \\
a_y &= \frac{3}{2}J_2\frac{\mu R_E^2}{r^5}y(5z^2/r^2-1) \\
a_z &= \frac{3}{2}J_2\frac{\mu R_E^2}{r^5}z(5z^2/r^2-3)
\end{aligned}
$$

## J2长期效应

### 升交点赤经变化率

$$
\dot{\Omega} = -\frac{3}{2}J_2 n \left(\frac{R_E}{a}\right)^2 \cos i
$$

### 近地点幅角变化率

$$
\dot{\omega} = \frac{3}{4}J_2 n \left(\frac{R_E}{a}\right)^2 (5\cos^2 i - 1)
$$

### 周期变化

| 参数 | J2效应 |
|------|--------|
| $a$ | 0 |
| $e$ | 0 |
| $i$ | 0 |
| $\Omega$ | 线性变化 |
| $\omega$ | 线性变化 |

## 特殊倾角的J2效应

### 临界倾角

当 $5\cos^2 i - 1 = 0$ 时，$\dot{\omega} = 0$：

$$
i_c = \arccos\left(\frac{1}{\sqrt{5}}\right) \approx 63.43°
$$

### 太阳同步条件

对于太阳同步轨道：

$$
\dot{\Omega} = \frac{360°}{\text{太阳年}} \approx 0.9856°/\text{天}
$$

解得：

$$
\cos i = -\frac{2\dot{\Omega}}{3J_2n}\left(\frac{a}{R_E}\right)^2
$$

## J3摄动

### 主要效应

- **近地点位置漂移**
- **轨道面不对称**

### J3对 $\dot{\omega}$ 的贡献

$$
\dot{\omega}_{J3} \propto J_3 \sin i \frac{\sin^2 i - \frac{3}{5}\sin^2 i \cos^2 i}{\ldots}
$$

## J4摄动

### 主要效应

- **轨道面曲率修正**
- **更精细的长期效应**

### J4对 $\dot{\Omega}$ 和 $\dot{\omega}$ 的修正

$$
\begin{aligned}
\dot{\Omega}_{J4} &= -\frac{15}{8}J_4 n \left(\frac{R_E}{a}\right)^4 \cos i (7\cos^2 i - 1) \\
\dot{\omega}_{J4} &= \frac{15}{32}J_4 n \left(\frac{R_E}{a}\right)^4 (7\cos^2 i - 1)(5\cos^2 i - 3)
\end{aligned}
$$

## 在ATK中的使用

### 配置方法

```python
# J2摄动模型
sat.Propagator.Type = "J2"
sat.Propagator.J2 = True

# J2-J4摄动模型
sat.Propagator.Type = "J2-J4"
sat.Propagator.J2 = True
sat.Propagator.J3 = True
sat.Propagator.J4 = True

# 设置地球参数
sat.Propagator.CentralBody = "Earth"
sat.Propagator.J2Coefficient = 1.08263e-3
sat.Propagator.J3Coefficient = -2.54e-6
sat.Propagator.J4Coefficient = -1.61e-6
sat.Propagator.ReferenceRadius = 6378.137  # km
```

### 轨道初始化

```python
# 太阳同步轨道
sat.Orbit.Type = "Keplerian"
```

```python
# 获取升交点赤经变化
```

### 计算冻结轨道

```python
# 计算冻结轨道倾角
def frozen_inclination(a):
    """计算给定半长轴的冻结轨道倾角"""
    mu = 398600.4418
    n = sqrt(mu / a**3)
    J2 = 1.08263e-3
    RE = 6378.137
    cos_i = -2 * 0.9856 / (3 * J2 * n) * (RE / a)**2
    return arccos(cos_i) * 180 / pi

a = 26558  # km (导航轨道)
i_frozen = frozen_inclination(a)
print(f"冻结轨道倾角: {i_frozen:.2f} deg")
```

## 应用场景

| 应用 | 模型选择 | 说明 |
|------|----------|------|
| 概念设计 | J2 | 快速估算 |
| 轨道维持 | J2-J4 | 精确计算 |
| 编队设计 | J2 | 长期漂移分析 |
| 导航轨道 | J2-J4 | 轨道保持 |

## 注意事项

1. **模型精度**：J2-J4模型是近似模型
2. **高阶效应**：高精度需使用HPOP
3. **共振效应**：特定轨道周期可能产生共振
4. **大气阻力**：LEO轨道还需考虑大气阻力
5. **数值积分**：长期积分需使用数值方法
