# 二体运动

## 概述

二体运动（Two-Body Problem）是最基础的轨道力学模型，假设只考虑一个天体（中心天体）对另一个天体（卫星）的引力作用，忽略其他所有摄动力。二体运动是理解轨道力学的基础，也是高精度轨道计算的重要近似。

## 基本方程

### 万有引力定律

$$
\vec{F} = -\frac{GMm}{r^3}\vec{r}
$$

其中：
- $G$ 为万有引力常数
- $M$ 为中心天体质量
- $m$ 为卫星质量
- $\vec{r}$ 为位置矢量

### 运动方程

$$
\ddot{\vec{r}} = -\frac{\mu}{r^3}\vec{r}
$$

其中 $\mu = GM$ 为引力常数。

## 开普勒定律

### 第一定律（椭圆轨道）

卫星在中心天体的引力作用下，沿椭圆轨道运动，中心天体在椭圆的一个焦点上。

### 第二定律（面积速度）

卫星与中心天体的连线在相等时间内扫过相等的面积：

$$
\frac{dA}{dt} = \frac{h}{2} = \text{常数}
$$

### 第三定律（周期定律）

轨道周期的平方与半长轴的立方成正比：

$$
T^2 = \frac{4\pi^2}{GM}a^3
$$

## 轨道积分

### 位置速度关系

对于给定的轨道根数 $(a, e)$：

$$
\vec{r} = \frac{a(1-e^2)}{1+e\cos\nu}\hat{r}
$$

$$
\dot{r} = \sqrt{\frac{\mu}{a(1-e^2)}}e\sin\nu
$$

### 能量方程

$$
\epsilon = \frac{v^2}{2} - \frac{\mu}{r} = -\frac{\mu}{2a}
$$

### 角动量

$$
|\vec{h}| = |\vec{r} \times \dot{\vec{r}}| = \sqrt{\mu a(1-e^2)}
$$

## 轨道周期

### 平均角速度

$$
n = \sqrt{\frac{\mu}{a^3}}
$$

### 周期公式

$$
T = \frac{2\pi}{n} = 2\pi\sqrt{\frac{a^3}{\mu}}
$$

### 地球轨道的特例

对于地球（$\mu = 398600.4418$ km³/s²）：

$$
T \approx 1.658 \times 10^{-4} \sqrt{a^3} \text{ min}
$$

| 半长轴(km) | 周期(分钟) | 轨道类型 |
|------------|------------|----------|
| 6678 | 90 | LEO |
| 42164 | 1440 | GEO |
| 93890 | 1440(恒星时) | Moon |

## 速度公式

### 活力公式

$$
v^2 = \mu\left(\frac{2}{r} - \frac{1}{a}\right)
$$

### 特殊情况

| 位置 | 速度 |
|------|------|
| 近地点 | $v_p = \sqrt{\frac{\mu(1+e)}{a(1-e)}}$ |
| 远地点 | $v_a = \sqrt{\frac{\mu(1-e)}{a(1+e)}}$ |
| 圆轨道 | $v_c = \sqrt{\frac{\mu}{a}}$ |

## 逃逸速度

### 圆轨道逃逸

从圆轨道逃逸所需的速度：

$$
v_{escape} = \sqrt{\frac{2\mu}{r}} = \sqrt{2} v_c
$$

### 能量关系

| 轨道类型 | 总能量 $\epsilon$ | 速度关系 |
|----------|------------------|----------|
| 圆轨道 | $-\mu/2a$ | $v = v_c$ |
| 椭圆轨道 | $-\mu/2a$ | $v_c < v < v_{escape}$ |
| 抛物线轨道 | $0$ | $v = v_{escape}$ |
| 双曲线轨道 | $>0$ | $v > v_{escape}$ |

## 在ATK中的使用

### 二体运动配置

```python
# 设置为二体运动
sat.Propagator.Type = "TwoBody"

# 仅考虑中心引力
sat.Propagator.PointMass = True

# 设置引力常数（使用地球）
sat.Propagator.CentralBody = "Earth"
sat.Propagator.Mu = 398600.4418  # km³/s²
```

### 轨道初始化

```python
# 设置初始状态
sat.Orbit.Type = "StateVector"
sat.Orbit.Position = [6678, 0, 0]  # km
sat.Orbit.Velocity = [0, 7.612, 0]  # km/s

# 或使用开普勒根数
sat.Orbit.Type = "Keplerian"
sat.Orbit.SemiMajorAxis = 6678  # km
sat.Orbit.Eccentricity = 0.0
sat.Orbit.Inclination = 28.5  # deg
```

### 轨道传播

```python
# 运行仿真
mission.StartTime = "2024-01-01 00:00:00 UTC"
mission.Duration = "1 day"
mission.Propagate()

# 获取位置和速度
position = sat.Orbit.Position(time)
velocity = sat.Orbit.Velocity(time)
```

### 分析工具

```python
# 计算轨道参数
orbit_elements = sat.Orbit.GetElements()
print(f"半长轴: {orbit_elements.SemiMajorAxis} km")
print(f"周期: {orbit_elements.Period} min")

# 计算逃逸速度
escape_vel = sat.Orbit.EscapeVelocity(position)
print(f"逃逸速度: {escape_vel} km/s")
```

## 应用场景

| 场景 | 适用性 | 说明 |
|------|--------|------|
| 概念设计 | ✓ | 快速估算轨道参数 |
| 初轨计算 | ✓ | 近似轨道确定 |
| 精密轨道 | ✗ | 需考虑摄动 |
| 轨道转移 | △ | 瞬时冲量近似 |
| 编队飞行 | △ | 线性化近似 |

## 注意事项

1. **摄动忽略**：二体模型不考虑地球非球形、大气阻力等
2. **精度限制**：长期积分误差累积
3. **适用条件**：仅适用于近圆轨道
4. **坐标系**：确保使用正确的惯性坐标系
5. **简化分析**：高精度任务需使用HPOP等模型
