J2-J4摄动模型

概述

J2-J4摄动模型考虑地球非球形引力位中的二阶、三阶和四阶带谐系数，是二体模型的自然扩展。J2摄动是最主要的地球非球形摄动源，它解释了地球赤道鼓起对轨道的长期影响。

地球引力位

球谐展开

地球引力位的球谐展开：

(1)V=GMr[1+∑n=2∞(REr)n∑m=0nPnm(sin⁡ϕ)(Cnmcos⁡mλ+Snmsin⁡mλ)]

系数值说明
J21.08263×10⁻³地球扁率
J3-2.54×10⁻⁶梨形不对称
J4-1.61×10⁻⁶四极矩

在ATK中的使用

配置方法

# J2摄动模型
sat.Propagator.Type = "J2"
sat.Propagator.J2 = True

# J2-J4摄动模型
sat.Propagator.Type = "J2-J4"
sat.Propagator.J2 = True
sat.Propagator.J3 = True
sat.Propagator.J4 = True

# 设置地球参数
sat.Propagator.CentralBody = "Earth"
sat.Propagator.J2Coefficient = 1.08263e-3
sat.Propagator.J3Coefficient = -2.54e-6
sat.Propagator.J4Coefficient = -1.61e-6
sat.Propagator.ReferenceRadius = 6378.137  # km

轨道初始化

# 太阳同步轨道
sat.Orbit.Type = "Keplerian"
sat.Orbit.SemiMajorAxis = 7178  # km
sat.Orbit.Eccentricity = 0.0
sat.Orbit.Inclination = 98.6  # deg (太阳同步倾角)

# 运行仿真
mission.Propagate()

分析升交点漂移

# 获取升交点赤经变化
initial_raan = sat.Orbit.RAAN(time_start)
final_raan = sat.Orbit.RAAN(time_end)
drift_rate = (final_raan - initial_raan) / (time_end - time_start)

print(f"升交点漂移率: {drift_rate} deg/day")
print(f"J2理论值: {calc_j2_raan_drift(sat.Orbit):.4f} deg/day")

计算冻结轨道

# 计算冻结轨道倾角
def frozen_inclination(a):
    """计算给定半长轴的冻结轨道倾角"""
    mu = 398600.4418
    n = sqrt(mu / a**3)
    J2 = 1.08263e-3
    RE = 6378.137
    cos_i = -2 * 0.9856 / (3 * J2 * n) * (RE / a)**2
    return arccos(cos_i) * 180 / pi

a = 26558  # km (导航轨道)
i_frozen = frozen_inclination(a)
print(f"冻结轨道倾角: {i_frozen:.2f} deg")

注意事项

  1. 模型精度：J2-J4模型是近似模型
  2. 高阶效应：高精度需使用HPOP
  3. 共振效应：特定轨道周期可能产生共振
  4. 大气阻力：LEO轨道还需考虑大气阻力
  5. 数值积分：长期积分需使用数值方法
