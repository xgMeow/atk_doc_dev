综合案例板块汇集了 ATK 在航天任务分析与设计中的典型应用，覆盖轨道机动规划、偏差演化分析、星座覆盖评估、碎片解体模拟以及相对绕飞等多个领域。案例基于 Connect 脚本模式、Component 组件模式等不同开发方式，使用 C++、MATLAB 等语言实现，展示了从问题建模、仿真计算到结果分析的全流程，为用户深入掌握 ATK 各项功能提供参考。
