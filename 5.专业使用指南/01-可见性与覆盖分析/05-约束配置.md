# 约束配置


在卫星通信、目标观测、指令发送等任务中，会受到包括视线遮挡、载荷活动范围、载荷作用距离等多种约束，只有在满足特定约束的情况下，两个对象才能够被判定为“可见”，从而执行信息传输、侦察拍照等任务。

根据约束类型不同，可将其分为基础约束、光照约束、通信约束三大类。

#### 基础约束

基础约束涵盖了任务分析与设计中最常考虑的两对象间的几何关系条件，包含方位角、仰角、距离等空间几何参数，以及视线、视场约束。

**几何参数**

|     参数名称     | 含义                                                         |
| :--------------: | :----------------------------------------------------------- |
| 方位角 (Azimuth) | 关联对象相对于访问对象在水平面上的投影方向角，表征关联对象相对于访问对象的空间方位 |
| 仰角 (Elevation) | 关联对象相对于访问对象在垂直方向的角度，表征关联对象相对于访问对象的高度关系 |
|   距离 (Range)   | 访问对象与关联对象之间的直线距离                             |
|   方位角变化率   | 方位角随时间的变化率                                         |
|    仰角变化率    | 仰角随时间的变化率                                           |
|    距离变化率    | 距离随时间的变化率                                           |
|   视线角变化率   | 表征关联对象相对访问对象的旋转速度，可用于判断通信链路的稳定性 |
|       高度       | 访问对象与关联对象建立"可见"关系时相对地面的高度约束         |
|     传播延时     | 访问对象和关联对象之间传输信息所需的时间                     |

**视线约束**

视线约束主要用于分析中心天体（如地球）遮挡导致的对象间不可见的情况，表征中心天体对对象可视关系的遮挡程度。

**视场约束**

视场约束与其所属传感器对象一一对应，该约束由传感器的特征角度决定，用于判断目标是否在传感器的可视范围内。

#### 光照约束

光照约束包含太阳、月球与所属对象的几何位置相关指标。

|    参数名称    | 含义                                                         |
| :------------: | :----------------------------------------------------------- |
|   太阳高度角   | 太阳相对访问对象的视位置高度角                               |
|   月球高度角   | 月球相对访问对象的视位置高度角                               |
| 当地太阳高度角 | 定义在地面站等地面对象的当地坐标系下的太阳高度角             |
|   太阳规避角   | 视线或视轴方向与太阳方向的最小夹角，用于某些传感器需要躲避太阳光的场景 |
|   月球规避角   | 视线或视轴方向与月球方向的最小夹角                           |

**太阳/月球规避角含义**

|    名称    | 含义                                                         |
| :--------: | :----------------------------------------------------------- |
| 视线规避角 | 指向关联对象的视线矢量与太阳/月球矢量之间的最小夹角，小于该角则视为访问无效 |
| 视轴规避角 | 视轴矢量与太阳/月球矢量之间的最小夹角，小于该角则视为访问无效 |

> [!NOTE]
> **操作步骤**：双击对象 → 进入 **【属性】** 页面 → 在 **【约束】** 选项卡中配置对应的约束参数。
