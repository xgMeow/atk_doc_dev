# 约束配置

在卫星通信、目标观测、指令发送等任务中，对象之间的可见性会受到多种约束条件的限制，例如视线遮挡、载荷活动范围、作用距离等。只有在满足特定约束的前提下，两个对象才能被判定为“可见”，进而执行信息传输、侦察拍照等任务。

根据约束类型的不同，可将其分为四大类：**基本约束**、**光照约束**、**时间约束** 和 **通信约束**。

## 基本约束

基本约束涵盖了任务分析与设计中最常考虑的两对象间的几何关系条件，包括方位角、仰角、距离等空间几何参数，以及视线、视场、地形约束。

### 几何参数

| 参数名称 | 含义 |
| :---: | --- |
| 方位角 | 关联对象相对于访问对象在水平面上的投影方向角，表征关联对象相对于访问对象的空间方位。 |
| 仰角 | 关联对象相对于访问对象在垂直方向的角度，表征两者之间的高度关系。 |
| 距离 | 访问对象与关联对象之间的直线距离。 |
| 方位角变化率 | 方位角随时间的变化率。 |
| 仰角变化率 | 仰角随时间的变化率。 |
| 距离变化率 | 距离随时间的变化率。 |
| 角变化率 | 关联对象相对于访问对象的旋转速度，可用于判断通信链路的稳定性。 |
| 高度 | 访问对象与关联对象建立可见关系时相对地面的高度约束。 |
| 传播延时 | 访问对象和关联对象之间传输信息所需的时间。 |

### 视线约束

视线约束主要用于分析中心天体（如地球）遮挡导致的对象间不可见的情况，表征中心天体对对象可视关系的遮挡程度。

### 视场约束

视场约束与传感器对象一一对应，由传感器的特征角度决定，用于判断目标是否在传感器的可视范围内。

### 地形约束

地形约束用于考虑地形高程对传感器观测、对象可见性及覆盖性的影响。该约束通过判断传感器与目标之间的视线是否被地形遮挡，确定目标在当前几何条件下是否可见。

## 光照约束

光照约束用于描述太阳、月球与分析对象之间的相对几何关系，并根据高度角、地平仰角、规避角以及附加中心天体遮挡等条件判断访问是否有效。该类约束常用于卫星观测、地面站可见性分析、传感器避光约束以及第三天体遮挡分析等场景。

| 参数名称 | 含义 |
| :---: | --- |
| 太阳仰角 | 太阳相对于分析对象的视位置高度角，由分析对象位置矢量与太阳相对分析对象的位置矢量共同确定，用于判断太阳在分析对象视几何中的高度关系。 |
| 太阳地平仰角 | 太阳在地面站等地面对象当地坐标系下相对于当地水平面的高度角，通常用于判断地面对象所在位置的太阳高度状态（如白昼、夜间或低太阳高度角条件）。 |
| 月球仰角 | 月球相对于分析对象的视位置高度角，用于描述月球在分析对象视几何中的高度关系，可用于月球可见性或月球规避相关分析。 |
| 视线太阳规避角 | 指向目标对象的视线矢量与太阳方向矢量之间的最小夹角。当实际夹角小于设定值时，认为太阳方向过近，当前访问无效。适用于避免太阳进入观测视线附近的场景。 |
| 视线月球规避角 | 指向目标对象的视线矢量与月球方向矢量之间的最小夹角。当实际夹角小于设定值时，认为月球方向过近，当前访问无效。 |
| 视轴太阳规避角 | 传感器视轴方向矢量与太阳方向矢量之间的最小夹角。当实际夹角小于设定值时，认为传感器视轴过于接近太阳方向，当前访问无效。常用于光学传感器避光分析。 |
| 视轴月球规避角 | 传感器视轴方向矢量与月球方向矢量之间的最小夹角。当实际夹角小于设定值时，认为传感器视轴过于接近月球方向，当前访问无效。 |
| 附加中心天体遮挡 | 用于设置除默认中心天体以外是否考虑其他中心天体遮挡。可从可用中心天体列表中选择需要参与遮挡判断的天体，加入“已选中心天体”。被选中的中心天体将在访问分析中作为附加遮挡体参与可见性判断。 |

## 时间约束

时间约束用于限定访问分析或覆盖分析在时间维度上的有效范围。通过设置开始时间、结束时间、持续时长或指定时段文件，可以控制对象之间访问关系的有效计算区间，从而筛选满足任务时间要求的访问结果。

| 参数名称 | 含义 |
| :---: | --- |
| 开始时间 | 访问或覆盖分析的起始时刻。只有晚于或等于该时间的访问结果才被认为满足时间约束。 |
| 结束时间 | 访问或覆盖分析的终止时刻。只有早于或等于该时间的访问结果才被认为满足时间约束。 |
| 最小时长 | 一次有效访问或覆盖持续时间的下限。若访问时长小于该值，则不满足时间约束。 |
| 最大时长 | 一次有效访问或覆盖持续时间的上限。若访问时长大于该值，则不满足时间约束。 |
| 时段 | 一个或多个有效时间区间。只有落入指定时段内的访问结果才被认为满足时间约束。 |
| 间隔文件 | 通过外部文件导入有效时段或无效时段。系统根据文件中定义的时间间隔对访问结果进行筛选。 |

## 通信约束

通信约束用于分析发射器与接收器之间的通信链路是否满足指定条件。该类约束通常适用于卫星通信、星间链路、地面站通信、遥测遥控链路以及数据传输任务等场景。

在访问分析过程中，系统可根据链路频率、接收功率、信噪比、误码率、链路裕量、多普勒频移等指标判断当前通信链路是否可用。若链路参数满足设定的最大值、最小值或取值范围，则认为该访问满足通信约束；否则判定为无效访问。

通信约束当前仅与发射器对象和接收器对象相关。

| 参数名称 | 含义 |
| :---: | --- |
| 频率 | 通信链路所使用的工作频率。可按波段或数值范围设置，用于限制链路必须工作在指定频率范围内。 |
| 波段 | 按通信频段对链路进行筛选，例如 L、S、C、X、Ku、Ka 等波段。具体可选项以软件界面提供的波段范围为准。 |
| 接收到的各向同性功率 | 假设接收端为理想各向同性天线时能够接收到的功率水平，用于评价信号到达接收端附近时的强弱。 |
| 通量密度 | 单位面积上接收到的电磁波功率密度，描述信号在接收位置处的空间功率分布强度。 |
| 链路等效各向同性辐射功率 | 发射端沿链路方向等效辐射出的功率水平，通常与发射功率和发射天线增益有关。该值越大，说明发射端在该方向上的等效辐射能力越强。 |
| 多普勒频移 | 由于发射器与接收器之间存在相对运动而引起的接收频率偏移，常用于高速运动平台之间的通信链路分析。 |
| C/No | 载波功率与噪声功率谱密度之比，用于衡量接收信号相对于噪声背景的强弱，是通信链路质量的重要指标。 |
| 接收机输入功率 | 进入接收机前端的信号功率。该值过低可能导致接收困难，过高则可能引起接收机饱和或非线性失真。 |
| C/N | 载波功率与噪声功率之比，用于评价接收信号在指定带宽内的信噪水平。 |
| 误码率 | 通信过程中错误比特数占总传输比特数的比例。误码率越低，通信质量越好。 |
| 链路裕量 | 链路实际性能相对于最低通信需求的余量。链路裕量为正通常表示链路具备一定可靠性，裕量不足则可能导致通信中断或质量下降。 |
| Eb/No | 每比特能量与噪声功率谱密度之比，用于衡量数字通信系统的抗噪声能力，常与误码率一起评价数据链路性能。 |
| 极化相对角 | 发射天线与接收天线极化方向之间的相对夹角。极化不匹配会造成极化损耗，从而降低接收信号强度。 |
| 天线性能品质因子 | 接收天线系统的综合性能，通常与天线增益和系统噪声温度有关。该值越高，说明接收系统对微弱信号的接收能力越强。 |
| 反向选择 | 对当前约束条件进行逻辑取反。启用后，原本满足约束范围的访问将被排除，原本不满足约束范围的访问将被保留。 |

::: note 操作步骤
双击对象 → 进入 **【属性】** 页面 → 在 **【约束】** 选项卡中配置对应的约束参数。
:::
