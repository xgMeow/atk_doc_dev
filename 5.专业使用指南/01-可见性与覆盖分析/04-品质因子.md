# 品质因子

品质因子（FOM, Figure of Merit）是覆盖分析的核心机制，用于对覆盖、访问、导航、通信等任务效果进行量化评估。ATK 支持 16 种品质因子，涵盖**覆盖时间**、**系统响应**、**导航定位**和**访问约束**四大类，通过统一的属性配置界面进行设置。

品质因子适用于**覆盖性工具**和**区域覆盖分析工具**，其属性设置包括 **基本属性** 和 **二维视图** 两部分。

---

## 基本属性

品质因子的基本属性配置包含四个部分：

|    配置项    |                     说明                     |
|:------------:|:--------------------------------------------:|
|     定义     | 选择品质因子类型、统计参数类型及类型特有参数 |
|   有效条件   |    在可见性约束之上进一步筛选有效覆盖窗口    |
| 无效数据指标 |      当特定条件不满足时赋予指定的无效值      |
|  有效值限制  |        对计算结果施加额外的上下限约束        |

### 定义

定义选项卡用于选择品质因子类型并指定计算参数，主要配置项包括：

- **类型**：从 16 种品质因子中选择
- **统计参数类型**：选择需要计算的统计值，不同品质因子类型对应不同的统计值选项
- **类型特有参数**：部分类型需要额外设置，例如：
  - 重访时间：设置最少重数
  - 精度衰减因子：选择子方法和计算类型

### 有效条件

有效条件用于在可见性约束之上进一步筛选覆盖窗口。

例如，若需要分析"被至少 2 个资源同时覆盖"的时段，可将"类型"设为"多重覆盖"，有效条件启用，并设定为"大于"有效值"2"。

### 无效数据指标

某些品质因子需要特定条件才能进行计算。当条件不满足时，系统会赋予一个指定的无效值，以区分"无效"和"零覆盖"。

例如，"几何精度定位因子"的计算需要实现至少 3 重的覆盖，对于小于 3 重覆盖的时间段，其品质因子始终显示为设定的无效值。

### 有效值限制

有效值限制提供了计算模型限制以外的约束。当覆盖情况满足品质因子的计算模型要求，但不在"有效值限制"所定义的范围内时，该值会被认为是一个无效值。

::: tip
分析完成后，品质因子结果可通过**数据报告**和**图表报告**输出，部分类型还支持在二维/三维视图中以**热力图**或**动态数据**形式展示。
:::

## 二维视图

支持 **动态** 与 **静态** 两种显示模式，两类模式均包含：

- **是否显示对应图像**：控制是否在视图中显示品质因子值
- **显示网格点设置**：配置品质因子的网格点显示选项
- **显示指标设置**：配置品质因子的显示指标及属性

## 品质因子类型

### 覆盖时间指标

| 覆盖品质类型 |                             含义                             |
|:------------:|:------------------------------------------------------------:|
|   简单覆盖   | 该目标在计算时段内是否被覆盖（1 表示可覆盖，0 表示不可覆盖） |
|   访问时长   |               单个资源对分析对象的可用覆盖时间               |
|   访问间隔   |     不同覆盖资源的覆盖时段间隔是否在设定的最大最小范围内     |
|   覆盖时间   |                    分析对象被覆盖的总时长                    |
|   多重覆盖   |                      对目标点的覆盖重数                      |
|   访问次数   |                     分析对象被覆盖的次数                     |
| 覆盖间隔次数 |                 分析时段内未被覆盖的时段数量                 |
|   响应时间   |             当前时刻距离下一次覆盖开始时间的间隔             |
|   重访时间   |                    两次覆盖之间的时间间隔                    |
| 时间平均间隔 |              在任意时刻位于一个覆盖间隔内的概率              |
|   数据时龄   |             当前时刻距离上一次覆盖结束时刻的间隔             |

### 系统响应指标

| 覆盖品质类型 |                             含义                             |
|:------------:|:------------------------------------------------------------:|
| 系统响应时间 |         从请求覆盖某个点到获取覆盖资源数据之间的时间         |
| 系统数据时龄 | 从最后一个满足任务序列要求的数据采集时段结束到当前时间的间隔 |

::: tip
系统响应时间和系统数据时龄需要额外配置系统分析对象（指令对象、接收对象、是否允许交叉传输）以及各阶段时长参数（指令准备时间、指令传输时间、数据准备时间、数据收集时间、数据处理时间、下传时间）。
:::

### 导航定位指标

| 覆盖品质类型 |                              含义                              |
|:------------:|:--------------------------------------------------------------:|
| 精度衰减因子 | 衡量用户在进行全球导航卫星系统测量时所具备的几何条件的定量指标 |
|   导航精度   |    基于一组发射器的单向距离测量，评估导航解决方案的不确定性    |

::: tip
精度衰减因子支持多种子方法，包括 GDOP、PDOP、VDOP、HDOP、TDOP 等，可在配置界面的【定义 - 方法】中选择。导航精度同样支持多种子方法（GACC、PACC、VACC、HACC、TACC），也可在配置界面的【定义 - 方法】中选择。
:::

### 访问约束

| 覆盖品质类型 |                         含义                         |
|:------------:|:----------------------------------------------------:|
|  可见性约束  | 在覆盖时段内，计算对象与分析对象之间的可见性参数约束 |

## 品质因子统计值

### 访问时长统计值

|    名称    |                            含义                           |
|:----------:|:---------------------------------------------------------:|
|   平均值   |            分析时段内，所有覆盖时段长度的平均值           |
|   最大值   |                分析时段内的最大覆盖时段长度               |
|   最小值   |                分析时段内的最小覆盖时段长度               |
| 百分比高于 | 假设所设比例为X，该统计值为V，表示访问时长有X%的时间高于V |
|   标准差   |              分析时段内，所有覆盖时长的标准差             |
|    总和    |              分析时段内所有覆盖时段的长度之和             |

### 覆盖时间统计值

|       名称       |                                           含义                                          |
|:----------------:|:---------------------------------------------------------------------------------------:|
|     每日最大     |                               每个UTC日内被覆盖的最大时长                               |
|  每日最大百分比  |                             每个UTC日内被覆盖的最大时长占比                             |
|     每日最小     |                               每个UTC日内被覆盖的最短时长                               |
|  每日最小百分比  |                             每个UTC日内被覆盖的最短时长占比                             |
|       每日       |                                    每天的平均覆盖时间                                   |

|      百分比      |                                总覆盖时长占分析时段的比例                               |

## 在覆盖性工具中使用

在覆盖性工具中，品质因子通过分析窗口右侧的【品质参数】区域进行配置：

1. 点击【定义...】，进入品质参数配置界面
2. 设置品质因子类型、统计参数及有效条件等
3. 执行覆盖计算后，通过报告输出区域生成品质因子相关报告

完整操作流程详见 [覆盖性工具](02-覆盖性工具.md)。

## 在区域覆盖分析工具中使用

在区域覆盖分析工具中，品质因子作为【覆盖定义】对象的子对象进行管理：

1. 点击 <kbd>插入</kbd>，选择【附加对象 - 品质因子】，选择【插入默认类型】，点击【插入...】
2. 在弹出的窗口中选择所属的【覆盖定义】对象
3. 双击【品质因子】对象，配置类型和参数
4. 执行区域覆盖计算后，通过报告输出区域生成品质因子相关报告

::: warning
在生成品质因子报告或图表前，应确保覆盖定义对象下已配置相应的品质因子，且区域覆盖计算已经完成。若未配置品质因子，或覆盖分析结果为空，则相关报告或图表可能无法生成有效数据。
:::

完整操作流程详见 [区域覆盖分析](03-区域覆盖分析.md)。
