# 品质因子

品质因子用于对覆盖、访问、导航、通信等任务效果进行量化评估，属性设置包括 **基本属性** 和 **二维视图** 两部分。

---

## 基本属性

用于定义评估规则与计算方式，主要配置项：

- 定义类型设置
- 有效条件设置
- 无效数据指标设置
- 有效值限制

---

## 品质因子类型

覆盖分析工具支持 16 类覆盖品质参数：

| 覆盖品质类型 | 含义 |
| :----------: | :----------------------------------------------------------: |
| 简单覆盖 | 该目标在计算时段内是否被覆盖（1 表示可覆盖，0 表示不可覆盖） |
| 访问时长 | 单个资源对分析对象的可用覆盖时间 |
| 访问间隔 | 不同覆盖资源的覆盖时段的间隔是否在设定的最大最小范围内 |
| 覆盖时间 | 分析对象被覆盖的时长 |
| 多重覆盖 | 对目标点的覆盖重数 |
| 访问次数 | 分析对象被覆盖的次数 |
| 覆盖间隔次数 | 在分析时段内未被覆盖的时段数量 |
| 响应时间 | 当前时刻距离下一次覆盖开始时间的间隔 |
| 重访时间 | 两次可覆盖的时间间隔 |
| 时间平均间隔 | 在任意时刻位于一个覆盖间隔内的概率 |
| 数据时龄 | 当前时刻距离上一次覆盖结束时刻的间隔 |
| 系统响应时间 | 从请求覆盖某个点到获取覆盖资源数据之间的时间 |
| 系统数据时龄 | 从最后一个满足数据下传等任务序列要求的数据采集时段结束到当前时间的间隔 |
| 精度衰减因子 | 衡量用户在进行全球导航卫星系统测量时所具备的几何条件的定量指标 |
| 导航精度 | 基于一组发射器测量的单向距离测量，测量导航解决方案的不确定性 |
| 可见性约束 | 计算对象与分析对象的可见性参数约束 |

## 品质因子统计值

### 访问时长统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 分析时段内，所有覆盖时段长度的平均值 |
| 最大值 | 分析时段内的最大覆盖时段长度 |
| 最小值 | 分析时段内的最小覆盖时段长度 |
| 百分比高于 | 假设所设比例为X，该统计值为V，表示访问时长有X%的时间高于V |
| 标准差 | 分析时段内，所有覆盖时长的标准差 |
| 总和 | 分析时段内所有覆盖时段的长度之和 |

### 覆盖时间统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 每日最大 | 每个UTC日内被覆盖的最大时长 |
| 每日最大百分比 | 每个UTC日内被覆盖的最大时长占比 |
| 每日最小 | 每个UTC日内被覆盖的最短时长 |
| 每日最小百分比 | 每个UTC日内被覆盖的最短时长占比 |
| 每日 | 每天的平均覆盖时间 |
| 每日标准差 | 每个UTC日内被覆盖总时间的标准差 |
| 百分比 | 总覆盖时长占分析时段的比例 |
| 每日百分比 | 每天的平均覆盖时长占比 |
| 每日百分比标准差 | 每个UTC日内被覆盖时长比例的标准差 |
| 百分比时间高于 | 假设所设重数为N，该统计值为X，表示在分析时段内，分析对象有V%的时间被至少N个覆盖资源覆盖 |
| 总计 | 总覆盖时长 |
| 总计时间高于 | 假设所设重数为N，表示在分析时段内，分析对象被至少N个覆盖资源覆盖的时段长度之和 |

### 多重覆盖统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 分析时段内，同时覆盖的资源数量的平均值 |
| 最大值 | 分析时段内，同时覆盖的资源数量的最大值 |
| 最小值 | 分析时段内，同时覆盖的资源数量的最小值 |
| 百分比高于 | 假设所设比例为X，该统计值为V，表示覆盖重数有X%的时间高于V |

### 访问次数统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 每日平均 | 总访问次数与分析天数的比例，表征了平均每天的访问次数 |
| 在范围内 | 在所设定的最小、最大时长范围内的覆盖时段的数量 |
| 每日在范围内 | 满足所设定的最小、最大时长范围的时段数量与分析天数的比例，表征平均每天的满足条件的访问次数 |
| 每日最大 | 在UTC日中，每天最多被覆盖的次数 |
| 每日最小 | 在UTC日中，每天最少被访问的次数 |
| 总计 | 在分析时段内，分析对象被覆盖的总次数 |

### 重访时间统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 两次被覆盖间隔的平均值，表示为所有覆盖间隔时段长度之和与覆盖间隔次数的比例 |
| 最大值 | 分析时段内的最大覆盖间隔 |
| 最小值 | 分析时段内的最小覆盖间隔 |
| 百分比低于 | 假设所设比例为X，该统计值为V，在X%的时间范围内，重访时间都低于V |
| 间隔时间百分比低于 | 假设所设比例为X，该统计值为V，表示在覆盖间隔的时段内，在X%的时间范围内，重访时间都低于V |
| 百分比低于的值 | 假设所设比例为X，该统计值为V，表示在所有覆盖间隔中，有X%数量的覆盖间隔时长低于V |
| 标准差 | 所有覆盖间隔时段长度的标准差 |

### 响应时间统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 在整个分析时段内的平均响应时间 |
| 最大值 | 在整个分析时段内的最大响应时间，该值与整个时段内的最大覆盖间隙长度相等 |
| 最小值 | 在整个分析时段内的最小响应时间，当分析对象存在被覆盖时刻时，该值为0 |
| 百分比低于 | 假设所设比例为X，该统计值为V，表示响应时间有X%的时间低于V |
| 间隔时间百分比低于 | 假设所设比例为X，该统计值为V，表示在覆盖间隙内，响应时间有X%的时间低于V |

### 数据时龄统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 在整个分析时段内的平均数据时龄 |
| 最大值 | 在整个分析时段内的最大数据时龄，该值与整个时段内的最大覆盖间隙长度相等 |
| 最小值 | 在整个分析时段内的最小数据时龄，当分析对象存在被覆盖时刻时，该值为0 |
| 百分比低于 | 假设所设比例为X，该统计值为V，表示数据时龄有X%的时间低于V |
| 间隔时间百分比低于 | 假设所设比例为X，该统计值为V，表示在覆盖间隙内，数据时龄有X%的时间低于V |

### 系统响应时间统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 在整个分析时段内的平均系统响应时间 |
| 最大值 | 在整个分析时段内的最大系统响应时间 |
| 最小值 | 在整个分析时段内的最小系统响应时间 |

### 系统数据时龄统计值

| 名称 | 含义 |
| :----: | :----------------------------------------------------------- |
| 平均值 | 在整个分析时段内的平均系统数据时龄 |
| 最大值 | 在整个分析时段内的最大系统数据时龄 |
| 最小值 | 在整个分析时段内的最小系统数据时龄 |

## 二维视图

支持 **动态** 与 **静态** 两种显示模式，两类模式均包含：

- 是否显示对应图像
- 显示网格点设置
- 显示指标设置
