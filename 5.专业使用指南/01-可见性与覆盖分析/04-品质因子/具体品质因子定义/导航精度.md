# 导航精度

## 定义

基于一组发射器的**单向距离测量**，评估导航解算结果的不确定性。

## 特有参数

|     配置项     |                                      说明                                      |
|:--------------:|:------------------------------------------------------------------------------:|
|    **方法**    |       选择需要评估的导航精度分量，例如 GACC、PACC、HACC、VACC、TACC 等。       |
|    **类型**    |       指定参与导航解算的发射器选择方式，例如超定、最优4、最优N等。      |
|    **计算**    | 指定覆盖时间段内静态结果的统计方式，例如平均值、最大值、最小值、百分比低于等。 |
|    **步长**    |                  指定对动态导航精度进行采样时使用的时间间隔。                  |
| **无效值** |         当可用发射器数量不足、无法计算导航解时，指定忽略或包含该样本。         |
|  **不确定度**  |    设置单向距离测量的不确定度，包括资源距离不确定度和接收距离不确定度。    |

## 方法

在【定义 - 方法】中选择具体的导航精度指标。不同方法对应导航解中不同部分的不确定性。

|        方法        |   名称   |                            说明                            |
|:------------------:|:--------:|:----------------------------------------------------------:|
|      **GACC**      | 几何精度 | 衡量完整导航解的不确定性，同时包含位置分量和时钟相关分量。 |
| **PACC / PACC(3)** | 位置精度 |             仅衡量导航解中位置部分的不确定性。             |
| **HACC / HACC(3)** | 水平精度 |  衡量水平位置分量的不确定性，即纬度、经度方向的不确定性。  |
| **VACC / VACC(3)** | 垂直精度 |            衡量垂直方向，即高度分量的不确定性。            |
|      **TACC**      | 时间精度 |           衡量导航解中时间或钟差部分的不确定性。           |

::: tip 说明
- 不带 `(3)` 的方法通常要求有足够的发射器参与完整导航解算。
- 带 `(3)` 的方法允许在仅有 3 个导航源可用时计算位置相关精度。
- 当使用 `(3)` 方法且仅有 3 个导航源时，系统会忽略导航解中的时钟分量。
- 当可用导航源达到 4 个或更多时，时钟分量会重新纳入解算。
:::

## 类型

【类型】用于指定参与导航精度计算的发射器选择策略。虽然完整导航解通常需要至少 4 个发射器，但更多发射器可用于改善解算精度。

|                类型               |                           说明                          |                     适用场景                     |
|:---------------------------------:|:-------------------------------------------------------:|:------------------------------------------------:|
|    **超定**    |           使用当前所有可用发射器计算导航精度。          | 适合评估系统在全部可见资源参与时的总体导航能力。 |
|     **最优4**     |    从当前可用发射器中选择使 GDOP 最小的 4 个发射器。    |   适合模拟仅选取最优 4 个导航源的传统解算方式。  |
|      **最优N**      | 按指定数量 N 选择发射器，并基于所选发射器计算导航精度。 |        适合限制参与导航解算的发射器数量。        |
| **最优4精度** |          选择使几何不确定性最小的 4 个发射器。          |      适合直接以导航精度最优为目标进行选择。      |
|  **最优N精度**  |   按指定数量 N 选择发射器，并使导航精度表现尽可能优。   |       适合研究不同数量导航源对精度的影响。       |

::: tip 说明
- 选择 **最优N** 或 **最优N精度** 时，需要额外指定 **N** 的取值。
- N 通常应大于或等于 4。
- 在特定 `(3)` 方法下，可允许 N 取 3，但此时不能使用依赖时间分量的指标，例如 GACC 或 TACC。
- 类型配置会同时影响动态导航精度和静态导航精度的计算结果。
:::

## 计算

【计算】用于指定在整个覆盖时间段内如何将动态导航精度采样值汇总为静态结果。

|             计算方式            |                                          说明                                          |
|:-------------------------------:|:--------------------------------------------------------------------------------------:|
|      **平均值**      |                计算整个覆盖时间段内每个网格点导航精度不确定性的平均值。                |
|      **最大值**      |                  计算整个覆盖时间段内每个网格点出现过的最大不确定性。                  |
|      **最小值**      |                  计算整个覆盖时间段内每个网格点出现过的最小不确定性。                  |
| **百分比低于** | 计算一个不确定度阈值，使导航精度在指定百分比的时间内低于该值。需要额外指定百分比水平。 |

::: tip 说明
- 该配置仅影响**静态导航精度**结果。
- 动态导航精度表示当前时刻的瞬时结果。
- 静态导航精度通过对动态结果按指定步长采样，并按照所选计算方式统计得到。
- 计算结果会受到所选方法、类型、步长以及无效值处理方式的共同影响。
:::

## 步长

【步长】用于指定在覆盖时间段内采样动态导航精度时使用的时间间隔。

|   参数   |                   说明                   |
|:--------:|:----------------------------------------:|
| **步长** | 用于静态导航精度计算的动态结果采样间隔。 |

::: tip 说明
- 步长越小，采样越密集，静态统计结果通常越精细，但计算量也越大。
- 步长越大，计算速度更快，但可能遗漏短时间内的精度变化。
- 当导航源可见性变化频繁时，建议使用较小步长。
- 当只需获得长期平均趋势时，可适当增大步长。
:::

## 无效值

在某些时间样本中，可能由于可用发射器数量不足，导致无法计算导航解。此时需要通过【无效值处理】指定系统如何处理该类样本。

| 无效值处理方式 |                                  说明                                  |
|:--------------:|:----------------------------------------------------------------------:|
|    **包括**    | 将无法计算导航解的样本赋值为指定的无效数据指示值，并将其纳入统计计算。 |
|    **忽略**    |  忽略无法计算导航解的样本，仅基于可成功计算导航解的时间样本进行统计。  |

::: tip 说明
- 若需要反映覆盖中断或导航不可用对整体指标的影响，建议选择 **包括**。
- 若只希望评估导航可用期间的精度水平，建议选择 **忽略**。
- 使用 **包括** 时，应合理设置无效数据指示值，避免其对平均值、最大值等统计结果造成误判。
:::

## 不确定度

导航精度计算需要设置单向距离测量的不确定度。不确定度可来自发射器侧，也可来自接收机侧。

|                        类型                        |                                 说明                                 |
|:--------------------------------------------------:|:--------------------------------------------------------------------:|
|   **资源距离不确定度**  |  针对每个发射器设置距离测量不确定度。可设置为常数，也可随仰角变化。  |
| **接收距离不确定度** | 接收机硬件引入的距离测量白噪声水平，对所有几何关系和发射器统一生效。 |

## 统计值

导航精度类型无额外的统计值配置。
