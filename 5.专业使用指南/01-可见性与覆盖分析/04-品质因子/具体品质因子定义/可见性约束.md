# 可见性约束

## 定义

在覆盖时段内，计算对象与分析对象之间的可见性参数约束。

## 特有参数

|  约束  |                含义                |
|:------:|:----------------------------------:|
| 高度 | 应用对象在最小/最大高度范围内的约束条件。 |
| 视线角速度 | 视线方向角变化率 |
| 方位角 | 在局部水平面内，从北向东测量的方向角。 |
| 方位角速率 | 方位角随时间变化的速度。 |
| 俯仰角 | 目标相对于地平面的仰角 |
| 俯仰角速率 | 仰角随时间变化率。 |
| 月球视线规避角 | 目标与月球方向之间的最小安全夹角。 |
| 太阳视线规避角 | 目标与太阳方向之间的安全夹角。 |
| 月球高度角 | 目标相对于月球方向的仰角。 |
| 太阳高度角 | 目标相对于太阳方向的仰角。 |
| 传播延时 | 信号在两个对象之间传播所需时间。 |
| 距离 | 两个对象之间的空间直线距离（斜距）。 |
| 速率 | 沿视线方向的相对速度（距离变化率）。 |


|  跨对象  |                含义                |
|:------:|:----------------------------------:|
| 平均值 | 某时刻，所有可用资产计算结果中的平均值。 |
| 最大值 | 某时刻，所有可用资产计算结果的最大值。 |
| 最小值 | 某时刻，所有可用资产计算结果中的最小值。 |
| 总值 |某时刻，所有可用资产计算结果的累加值。|

可用资产 = 当前时刻满足所有访问条件、可以参与该网格点计算的所有卫星/平台/资源集合。

## 统计值

|  名称  |                含义                |
|:------:|:----------------------------------:|
| 平均值 | 对时间采样结果取平均。 |
| 最大值 | 时间序列中的最大值。 |
| 最小值 | 时间序列中的最小值。 |
| 百分比低于 | 假设所设比例为X，该统计值为V，表示响应时间有X%的时间低于V |
| 百分比高于 | 假设所设比例为X，该统计值为V，表示响应时间有X%的时间高于V |
| 总值 |时间采样值的累加和。|
