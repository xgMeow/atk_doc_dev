# 访问时长

## 定义

单个资源对分析对象的可用覆盖时间。

## 统计值

|    名称    |                            含义                           |
|:----------:|:---------------------------------------------------------:|
|   平均值   |            分析时段内，所有覆盖时段长度的平均值           |
|   最大值   |                分析时段内的最大覆盖时段长度               |
|   最小值   |                分析时段内的最小覆盖时段长度               |
| 百分比高于 | 假设所设比例为X，该统计值为V，表示访问时长有X%的时间高于V |
|   标准差   |              分析时段内，所有覆盖时长的标准差             |
|    总和    |              分析时段内所有覆盖时段的长度之和             |
