# 访问次数

## 定义

分析对象被覆盖的次数。

## 统计值

|     名称     |                                            含义                                            |
|:------------:|:------------------------------------------------------------------------------------------:|
|   每日平均   |                    总访问次数与分析天数的比例，表征了平均每天的覆盖次数                    |
|   在范围内   |                       在所设定的最小、最大时长范围内的覆盖时段的数量                       |
| 每日在范围内 | 满足所设定的最小、最大时长范围的时段数量与分析天数的比例，表征平均每天的满足条件的覆盖次数 |
|   每日最大   |                               在UTC日中，每天最多被覆盖的次数                              |
|   每日最小   |                               在UTC日中，每天最少被覆盖的次数                              |
|     总计     |                            在分析时段内，分析对象被覆盖的总次数                            |
