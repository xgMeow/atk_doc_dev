# 网格点文件导入说明

本文档说明网格点文件（`.pnt`）的导入方式、文件规范及格式要求。

## 操作步骤

1. 选中【覆盖定义】对象，右键打开属性。

2. 切换到【网格】选项卡。

3. 在【点位置】中选择 "自定义文件"。

4. 点击 <kbd>导入</kbd>，选择 `.pnt` 文件即可。

![网格点文件导入步骤](./media/网格点文件导入说明/image.png)

## 文件规范

`.pnt` 文件由 **单位声明**（可选）和 **网格点数据**（必填）两部分组成：

```text
[LatLon Unit <值>]              ← 可选声明
[Alt Unit <值>]                 ← 可选声明
Begin PointList                 ← 数据开始标记（必填）
    <纬度> <经度> [高度]         ← 每行一个点，空格分隔
    ...
End PointList                   ← 数据结束标记（必填）
```

### 单位声明

位于 `Begin PointList` 之前，可省略（省略时使用默认值）。

| 关键字 | 含义 | 可选值 | 默认值 |
|--------|------|--------|--------|
| `LatLon Unit` | 经纬度单位 | `0` = 弧度，`1` = 角度 | `1`（角度） |
| `Alt Unit` | 高度单位 | `0` = 米，`1` = 千米，`2` = 分米，`3` = 厘米 | `0`（米） |

示例：

```text
LatLon Unit 1
Alt Unit 0
```

### 网格点数据

- 必须由 `Begin PointList` 和 `End PointList` 包裹。
- 每行一个点，格式为 `纬度 经度 [高度]`，值之间用空格分隔。
- 高度为**可选项**，是否生效由界面中的【点高度定义】选项控制。

![高度生效配置](./media/网格点文件导入说明/image123.png)

::: tip 经纬度范围校验（v4.0.1-rc.2+）
经度范围 **-180° ~ 360°**，纬度范围 **-90° ~ 90°**。超出范围的数据点将被跳过并弹框提示。
:::

::: tip 数值格式
支持常规小数（如 `39.3464`）和科学计数法（如 `3.9346423789e+01`）。
:::

## 示例

### 仅坐标（最简）

省略单位声明和高度，使用默认值。

```text title="grid.pnt"
Begin PointList
    39.3464    -60.2607
    39.6134    -66.2854
    39.8803    -73.8818
End PointList
```

### 坐标 + 高度

每行追加高度值（单位：米）。使用此格式时，需在界面中将【点高度定义】设为 "使用文件值"。

```text title="grid_with_alt.pnt"
Begin PointList
    39.3464    -60.2607    100.0
    39.6134    -66.2854    150.0
    39.8803    -73.8818    200.0
End PointList
```

### 科学计数法 + 单位声明

包含单位声明，坐标以科学计数法表示，适用于高精度场景。

```text title="Sample.pnt"
LatLon Unit 1
Alt Unit 0

Begin PointList
    3.9346423789e+01    -6.0260748372e+01    0.0000000000e+00
    3.9613371741e+01    -6.6285429903e+01    0.0000000000e+00
    3.9880319688e+01    -7.3881767479e+01    0.0000000000e+00
End PointList
```

## 常见问题

**Q：导入后点位置未生效？**

A：检查界面中【点高度定义】的设置——如果文件中不含高度，应设为 "使用默认值" 或 "自动计算"，而非 "使用文件值"。

**Q：部分数据点被跳过？**

A：检查是否超出经纬度范围（纬度 -90° ~ 90°，经度 -180° ~ 360°），超出范围的点会被自动过滤并弹框提示。

**Q：文件中有多余的空行或注释会影响解析吗？**

A：不会。空行和以 `#` 开头的注释行在解析时会被自动忽略。
