PIMPL 模式优势
  • 编译速度：修改私有成员只需重新编译单个 cpp 文件
  • 二进制兼容：私有成员变化不影响 ABI 兼容性
  • 头文件整洁：头文件只包含公共接口声明
📝
注释说明
  • 该语法仅 VuePress 2 + Default Theme 原生支持
  • 自定义主题需要自行实现对应样式
ℹ️
功能信息
  • PIMPL 全称 Pointer to Implementation
  • 核心思想：将实现细节隐藏在 cpp 文件内部
⚠️
使用警告
  • PIMPL 会带来少量堆内存开销
  • 频繁小对象场景不推荐盲目使用
❗
重要注意点
  • 智能指针必须完整声明内部实现类才能析构
  • 拷贝/移动构造函数需要手动处理 Impl 对象
🚨
风险提示
  • 不要在头文件内直接定义 Impl 的成员函数
  • 跨动态库使用时要统一内存分配器，避免崩溃
