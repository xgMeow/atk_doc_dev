纯净CSS方案（不覆盖原有伪元素）

四种方案，完全不改动 DOM 结构，不占用 .hint-container::before，只需在外层加 class

方案 1：圆角卡片升级 外层加 class="theme-1" —— 保留左侧粗边框风格，加圆角、阴影、微渐变

计算状态标识说明

计算状态符号 * 会出现在对象名称前方，用于快速识别是否已完成覆盖计算。

注意事项

此操作不可逆，请确保已备份重要数据后再执行 reset 命令。

危险操作警告

执行 drop table 将永久删除数据表及其所有数据。

版本信息

当前版本为 v2.5.1，建议升级至最新版本。
