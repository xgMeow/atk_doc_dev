# 简介与配置

## 简介

Python 客户端工具是 ATK 内置的 Python 脚本工具，打开即可编写脚本操控 ATK，无需额外配置环境。

作为 CONNECT 模式的核心开发方式之一，Python 客户端工具通过 TCP 网络通信与 ATK 交互，使用 `atkOpen` / `atkConnect` / `atkClose` 三组核心 API 发送 CONNECT 命令。如果你不想搭建外部 Python 开发环境，希望在 ATK 中直接编写和运行脚本，Python 客户端工具是最便捷的选择。

::: danger 场景限制
ATK CONNECT 模式仅支持加载一个场景，若需新建场景，需将已打开的场景关闭。
:::

::: tip 开发方式选择
各开发方式的详细对比请参考 [CONNECT 模式概述](../../README.md#开发方式对比)。
:::

## 使用方式

### 入口

在 ATK 菜单栏选择 **集成** → **客户端**，即可打开 Python 客户端工具。

![Python 客户端工具入口](./media/1-简介与配置/image-20260625154139143.png)

### 界面布局

客户端窗口主要包含以下区域：

- **脚本窗口**：批量编写 Python 脚本，一键运行，适合批量操作和脚本复用。
- **命令窗口**：逐条输入 Python 命令，与 ATK 实时交互，适合调试和单步操作。
- **工具栏**：提供 **New**（新建脚本）、**Open**（打开脚本）、**Save**（保存脚本）、**Run**（运行脚本）等常用功能。

![Python 客户端工具界面](./media/1-简介与配置/image-20260625154355343.png)

### 操作方式

客户端工具提供三种操作方式，可根据需要选择：

1. **脚本窗口（推荐）**：将代码粘贴到脚本窗口，点击 <kbd>Run</kbd> 一键运行，适合批量操作和脚本复用。
2. **命令窗口**：在命令窗口中逐条输入代码，按 <kbd>Enter</kbd> 执行，适合调试和单步操作。
3. **打开脚本文件**：点击 <kbd>Open</kbd> 按钮打开已有的脚本文件（`.atks` 或 `.py`），加载后点击 <kbd>Run</kbd> 运行。

## 环境与配置

Python 客户端工具为 ATK 内置工具，**无需额外安装 Python 环境或配置库文件路径**。ATK 内置了 Python 解释器及常用标准库，客户端启动后即可直接编写和执行 Python 脚本。

与 [Python SDK](../4-语言SDK/1-Python/1-简介与配置.md) 的区别如下：

| 对比项 | Python 客户端工具 | Python SDK |
| :--- | :--- | :--- |
| Python 环境 | ATK 内置，无需安装 | 需自行安装和配置 |
| 库文件 | ATK 内置，无需配置 | 需手动复制到工作目录 |
| 第三方库 | 仅限 ATK 内置标准库 | 可使用 numpy、matplotlib 等 |
| 运行方式 | ATK 内置客户端窗口 | 外部 IDE 或命令行 |
| 适用场景 | 快速上手、轻量脚本 | 集成到自有项目、复杂开发 |

下一步请参考 [核心 API](./2-核心API.md) 了解接口用法，或直接查看 [完整示例](./3-完整示例.md) 跟随实操。
