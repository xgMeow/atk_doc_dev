# 偏差分析规划段复制粘贴

## 作用

偏差分析规划段复制粘贴

## 语法

```atk-command
AstroUQ <Satellite Object Path> Paste CopySegmentPath PasteSegmentPath
```

::: tip 注意
- 此命令针对偏差分析使用
:::

## 示例

::: details open **偏差分析规划段复制粘贴**
```
AstroUQ */Satellite/Satellite1 Paste MainSequence.SegmentList.Propagate.- MainSequence.SegmentList.InitialState
```
:::
