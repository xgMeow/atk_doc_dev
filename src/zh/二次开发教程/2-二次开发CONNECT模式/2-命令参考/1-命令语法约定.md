# 命令语法约定

ATK CONNECT 命令使用以下符号表示参数的类型和约束，阅读命令语法时请参照本约定。

## 基础符号

| 符号 | 含义 | 说明 |
|------|------|------|
| `<参数>` | 必填参数 | 使用时替换为实际值。如 `<ObjectPath>` → `*/Satellite/Satellite1`。 |
| `[参数]` | 可选参数 | 可按需省略。如 `[WindowID <WinNumber>]` 可写可不写。 |
| `{选项}` | 必选项 | 须从给定选项中**选取一个**。如 `{On \| Off}` 填 `On` 或 `Off`；`{Color}` 按颜色格式填写。 |
| `\|` | 选项分隔符 | 在 `{ }` 内分隔互斥选项，表示"或"。如 `{Details \| Platform}` 二选一。 |
| `"文本"` | 字符串字面量 | 按原样输入，**保留双引号**。如 `"<FilePath>"` → `"C:\data\file.a"`。 |
| `...` | 可重复 | 前方元素可多次出现。如 `({Option} <Value>)...` 可写多组选项-值对。 |

## 路径符号

| 符号 | 含义 | 说明 |
|------|------|------|
| `*` | 场景通配符 | 代表"当前场景"，等价于 `当前场景/`。如 `VO * CentralBody Mars`（`*` 即当前场景）。 |
| `/` | 应用路径 | 代表当前程序。如 `AllInstanceNames /` 列出当前程序下的所有对象。 |

## 路径参数

命令中反复出现的具名路径参数，含义如下。

| 参数 | 含义 | 说明 |
|------|------|------|
| `<ApplicationPath>` | 应用路径 | 当前程序，填 `/`。如 `UnloadSubObj / *`、`Copy / Satellite/Satellite1 Name Sat2`。 |
| `<ScenarioPath>` | 场景路径 | 命令作用的场景，通常填 `*`（当前场景）。如 `Animate * Start`、`Units_Get * GUI`。 |
| `<ObjectPath>` | 对象完整路径 | 自场景 `*` 起写全，如 `*/Satellite/Satellite1`。 |
| `<FacilityPath>` | 地面站路径 | 命令作用的地面站对象路径，如 `*/Facility/Facility1`。 |
| `<VehObjectPath>` | 飞行器路径 | 命令作用的飞行器对象路径，覆盖飞机、船、车辆、卫星、导弹、火箭，如 `*/GroundVehicle/GroundVehicle1`。 |
| `<TruncObjPath>` | 对象截断路径 | 省略场景前缀 `*/`，如 `Satellite/Satellite1`。 |
| `<ClassPath>` | 对象类路径 | 待创建对象的类型，如 `Scenario`、`*/Satellite`。 |
| `<AxesPath>` | Axes 组件路径 | 数据所参考的 Axes 组件，为截断路径且须用双引号括起来，如 `"CentralBody/Earth J2000.Axes"`。 |

::: tip 完整路径与截断路径

`<ObjectPath>` 从场景 `*` 起写全，为**完整路径**。一条命令中，**第一组路径写成完整路径**（以 `*` 或 `/` 开头），**其余位置的路径一律写成截断路径**，即省略场景前缀 `*/`。

如 `Copy / Satellite/Satellite1 Name Sat2` 中，`/` 是第一组路径（应用路径），`Satellite/Satellite1` 是其后的截断路径。
:::

## 常用逻辑

命令在解析时遵循以下规则。

**关键字不区分大小写**

命令名、子命令名、选项关键字等**命令自身的固定单词，不区分大小写**，写成全大写、全小写或驼峰式都能识别，效果完全相同。例如下面三条命令等价：

```atk-command
Compute CAMEnum
COMPUTE camenum
compute camenum
```

**类型与名称区分大小写**

对象类型（如 `Satellite`、`Missile`、`Antenna`）、对象名称，以及路径中的标识符，**区分大小写**，须与对象定义时的写法一致。如 `*/Satellite/Satellite1` 与 `*/satellite/satellite1` 并不等价。

**空格数量不敏感**

未用双引号括起的部分，单词之间写一个空格或多个空格等效，命令的解析结果相同。

**双引号内按原样保留**

双引号内部的空格属于字符串内容本身，不会被合并，因此字面量内部词与词之间**只能有一个空格**，多写一个空格就变成了另一个字符串。如日期时间 `"1 Jul 2021 09:00:00.000"`，各段之间均须为单个空格。

## 补充说明

- 命令以**空格**分隔单词，连续多个空格等同于一个；参数中**不允许包含空格**（除字符串字面量内部）。

- 所有参数值均按**字符串**输入，数值只是内容为纯数字的字符串。参数值内部若含空格（如日期时间 `"1 Jul 2021 09:00:00.000"`），必须整体用双引号包裹。

- 参数顺序必须严格遵循语法定义，不可调换。
