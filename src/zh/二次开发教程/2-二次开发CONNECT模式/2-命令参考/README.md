# 命令参考

本目录收录 CONNECT 模式下的全部命令，并按不同的检索习惯提供多个入口。

## 检索入口

- **[命令总索引](./3-命令总索引.md)**：已知命令名称时的字母序检索。
- **[按对象查命令](./4-Connect对象命令库/README.md)**：已知要操作的对象类型（卫星、地面站、导弹等）时，查出该对象可用的命令。
- **[按功能查命令](./5-Connect功能索引/README.md)**：已知任务目标（覆盖分析、可见性分析、姿态与指向、碰撞规避、矢量几何、三维视图、二维视图）时，确定应使用的命令。

## 条目类型

本目录中的条目分为两类，请注意区分：

- **索引容器**：「按对象查命令」「按功能查命令」。条目下挂有若干检索页，条目本身仅作分组，不承载命令内容。
- **独立页**：「命令总索引」。一个条目即一页，不设下级。

## 关于重复

同一条命令可出现在多个检索入口中，例如 `AddAttitude Euler` 同时见于「姿态与指向」与「卫星」。这是各入口互为补充的结果，并非内容重复——命令正文全库仅一份，各入口均指向同一页面。
