# 按功能查命令

本页按**功能模块**组织命令，适用于已知任务目标、需确定使用哪条命令的情况。若需按对象检索（如卫星、地面站可用的命令），请参见[按对象查命令](../4-Connect对象命令库/README.md)。

## 功能模块

- **[覆盖分析](./覆盖分析.md)**：覆盖定义的计算、区域划分与品质因子
- **[可见性分析](./可见性分析.md)**：可见性报告与批量可见性计算
- **[姿态与指向](./姿态与指向.md)**：姿态的设置、读取与约束
- **[碰撞规避](./碰撞规避.md)**：碰撞规避的参数设置，以及自然交会分析、避撞机动规划与机动复核
- **[矢量几何](./矢量几何.md)**：自定义坐标系及其构建元素（点、矢量、轴、平面、角）
- **[三维视图](./三维视图.md)**：三维图形窗口中的模型、点、矢量、轮廓线与关节（articulation）控制
- **[二维视图](./二维视图.md)**：二维图形窗口中的轨迹、标签、地面轨迹、轮廓线与线型配色

> 「矢量几何」建立的是可供其他命令引用的几何组件，本身不作用于具体对象；其显示由[三维视图](./三维视图.md)的 `VO SetVectorGeometry` 负责。
>
> 「三维视图」「二维视图」作用于图形窗口本身，而非场景中的具体对象。
