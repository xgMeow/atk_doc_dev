# 按功能查命令

同一批 CONNECT 命令有两种查法：

- **[按对象查命令](../3-Connect对象命令库/README.md)**：按对象（卫星、地面站、导弹……）组织，适合「我要操作某类对象，有哪些命令」。
- **按功能查命令**（本页）：按功能模块组织，适合「我要完成某项任务，该用哪条命令」。

## 功能模块

- **[覆盖分析](./覆盖分析.md)**：覆盖定义的计算、区域划分与品质因子
- **[可见性与接近分析](./可见性与接近分析.md)**：可见性报告、批量可见性计算与高级接近分析
- **[姿态与指向](./姿态与指向.md)**：姿态的设置、读取与约束

## 共用命令集

以下命令不专属某类对象、也不归属某个功能模块，独立成页，与上面两个查法平级：

- **[三维视图显示](../7-三维视图显示.md)**：三维图形窗口中的模型、点、矢量、轮廓线与关节（articulation）控制
- **[二维视图显示](../8-二维视图显示.md)**：二维图形窗口中的轨迹、标签、地面轨迹、轮廓线与线型配色
- **[对象通用命令](../9-对象通用命令.md)**：跨对象通用的状态、姿态与约束设置
- **[对象工具](../10-对象工具.md)**：不专属某类对象、可作用于多种对象的工具命令（矢量几何、避碰，以及可见性与覆盖分析工具）

> 「对象工具」与「对象通用命令」不是一回事：后者是各类对象共有的状态、路径点等基础命令，前者是可作用到多种对象上的独立工具。
