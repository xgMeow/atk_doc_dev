# 按功能查命令

本页按**功能模块**组织命令，适用于已知任务目标、需确定使用哪条命令的情况。若需按对象检索（如卫星、地面站可用的命令），请参见[按对象查命令](../3-Connect对象命令库/README.md)。

## 功能模块

- **[覆盖分析](./覆盖分析.md)**：覆盖定义的计算、区域划分与品质因子
- **[可见性分析](./可见性分析.md)**：可见性报告与批量可见性计算
- **[姿态与指向](./姿态与指向.md)**：姿态的设置、读取与约束

## 共用命令集

下列命令由多个对象共用、无单一对象归属，故单独成页：

- **[三维视图显示](../7-三维视图显示.md)**：三维图形窗口中的模型、点、矢量、轮廓线与关节（articulation）控制
- **[二维视图显示](../8-二维视图显示.md)**：二维图形窗口中的轨迹、标签、地面轨迹、轮廓线与线型配色
- **[对象通用命令](../9-对象通用命令.md)**：跨对象通用的状态、姿态与约束设置
- **[对象工具](../10-对象工具.md)**：可作用于多种对象的工具命令（矢量几何、避碰，以及可见性与覆盖分析工具）

> 「对象工具」与「对象通用命令」并非同一概念：后者为各类对象共有的状态、路径点等基础命令，前者为可作用于多种对象的独立工具。
