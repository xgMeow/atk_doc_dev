# 单位格式

ATK 中的物理量按量纲划分，同一量纲可选用多种单位。Connect 命令中的数值按当前 Connect 单位解释，本页给出单位的分类、取值规则、可设置的量纲与单位，以及速度等组合量的单位如何确定。

## 单位的分类

ATK 的单位按模块分四类，修改其中一类不影响其余三类。

| 类别 | 作用范围 |
|------|----------|
| GUI | 在ATK界面上输入数据时使用的单位 |
| Report | 在ATK界面上生成和显示报告时使用的单位 |
| Connect | 发送 Connect 命令时取值的单位 |
| ConnectReport | 在 Connect 会话中生成和显示报告时使用的单位 |

如把 GUI 的距离单位设为 km，Connect 命令中的距离值仍按 Connect 的距离单位解释。

修改 Connect 类单位有两条等效命令，两条命令的写法见各自命令页：
- [Units_SetConnect](../4-Connect对象命令库/命令/Units_SetConnect.md) 只作用于 Connect 类单位。
- [Units_Set](../4-Connect对象命令库/命令/Units_Set.md) 通过 Connect 类别作用于同一范围。

## 取值规则

- 值后不附单位时，按该量纲当前的 Connect 单位解释；距离单位设为 km 时，1000 表示 1000 km。
- 值后可附单位，附了单位时按所附单位换算，如写成 1000 m 则该值始终表示 1000 m。并非所有命令都允许附单位，只有参数说明中标注了可选单位的参数才可以附带。
- 日期时间的格式（UTCG、BJT、JDate 等）同属 Date 量纲，随 Date 单位设置变化，参见[日期时间格式](日期时间格式.md)。
- 当前 Connect 单位设置可用 [Units_Get](../4-Connect对象命令库/命令/Units_Get.md) 查询。
- 个别命令对单位另有约定的，以该命令的说明为准。

## 可设量纲与可选单位

命令语法中的 `{Dimension}` 与 `{Unit}` 即下表所列的量纲名与单位名。四类单位均可设置下表的全部量纲。

| 量纲 | 说明 | 可选单位 |
|------|------|----------|
| Date | 日期 | `UTCG_MM`、`UTCG`、`BJT`、`BDT`、`BDTG`、`GPS`、`GPSG`、`TDTG`、`JDate`、`ModJDate`、`EpSec` |
| Distance | 距离 | `m`、`km`、`dm`、`cm`、`mm`、`in`、`kin`、`ft`、`yd`、`kyd`、`fur`、`mi`、`nm`、`Au`、`ly`、`Re` |
| Time | 时间 | `s`、`min`、`h`、`day`、`cd`、`EarthTU`、`SunTU`、`FN`、`yr` |
| Angle | 角度 | `deg`、`rad`、`arcSec`、`arcMin`、`revs` |
| Mass | 质量 | `g`、`kg`、`t` |
| Power | 功率 | `W`、`kW`、`MW` |
| Frequency | 频率 | `Hz`、`KHz`、`MHz`、`GHz`、`THz` |
| Temperature | 温度 | `degC`、`degF`、`K` |
| Ratio | 比值 | `dB` |
| Force | 力 | `N`、`kN`、`lbf` |
| Pressure | 压力 | `Pa`、`kPa` |

## 组合量的单位

速度、加速度、角速度、面积等由基本量纲组合而成的量，没有单独的单位设置项，其单位随所涉量纲的单位而定。常见组合量如下：

| 组合量 | 单位 |
|------|------|
| 速度 | 距离单位与时间单位之比，距离为 km、时间为 s 时为 km/s |
| 加速度 | 距离单位与时间单位平方之比，距离为 km、时间为 s 时为 km/s² |
| 角速度 | 角度单位与时间单位之比，角度为 deg、时间为 s 时为 deg/s |
| 面积 | 距离单位的平方，距离为 km 时为 km² |
