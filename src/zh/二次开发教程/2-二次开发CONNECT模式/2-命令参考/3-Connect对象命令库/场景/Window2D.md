# Window2D

## 作用

创建、移除二维窗口

## 语法

```atk-command
Window2D <ScenarioPath> {2DGfxWinOption} <Value> [WindowID <WinNumber>]
```

## 参数说明

| `{2DGfxWinOption}` | 说明 |
|------|------|
| `Create` | 使用默认设置打开一个二维窗口 |
| `Remove` | 移除一个二维窗口 |

## 示例

::: details open **创建二维窗口**

```
Window2D / Create
```

:::
