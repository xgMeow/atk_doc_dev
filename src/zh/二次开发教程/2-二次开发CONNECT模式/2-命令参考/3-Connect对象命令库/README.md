# 按对象查命令

要查某类对象（卫星、地面站、导弹等）能用哪些命令，从左侧目录进入对应对象页即可。

本页是**全量速查表**：按字母序列出对象命令库中的全部命令，不确定命令归属哪个对象时，可在此直接检索。

::: tip 其他查法
- 按功能模块查找命令，请参见[按功能查命令](../6-Connect功能索引/README.md)。
:::
