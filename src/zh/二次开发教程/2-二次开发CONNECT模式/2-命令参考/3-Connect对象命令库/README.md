# 按对象查命令

按**对象**组织 CONNECT 命令：先选对象（卫星、地面站、导弹……），再在该对象页中查看可用命令。适合「我要操作某类对象，有哪些命令」的查法。

本页按**字母序**列出对象命令库中的全部命令，不知道命令属于哪个对象时，可在此直接检索。

::: tip 其他查法
- 按功能模块查找同一批命令，请参见[按功能查命令](../6-Connect功能索引/README.md)。
- 命令语法的符号约定请参见[命令语法约定](../1-命令语法约定.md)。
:::
