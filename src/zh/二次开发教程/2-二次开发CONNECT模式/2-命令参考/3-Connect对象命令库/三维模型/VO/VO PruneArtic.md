# VO PruneArtic

## 作用

控制系统在通过 Connect 接收关节数据时保留的数据量，即裁剪删除对象已记录的关节数据。

删除范围由 `{PruneOption}` 指定：可以只删除指定时刻之前的数据，也可以删除该对象的全部关节数据。

适用于卫星、地面站、飞机、船、车辆、导弹、火箭共 7 类对象。

## 语法

```atk-command
VO <ObjectPath> PruneArtic {PruneOption}
```

## 参数说明

| 参数 | 说明 |
|------|------|
| `<ObjectPath>` | 关节所属对象的完整路径，自场景 `*` 起写全，如 `*/Satellite/ERS1`；路径参数的写法参见[命令语法约定](../../../1-命令语法约定.md) |

`{PruneOption}` 须从下列选项中**选取一个**：

| 选项 | 说明 |
|------|------|
| `Before <TimeValue>` | 删除该对象在指定时刻之前的全部关节数据 |
| `All` | 删除该对象的全部关节数据 |

`<TimeValue>` 的合法取值参见[日期时间格式](../../../2-参数值格式/日期时间格式.md)。

## 示例

::: details open **删除 ERS1 卫星在指定时刻之前的关节数据**

```
VO */Satellite/ERS1 PruneArtic Before "1 Jul 1998 03:00:00.00"
```

- `*/Satellite/ERS1`：关节所属卫星的完整路径
- `Before`：删除**指定时刻之前**的关节数据
- `"1 Jul 1998 03:00:00.00"`：指定的时刻，即删除 1998 年 7 月 1 日 03:00 之前的关节数据；为字符串字面量，**须保留双引号**

:::
