# 时间约束

## 1. 功能说明

时间约束用于限定访问分析或覆盖分析在时间维度上的有效范围。通过设置开始时间、结束时间、持续时长或指定时段文件，可以控制对象之间访问关系的有效计算区间，从而筛选满足任务时间要求的访问结果。

---

## 2. 参数说明

| 参数名称 | 含义 |
| :---: | --- |
| 开始时间 | 访问或覆盖分析的起始时刻。只有晚于或等于该时间的访问结果才被认为满足时间约束。 |
| 结束时间 | 访问或覆盖分析的终止时刻。只有早于或等于该时间的访问结果才被认为满足时间约束。 |
| 最小时长 | 一次有效访问或覆盖持续时间的下限。若访问时长小于该值，则不满足时间约束。 |
| 最大时长 | 一次有效访问或覆盖持续时间的上限。若访问时长大于该值，则不满足时间约束。 |
| 时段 | 一个或多个有效时间区间。只有落入指定时段内的访问结果才被认为满足时间约束。 |
| 间隔文件 | 通过外部文件导入有效时段或无效时段。系统根据文件中定义的时间间隔对访问结果进行筛选。 |
