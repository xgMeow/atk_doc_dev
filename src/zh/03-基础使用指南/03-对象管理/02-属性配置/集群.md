# 集群

集群用于将多个对象组织为同一成员集合的组合对象。集群可用于访问、链路和覆盖分析，既可使成员分别参与计算，也可根据设定的逻辑条件对成员结果进行整体判定。与链路不同，**集群成员不因列表中的排列顺序而构成逐段连接的路径**。

集群包含以下属性可配置：

- [基本](#基本)：选择集群成员并管理成员列表。
- [可视化](#可视化)：配置集群相关图形的显示方式。
- [约束](#约束)：设置成员计算方式及集群整体有效的判定条件。

## 基本

| 属性 | 说明 |
| --- | --- |
| [定义](../通用属性/对象属性/基本/集群定义.md) | 通过对象类型过滤器筛选场景对象，将所需对象加入或移出集群，并管理已选成员。对象选择操作与链路类似，但集群成员的排列不用于定义相邻对象间的连接关系。 |

## 可视化

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/可视化/显示.md) | 设置集群相关图形的显示状态与外观样式。该属性与区域目标共用可视化显示说明。 |

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/07-集群逻辑限定.md) | 选择**独立计算**或**打包计算**。打包计算时，可通过**任意、全部、至少**及对应的成员数量要求，确定集群整体满足条件的判定方式。 |
