# 覆盖定义

覆盖定义用于建立覆盖分析区域及采样网格的对象。通过设置区域边界、网格点间隔和高度，或导入自定义网格点文件，确定覆盖分析所使用的空间位置，并配置网格显示及访问约束。

覆盖定义包含以下属性可配置：

- [基本](#基本)：定义覆盖区域范围、网格点分布及计算相关选项。
- [可视化](#可视化)：设置覆盖区域和网格点的显示方式。
- [约束](#约束)：设置网格点参与访问计算时需满足的几何、太阳及时间条件。

## 基本

| 属性 | 说明 |
| --- | --- |
| [网格](../通用属性/对象属性/基本/网格.md) | 选择网格区域类型并设置经纬度范围，配置网格间隔、点高度及点位置；支持按间隔生成网格点或导入自定义网格点文件，并提供并行计算和结果保存选项。 |

## 可视化

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/可视化/覆盖定义显示.md) | 控制覆盖区域与网格点的显示状态，并设置区域填充、颜色和网格点大小等图形属性。 |

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 设置覆盖网格点参与访问计算时的几何和视线条件，如俯仰角、距离及遮挡等。 |
| [太阳](../03-约束配置/02-太阳约束.md) | 设置与太阳、月球相对位置有关的访问条件。 |
| [时间](../03-约束配置/03-时间约束.md) | 限定覆盖网格点参与访问计算的时间窗口和有效时段。 |
