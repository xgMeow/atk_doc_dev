# 区域目标

区域目标用于描述中心天体表面指定范围的面状对象。通过边界点定义区域轮廓，并设置质心作为区域的参考位置，可用于区域显示及与其他对象的访问分析。

区域目标包含以下属性可配置：

- [基本](#基本)：定义区域边界和质心位置。
- [可视化](#可视化)：设置区域轮廓、中心点和填充区域的显示样式。
- [约束](#约束)：设置区域目标参与访问计算时应满足的基本与时间条件。

## 基本

| 属性 | 说明 |
| --- | --- |
| [边界](../通用属性/对象属性/基本/边界.md) | 通过经纬度边界点定义区域轮廓，支持添加、删除边界点及在地图中选点，并显示区域面积。 |
| [质心](../通用属性/对象属性/基本/质心.md) | 设置区域目标的参考中心位置，用于表示区域的中心参考点；质心位置与边界轮廓分别配置。 |

## 可视化

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/可视化/区域目标显示.md) | 控制区域目标及其名称标签、中心点、边界点的显示，并设置区域填充、透明度、颜色、线型和线宽。 |

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/08-区域目标基本约束.md) | 配置区域目标与其他对象之间的访问几何条件，包括俯仰角、视线条件及区域访问判定相关选项。 |
| [时间](../03-约束配置/03-时间约束.md) | 限定区域目标与其他对象之间允许进行访问计算的时间窗口或时间区间。 |
