# 链路

链路用于组织多个对象之间连续访问关系的分析对象。链路中的对象按照选定顺序依次连接，相邻对象构成各段连接；只有各段连接在同一时刻均满足访问条件，才能形成完整链路的有效时段。链路可用于多对象可见性分析及含中继节点的通信路径分析。

链路包含以下属性可配置：

- [基本](#基本)：选择参与链路的对象并确定连接顺序。
- [可视化](#可视化)：配置链路连接关系及有效连接的图形显示方式。

## 基本

| 属性 | 说明 |
| --- | --- |
| [定义](../通用属性/对象属性/基本/链路定义.md) | 通过对象类型过滤器筛选可选对象，将所需对象加入链路并调整排列顺序。**已选对象的先后顺序决定各段连接关系**。 |

## 可视化

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/可视化/链路显示.md) | 配置链路图形的总显示开关，以及**静态连接线**和随动画时间变化的**动态连接线、高亮及方向标识**等显示属性。 |
