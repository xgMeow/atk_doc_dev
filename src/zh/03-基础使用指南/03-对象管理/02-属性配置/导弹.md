# 导弹

导弹属性设置包括：**基本属性、二维视图、三维视图、约束、RF**。

- 整体配置项与 **火箭** 基本一致
- 仅在 **二维视图** 中 **不包含刈幅设置**
- 其余所有参数、界面、操作方式均与[火箭的属性设置](./火箭.md)完全相同，此处不再重复说明。

---

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 导弹与其他对象间的访问需满足的几何与视线条件（方位角、仰角、距离、传播延时、高度、视场等） |
| [太阳](../03-约束配置/02-太阳约束.md) | 导弹与其他对象间的访问需满足的、按太阳与月球相对位置判定的条件（太阳/月球仰角、规避角、附加中心天体遮挡等） |
| [时间](../03-约束配置/03-时间约束.md) | 导弹与其他对象间的访问需落入的时间窗口（当地时间/GMT/当地太阳时/时长/时段） |
