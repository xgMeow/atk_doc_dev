# 地面站

地面站用于表示固定地面设施的对象。通过设置站点位置和方位-俯仰掩码，可确定地面站的空间位置及周围方向的遮挡条件，并用于与其他对象的访问分析和射频相关计算。

地面站包含以下属性可配置：

- [基本](#基本)：设置地面站位置及方位-俯仰掩码。
- [二维视图](#二维视图)：设置地面站在二维地图中的标识及范围轮廓显示。
- [三维视图](#三维视图)：设置地面站的三维模型、向量、姿态球及其他图形显示。
- [约束](#约束)：设置地面站与其他对象之间访问成立所需的条件。
- [RF](#rf)：设置地面站的射频传播环境及雷达散射截面属性。

## 基本

| 属性 | 说明 |
| --- | --- |
| [位置](../通用属性/对象属性/基本/位置.md) | 选择坐标表示方式并输入站点位置参数，设置高度参考及离地高度；支持通过地图交互调整位置。 |
| [方位-俯仰掩码](../03-约束配置/06-方位俯仰掩码.md) | 加载方位-俯仰掩码文件，描述站点周围不同方位上的遮挡范围，并设置掩码是否参与可见性判定。 |

## 二维视图

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/二维视图/显示.md) | 设置站点标识与名称标签的显示状态，并配置颜色和标识类型。 |
| [范围](../通用属性/对象属性/二维视图/范围.md) | 按指定距离分级绘制站点周围的范围轮廓，配置轮廓线、标签及填充效果。 |

## 三维视图

| 属性 | 说明 |
| --- | --- |
| [模型](../通用属性/对象属性/三维视图/模型.md) | 加载地面站三维模型，设置模型比例、位置偏移及外观。 |
| [向量](../通用属性/对象属性/三维视图/向量.md) | 配置参考向量及相关图形的显示方式。 |
| [姿态球](../通用属性/对象属性/三维视图/姿态球.md) | 设置姿态球的显示、参考坐标系及图形参数。 |
| [范围](../通用属性/对象属性/三维视图/范围.md) | 设置站点范围轮廓在三维场景中的显示方式。 |
| [模型指向](../通用属性/对象属性/三维视图/模型指向.md) | 配置地面站三维模型的指向相关属性。 |
| [数据显示](../通用属性/对象属性/三维视图/数据显示.md) | 设置三维场景中动态数据的显示内容与样式。 |

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 设置方位角、仰角、距离等几何和视线约束。 |
| [太阳](../03-约束配置/02-太阳约束.md) | 设置与太阳、月球相对位置有关的访问约束。 |
| [时间](../03-约束配置/03-时间约束.md) | 设置允许访问的时间窗口和有效时段。 |

| [雷达散射截面](../08-RF/雷达散射截面.md) | 设置雷达散射截面及相关散射模型参数。 |
