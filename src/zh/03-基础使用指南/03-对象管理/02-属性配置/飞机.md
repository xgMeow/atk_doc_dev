# 飞机

飞机是 ATK 场景中的运动载体对象，包含以下属性可配置：

- [基本](#基本) ：设置飞机运动、姿态及地面椭圆等基础属性。
- [二维视图](#二维视图) ：控制飞机在二维地图上的图形显示。
- [三维视图](#三维视图) ：控制飞机在三维场景中的模型、向量与附加数据显示。
- [约束](#约束) ：限定飞机与其他对象之间访问成立所需的条件。
- [RF](#RF) ：飞机对象可配置的射频环境与散射相关属性。

## 基本

| 属性 | 说明 |
| --- | --- |
| [航线](../通用属性/对象属性/基本/航线.md) | 设置飞机的运动轨迹，使用以下预报器之一来定义飞机航线：<br>• **[路径生成](../通用属性/对象属性/基本/航线.md#路径生成)**：根据航点的位置、时间或运动参数生成飞机航线。<br>• **[STK星历](../通用属性/对象属性/基本/航线.md#stk星历)**：从外部文件导入星历数据，使用文件中的轨迹信息定义飞机航线。 |
| [姿态](../通用属性/对象属性/基本/姿态.md) | 用于配置飞机的姿态描述及姿态相关参数。 |
| [地面椭圆](../通用属性/对象属性/基本/地面椭圆.md) | 配置飞机地面椭圆的相关参数。 |

## 二维视图

| 属性 | 说明 |
| --- | --- |

| [轨迹](../通用属性/对象属性/二维视图/轨迹.md) | 设置二维地图上的轨迹显示方式。 |
| [等高线](../通用属性/对象属性/二维视图/等高线.md) | 配置二维视图中的仰角轮廓线等显示。 |
| [范围](../通用属性/对象属性/二维视图/范围.md) | 配置二维视图中的范围轮廓线及分级显示。 |
| [刈幅](../通用属性/对象属性/二维视图/划幅.md) | 配置飞机二维视图中的刈幅显示。 |
| [地面椭圆](../通用属性/对象属性/二维视图/地面椭圆.md) | 配置地面椭圆在二维视图中的显示方式。 |

## 三维视图

| 属性 | 说明 |
| --- | --- |
| [模型](../通用属性/对象属性/三维视图/模型.md) | 加载并配置飞机的三维模型及其外观参数。 |

| [范围](../通用属性/对象属性/三维视图/范围.md) | 配置三维场景中的范围轮廓与显示样式。 |
| [模型指向](../通用属性/对象属性/三维视图/模型指向.md) | 配置飞机三维模型的指向显示相关参数。 |
| [数据显示](../通用属性/对象属性/三维视图/数据显示.md) | 在三维场景中配置动态数据的显示方式。 |
