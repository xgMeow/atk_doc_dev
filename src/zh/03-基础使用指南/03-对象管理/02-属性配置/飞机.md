# 飞机

飞机是 ATK 场景中的运动载体对象，可配置运动和姿态属性、二维与三维显示方式，以及访问约束和 RF 相关属性。

飞机对象包含以下属性类别，点击属性名称可查看具体配置参数及使用说明。

| 属性类别 | 属性 | 说明 |
| --- | --- | --- |
| 基本属性 | [基本](./飞机/01-基本/index.md) | 设置飞机的航线、姿态及地面椭圆等基本属性。 |
| 二维视图 | [二维视图](./飞机/02-二维视图/index.md) | 设置飞机在二维场景中的显示、轨迹、等高线、范围、划幅及地面椭圆。 |
| 三维视图 | [三维视图](./飞机/03-三维视图/index.md) | 设置飞机在三维场景中的模型、向量、姿态球、接近、等高线、范围、模型指向及数据显示。 |
| 约束 | [约束](./飞机/04-约束/index.md) | 设置飞机与其他对象之间的访问约束，包括基本约束、太阳约束及时间约束等。 |
| RF 环境 | [RF](./飞机/05-RF/index.md) | 设置射频传播环境及雷达散射截面等相关属性。 |
