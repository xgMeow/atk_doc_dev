# 飞机

飞机是ATK中典型的运动载体对象，属性完整包含 **基本属性、二维视图、三维视图、约束、RF** 五大模块，也是其他平台类对象（车辆、舰船、潜艇等）的参考基准。

---

## 基本属性

- **航线**：设置飞机的运动轨迹
- **地面椭圆**：配置地面投影相关椭圆参数

## 二维视图

包含 **显示、轨迹、等高线、距离、地面椭圆** 五组设置。

### 显示

控制整体可见性、标签、轨迹、轨道、颜色、标识、线型等。

### 轨迹

支持四种轨迹类型：
- 点
- 时间
- 所有
- 无

### 等高线 / 距离

- 等高线：仰角轮廓线、仰角椭圆
- 距离：范围轮廓线
两类轮廓均支持分级显示设置。

## 三维视图

包括 **模型、向量、姿态球、接近、等高线、距离、数据显示**。

### 模型

可加载 3D 模型（ive / 3ds / flt / fbk 等），并设置比例、欧拉角、偏移、平移等。

### 向量

配置各坐标系向量的显示、标签、粗细、颜色。

### 姿态球

设置姿态球显示、颜色、零度线、参考坐标系、比例与投影。

### 接近

配置不确定区域的类型、显示、颜色、线宽、文字标注。

### 等高线 / 距离

同二维视图，支持仰角轮廓与范围轮廓显示。

### 数据显示

在三维场景中叠加动态报告数据，可设置位置、字体、颜色等。

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 飞机与其他对象间的访问需满足的几何与视线条件（方位角、仰角、距离、传播延时、高度等） |
| [太阳](../03-约束配置/02-太阳约束.md) | 飞机与其他对象间的访问需满足的、按太阳与月球相对位置判定的条件（太阳/月球仰角、规避角、附加中心天体遮挡等） |
| [时间](../03-约束配置/03-时间约束.md) | 飞机与其他对象间的访问需落入的时间窗口（当地时间/GMT/当地太阳时/时长/时段） |

## RF 环境

| 属性 | 说明 |
| --- | --- |
| [环境](../08-RF/RF.md) | 用于描述大气吸收、降雨及云雾等传播环境对射频信号传输造成的附加衰减，并将其计入通信或雷达链路性能计算。 |
| [雷达散射截面](../08-RF/雷达散射截面.md) | 用于描述目标在雷达电磁波照射下的等效散射能力，并通过频段、RCS 计算模型和 Swerling 起伏模型为雷达回波与探测性能计算提供目标散射参数。 |
