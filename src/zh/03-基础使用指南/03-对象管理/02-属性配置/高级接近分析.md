# 高级接近分析

高级接近分析用于在指定分析时段内，对选定的主目标与次目标开展接近分析，识别满足设定条件的接近事件，并可进一步进行线性运动检测和非线性碰撞概率计算。通过主配置指定分析对象与接近判据，通过高级属性设置预筛选条件、误差椭球数据来源及采样方式，并可在可视化属性中控制误差椭球的显示状态。

高级接近分析包含以下属性可配置：

- [基本](#基本)：设置分析时段、主目标与次目标，配置预筛选条件及线性、非线性计算参数。
- [可视化](#可视化)：设置主目标与次目标误差椭球的显示状态及显示范围。

## 基本

| 属性 | 说明 |
| --- | --- |
| [主配置](../通用属性/对象属性/基本/主配置.md) | 设置分析时段和接近判定阈值，指定主目标与次目标，并配置已选对象的误差椭球类别、各方向尺寸及包络球半径。 |
| [高级](../通用属性/对象属性/基本/高级.md) | 设置候选对象预筛选条件、误差椭球数据库、SSC 目标半径文件、采样步长及接近事件的报告方式。 |
| [非线性计算](../通用属性/对象属性/基本/非线性计算.md) | 根据接近分析结果执行线性运动检测，并按需采用 Cylinders 或 Bundles 方法计算非线性碰撞概率。 |

## 可视化

| 属性 | 说明 |
| --- | --- |
| [显示](../通用属性/对象属性/可视化/高级接近分析显示.md) | 设置误差椭球的整体显示状态，分别控制主目标与次目标误差椭球的显示，并选择显示所有次目标误差椭球或仅显示与碰撞事件相关的次目标误差椭球。 |
