# 火箭

火箭属性设置包含 **基本属性、二维视图、三维视图、约束、RF** 五大模块，多用于发射弹道与上升段仿真。

---

## 基本属性

包括 **弹道、姿态、地面椭圆** 三部分。

### 弹道

支持两种轨道预报器：

::: details 简单上升轨道
- 发射开始/终点时刻、仿真步长
- 发射点经纬度、高度
- 发射终点速度、经纬度、高度
:::

![简单上升轨道参数设置界面](./media/火箭/update2601-147.png)

::: details STK星历
- 开始/结束历元
- 星历文件加载
- 可选是否覆盖文件时间
:::

![STK星历参数设置界面](./media/火箭/update2601-148.png)

星历转换工具设置：点击 <kbd>导入数据</kbd>，进入【导入数据】页面。这里设置历元（UTC）、源坐标系、弹道/轨迹，并增加 <kbd>数据列</kbd> 功能，通过指定列号，将导入文件中的各列数据映射到对应的字段（相对时间、位置、速度），以解决文件列顺序混乱的问题。此外，星历转换工具支持参数自动保存，退出后重新打开时无需重复配置。

![星历转换工具设置界面](./media/火箭/update2603-1.png)

### 姿态

提供三种姿态模式：

::: details 标准
姿态类型 + 偏置姿态（四元数/欧拉角/YPR）
:::

![标准姿态模式参数设置界面](./media/火箭/update2601-149.png)

::: details 多分段
按时间段设置多段姿态与四元数
:::

![多分段姿态模式参数设置界面](./media/火箭/update2601-150.png)

::: details STK文件
导入外部姿态文件
:::

![STK文件姿态模式参数设置界面](./media/火箭/update2601-151.png)

### 地面椭圆

设置同 [飞机的属性设置](./飞机.md)，不再赘述。

## 二维视图

包含 **显示、轨迹、等高线、距离、刈幅、地面椭圆**。

### 刈幅

可选择刈幅类型并配置显示：

- 地面仰角、飞行器半锥角、刈幅半幅宽
- 地面仰角包络、飞行器半锥角包络

![刈幅设置界面](./media/火箭/update2601-152.png)

其余项同 [飞机的属性设置](./飞机.md)。

---

## 三维视图

包含 **模型、向量、姿态球、轨道系统、接近、等高线、距离、数据显示**。

### 轨道系统

- 选择坐标系统
- 是否显示、是否自定义颜色及颜色设置

![轨道系统设置界面](./media/火箭/update2601-153.png)

其余项同 [飞机的属性设置](./飞机.md)。

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 火箭与其他对象间的访问需满足的几何与视线条件（方位角、仰角、距离、传播延时、高度等） |
| [太阳](../03-约束配置/02-太阳约束.md) | 火箭与其他对象间的访问需满足的、按太阳与月球相对位置判定的条件（太阳/月球仰角、规避角、附加中心天体遮挡等） |
| [时间](../03-约束配置/03-时间约束.md) | 火箭与其他对象间的访问需落入的时间窗口（当地时间/GMT/当地太阳时/时长/时段） |

## RF

| 属性 | 说明 |
| --- | --- |
| [环境](../08-RF/RF.md) | 用于描述大气吸收、降雨及云雾等传播环境对射频信号传输造成的附加衰减，并将其计入通信或雷达链路性能计算。 |
| [雷达散射截面](../08-RF/雷达散射截面.md) | 用于描述目标在雷达电磁波照射下的等效散射能力，并通过频段、RCS 计算模型和 Swerling 起伏模型为雷达回波与探测性能计算提供目标散射参数。 |
