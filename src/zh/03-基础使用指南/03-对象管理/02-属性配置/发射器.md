# 发射器

发射器属性用于配置信号发射设备，包含 **基本属性、约束、RF** 三大配置模块。

---

## 基本属性

可选择发射器类型，并配置对应发射/转发参数：

- 简单发射机模型

- 中等发射机模型

- 复杂发射机模型

- 简单转发器模型

- 中等转发器模型

- 复杂转发器模型

> - 简单、中等、复杂发射/转发模型均支持：**模型规格、调制器、滤波器、额外损益** 配置
> - 复杂模型额外包含 **天线参数** 设置

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 发射器与其他对象间的访问需满足的几何与视线条件（方位角、仰角、距离、高度等） |
| [时间](../03-约束配置/03-时间约束.md) | 发射器与其他对象间的访问需落入的时间窗口（当地时间/GMT/当地太阳时/时长/时段） |
| [通信](../03-约束配置/04-通信约束.md) | 发射器的通信链路需满足的指标（频率、系统噪声温度、信噪比、误码率等） |

---

## RF

| 属性 | 说明 |
| --- | --- |
| [环境](../08-RF/RF.md) | 用于描述大气吸收、降雨及云雾等传播环境对射频信号传输造成的附加衰减，并将其计入通信或雷达链路性能计算。 |
