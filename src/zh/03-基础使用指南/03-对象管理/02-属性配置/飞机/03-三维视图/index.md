# 三维视图

控制飞机在三维场景中的模型、向量与附加数据显示。

| 属性 | 说明 |
| --- | --- |
| [模型](./01-模型.md) | 加载并配置飞机的三维模型及其外观参数。 |
| [向量](./02-向量.md) | 配置坐标系向量、标签和相关图形属性。 |
| [姿态球](./03-姿态球.md) | 配置姿态球的显示及参考坐标系等参数。 |
| [接近](./04-接近.md) | 配置三维场景中接近区域或不确定区域的图形显示。 |
| [等高线](./05-等高线.md) | 配置三维场景中的仰角轮廓等显示。 |
| [范围](./06-范围.md) | 配置三维场景中的范围轮廓与显示样式。 |
| [模型指向](./07-模型指向.md) | 配置飞机三维模型的指向显示相关参数。 |
| [数据显示](./08-数据显示.md) | 在三维场景中配置动态数据的显示方式。 |
