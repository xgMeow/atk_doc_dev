# 二维视图

控制飞机在二维地图上的图形显示。

| 属性 | 说明 |
| --- | --- |
| [显示](./01-显示.md) | 配置飞机在二维场景中的显示状态和图形样式。 |
| [轨迹](./02-轨迹.md) | 设置二维地图上的轨迹显示方式。 |
| [等高线](./03-等高线.md) | 配置二维视图中的仰角轮廓线等显示。 |
| [范围](./04-范围.md) | 配置二维视图中的范围轮廓线及分级显示。 |
| [划幅](./05-划幅.md) | 配置飞机二维视图中的划幅显示。 |
| [地面椭圆](./06-地面椭圆.md) | 配置地面椭圆在二维视图中的显示方式。 |
