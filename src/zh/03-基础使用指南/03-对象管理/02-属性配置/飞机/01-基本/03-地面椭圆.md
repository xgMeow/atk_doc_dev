# 地面椭圆

地面椭圆用于定义飞机在地表上的椭圆形区域。通过设置椭圆中心、半长轴、半短轴及方位角，可指定椭圆的位置、大小和方向。每个椭圆关联一个时间，多个椭圆可组成同一椭圆集合。

地面椭圆属性包含 **椭圆设置** 和 **椭圆数据** 两部分。此处定义椭圆的几何数据，具体显示效果可在[二维视图—地面椭圆](../02-二维视图/06-地面椭圆.md)中设置。

## 椭圆设置

椭圆设置用于创建和管理椭圆集合。一个飞机对象可以包含多个椭圆集合，每个集合可保存多条椭圆数据。

| 选项 | 说明 |
| --- | --- |
| 椭圆集合列表 | 显示当前飞机已创建的椭圆集合，如 `EllipseSet1`。选择集合后，下方显示对应的椭圆数据。 |
| 新建 | 新增一个椭圆集合。 |
| 删除 | 删除选中的椭圆集合及其包含的椭圆数据。 |

## 椭圆数据

椭圆数据用于定义当前所选集合内各个椭圆的时间、中心位置、尺寸和方向。选择椭圆集合后，可通过表格编辑对应数据。

| 参数 | 说明 |
| --- | --- |
| 时间 | 椭圆对应的时间，可在时间输入框中设置；界面示例采用 `UTCG` 时间格式。 |
| 自定义位置 | 勾选后，可通过纬度和经度指定椭圆中心；未勾选时，使用飞机在对应时刻的地面位置作为椭圆中心。 |
| 纬度（deg） | 自定义椭圆中心的地理纬度 |
| 经度（deg） | 自定义椭圆中心的地理经度 |
| 半长轴（m） | 椭圆长轴长度的一半，用于定义椭圆的主要尺寸 |
| 半短轴（m） | 椭圆短轴长度的一半，用于定义椭圆的另一尺寸 |
| 方位角（deg） | 椭圆长轴相对于当地正北方向顺时针旋转的角度 |

## 设置方法

1. 在**椭圆设置**区域点击【新建】，创建椭圆集合，或从列表中选择已有集合。
2. 在**椭圆数据**区域点击【新建】，添加椭圆数据行。
3. 设置椭圆对应的时间。若需要指定固定地理位置，勾选【自定义位置】并填写纬度、经度；否则使用飞机在该时刻的地面位置。
4. 输入半长轴、半短轴及方位角，确定椭圆的大小和方向。
5. 根据需要继续添加数据行，或创建其他椭圆集合。
