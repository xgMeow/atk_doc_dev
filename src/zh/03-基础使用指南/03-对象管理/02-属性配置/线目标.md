# 线目标

线目标用于描述中心天体表面线状地理目标的对象。通过依次连接具有经纬度坐标的路径点，可定义道路、海岸线等线状地理要素，并设置锚点作为线目标的参考位置，用于与其他对象的访问分析。

线目标包含以下属性可配置：

- [基本](#基本)：定义线目标的路径及锚点。
- [二维视图](#二维视图)：设置线目标在二维地图中的图形显示。
- [约束](#约束)：设置线目标与其他对象之间访问成立所需的几何与时间条件。

## 基本

| 属性 | 说明 |
| --- | --- |
| [路径](../通用属性/对象属性/基本/线目标路径.md) | 通过经纬度坐标定义路径点，按点的排列顺序构建线目标；支持在地图中新增、修改和选择路径点，并设置线目标的锚点。 |

## 二维视图

| 属性 | 说明 |
| --- | --- |
| [二维属性](../通用属性/对象属性/二维视图/线目标二维属性.md) | 设置线目标在二维地图中的路径图形及显示样式。 |

## 约束

| 属性 | 说明 |
| --- | --- |
| [基本](../03-约束配置/01-基本约束.md) | 设置线目标与其他对象之间访问成立所需的基本几何与视线条件。 |
| [时间](../03-约束配置/03-时间约束.md) | 设置访问成立所需满足的时间窗口与时段条件。 |
