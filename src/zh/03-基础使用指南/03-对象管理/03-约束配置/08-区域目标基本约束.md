# 基本

限定其他对象访问该区域时应满足的几何条件。区域目标由边界围成一定范围，可以按**区域内部分位置满足条件**或**整个区域均满足条件**两种方式判定访问。

## 约束参数

| 参数 | 说明 |
| --- | --- |
| 最小俯仰角 | 勾选后设置访问区域目标所需的最低仰角。仰角由区域内相应位置的**当地水平面**与指向关联对象的视线确定。低于设定角度的区域位置不满足该约束。 |
| 访问整个对象 | 勾选后，要求**整个区域**满足启用的访问约束；不勾选时，区域中存在满足全部启用约束的部分，即可判定该时刻对区域目标的访问成立。 |
| 视线约束 | 勾选后，将中心天体的几何遮挡纳入访问判定。只有区域内符合访问要求的位置与关联对象之间存在无遮挡视线时，才满足此约束。 |
| 高度 — 最小值 | 勾选后启用高度下限，仅保留满足所设最低高度的访问条件。 |
| 高度 — 最大值 | 勾选后启用高度上限，仅保留满足所设最高高度的访问条件。 |

## 访问整个对象

**访问整个对象**决定对区域范围的判定要求。

- **未勾选访问整个对象**：允许部分区域满足访问条件。例如卫星仅能通视区域的一部分，且该部分满足最小俯仰角等已启用约束时，可形成对区域目标的访问。
- **勾选访问整个对象**：要求区域整体满足已启用约束。如果区域内仍有部分位置不满足最小俯仰角或被中心天体遮挡，则不能判定为对整个区域的有效访问。

当同时启用多个约束时，**同一位置需要同时满足这些条件**，不能以区域内不同位置分别满足不同约束来代替一次有效访问。

最小俯仰角以区域内位置的当地水平面为参考；**基本 → 质心**中设置的参考中心点不代替整个区域的访问判断。

## 设置方法

1. 在**基本 → 边界**中定义区域目标的轮廓，打开**约束 → 基本**。
2. 如需限制观测方向，勾选**最小俯仰角**，填写最低角度。
3. 根据分析任务决定是否勾选**访问整个对象**：部分区域可访问即可满足任务时不勾选；要求整个区域均满足访问条件时勾选。
4. 如需考虑中心天体遮挡，勾选**视线约束**。
5. 如需限制高度，在**高度**区域分别勾选**最小值**、**最大值**并填写对应数值。
6. 点击**应用**或**确定**保存设置，再执行区域目标与关联对象的访问分析。

有关最小俯仰角、视线约束和高度的几何定义与计算原理，参见[基本约束](../../../03-约束配置/01-基本约束.md)。
