# 约束配置

## 功能说明

约束限定对象之间在何种条件下才构成一次有效访问。进行可见性分析、覆盖性分析或通信链路计算时，软件先根据对象的相对运动求出访问时段，再由已启用的约束对时段逐时刻筛选：某一时刻只有全部已启用的约束都满足，该时刻才被判定为满足约束，并计入访问时段。

::: tip 判定规则
各类约束相互独立：可以单独启用一类约束，也可以组合使用多类约束。每个条件也相互独立，未被启用的条件不参与判定；只有全部已启用的条件均满足时，该时刻才被判定为满足该类约束。
:::

## 对象与术语

约束描述的是两个对象之间的访问条件，本册各约束页统一使用下列称呼：

- **分析对象**：本次分析中的参考方。方位角、仰角、距离描述的是关联对象相对于分析对象的空间方位与距离；高度取分析对象自身的高度；太阳、月球的仰角与规避角也以分析对象为顶点。在可见性分析中，它由窗口的「访问对象」指定；在覆盖分析中，它由「分析对象」指定，即被覆盖的一方；进行光延迟修正时，默认分析对象为接收信号的一方。理论基础页中又称受约束对象（见[太阳约束](../../../04-理论基础/02-约束配置/02-太阳约束.md)）。

- **关联对象**：与分析对象配对的另一方。在可见性分析中，它是在窗口左下角对象列表中选定的目标对象；在覆盖分析中，它对应所选覆盖资源。分析对象与关联对象互为对方的关联对象。

- **中心天体**：分析对象所环绕或所在的天体，例如绕地卫星的中心天体为地球。高度相对它度量，视线约束与地形约束也按它判断遮挡；太阳约束中的“附加中心天体”是除它以外另行指定的天体，用于判断月球等其它天体是否挡住访问路径。

- **地面对象**：位于中心天体表面的对象，如地面站、车辆、舰船等。太阳地平仰角这类当地仰角定义在分析对象的当地 LH（当地水平）坐标系下，分析对象为地面对象时，参考的就是该对象所在地面的当地水平面。

## 打开约束

1. 在【对象视图】中右键对象，在弹出菜单中选择【属性】，打开该对象的属性面板。

2. 在属性面板左侧的属性树中展开【约束】节点，其下列出该对象开放的各项约束，点击其中一项即可打开对应的约束页。

![对象属性中的约束页](./media/README/image-20260916161206139.png)

图中为卫星对象的属性面板：【约束】节点下包含基本、太阳、时间三项，右侧为【基本】约束页的参数区，以及底部的视线约束、地形约束开关。

## 约束页

不同对象开放的约束页可能不同，例如通信约束只与发射器、接收器相关。各对象实际开放的约束页见对象属性页的「约束」段。

- [基本约束](01-基本约束.md) — 按方位角、仰角、距离等相对几何关系，以及视线、视场和地形遮挡判定访问是否有效

- [太阳约束](02-太阳约束.md) — 按太阳、月球及指定天体的仰角与规避角，以及附加中心天体遮挡判定访问是否有效

- [时间约束](03-时间约束.md) — 限定访问在时间维度上落入允许的时间范围

- [通信约束](04-通信约束.md) — 按频率、接收功率、信噪比、误码率等链路指标判定通信访问是否可用

## 参数与判定规则

同一约束页中各项条件的类型与设置方式如下：

- **取值范围**：几何参数、链路指标等数值型参数提供【最小值】与【最大值】，勾选并输入数值后，参数取值须落在所设范围之内；未勾选的一端不作限制。同时启用最小值与最大值时，对应参数 $x$ 应满足 $x_{\min}\leq x\leq x_{\max}$。

- **反向选择**：基本约束的几何参数与通信约束的链路指标提供该项，勾选后落在所设范围内的访问将被剔除，仅保留范围之外的访问。

- **开关类条件**：视线约束、地形约束等以复选框的形式给出，勾选即参与判定。

- **组类条件**：时间约束的时段、太阳约束的附加中心天体遮挡等成组给出，需先勾选该组的【使用】，组内的设置才生效。
