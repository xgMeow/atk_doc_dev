# 显示

查看覆盖定义对象的**分析区域边界**和**网格采样点**，并调整网格图形的大小与颜色。

## 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 | 覆盖定义图形的总开关。勾选后按下方网格选项显示相关图形。 |
| 显示区域 | 勾选后显示在**基本 → 网格**中定义的覆盖区域边界，用于检查分析范围。取消勾选后隐藏区域边界，不影响网格点的显示。 |
| 显示点 | 勾选后在网格采样位置绘制点标记，便于查看网格分布及疏密程度；取消勾选后隐藏点标记，不删除网格点。 |
| 点大小 | 设置网格点标记在视图中的显示尺寸。增大数值可使点标记更醒目，但不会改变网格点数量、位置或间隔。 |
| 填充 | 控制网格图形的颜色填充。勾选后以填充方式呈现网格区域或网格点对应的图形。 |
| 颜色 | 点击颜色区域选择网格图形的显示颜色，用于区分不同覆盖定义对象。 |

**显示区域**与**显示点**相互独立。例如，可以只显示区域边界以检查覆盖范围，也可以只显示网格点以检查采样位置；两项同时启用时，可同时观察区域边界和采样点的分布。

## 设置方法

1. 在**基本 → 网格**中完成覆盖区域、网格间隔和网格点位置的设置。
2. 打开覆盖定义对象的**可视化 → 显示**，勾选**显示**。
3. 根据需要勾选**显示区域**或**显示点**。显示网格点时，可通过**点大小**调整点标记尺寸。
4. 如需显示网格填充效果，勾选**填充**，并在**颜色**中选择显示颜色。
5. 查看场景中的覆盖区域边界与网格点分布，完成显示配置。
