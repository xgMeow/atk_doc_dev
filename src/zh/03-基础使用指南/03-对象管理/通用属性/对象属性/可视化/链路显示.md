# 显示

设置链路在场景中的图形表现，包括**静态可视化**和**动态可视化**。
静态可视化用于查看链路的整体连接关系，动态可视化用于观察动画当前时刻的有效连接。两类图形可分别启用，并使用不同的颜色和线条样式。

## 显示开关

| 参数 | 说明 |
| --- | --- |
| 显示 | 链路图形的总开关。取消勾选后，静态连接图形、动态高亮及动态连接线均不显示；重新勾选后，按照下方的静态和动态可视化设置显示。 |

## 静态可视化

静态可视化用于呈现链路计算所涉及的连接关系，便于从整体上查看链路中的对象及其连接情况。静态图形不随动画时间逐帧切换，**不能仅凭静态连接图形判断当前时刻链路是否有效**。

| 参数 | 说明 |
| --- | --- |
| 显示 | 勾选后启用静态链路图形，并开放下方的样式设置；取消勾选后隐藏静态图形。 |
| 颜色 | 设置静态链路图形的颜色，可与动态连接线采用不同颜色，以便区分。 |
| 线型 | 选择静态连接线的线条样式。 |
| 线宽 | 设置静态连接线的绘制宽度。 |

## 动态可视化

动态可视化根据**当前动画时刻的链路访问状态**更新图形。当链路形成有效连接时，可通过对象高亮和连接线识别参与连接的对象；动画时间改变后，相关图形随有效连接状态变化。

| 参数 | 说明 |
| --- | --- |
| 显示高亮 | 勾选后，在动画过程中突出显示当前参与有效链路连接的对象，便于识别有效连接涉及的节点。 |
| 显示线 | 勾选后，在当前有效连接的相邻对象之间绘制动态连接线；连接不再有效时，相应连接线不再表示为有效连接。 |
| 颜色 | 设置动态连接线的颜色，与静态可视化的颜色分别配置。 |
| 线型 | 选择动态连接线的线条样式。 |
| 线宽 | 设置动态连接线的绘制宽度。 |
| 显示方向 | 在动态连接线上显示连接方向或顺序标识，用于辨识链路中各段连接的先后关系。该功能配合**显示线**使用。 |

**显示高亮**和**显示线**可以分别启用：前者用于突出参与连接的对象，后者用于展示对象之间的连接关系。例如，链路依次包含 A、B、C 三个对象时，启用**显示线**可在有效连接期间查看 A—B 和 B—C 两段连接；启用**显示方向**则有助于按照链路定义的顺序辨识连接次序。

## 设置方法

1. 在**基本 → 定义**中选择参与链路的对象，并设置其连接顺序。
2. 打开**可视化 → 显示**，勾选顶部的**显示**。
3. 如需查看链路整体连接图形，在**静态可视化**中勾选**显示**，并设置颜色、线型和线宽。
4. 如需观察动画中的连接状态，在**动态可视化**中勾选**显示高亮**或**显示线**；启用连接线后，可设置其颜色、线型和线宽。
5. 如需辨识连接次序，在启用**显示线**的同时勾选**显示方向**。
6. 点击**应用**或**确定**，运行场景动画，查看链路图形随时间的变化。

## 显示说明

- **静态可视化**主要用于查看链路连接的整体情况，**动态可视化**主要用于观察当前动画时刻的有效连接。两者的开关和线条样式分别设置。
- **显示方向**用于辨识链路段的连接顺序，不会调整**基本 → 定义**中已选对象的排列次序。

链路对象的选择和排列方式参见[链路定义](../基本/链路定义.md)。
