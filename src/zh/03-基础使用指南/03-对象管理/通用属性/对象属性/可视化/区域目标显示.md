# 显示

设置区域目标在场景中的图形表现，包括区域轮廓、名称标签、中心点、边界点及内部填充。

## 显示内容

| 参数 | 说明 |
| --- | --- |
| 显示 | 区域目标的图形显示总开关。勾选后，按照下方选项绘制区域；取消勾选后，区域轮廓及相关标记一并隐藏，已定义的区域数据仍保留。 |
| 显示标签 | 在区域目标旁显示对象名称。 |
| 显示中心点 | 显示区域目标的质心位置标记。 |
| 显示边界点 | 显示用于定义区域轮廓的边界点，便于检查点的位置及其构成的区域形状。对于通过边界点创建的区域，可与轮廓线配合查看。 |
| 填充 | 勾选后，对区域轮廓围成的内部范围进行颜色填充；取消勾选后，保留轮廓线而不显示内部填充。 |
| 透明度（%） | **勾选填充后**可设置。通过输入数值或拖动滑块调整填充区域的透明程度。 |

## 图形样式

| 参数 | 说明 |
| --- | --- |
| 颜色 | 点击颜色区域选择区域目标的显示颜色，用于区分场景中的不同区域。 |
| 线型 | 选择区域边界轮廓的线条样式。 |
| 线宽 | 调整区域边界轮廓的绘制宽度，使轮廓在地图背景上更容易辨认。 |

## 设置方法

1. 在**基本 → 边界**中完成区域轮廓定义；如需设置中心点，在**基本 → 质心**中指定位置或启用自动计算质心。
2. 打开区域目标的**可视化 → 显示**，勾选**显示**，启用区域图形。
3. 根据查看需要，分别勾选**显示标签、显示中心点、显示边界点**。
4. 设置**颜色、线型、线宽**，调整区域边界的显示样式。
5. 如需突出区域覆盖范围，勾选**填充**，再通过**透明度（%）**调整填充效果，使区域位置与底图信息均清晰可见。
