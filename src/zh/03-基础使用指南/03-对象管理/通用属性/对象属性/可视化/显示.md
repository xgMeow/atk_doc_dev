# 显示

显示属性用于控制集群对象相关图形的可见性，并设置其颜色、线型和线宽。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 显示 | 集群图形的显示开关。勾选后启用集群图形显示，并可编辑下方的样式参数；取消勾选后隐藏集群图形。 |
| 颜色 | 点击颜色区域，选择集群图形的显示颜色。 |
| 线型 | 从下拉列表选择集群图形的线条样式。 |
| 线宽 | 从下拉列表设置集群图形的线条宽度。 |

## 设置方法

1. 打开集群对象的**可视化 → 显示**属性页。
2. 勾选**显示**，启用集群图形，并激活颜色、线型和线宽设置。
3. 根据需要选择**颜色、线型和线宽**，调整图形外观。
4. 点击**应用**或**确定**，保存设置。
