# 显示

> **适用范围：** 仅限高级接近分析可用。

## 功能说明

【显示】用于控制高级接近分析中误差椭球在三维视图中的显示状态。可以统一开启或关闭误差椭球显示，也可以分别控制主目标误差椭球和次目标误差椭球的显示，并设置次目标误差椭球的显示范围。

## 可视性设置

【可视性】区域包含总显示开关、主椭球显示、次椭球显示及次椭球显示范围等选项。

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制误差椭球的整体显示状态。勾选后，按照下方的主椭球和次椭球设置显示相应误差椭球；取消勾选后，不显示误差椭球。 |
| 显示主椭球 | 控制主目标误差椭球是否在三维视图中显示。勾选后显示主目标误差椭球。 |
| 显示次椭球 | 控制次目标误差椭球是否在三维视图中显示。勾选后显示次目标误差椭球。 |
| 所有 | 显示所有次目标误差椭球。 |
| 带碰撞 | 仅显示与碰撞事件相关的次目标误差椭球。 |

## 设置方法

1. 打开高级接近分析对象的属性设置界面，进入【可视化】-【显示】页面。
2. 勾选【显示】，启用误差椭球的整体显示。
3. 根据需要勾选【显示主椭球】和【显示次椭球】，分别控制主目标和次目标误差椭球的显示。
4. 显示次目标误差椭球时，根据查看需求选择【所有】或【带碰撞】。
5. 点击【确定】或【应用】，在三维视图中检查误差椭球的显示效果。

## 注意事项

- 【显示】用于控制误差椭球的整体显示；未启用时，主椭球和次椭球均不显示。
- 【显示主椭球】和【显示次椭球】分别控制两类误差椭球，二者可以根据需要单独启用或关闭。
- 【所有】和【带碰撞】用于筛选次目标误差椭球的显示范围，不改变主目标、次目标及误差椭球的分析参数。
- 本页面用于设置误差椭球的可视化效果，不用于配置接近分析的计算条件。
