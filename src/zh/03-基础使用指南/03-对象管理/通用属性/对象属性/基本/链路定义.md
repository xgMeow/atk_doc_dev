# 定义

用于确定链路包含哪些场景对象，以及这些对象之间的连接顺序。
链路按**已选对象**列表中的排列顺序依次连接，相邻两个对象构成一段连接。只有各段连接在同一时刻均满足访问条件，完整链路才处于有效状态。

## 选项过滤器

**选项过滤器**用于从场景对象中筛选可加入链路的对象类型，便于在对象较多时查找所需成员。界面提供卫星、区域目标、集群等对象类型选项。

| 参数 | 说明 |
| --- | --- |
| 对象类型 | 勾选需要查看的对象类型，按类型筛选下方**可选对象**列表。可同时选择多个类型。 |
| 选择所有过滤器 | 勾选全部对象类型过滤器。 |
| 清除所有过滤器 | 取消全部对象类型过滤器的勾选。 |

过滤器只用于筛选候选对象，**不会移除已经加入链路的对象，也不会改变链路连接顺序**。

## 对象选择与排序

左侧的**可选对象**列表列出场景中可供选择的对象。
右侧的**已选对象**列表列出当前链路的组成对象。
使用两列之间的箭头按钮添加或移除对象，并通过右侧的上下箭头调整连接顺序。

| 项目 | 说明 |
| --- | --- |
| 可选对象 | 显示可供加入链路的场景对象。选中对象后，点击**右箭头**将其加入链路。 |
| 已选对象 | 按当前连接顺序显示已加入链路的对象。**列表自上而下的顺序即链路连接顺序**。 |
| 右箭头 | 将左侧选中的对象加入**已选对象**列表。 |
| 左箭头 | 从**已选对象**列表中移除选中的对象，不删除场景中的原对象。 |
| 上箭头 | 将右侧选中的对象向前移动一位。 |
| 下箭头 | 将右侧选中的对象向后移动一位。 |

### 连接顺序

假设**已选对象**列表自上而下依次为 A、B、C，则链路定义为：

`A → B → C`

该链路包含 **A—B** 和 **B—C** 两段相邻连接，**不会因这三个对象被加入同一链路，就自动建立 A—C 的直接连接**。只有 A—B 与 B—C 在同一时刻均有效，整条链路才有效。

对象的排列顺序具有实际意义。例如，将 `A → B → C` 调整为 `A → C → B`，相邻连接就变为 **A—C** 和 **C—B**，对应不同的链路结构。构建包含中继节点的链路时，应按照实际传递路径依次排列起点、中继对象和终点。

## 设置方法

1. 打开链路对象的**基本 → 定义**属性。
2. 根据需要，在**选项过滤器**中选择对象类型，并从**可选对象**列表中找到链路成员。
3. 选中一个对象，点击**右箭头**将其加入**已选对象**列表；依次加入其余对象。
4. 检查**已选对象**的排列顺序。若顺序不符合预期，选中相应对象，通过**上箭头**或**下箭头**调整位置。
5. 如需取消某个链路成员，在**已选对象**列表中选中该对象，点击**左箭头**移除。
6. 确认链路成员及连接顺序后，点击**确定**或**应用**保存设置。

**注意事项：**

- **可选对象**中的对象只有加入**已选对象**列表后，才成为链路成员。
- 调整**已选对象**的顺序会改变相邻连接关系；仅修改对象类型过滤器不会改变已建立的链路。
- 链路是否有效取决于各相邻对象之间的访问条件。某一段连接有效，不代表整条链路同时有效。
