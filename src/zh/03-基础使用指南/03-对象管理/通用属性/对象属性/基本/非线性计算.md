# 非线性计算

> **适用范围：** 仅限高级接近分析可用。

## 功能说明

【非线性计算】用于判断接近过程中的相对运动是否可以采用线性模型近似，并在需要时使用非线性方法计算碰撞概率。该页面使用主配置中接近分析得到的目标组合和最近接近时刻，并通过参数设置控制线性检测及非线性碰撞概率计算过程。

## 目标与最近时刻

页面上方显示主目标、次目标和最近时刻三个信息区域。

| 参数 | 说明 |
| --- | --- |
| 主目标 | 显示当前选中的主目标。 |
| 次目标 | 显示与主目标对应的次目标。 |
| 最近时刻 | 显示两目标对应接近事件的最近接近时刻。 |

点击【高级接近分析计算】后，根据主配置中的对象和分析时段执行接近分析，并更新可供非线性计算使用的目标及最近时刻信息。

## 结果参数

| 参数 | 说明 |
| --- | --- |
| 概率冲淡阈值 | 设置或显示概率冲淡区域对应的距离阈值，单位为 km。该参数用于判断当前接近事件是否处于概率冲淡区域。 |
| 最大碰撞概率 | 显示最大碰撞概率计算结果，用于评估给定不确定性条件下的碰撞风险。 |

> **注意：** 【概率冲淡阈值】的单位为 km，表示距离量，不是碰撞概率数值。

## 参数设置

参数设置区域用于控制非线性碰撞概率计算的时间范围、分段精度及概率计算精度。

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 积分时长 | 0 s | 设置非线性碰撞概率计算所考虑的时间范围。设置为 0 s 时，采用计算过程的默认时间范围。 |
| 最大时间步长 | 10 s | 设置非线性计算中每个分段允许采用的最大时间步长。 |
| 最大弯角 | 1 deg | 限制相邻轨迹分段之间允许的最大方向变化角度，用于控制分段轨迹的弯曲程度。 |
| 分辨率 | 0.0001 km | 设置 Bundles 方法中空间概率计算的网格分辨率。分辨率越小，空间划分越细，计算量通常也越大。 |
| 概率分数极限 | 0.05 | 设置线性与非线性概率计算结果之间允许的相对差异限值，用于判断线性近似是否满足精度要求。 |
| 末端标准差 | 4 | 设置非线性计算所考虑的末端标准差范围，用于限定计算区域。 |
| 最大标准差步长 | 0.25 | 限制相邻计算分段在标准差方向上的最大步长，用于控制分段长度及计算精度。 |

## 线性检测计算

【线性检测计算】用于判断最近接近时刻附近的相对运动是否满足线性近似条件。计算时结合相对速度及碰撞概率误差要求，对线性相对运动假设的适用性进行判断。

| 参数 | 说明 |
| --- | --- |
| 最近时刻相对速度 | 显示次目标相对于主目标在最近接近时刻的相对速度。 |
| 最小估计相对速度 | 显示满足线性运动近似要求的最小相对速度估计值。 |
| 线性碰撞概率 | 显示假设两目标在最近接近时刻附近作线性相对运动时计算得到的碰撞概率。 |

当最近接近时刻的实际相对速度不小于最小估计相对速度时，线性相对运动假设满足相应的概率误差要求；否则，应考虑采用非线性方法进一步计算碰撞概率。

点击【线性检测计算】按钮，执行线性检测并更新相应结果。

## 非线性碰撞概率计算

非线性计算区域提供两种计算方法，分别为 Cylinders 和 Bundles。

| 方法 | 说明 |
| --- | --- |
| Cylinders | 将非线性相对运动过程划分为连续的圆柱分段，并根据各分段计算碰撞概率。 |
| Bundles | 将非线性相对运动过程划分为连续的空间分段，并根据各分段计算碰撞概率。 |

点击【碰撞概率计算（Cylinders）】或【碰撞概率计算（Bundles）】按钮，执行对应方法的非线性碰撞概率计算。计算完成后，在相应的【碰撞概率】字段中显示结果。

## 设置与计算流程

1. 完成【主配置】页面中的分析时段、目标对象、误差椭球和包络球半径设置；
2. 完成【高级】页面中的筛选器、数据库、采样步长及碰撞类型设置；
3. 执行接近分析，获得主目标、次目标及对应的最近接近时刻；
4. 进入【非线性计算】页面，检查主目标、次目标和最近时刻信息；
5. 根据计算需求设置积分时长、最大时间步长、最大弯角、分辨率及概率计算相关参数；
6. 点击【线性检测计算】，查看最近时刻相对速度、最小估计相对速度和线性碰撞概率；
7. 如需进行非线性概率计算，选择 Cylinders 或 Bundles 方法，点击对应计算按钮并查看结果。

## 注意事项

- 非线性计算依赖主配置中已经完成的接近分析结果。执行计算前，应确认主目标、次目标和最近时刻信息正确。
- 进行线性检测和非线性碰撞概率计算时，应确保对象具有满足分析要求的位置、速度及协方差信息。
- 【概率冲淡阈值】的单位为距离单位，不应与碰撞概率数值混淆。
- 最大时间步长、最大弯角和分辨率会影响非线性计算的分段精度及计算量，应根据任务精度要求合理设置。
- Cylinders 和 Bundles 为不同的非线性概率计算方法，应根据分析需求选择；两种方法的计算结果应结合各自的计算设置进行理解。
- 软件提供默认值，实际使用时应根据轨道数据质量、相对运动特征和计算精度要求进行设置。
