# 主配置

> **适用范围：** 仅限高级接近分析可用。

## 功能说明

【主配置】用于设置接近分析的时间范围和距离判定阈值，并指定参与分析的主目标与次目标。通过配置目标的误差椭球类别、各方向尺寸及包络球半径，确定接近事件的判定对象和几何参数。

## 分析时段与阈值

分析时段用于确定执行接近分析的时间范围。可以直接使用当前场景的时间区间，也可以单独指定开始历元和结束历元。

| 参数 | 说明 |
| --- | --- |
| 使用场景区间 | 勾选后，使用当前场景设定的时间区间进行分析。 |
| 区间 | 显示当前使用的场景时间区间。 |
| 开始历元 | 未使用场景区间时，设置分析的开始时间。 |
| 结束历元 | 未使用场景区间时，设置分析的结束时间。 |
| 时间格式 | 设置开始历元和结束历元的时间表示方式，可选择 UTCG_MM、UTCG、BJT、BDT、BDTG、GPS、GPSG、TDTG、JDate、ModJDate 和 EpSec。点击时间格式右侧的下拉按钮，还可以通过快捷菜单设置日期。|
| 阈值 | 设置接近事件的距离判定阈值。默认情况下，以主目标与次目标误差椭球之间的间距作为判定依据；当间距小于设定阈值时，记录相应接近事件。 |
| 使用距离测量 | 勾选后，使用两个对象之间的相对距离作为判定依据，而不使用误差椭球之间的间距。 |

时间输入框右侧的下拉菜单还提供以下快捷操作：

| 选项 | 说明 |
| --- | --- |
| 单位 | 展开时间单位列表，选择时间的表示格式。 |
| 设置为今天 | 将对应的时间设置为当前日期。 |
| 设置为明天 | 将对应的时间设置为下一日。 |
| 设置日期 | 打开日期选择功能，指定对应的日期。 |

> **说明：** 【阈值】的单位可通过输入框右侧的单位选项设置。

## 计算与报告

主配置界面提供【计算】和【报告】两个按钮，用于执行接近分析及查看分析报告。

| 按钮 | 说明 |
| --- | --- |
| 计算 | 根据当前设置的分析时段、主目标、次目标及相关参数执行接近分析。计算完成后，弹出【计算完成】提示框。 |
| 报告 | 查看接近分析结果报告。当存在可用的接近事件时，打开相应的分析报告；当未找到接近事件时，弹出【未找到接近事件！】提示框。 |

**操作说明：**

1. 完成分析时段、主目标和次目标等参数设置。
2. 点击【计算】按钮，执行接近分析。
3. 等待计算完成，确认弹出的提示信息。
4. 点击【报告】按钮，查看分析结果。如果没有找到接近事件，则无法生成相应的分析报告。

## 主目标列表与次目标列表

主目标列表和次目标列表的界面组成及操作方式完全相同，分别用于指定分析中的两组对象。

- **主目标列表：** 选择需要重点关注的对象。
- **次目标列表：** 选择可能与主目标发生接近的对象。

两个列表中的【类型】下拉框均可选择以下类型：

| 类型 | 说明 |
| --- | --- |
| 卫星 | 从当前场景中的卫星对象列表中选择分析对象。 |
| 库目标 | 显示已添加的库目标文件及其包含的目标，通常为 TLE 文件。可点击【添加】按钮，导入目标文件。 |

左侧列表显示当前类型下可供选择的对象，右侧【已选中】列表显示已经加入分析的对象。选中左侧对象后，点击右箭头可将其加入右侧列表；选中右侧对象后，点击左箭头可将其移除。

主目标和次目标可以分别选择对象，两组列表中的对象不要求相同。

## 已选中对象的参数

【已选中】列表用于设置每个对象的误差椭球类别、各方向尺寸及包络球半径。列表中的参数如下：

| 参数 | 说明 |
| --- | --- |
| 名称 | 显示已加入分析的对象名称。 |
| 类别 | 设置对象误差椭球的定义方式。 |
| 切向 | 设置误差椭球沿切向的尺寸。 |
| 径向 | 设置误差椭球沿径向的尺寸。 |
| 法向 | 设置误差椭球沿法向的尺寸。 |
| 包络球半径 | 设置对象的包络球半径，用于表示对象本体尺寸，并参与碰撞相关计算。 |

【类别】下拉列表包含以下选项：

| 类别 | 说明 |
| --- | --- |
| 固定 | 根据手动输入的切向、径向和法向尺寸定义误差椭球。 |
| 轨道类型 | 根据对象所属的轨道类型，从固定轨道类型数据库中读取对应的误差椭球尺寸。 |
| 二次曲线 | 从时间二次曲线数据库中读取各方向的二次函数系数，使误差椭球尺寸随时间变化。 |
| 二次/轨道 | 根据对象所属的轨道类型，从相应数据库中读取二次函数系数，计算随时间变化的误差椭球尺寸。 |
| 协方差 | 根据对象的位置协方差信息确定误差椭球的尺寸和方向。 |

选择【固定】时，可以直接编辑切向、径向和法向尺寸；选择其他类别时，这三个方向的参数显示为“------”，不能手动修改。

## 默认参数

主目标列表和次目标列表下方分别设有【默认】参数区域。该区域包含切向、径向、法向和类别四项参数。

| 参数 | 默认值 |
| --- | --- |
| 切向 | 20000 m |
| 径向 | 10000 m |
| 法向 | 5000 m |
| 类别 | 固定 |

默认参数与【已选中】列表中对象的前四项参数相对应，即类别、切向、径向和法向；包络球半径为单独设置的第五项参数，不包含在默认参数区域内。

修改默认参数后，参数用于后续加入列表的对象，不会自动覆盖已经加入列表的对象参数。

当【类别】选择【固定】时，切向、径向和法向尺寸可以编辑；选择其他类别时，三个方向的尺寸不可手动设置。

## 设置方法

1. 在【分析时段】区域勾选【使用场景区间】，或分别设置开始历元和结束历元；
2. 设置接近判定【阈值】，根据分析需求决定是否勾选【使用距离测量】；
3. 在主目标列表和次目标列表中选择对象类型，从左侧列表选择对象并点击右箭头，将对象加入右侧【已选中】列表；
4. 为已选对象设置误差椭球类别、各方向尺寸和包络球半径；
5. 检查主目标和次目标列表中的对象及参数，确认设置无误后，点击【确定】或【应用】。

## 注意事项

- 主目标列表和次目标列表的界面及设置方式相同，但两者在分析中的作用不同。
- 默认参数区域中的四项参数对应已选中对象的类别、切向、径向和法向；包络球半径需要单独设置。
- 默认参数主要用于后续加入列表的对象，修改默认值不会自动改变已加入对象的参数。
- 选择非【固定】类别后，切向、径向和法向尺寸由相应数据库或协方差信息确定，不能在列表中直接修改。
- 使用【协方差】类别时，应确保对象具有满足分析时段要求的协方差信息。
- 勾选【使用距离测量】后，接近事件判定采用对象之间的相对距离，不再以误差椭球之间的间距作为判据。
