# 网格

确定覆盖分析的空间范围及参与计算的采样点。首先通过**网格区域配置参数**限定分析范围，再通过**网格定义**设置采样点的分布密度、高度和位置。网格点可以按指定间隔自动生成，也可以从自定义文件导入。

## 网格区域配置参数

在**类型**下拉列表中选择网格区域的定义方式。不同类型对应的参数如下：

| 类型 | 参数 | 说明 |
| --- | --- | --- |
| 全球范围 | 无 | 以整个中心天体表面作为覆盖分析区域。 |
| 经纬度区域 | 最小纬度、最小经度、最大纬度、最大经度（deg） | 通过经纬度上下限指定分析区域，适用于限定某一经纬度范围内的覆盖分析。 |
| 纬度边界 | 最小纬度、最大纬度（deg） | 以两条纬线作为南北边界，分析区域沿经度方向延伸。 |
| 纬度线 | 最小经度、最大经度、纬度（deg） | 在指定纬度上，沿给定的经度范围布置采样点，适合分析一条纬线上的覆盖变化。 |
| 经度线 | 最小纬度、最大纬度、经度（deg） | 在指定经度上，沿给定的纬度范围布置采样点，适合分析一条经线上的覆盖变化。 |
| 自定义区域 | 区域类型、对象、已选择对象 | 使用已选区域目标对象或国家/区域所定义的范围，在区域内部布置覆盖网格点。 |
| 自定义边界 | 区域类型、对象、已选择对象 | 使用已选区域目标对象或国家/区域的边界作为布点依据，用于沿指定区域边界进行采样。 |

### 自定义区域与自定义边界

可通过**区域类型**选择区域来源：

- **区域目标对象**：使用场景中已建立的**区域目标**定义覆盖范围。
- **国家/区域**：从提供的国家或行政区域列表中选择覆盖范围。

左侧**对象**列表显示可选区域，选中后点击**右箭头**，将其加入**已选择对象**列表；点击**左箭头**可移除已选区域。可添加多个对象，共同参与覆盖网格的区域定义。

两种方式的区别在于采样范围：**自定义区域**面向所选区域的内部，**自定义边界**面向所选区域的轮廓边界。

## 网格定义

### 网格分辨率

**网格定义**用于设置自动生成网格点时的采样密度，支持三种参数形式。

| 类型 | 单位 | 说明 |
| --- | --- | --- |
| 面积 | km² | 按指定的网格单元面积确定采样疏密。面积值越小，生成的网格通常越密。 |
| 距离 | km | 按指定的距离尺度确定网格点间隔。距离值越小，相邻采样点通常越接近。 |
| 经纬度 | deg | 以经纬度角度设置网格分辨率。例如设置为 `6 deg`，表示以约 6° 的角度尺度生成网格。 |

三种方式都用于控制网格的**空间采样密度**。减小分辨率对应的面积、距离或角度数值，通常会增加网格点数量和覆盖分析的计算量。由于地表曲率以及网格划分方式的影响，生成后的点间隔不一定处处严格等于输入值。

### 点高度

**点高度**用于定义网格采样点相对于指定参考面的高度。选择高度基准后，在右侧输入高度值。

| 参数 | 说明 |
| --- | --- |
| WGS84 | 以 WGS84 参考椭球面作为高度基准。例如设置 `0 km`，表示网格点位于参考椭球面上。|
| 地形 | 以网格点所在位置的地形表面作为高度基准。设置 `0 km` 表示按地形表面确定点高度。 |
| 自动刷新 | 在**地形**模式下启用，使地形相关高度数据随更新自动刷新。 |
| 刷新 | 在**地形**模式下手动更新地形相关的网格点高度。 |

**WGS84**与**地形**采用不同的高度参考面。对于地形起伏明显的地区，两种模式即使都设置为 `0 km`，生成的网格点高度也可能不同。

## 点位置

**点位置**决定各采样点的具体分布，可选择**按间隔计算**或**自定义文件**。

### 按间隔计算

选择**按间隔计算**后，根据前面设置的区域范围、网格分辨率及下列布点方式生成网格点。

| 布点方式 | 说明 |
| --- | --- |
| 等距离 | 侧重使相邻采样点的地表距离保持接近，适合按空间距离控制采样疏密。 |
| 等角度 | 侧重按经纬度角度间隔排列采样点。由于不同纬度上相同经度差对应的地表距离不同，点的实际空间间距会随纬度变化。 |
| 标准网格 | 按标准格网形式布置采样点，适用于采用规则网格开展覆盖分析。 |

### 自定义文件

如果已经具有指定位置的网格点数据，可选择**自定义文件**，通过文件路径输入框选择文件，再点击**导入**。此时，网格点位置由导入文件给出，不再由分辨率自动生成。

在**点高度定义**中选择导入点的高度来源：

| 选项 | 说明 |
| --- | --- |
| 使用点高度值 | 采用本页**点高度**区域中设置的高度基准和数值，为导入的网格点确定高度。 |
| 使用文件值 | 使用网格点文件中提供的高度数据，保留各点分别定义的高度。 |

选择**使用文件值**时，导入文件需要提供相应的高度信息；若只包含平面位置，可使用**使用点高度值**统一指定高度。

导入要求参见[网格点文件导入说明](../../网格点文件导入说明.md)。

## 计算选项

| 参数 | 说明 |
| --- | --- |
| 使用并行计算 | 将覆盖分析中的计算任务并行执行，以利用多个计算资源处理大量网格点。适用于计算规模较大的覆盖任务。 |
| 保存结果 | 保存覆盖分析产生的计算结果，以便后续读取或复用，减少重复计算。 |

## 设置方法

1. 打开**覆盖定义 → 基本 → 网格**，在**网格区域配置参数**中选择区域类型，并填写相应的经纬度参数；使用自定义区域或自定义边界时，将需要的区域加入**已选择对象**列表。
2. 在**网格定义**中选择**面积、距离**或**经纬度**，输入分辨率数值。
3. 在**点高度**中选择 **WGS84** 或**地形**，设置相应高度。采用地形时，可根据需要启用**自动刷新**或点击**刷新**。
4. 在**点位置**中选择**按间隔计算**，并指定布点方式；或者选择**自定义文件**，导入网格点数据并设置高度来源。
5. 根据分析规模决定是否启用**使用并行计算**，并按需要勾选**保存结果**。
6. 点击**应用**或**确定**保存设置，完成覆盖网格的定义。

**说明：** 网格区域确定分析范围，网格分辨率与点位置决定采样点的分布，点高度决定采样点的空间高度。覆盖分析以这些网格点作为采样位置；显示样式在**可视化 → 显示**中设置，访问判定条件在**约束**属性中设置。
