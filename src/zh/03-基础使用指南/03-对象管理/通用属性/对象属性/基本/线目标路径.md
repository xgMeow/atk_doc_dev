# 路径

**路径**用于定义线目标在中心天体表面的位置和形状。线目标由一组具有经纬度坐标的路径点依次连接而成，可通过编辑点列表或在二维地图中点选的方式构建路径。

**锚点**是线目标的参考位置，可从路径的初始点、中间点、最终点或指定的路径点中确定。更改锚点不会改变路径点的坐标及连接顺序。

## 点

【点】列表记录构成线目标的各路径点，列表中的排列顺序决定各点之间的连接关系。

| 参数 | 说明 |
| --- | --- |
| 纬度 | 设置路径点的地理纬度。 |
| 经度 | 设置路径点的地理经度。 |
| 锚点 | 标识当前作为线目标参考位置的路径点。该列中带有 `*` 标记的点为锚点，通过右侧【锚点】区域进行设置。 |

路径点的编辑操作如下：

| 操作 | 说明 |
| --- | --- |
| 添加 | 在列表中新增一个路径点，随后填写该点的纬度和经度。 |
| 删除 | 选中需要移除的路径点所在行，点击【删除】，将该点从路径中移除。 |
| 删除所有 | 清空列表中的全部路径点，用于重新定义线目标路径。 |

修改已有路径点时，可直接编辑对应行的纬度和经度。构建线目标时，应按实际地理路径的先后顺序添加各点；至少需要两个不同位置的点才能形成一段线状路径。

## 地图点选模式

地图点选模式用于通过**二维地图交互**获取路径点的经纬度，无需逐个手动输入坐标。选择点选模式后，在二维地图中点击所需位置，即可执行相应的路径点编辑操作。

| 模式 | 说明 |
| --- | --- |
| 新增点 | 在二维地图中点击所需位置，将该位置的经纬度作为新的路径点加入【点】列表。连续点击地图可依次添加多个路径点。 |
| 修改选中点 | 先在【点】列表中选中需要修改的路径点，再点击二维地图中的新位置，将选中点的纬度和经度更新为该位置的坐标，而不新增路径点。 |
| 选择点 | 用于选择地图中的已有路径点，而非新增或移动路径点。该选项灰显时，可直接在【点】列表中选中对应的路径点。 |

## 锚点

锚点用于确定线目标的参考位置。在【锚点】区域的【使用】下拉列表中选择锚点的确定方式。

| 类型 | 说明 |
| --- | --- |
| 初始点 | 使用路径起始位置对应的点作为锚点。 |
| 中间点 | 由软件根据路径的中间位置确定锚点，无需手动指定路径点。 |
| 最终点 | 使用路径末端位置对应的点作为锚点。 |
| 自定义点 | 从【点】列表中指定一个已有路径点作为锚点。 |

选择【初始点】、【中间点】或【最终点】后，由软件确定对应的锚点。选择【自定义点】时，按以下步骤设置：

1. 在【使用】下拉列表中选择**自定义点**。
2. 在【点】列表中选中需要作为锚点的路径点所在行。
3. 点击【设置锚点】，将选中点设置为线目标的锚点。
4. 查看列表中的【锚点】列，确认所选路径点已标记为 `*`。

**设置锚点只改变线目标的参考位置，不会新增路径点，也不会改变已定义的路径形状。**

## 设置方法

1. 打开线目标属性中的**基本 → 路径**。
2. 点击【添加】并填写路径点的纬度和经度，或选择【新增点】后在二维地图中依次点击所需位置，建立线目标路径。
3. 如需调整已有路径点，可直接编辑坐标，或通过【修改选中点】在地图中重新指定其位置。
4. 在【锚点】区域选择所需的锚点类型；使用自定义点时，选中相应的路径点并点击【设置锚点】。
5. 检查二维地图中的路径形状以及列表中的锚点标记，完成路径属性配置。
