# 质心

确定区域目标的参考中心位置。区域目标的形状和覆盖范围由**基本 → 边界**定义；质心用于表示区域的参考位置，并可作为区域中心点显示及访问连线的参考点。

质心位置可以**手动指定**，也可以通过**自动计算质心**根据区域边界确定。

## 位置设置

在**基本 → 质心**的**位置**区域，通过**类型**下拉列表选择坐标表示方式，再输入对应的位置参数。

| 类型 | 输入参数 | 说明 |
| --- | --- | --- |
| 地理坐标 | 纬度、经度、高度 | 以中心天体的参考椭球为基准定位。纬度表示相对于参考椭球的地理纬度，高度表示相对于参考椭球面的距离。 |
| 笛卡尔坐标 | 纬度、经度、半径 | 纬度、经度给出位置方向，半径用于指定质心与中心天体中心的距离。 |
| 球坐标 | 纬度、经度、高度 | 使用纬度、经度确定质心所在方向，并通过高度指定其相对参考面的高度。与地理坐标相比，纬度采用以中心天体中心为参考的方向定义。 |

## 自动计算质心

勾选**自动计算质心**后，软件根据**基本 → 边界**中已定义的区域几何计算质心位置，无需逐项输入位置坐标。取消勾选后，可通过所选坐标类型手动指定质心。

- 对于采用**模式**定义的区域，应先在**基本 → 边界**中建立完整的边界点，再启用自动计算。

- 对于采用**椭圆**定义的区域，椭圆的半长轴、半短轴及方位角在**基本 → 边界**中设置，椭圆中心位置通过质心确定。

- **质心不一定在区域内部。** 对于凹形或形状不规则的区域，依据边界计算得到的参考中心点可能位于区域轮廓之外。如需将参考点放在特定位置，可关闭自动计算并手动输入坐标。

## 设置方法

### 手动设置

1. 打开区域目标的**基本 → 质心**属性，取消勾选**自动计算质心**。
2. 在**位置**区域选择**地理坐标**、**笛卡尔坐标**或**球坐标**。
3. 按照所选类型输入纬度、经度，以及高度或半径。
4. 点击**应用**或**确定**，查看区域目标的中心位置。

### 自动计算

1. 在**基本 → 边界**中完成区域轮廓的定义。
2. 打开**基本 → 质心**，勾选**自动计算质心**。
3. 点击**应用**或**确定**，由软件根据区域边界计算质心位置。

## 使用说明

- **边界与质心分别设置。** 边界用于定义区域的形状和覆盖范围，质心用于指定区域的参考位置；移动手动指定的质心，不会将已有多边形边界整体平移。
- **坐标类型决定输入参数。** 地理坐标与球坐标均输入纬度、经度和高度；笛卡尔坐标选项在当前界面中输入纬度、经度和半径，半径不可当作高度填写。
- **自动计算与手动指定二选一。** 使用自动计算时由区域几何确定质心；需要指定特定参考位置时，应取消自动计算后输入坐标。
