# 高级

> **适用范围：** 仅限高级接近分析可用。

## 功能说明

【高级】页面用于设置接近分析前的筛选条件、误差椭球数据库、目标半径文件、采样步长以及接近事件的报告方式。合理设置这些参数，可以筛选候选对象和分析区间，并控制接近事件的搜索与输出方式。

## 筛选器

筛选器用于在正式计算前排除不满足预筛选条件的候选对象或时间区间，以减少后续计算量。每项筛选器均包含【使用】复选框和数值设置框，勾选【使用】后启用对应筛选条件。

| 筛选器 | 默认值 | 说明 |
| --- | ---: | --- |
| 轨道历元过期门限 | 2592000 s | 设置轨道根数历元允许的时间裕度，用于筛除轨道历元与分析时段相差过大的数据。 |
| 远/近地点门限 | 30000 m | 根据对象轨道远地点和近地点的高度范围进行预筛选，排除轨道高度范围明显不满足条件的候选对象。 |
| 轨道路径筛选器门限 | 100000 m | 根据两个对象轨道路径之间的最小距离进行预筛选。该筛选主要比较轨道路径的几何关系，不判断两个对象是否在同一时刻到达相应位置。 |
| 时间筛选器门限 | 30000 m | 根据对象之间的相对轨道几何关系筛选可能发生接近的时间区间，以减少后续需要计算的时间范围。 |

**说明：**

- 轨道历元筛选主要针对具有轨道历元信息的根数数据。启用该筛选时，应结合轨道数据的历元和分析时段合理设置时间裕度。
- 远/近地点筛选用于排除轨道高度范围明显不满足条件的对象；轨道路径筛选用于排除轨道路径之间距离过大的对象。
- 轨道路径筛选不考虑两个对象在具体时刻的位置关系。对于包含轨道机动的对象，使用该筛选时应谨慎；筛选门限过严可能排除实际存在接近事件的对象。
- 时间筛选用于缩小可能发生接近的时间范围，具体筛选效果与轨道相对几何关系有关。
- 筛选器属于预筛选手段，设置过于严格可能影响候选对象的保留情况。应结合主配置中的距离阈值、轨道类型和分析精度要求设置筛选裕度。

## 高级椭球属性

【高级椭球属性】用于指定不同误差椭球类别所使用的数据库文件。

| 参数 | 说明 |
| --- | --- |
| 时间二次曲线数据库 | 为【二次曲线】类别提供各方向误差椭球尺寸随时间变化的二次函数系数。可选文件为 `atkQuadDB.qdb`。 |
| 固定轨道类型数据库 | 为【轨道类型】类别提供不同轨道类型对应的固定误差椭球尺寸。可选文件为 `atkFxdOrbCls.foc`。 |
| 二次/固定类型数据库 | 为【二次/轨道】类别提供不同轨道类型对应的二次函数系数。可选文件为 `atkQuadOrbCls.qoc`。 |
| 椭球比例因子 | 用于调整误差椭球尺寸的比例。默认值为 1。 |

点击各数据库右侧的按钮，可以选择相应的数据库文件。

> **说明：** 数据库文件应与对应的误差椭球类别匹配。选择其他类别时，应确认相应数据库文件已正确指定。

## SSC目标半径文件

该区域用于读取目标包络球半径文件。

| 参数 | 说明 |
| --- | --- |
| 读取文件 | 勾选后启用目标半径文件读取功能。 |
| 文件名 | 显示所选择的目标半径文件路径。点击右侧按钮可以选择文件。 |

目标半径文件用于提供相应目标的包络球半径信息。启用读取功能后，应选择符合要求的目标半径文件，并确认文件路径正确。

## 采样设置

采样设置用于限定接近分析过程中采用的时间步长范围。包含最大采样步长和最小采样步长两项参数。

| 参数 | 默认值 | 说明 |
| --- | ---: | --- |
| 最大采样步长 | 300 s | 限制相邻采样点之间允许采用的最大时间步长。 |
| 最小采样步长 | 1 s | 限制相邻采样点之间允许采用的最小时间步长。 |

采样过程中，时间步长可根据相对运动情况在设定范围内调整。因此，最大采样步长和最小采样步长用于限定采样间隔的范围，并不表示整个分析过程始终采用固定步长。

## 碰撞类型

【碰撞类型】用于设置接近区间内最近接近事件的报告方式。下拉列表包含以下选项：

| 类型 | 说明 |
| --- | --- |
| 全局解 | 对接近区间进行整体搜索，报告区间内距离的全局最小值对应的最近时刻。 |
| 局部解 | 报告接近区间内各个局部距离最小值对应的事件。 |
| 全局解+局部解 | 同时考虑区间内的全局最小值和局部最小值，报告相应接近事件。 |
| 局部解+边界解 | 报告区间内的局部距离最小值，并将满足边界解判定条件的区间端点作为接近事件报告。 |

不同碰撞类型会影响接近事件的搜索方式及报告数量。若需要识别同一分析区间内的多个局部接近事件，可根据分析需求选择相应类型。

## 设置方法

1. 根据分析需求勾选需要启用的筛选器，并设置相应门限；
2. 检查时间二次曲线数据库、固定轨道类型数据库和二次/固定类型数据库的文件路径；
3. 根据需要设置椭球比例因子；
4. 如需从文件读取目标包络球半径，勾选【读取文件】并选择相应文件；
5. 设置最大采样步长和最小采样步长；
6. 选择所需的碰撞类型，完成设置后点击【确定】或【应用】。

## 注意事项

- 筛选器属于预筛选手段，门限设置过严可能导致实际存在接近事件的候选对象或时间区间被排除。
- 对于包含轨道机动的对象，应谨慎使用轨道路径筛选器。
- 不同误差椭球类别对应不同的数据来源，应确保数据库文件与所选类别相匹配。
- 启用目标半径文件读取功能时，应确认文件路径正确，且文件内容符合目标半径数据的要求。
- 最大采样步长和最小采样步长共同限定采样间隔范围。设置时应兼顾计算效率与接近事件搜索精度。
- 软件提供默认值，实际使用时应根据轨道数据质量、分析时段和任务精度要求进行设置。
