# 边界

定义区域目标在中心天体表面上的轮廓。**区域类型**包括**模式**和**椭圆**两种：

- 模式通过一组经纬度点构成不规则区域。

- 椭圆通过半长轴、半短轴和方位角定义规则区域。

## 椭圆

选择**区域类型 → 椭圆**后，通过以下三个参数定义椭圆边界：

| 参数 | 说明 |
| --- | --- |
| 半长轴 | 椭圆长轴长度的一半，用于确定椭圆沿主轴方向的范围。 |
| 半短轴 | 椭圆短轴长度的一半，用于确定椭圆垂直于主轴方向的范围。 |
| 方位角 | 椭圆长轴相对于当地正北方向的转角；以正北为 0°，沿顺时针方向增加。 |

椭圆的位置由**基本 → 质心**中的中心坐标确定，三个参数用于设置其**大小和朝向**。例如，半长轴设为 `300000 m`、半短轴设为 `150000 m`、方位角设为 `0 deg` 时，椭圆的长轴为 600 km、短轴为300 km，长轴沿当地南北方向。

## 模式

选择**区域类型 → 模式**后，可在边界点表格中直接编辑经纬度，也可通过**响应地图**在二维地图上添加或调整边界点。

### 边界点

| 参数 | 说明 |
| --- | --- |
| 纬度（deg） | 边界点的纬度坐标，北纬为正、南纬为负。 |
| 经度（deg） | 边界点的经度坐标，东经为正、西经为负。 |
| 添加 | 在边界点列表中增加一行，用于输入新的经纬度坐标。 |
| 删除 | 删除当前选中的边界点。 |
| 删除全部 | 清空边界点列表，重新定义区域轮廓。 |
| 区域 | 显示区域面积，单位为 km²。自动计算区域大小 |

表格中的边界点**按行顺序连接**，最后一个点与第一个点连接形成闭合轮廓。定义面状区域至少需要三个有效边界点。需要调整轮廓时，可直接修改相应行的经纬度；插入或删除点后，连接顺序随列表变化。

### 响应地图

勾选**响应地图**后，可通过单击二维地图直接设置边界点的经纬度。下拉列表提供三种操作方式：

| 操作方式 | 说明 |
| --- | --- |
| 点击地图改变当前点数据 | 先在边界点表格中选中一行，再点击地图，将该行的经纬度更新为点击位置，不增加新的边界点。 |
| 在当前行后面插入一行 | 先选中一行，再点击地图，在该行之后插入一个新边界点。适用于在已有轮廓的两点之间补充节点。 |
| 在最后一行后面插入一行 | 每次点击地图，都在列表末尾添加一个边界点。适用于沿区域边缘依次描绘完整轮廓。 |

例如，首次建立不规则区域时，可选择**在最后一行后面插入一行**，沿区域边界依次点击地图；若需要细化某段边界，则选中对应位置的前一个点，改用**在当前行后面插入一行**。如需移动某个已定义的点，选择**点击地图改变当前点数据**即可。

## 设置方法

### 使用模式定义区域

1. 打开区域目标的**基本 → 边界**，将**区域类型**设为**模式**。
2. 如已知边界点坐标，点击**添加**建立数据行，并依次填写**纬度**和**经度**；至少设置三个有效边界点。
3. 如需在地图上绘制轮廓，勾选**响应地图**，选择**在最后一行后面插入一行**，沿区域外围依次点击地图。
4. 需要修改某个点时，直接编辑表格坐标，或选择**点击地图改变当前点数据**后重新取点；需要在相邻点之间增加节点时，选择**在当前行后面插入一行**。
5. 检查二维地图中的闭合轮廓及**区域**面积，确认后点击**应用**或**确定**。

### 使用椭圆定义区域

1. 在**基本 → 质心**中设置区域的参考中心位置。
2. 打开**基本 → 边界**，将**区域类型**设为**椭圆**。
3. 输入**半长轴、半短轴**和**方位角**，确定区域的尺寸与方向。
4. 在二维地图中检查椭圆位置和覆盖范围，确认后点击**应用**或**确定**。
