# 位置

位置属性用于确定地面站在中心天体上的位置。支持通过**笛卡尔坐标**或**地理坐标**输入站点位置，并可结合地形数据与离地高度设置站点相对于地面的高度。

## 类型

在**基本 → 位置**页面，通过**类型**下拉列表选择坐标表示方式。

### 笛卡尔坐标

笛卡尔坐标使用地球固定坐标系下的三个直角坐标分量描述站点位置，坐标原点位于地心。适用于已知站点地心直角坐标的情况。

| 参数 | 说明 |
| --- | --- |
| X | 站点位置在 X 轴方向的坐标分量，X 轴指向赤道与本初子午线的交点方向。 |
| Y | 站点位置在 Y 轴方向的坐标分量，与 X、Z 轴共同构成地球固定直角坐标系。 |
| Z | 站点位置在 Z 轴方向的坐标分量，正方向指向北极。 |

**X、Y、Z 为相对于地心的坐标分量**，不是以地面站为原点的局部东、北、天坐标。例如，在 WGS84 椭球面上，赤道与本初子午线交点处的坐标约为 `X = 6378137 m、Y = 0 m、Z = 0 m`。

### 地理坐标

地理坐标通过纬度、经度和高度定义站点位置，适用于已知站点经纬度的情况。

| 参数 | 说明 |
| --- | --- |
| 纬度 | 输入站点的地理纬度，北纬为正，南纬为负。 |
| 经度 | 输入站点的地理经度，东经为正，西经为负。 |
| 高度 | 输入站点地面位置相对于 WGS84 参考椭球面的高度。勾选**使用地形数据**后，该输入框不可编辑，地面高度由地形数据确定。 |

## 地形与高度设置

两种位置类型均提供地形及离地高度相关选项。

| 参数 | 说明 |
| --- | --- |
| 使用地形数据 | 勾选后，根据站点位置使用地形数据确定地面高度。采用地理坐标时，原有**高度**输入框不可编辑。 |
| 高度参考 | 设置高度使用的参考基准。当前以 WGS84 参考椭球面作为高度基准。 |
| 离地高度 | 设置站点相对于所定义地面的抬升高度。需要表示高于地面的设施位置时，可输入相应高度。 |

当使用地形数据时，**地形数据用于确定地面高度，离地高度用于表示站点高出该地面的距离**。例如，站点所在位置的地形高程由数据提供，若设备安装在高出地面 10 m 的位置，可将**离地高度**设为 `10 m`。

**使用地形数据**用于确定站点位置的地面高程；是否在访问计算中考虑周围山体遮挡，还需通过相应的地形遮挡或方位-俯仰掩码等约束配置。

## 响应地图

勾选**响应地图**后，可在二维地图中通过交互方式设置地面站位置，位置参数随选定地点更新。取消勾选后，可继续通过坐标输入框直接编辑站点位置。

## 设置方法

1. 打开地面站属性中的**基本 → 位置**，确认页面上方的中心天体。
2. 在**类型**下拉列表中选择**笛卡尔坐标**或**地理坐标**。
3. 使用笛卡尔坐标时填写 `X、Y、Z`；使用地理坐标时填写**纬度、经度、高度**。
4. 根据站点位置数据来源选择是否勾选**使用地形数据**。采用地理坐标且启用地形数据后，无需手动输入**高度**。
5. 在**离地高度**中设置站点高出地面的距离。
6. 如需通过地图调整位置，勾选**响应地图**并在二维地图中选取站点位置。
7. 点击**应用**或**确定**，保存位置设置。
