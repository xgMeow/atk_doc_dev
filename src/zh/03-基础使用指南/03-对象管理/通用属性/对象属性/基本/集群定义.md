# 定义

用于选择集群的组成对象。集群将多个场景对象归入同一成员集合，便于在访问、链路或覆盖分析中统一引用。

## 选项过滤器

**选项过滤器**用于按对象类型筛选可加入集群的场景对象。可以同时勾选多个类型，缩小下方**可选对象**列表的查找范围。

| 参数 | 说明 |
| --- | --- |
| 对象类型 | 勾选需要查找的对象类型，使对应的场景对象出现在**可选对象**列表中。 |
| 选择所有过滤器 | 一次勾选全部对象类型，查看所有可选择的对象。 |
| 清除所有过滤器 | 取消全部对象类型的勾选，清空当前类型筛选。 |

过滤器只改变候选对象的显示范围。**已加入集群的成员不会因取消类型过滤器而被移除。**

## 成员选择

**可选对象**列出符合当前过滤条件的场景对象，**已选对象**列出当前集群的成员。通过两列之间的箭头按钮添加或移除成员。

| 项目 | 说明 |
| --- | --- |
| 可选对象 | 从场景中查找准备加入集群的对象。选中对象后，可点击**右箭头**添加。 |
| 已选对象 | 显示已加入集群的成员。只有进入此列表的对象才参与集群的后续分析。 |
| 右箭头 | 将选中的可选对象加入**已选对象**列表。 |
| 左箭头 | 将选中的集群成员从**已选对象**列表移除，场景中的原对象不受影响。 |
| 上箭头 | 将已选成员在列表中上移一位。 |
| 下箭头 | 将已选成员在列表中下移一位。 |

## 设置方法

1. 打开集群对象的**基本 → 定义**属性。
2. 在**选项过滤器**中勾选需要的对象类型，从**可选对象**列表中查找成员。
3. 选中对象，点击**右箭头**加入**已选对象**；重复操作，完成集群成员选择。
4. 如需移除成员，在**已选对象**中选中该成员，点击**左箭头**。
5. 如需整理成员列表，可使用**上箭头**或**下箭头**调整显示顺序。
6. 检查**已选对象**列表，点击**应用**或**确定**保存集群定义。

**说明：** 修改集群成员会改变后续分析所考虑的对象集合；调整过滤器或成员在列表中的排列顺序，不会产生新的对象间连接。集群的整体有效性由**约束 → 基本**中的计算方式和逻辑限定条件确定。
