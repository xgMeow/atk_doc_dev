# 航线

航线属性用于定义飞机在场景中的运动轨迹。通过设置航点及其运动参数，或导入外部星历数据，可确定飞机在相应时刻的位置及航线路径。

在**预报器**下拉框中选择航线定义方式。当前支持以下两种类型：

| 预报器 | 说明 |
| --- | --- |
| 路径生成 | 根据航点的位置、时间或运动参数生成飞机航线。 |
| STK星历 | 从外部文件导入星历数据，使用文件中的轨迹信息定义飞机航线。 |

## 路径生成

选择【路径生成】后，可设置**路径计算方式**，并通过航点表格输入位置、时间、速度及转动半径等信息。

### 路径计算方式

**路径计算方式**用于指定生成航线时主要依据的运动参数。可选择以下方式：

| 计算方式 | 说明 |
| --- | --- |
| 指定速度/加速度 | 根据航点设置的速度和加速度参数计算航段运动与相应时间。 |
| 指定速度 | 根据航点设置的速度参数计算航段运动与相应时间。 |
| 指定时间 | 通过设置各航点的到达时间定义运动时间关系，并据此确定航段运动。 |

### 航点参数

航点表格按行记录飞机经过的路径节点。每一行对应一个航点，主要参数如下。

| 参数 | 说明 |
| --- | --- |
| 序号 | 航点在路径中的排列顺序。 |
| 时间（UTCG） | 飞机到达该航点的时间，采用 UTCG 时间表示格式。其输入或计算方式与所选路径计算方式有关。 |
| 纬度（deg） | 航点的纬度 |
| 经度（deg） | 航点的经度 |
| 高度（m） | 航点高度 |
| 速度（m/s） | 航点对应的运动速度 |
| 采用转动半径 | 控制是否为该航点启用转动半径设置。 |
| 转动半径（m） | 设置航线转弯处的半径，单位为米；通过表格横向滚动查看相应列。 |

#### 转动半径

转动半径用于描述飞机经过转向航点时的航线弯曲程度。勾选对应航点的【采用转动半径】后，可设置该航点的【转动半径（m）】。通常，较小的半径对应较急的转向，较大的半径对应较平缓的转向。

> 转动半径描述的是航线转弯几何参数，不等同于飞机动力学模型所能实现的最小转弯半径。

### 航点编辑

| 操作 | 说明 |
| --- | --- |
| 添加 | 在航点表格中新增航点。 |
| 删除 | 删除当前选中的航点。 |
| 修改航点 | 直接编辑航点表格中允许输入的参数。 |

航点按照表格排列顺序构成路径。设置航线时，应保证航点顺序与预期飞行路线一致。

### 响应地图

勾选【响应地图】后，可通过**二维地图**对航点进行交互编辑。下拉框用于指定点击地图时对航点表格执行的操作。未勾选时，该地图交互功能不启用。

| 地图交互方式 | 说明 |
| --- | --- |
| 点击地图改变当前点数据 | 将地图点击位置的地理坐标写入当前选中的航点。 |
| 在当前行后面插入一行 | 在当前航点后新增一行，并使用地图点击位置设置新航点。 |
| 在最后一行后面插入一行 | 在航点表格末尾追加一行，并使用地图点击位置设置新航点。 |

> 可以调整一下UI布局，将二维视图与属性浏览器调整为左右分栏的同窗布局

### 设置方法

1. 在【预报器】中选择【路径生成】。
2. 在【路径计算方式】中选择【指定速度/加速度】、【指定速度】或【指定时间】。
3. 点击【添加】建立航点，在表格中设置时间、纬度、经度、高度及所需的运动参数。
4. 如需设置转弯几何，勾选相应航点的【采用转动半径】，并填写转动半径。
5. 如需在地图上编辑航点，勾选【响应地图】，选择交互方式后在二维地图中操作。
6. 检查航点顺序及各项参数，完成航线配置。

## STK星历

STK星历预报器用于通过外部星历文件定义飞机的运动轨迹。用户可直接加载已有的星历文件，也可通过星历转换工具将外部轨迹数据转换为支持的星历文件格式。

该预报器支持开始历元、结束历元、星历文件及时间覆盖等参数配置。

具体参数、文件格式及导入方法参见[STK星历](../../STK星历.md)。
