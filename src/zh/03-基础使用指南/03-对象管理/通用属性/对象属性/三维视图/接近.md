# 接近

接近属性用于在三维视图中显示对象周围的不确定区域。当前界面提供的区域类型为【控制盒】。控制盒用于在对象周围定义一个随对象运动的空间范围，可通过设置各轴方向的尺寸和偏移量，调整控制盒的大小及相对位置，并设置边框和文字的显示效果。

## 不确定区域

不确定区域列表用于管理当前对象的不确定区域，并设置其基本显示属性。

| 参数     | 说明        |
|----------|-----------|
| 类型     | 显示不确定区域的类型。目前只支持【控制盒】类型。        |
| 显示     | 控制是否在三维视图中显示对应的不确定区域。勾选后显示控制盒；取消勾选后隐藏控制盒。     |
| 颜色     | 设置控制盒边框的显示颜色。        |
| 线宽     | 设置控制盒边框线条的显示宽度。  |
| 显示文字 | 控制是否在三维视图中显示自定义文字。     |
| 文字     | 设置控制盒关联的自定义文字内容。       |
| 更多 | 打开控制盒详细设置窗口，用于设置控制盒的尺寸、偏移量及线型等参数。部分参数与外层界面共用，并保持双向同步。颜色参数仅能在外层界面设置。 |

### 控制盒

控制盒用于定义对象周围的长方体空间范围，并随对象运动。控制盒的尺寸和位置由对象所关联的参考坐标系确定。

点击【更多】，打开控制盒详细设置窗口。

#### 显示

| 参数 | 说明   |
|------|-----|
| 显示 | 控制当前控制盒是否在三维视图中显示。勾选后显示控制盒；取消勾选后隐藏控制盒。 |

#### 尺寸

| 参数    | 说明                    |
|---------|----------------------|
| X轴长度 | 设置控制盒沿参考坐标系 X 轴方向的延伸尺寸。 |
| Y轴长度 | 设置控制盒沿参考坐标系 Y 轴方向的延伸尺寸。 |
| Z轴长度 | 设置控制盒沿参考坐标系 Z 轴方向的延伸尺寸。 |

控制盒以其几何中心为基准定义尺寸。输入的轴向长度表示从几何中心沿对应轴向延伸的距离，因此控制盒沿该轴的完整边长为输入值的两倍。

#### 偏移量

| 参数      | 说明                 |
|-----------|-----------|
| X轴偏移量 | 设置控制盒沿参考坐标系 X 轴方向的平移偏移量。 |
| Y轴偏移量 | 设置控制盒沿参考坐标系 Y 轴方向的平移偏移量。 |
| Z轴偏移量 | 设置控制盒沿参考坐标系 Z 轴方向的平移偏移量。 |

偏移量用于调整控制盒相对于对象参考位置的空间位置。正值和负值分别表示沿对应坐标轴正向和负向偏移。偏移量不会改变控制盒的尺寸。

#### 单位选择

X轴长度、Y轴长度、Z轴长度及对应的偏移量均可单独设置距离单位。点击输入框右侧的单位选择图标，可从下拉列表中选择对应单位。

| 单位 | 含义          |
|------|---------------|

| km   | 千米          |
| dm   | 分米          |
| cm   | 厘米          |
| mm   | 毫米          |
| in   | 英寸          |
| kin  | 千英寸        |
| ft   | 英尺          |
| kft  | 千英尺        |
| yd   | 码            |
| kyd  | 千码          |
| fur  | 浪（Furlong） |

#### 线条与文字

| 参数     | 说明            |
|----------|-------------|
| 线宽     | 设置控制盒边框线条的显示宽度。       |
| 线型     | 设置控制盒边框线条的显示样式。       |
| 显示文字 | 控制是否在三维视图中显示自定义文字。 |
| 文字     | 设置需要显示的自定义文字内容。       |

线宽、显示文字和文字参数与外层界面中的对应参数共用，任一界面修改后，另一界面会自动同步更新。

## 设置方法

1.  在【不确定区域】列表中找到【控制盒】。
2.  根据需要勾选【显示】，启用控制盒显示。
3.  在列表中设置控制盒的【颜色】和【线宽】；如需显示文字，勾选【显示文字】并设置【文字】内容。
4.  点击【更多】，打开控制盒详细设置窗口。
5.  分别设置 X、Y、Z 轴方向的长度，确定控制盒的空间尺寸。
6.  根据需要设置 X、Y、Z 轴偏移量，调整控制盒相对于对象参考位置的位置。
7.  点击各长度或偏移量输入框右侧的单位选择图标，选择相应的距离单位。
8.  根据需要设置控制盒的【线宽】、【线型】及文字显示选项。
9.  点击【确定】保存设置，并检查三维视图中的控制盒显示效果。

**注意事项：**

- 控制盒是围绕对象定义的空间范围，会随对象运动；其显示用于三维场景中的范围标示，不应直接理解为对象真实外形或经过统计计算得到的概率置信区域。
- 控制盒的 X、Y、Z轴方向由其参考坐标系确定。各轴的实际空间指向取决于所采用的参考坐标系。
- X、Y、Z轴偏移量用于移动控制盒的位置，不改变其尺寸；正负方向对应参考坐标系中相应轴的正向和负向。
- 各长度和偏移量可以分别选择距离单位，设置时应注意不同字段的单位，避免因单位不一致造成尺寸或位置理解错误。
- 【显示文字】用于控制自定义文字是否显示；【文字】用于设置具体显示内容。
- 外层界面与【更多】详细设置窗口中的线宽、显示文字和文字参数保持双向同步。颜色仅能在外层界面设置；线型、控制盒尺寸及偏移量仅能在详细设置窗口中设置。
