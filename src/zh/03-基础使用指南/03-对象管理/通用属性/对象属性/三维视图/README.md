# 三维视图

三维视图属性用于配置场景对象在三维场景中的模型外观、几何元素、轨道显示及其他辅助显示效果。通过设置相关属性，可以调整对象的三维显示方式，并根据需要显示相应的空间信息。

## 属性说明

| 属性 | 说明 |
| --- | --- |
| [模型](./模型.md) | 加载并配置对象的三维模型，设置模型比例、欧拉角、标签偏移量及平移补偿等参数。 |
| [向量](./向量.md) | 配置三维视图中的坐标系、向量和点，设置其显示状态、标签及图形属性。 |
| [姿态球](./姿态球.md) | 配置姿态球的显示、网格外观、参考坐标系及中心天体投影。 |
| [轨道系统](./轨道系统.md) | 添加和配置轨道参考坐标系，设置不同轨道系统下的轨道或轨迹显示。 |
| [接近](./接近.md) | 配置对象周围不确定区域的显示方式、尺寸、偏移量及文字样式。 |
| [等高线](./等高线.md) | 配置三维视图中仰角轮廓线、轮廓锥及中心天体表面填充效果。 |
| [范围](./范围.md) | 配置三维视图中对象范围轮廓线的显示及半透明效果。 |
| [模型指向](./模型指向.md) | 为三维模型中的可指向元素指定目标，并设置分时段指向及转向过程。 |
| [数据显示](./数据显示.md) | 配置动态数据显示项目，设置文字的显示位置、颜色、背景及边框。 |
| [空间投影](./空间投影.md) | 配置传感器视场在三维空间中的投影延伸距离及距离约束。 |
| [脉冲](./脉冲.md) | 配置传感器三维投影的脉冲显示效果，包括振幅、脉冲长度及频率。 |

## 注意事项

- 不同类型的对象所支持的三维视图属性可能有所不同，具体以对象属性面板中实际显示的配置项为准。
- 【空间投影】和【脉冲】仅适用于传感器对象。
- 各属性页面分别介绍对应功能的配置参数、设置方法及注意事项。
