# 向量

向量属性用于管理三维视图中显示的坐标轴、向量和点等几何元素。通过选择中心天体或场景中的对象，并添加相应的几何组件，可在三维视图中显示对象的空间参考方向、向量信息及特征点位置。

向量属性包含 **坐标系、向量和点**三个部分。坐标轴用于表示空间参考方向，向量用于表示三维空间中的方向和大小，点用于表示三维空间中的位置。各类几何组件可根据需要分别设置显示状态、标签、尺寸及颜色。

## 尺寸

尺寸用于调整几何元素在三维视图中的整体显示比例。

| 参数     | 说明          |
|----------|----------|
| 对应比例 | 设置坐标轴、向量及点等几何元素的显示比例。可直接输入数值，也可拖动滑块调整。 |

该参数用于调整几何元素的图形显示效果，不改变组件本身的几何定义。

## 坐标系

坐标系区域用于添加和管理三维视图中显示的坐标轴组件。通过选择相应的坐标轴及参考坐标系，可显示对象或中心天体关联的空间方向。

### 坐标轴列表

坐标轴列表用于显示当前已添加的坐标轴组件，并设置各组件的显示属性。

| 参数     | 说明         |
|----------|----------|
| 名称     | 显示已添加坐标轴组件的名称。           |
| 显示     | 控制是否在三维视图中显示对应的坐标轴。 |
| 显示标签 | 控制是否显示坐标轴组件的文字标签。     |
| 粗细     | 设置坐标轴线条的显示粗细。             |
| 颜色     | 设置坐标轴的显示颜色。                 |

### 坐标轴显示参数

选择坐标轴列表中的组件后，可在右侧设置其参考坐标系及绘制位置。

| 参数             | 说明        |
|----------|---------|
| 参考轴           | 显示当前坐标轴组件所采用的参考坐标轴。点击右侧【...】按钮，可打开坐标轴选择窗口。 |
| 绘制在中心天体上 | 控制是否将坐标轴绘制在中心天体处。           |
| 绘制在点上       | 控制是否将坐标轴绘制在指定点处。勾选后，可通过【点】选择绘制位置。                |
| 点               | 指定坐标轴的绘制位置。点击右侧【...】按钮，可打开点选择窗口。 |

### 添加坐标轴

点击【添加】，打开组件选择窗口。窗口左侧显示中心天体及当前场景中的对象，右侧显示所选对象可用的坐标轴组件。

右侧组件列表分为以下两类：

| 组件分类   | 说明        |
|------------|--------|
| 自定义组件 | 显示用户创建的自定义坐标轴组件。   |
| 预定义组件 | 显示软件预先提供的坐标轴组件。可根据需要选择相应的参考坐标系。 |

组件选择窗口的主要操作如下：

| 操作     | 说明          |
|----------|-----------|
| 筛选     | 设置左侧对象列表的筛选范围。选择【所有对象】时，可浏览当前场景中的中心天体及其他对象。 |
| 对象列表 | 显示可供选择的中心天体和场景对象。选择对象后，右侧显示该对象对应的可用组件。           |
| 组件列表 | 显示所选对象下的自定义组件和预定义组件。      |
| 添加组件 | 选择右侧所需的坐标轴组件。             |
| 确定     | 确认组件选择并返回向量属性页面。      |
| 取消     | 取消本次组件选择并关闭窗口。    |

## 向量

向量区域用于添加和管理三维视图中显示的向量组件。向量用于描述三维空间中的方向和大小，可用于显示对象的运动方向、角速度方向、位置方向及其他几何方向信息。

### 向量列表

向量列表用于显示当前已添加的向量组件，并设置各组件的显示属性。

| 参数     | 说明            |
|----------|-------------|
| 名称     | 显示已添加向量组件的名称。           |
| 显示     | 控制是否在三维视图中显示对应的向量。 |
| 显示标签 | 控制是否显示向量的文字标签。         |
| 粗细     | 设置向量线条的显示粗细。             |
| 颜色     | 设置向量的显示颜色。                 |

### 向量显示参数

选择向量列表中的组件后，可在右侧设置其参考坐标系、绘制位置及显示比例。

| 参数             | 说明        |
|------------------|------------|
| 参考轴           | 显示当前向量所采用的参考坐标轴。点击右侧【...】按钮，可打开坐标轴选择窗口。     |
| 绘制在中心天体上 | 控制是否将向量绘制在中心天体处。                      |
| 绘制在点上       | 控制是否将向量绘制在指定点处。勾选后，可通过【点】选择绘制位置。         |
| 点               | 指定向量的绘制位置。点击右侧【...】按钮，可打开点选择窗口。            |
| 采用真实比例     | 控制是否按照向量的实际大小显示其长度。勾选后，向量按照真实比例绘制；未勾选时，向量显示长度受整体显示比例设置影响。该选项适用于具有距离量纲的向量。 |

参考坐标轴决定向量的方向如何相对于坐标系表达；绘制位置决定向量在三维视图中的起点。调整这两项时，应结合所选向量组件的定义进行设置。

### 添加向量

点击【添加】，打开组件选择窗口。窗口左侧显示中心天体及当前场景中的对象，右侧显示所选对象可用的向量组件。

右侧组件列表分为以下两类：

| 组件分类   | 说明         |
|------------|----------|
| 自定义组件 | 显示用户创建的自定义向量组件。            |
| 预定义组件 | 显示软件预先提供的向量组件。可用类型取决于所选对象及其数据条件，常见类型包括角速度、位置、运动方向、局部方向及环境场相关向量等。 |

组件选择窗口中的【筛选】、对象列表、组件列表及【确定】【取消】等操作与坐标轴组件的添加方式相同。

## 点

点区域用于添加和管理三维视图中显示的点组件。点用于表示三维空间中的位置，可通过选择参考坐标系及其关联点，确定点的位置及其显示方式。

### 点列表

点列表用于显示当前已添加的点组件，并设置各组件的显示属性。

| 参数     | 说明      |
|----------|----------------|
| 名称     | 显示已添加点组件的名称。           |
| 显示     | 控制是否在三维视图中显示对应的点。 |
| 显示标签 | 控制是否显示点的文字标签。         |
| 尺寸     | 设置点标记的显示尺寸。             |
| 颜色     | 设置点标记的显示颜色。             |

### 点显示参数

选择点列表中的组件后，可在右侧设置点所采用的坐标系及相关显示信息。

| 参数           | 说明      |
|----------------|---------|
| 系统           | 显示点所采用的参考坐标系。点击右侧【...】按钮，可打开坐标系及点选择窗口。 |
| 弹道           | 设置点在三维视图中的轨迹显示方式，可选择【点】【线】【轨迹】和【线集】。  |
| 显示RA-Dec     | 控制是否显示点相对于所选参考坐标系的赤经和赤纬信息。                      |
| 显示距离       | 控制是否显示点到参考坐标系原点的距离。                                    |
| 显示笛卡尔坐标 | 控制是否显示点在所选参考坐标系下的笛卡尔坐标信息。                        |

【弹道】的显示方式说明如下。

| 显示方式 | 说明      |
|----------|----------|
| 点       | 仅显示当前动画时刻对应的点位置。                                     |
| 线       | 根据点的采样位置绘制连接线，并显示采样点与系统中所选参考坐标系原点之间的连线。 |
| 轨迹     | 显示点随时间变化形成的采样轨迹。                                     |
| 线集     | 以线段集合的形式显示点的位置或轨迹信息。                             |

### 添加点

点击【添加】，打开组件选择窗口。窗口左侧显示中心天体及当前场景中的对象，右侧显示所选对象可用的点组件。

右侧组件列表分为以下两类：

| 组件分类   | 说明    |
|------------|-----------|
| 自定义组件 | 显示用户创建的自定义点组件。                                                |
| 预定义组件 | 显示软件预先提供的点组件。组件按照所属坐标系组织，可展开坐标系节点查看其下可用的点，例如中心点、对象原点及其他坐标系关联的原点。 |

选择所需点组件后，点击中间的添加按钮，将其加入当前点列表。组件选择窗口中的【筛选】、对象列表、组件列表及【确定】【取消】等操作与坐标轴组件的添加方式相同。

## 组件管理

坐标轴、向量和点三个区域分别通过列表管理已添加的几何组件。

| 操作 | 说明       |
|------|-------------------|
| 添加 | 打开组件选择窗口，从中心天体或场景对象中选择相应的自定义组件或预定义组件，并添加到当前列表。 |
| 删除 | 删除当前选中的组件。删除后，该组件不再显示在当前属性页面的对应列表中。                       |

坐标轴、向量和点的组件列表相互独立，可分别添加、删除及设置显示属性。

## 设置方法

1.  在【尺寸】区域设置几何元素的【对应比例】。
2.  根据显示需求，选择【坐标系】【向量】或【点】选项卡。
3.  点击【添加】，打开组件选择窗口。
4.  在左侧对象列表中选择中心天体或场景中的目标对象。
5.  在右侧【预定义组件】或【自定义组件】中选择所需的坐标轴、向量或点组件。添加点组件时，可展开相应坐标系，选择其下的点。点击【确定】返回属性页面。
6.  在组件列表中勾选【显示】，并根据需要设置【显示标签】【粗细】或【尺寸】及【颜色】。
7.  对于坐标轴和向量，可根据需要设置【参考轴】、绘制位置及对应的点；对于向量，还可设置【采用真实比例】。
8.  对于点，可设置【系统】、【弹道】及RA-Dec、距离和笛卡尔坐标显示选项。
9.  检查三维视图中的几何元素显示效果，完成向量属性配置。

**注意事项：**

- 坐标轴、向量和点的可选组件取决于所选中心天体或对象，以及该对象当前可用的几何数据。
- 【参考轴】和【系统】用于确定几何元素所依赖的参考坐标系，不同参考坐标系下的方向和坐标表示可能不同。
- 【绘制在点上】用于指定坐标轴或向量的绘制位置，不等同于改变组件本身的定义。
- 【采用真实比例】用于按向量实际大小显示其长度；当向量数值较小或较大时，可能需要结合整体【对应比例】调整显示效果。
- 点的轨迹显示效果取决于点组件是否具有随时间变化的位置数据。
- 本页面中的参数用于控制三维视图的几何元素显示，不改变对象本身的位置、姿态及运动数据。
