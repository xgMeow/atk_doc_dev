# 范围

范围属性用于控制对象范围轮廓线在三维视图中的显示效果。范围轮廓线用于表示与对象具有指定距离关系的轮廓，并显示其在中心天体表面上的投影。

范围轮廓的距离等级及各等级的线条属性在二维视图的【范围】属性中定义；三维视图的【范围】属性主要用于控制范围轮廓线是否显示，以及其半透明效果。

## 范围轮廓线

范围轮廓线区域用于设置范围轮廓在三维视图中的显示状态及透明效果。

| 参数          | 说明               |
|---------------|-------------------------|
| 显示          | 控制是否在三维视图中显示范围轮廓线。勾选后显示范围轮廓线；取消勾选后隐藏范围轮廓线。                                         |
| 半透明线条    | 控制是否启用范围轮廓线的半透明显示效果。勾选后，可通过【半透明度】设置线条的透明程度；未勾选时，线条不采用该半透明效果。     |
| 半透明度（%） | 设置范围轮廓线的半透明程度，可直接输入数值或拖动滑块调整，取值范围为 0%～100%。数值越大，线条越透明；100% 时线条完全不可见。 |

## 范围轮廓设置说明

范围轮廓线的距离等级及线条显示属性由二维视图中的【范围】属性定义。二维视图中可设置范围轮廓等级，并配置各等级对应的颜色、线型、线宽及标签等属性。三维视图中的范围轮廓线根据这些设置进行显示。

范围轮廓由一组与对象保持指定距离且处于**相同高度**的点构成。在三维视图中，以对象为顶点、范围轮廓为边界形成的锥面，其在中心天体表面上的投影作为范围轮廓显示。在三维视图中，显示的是范围轮廓锥面在中心天体表面上的投影。

> 如果三维视图中未显示范围轮廓线，应先检查二维视图【范围】属性中是否已定义有效的范围等级，再检查本页面的【显示】是否勾选。

## 设置方法

1.  在二维视图的【范围】属性中定义所需的范围轮廓等级，并设置各等级的线条颜色、线型、线宽及标签等显示属性。
2.  打开对象的三维视图【范围】属性。
3.  在【范围轮廓线】区域勾选【显示】，启用范围轮廓线显示。
4.  如需设置线条透明效果，勾选【半透明线条】。
5.  在【半透明度（%）】中输入所需数值，或拖动滑块调整透明程度。
6.  检查三维视图中的范围轮廓线显示效果，完成范围属性配置。

**注意事项：**

- 三维视图中的范围轮廓线依赖二维视图【范围】属性中定义的范围等级；本页面不用于新增或编辑范围距离等级。
- 【显示】用于控制范围轮廓线在三维视图中的显示与隐藏，不等同于二维视图中的范围轮廓设置。
- 【半透明线条】用于启用或关闭半透明显示效果；【半透明度（%）】用于调整启用该效果后的透明程度。
- 半透明度为 0% 时线条不透明；数值为 100% 时线条完全不可见。
