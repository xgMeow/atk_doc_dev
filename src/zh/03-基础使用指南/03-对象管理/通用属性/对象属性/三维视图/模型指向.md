# 模型指向

模型指向用于为三维模型中的可指向元素指定目标，使相应元素能够根据设定朝向目标。目标可以是中心天体、场景中的其他对象，也可以按照不同时间区间进行设置。

模型指向针对的是模型内部的可指向元素，不是对对象整体位置、轨道或整体姿态进行设置。

## 可指向元素

【可指向元素】列表用于显示当前模型中可进行目标指向设置的元素，以及各元素当前对应的指向目标。

| 参数 | 说明 |
| --- | --- |
| 指向名称 | 显示模型中可指向元素的名称。元素名称由模型文件定义。 |
| 指向目标对象 | 显示当前元素所指向的目标。采用分时段指向时，此处显示时段设置。 |

可指向元素的名称和数量取决于所使用的模型。列表中只显示模型已定义的可指向元素。如果列表为空，说明当前模型没有可供此功能设置的可指向元素，或模型中未提供相应定义。

## 可选目标

【可选目标】列表用于为当前选中的可指向元素指定指向目标。可选项包括中心天体、场景对象，以及用于设置指向方式的特殊选项。

| 选项 | 说明 |
| --- | --- |
| 中心天体 | 展开中心天体列表，选择需要指向的中心天体。 |
| 场景对象 | 展开场景对象列表，选择需要指向的对象。 |
| 时段 | 按时间区间设置指向目标。选择此项后，可在间隔列表配置不同时间区间对应的指向目标及转向过程。 |
| 无 | 不为当前可指向元素指定指向目标。 |

直接选择中心天体或场景对象时，该元素以所选对象作为指向目标。选择【时段】时，可以根据任务时间安排，为不同时间区间分别指定目标，并在目标切换之间设置转向时段。

## 模型指向间隔

【模型指向间隔】用于设置当前可指向元素在不同时间区间内的指向安排。选择【可选目标】中的【时段】后，可打开【模型指向间隔】设置窗口。

每条记录对应一个时间区间，需要设置 UTC 开始时间、UTC 结束时间和模式。通过多条记录，可以依次安排模型在不同时间段内的指向目标，以及目标切换时所需的过渡时间。

| 参数 | 说明 |
| --- | --- |
| UTC开始时间 | 设置当前时间区间的起始时刻，采用 UTC 时间。 |
| UTC结束时间 | 设置当前时间区间的结束时刻，采用 UTC 时间。 |
| 模式 | 设置当前时间区间内的指向状态，可以选择中心天体、场景对象、转向或无。 |

### 模式

【模式】用于指定当前时间区间内模型的指向状态。

| 模式 | 说明 |
| --- | --- |
| 中心天体 | 在该时间区间内，将所选中心天体作为指向目标。 |
| 场景对象 | 在该时间区间内，将所选场景对象作为指向目标。 |
| 转向 | 表示当前时间区间为指向机构的转向过渡时间，即指向机构从前一个指向目标转向下一个指向目标的过程。该时间段用于安排目标切换所需的过渡过程，不表示一个需要持续指向的对象。 |
| 无 | 当前时间区间不指定指向目标。 |

设置多个目标时，可以按照任务时间顺序安排目标指向时段，并在两个目标指向时段之间插入【转向】时段。例如，先设置一个时间段指向目标 A，再设置一段【转向】时间，随后设置另一个时间段指向目标 B。这样可以表达指向机构由目标 A 转向目标 B 的时间安排。

### 列表操作

| 操作 | 说明 |
| --- | --- |
| 添加 | 新增一条时间区间记录，用于设置新的指向时段或转向时段。 |
| 删除 | 删除当前选中的时间区间记录。 |
| 删除所有 | 删除间隔列表中的全部记录。 |

完成时间区间设置后，点击【确定】或【应用】保存设置；点击【取消】则放弃本次修改。

## 设置方法

1. 打开对象的三维视图属性，进入【模型指向】页面。
2. 在【可指向元素】列表中选择需要设置的元素。
3. 在【可选目标】列表中展开【中心天体】或场景对象，选择所需的指向目标。
4. 检查【指向目标对象】列，确认目标设置正确。
5. 如果需要根据时间切换指向目标，在【可选目标】中选择【时段】，点击【间隔列表】，在【模型指向间隔】窗口中，点击【添加】，设置每条记录的 UTC 开始时间、UTC 结束时间和模式。
6. 对于需要指向特定对象的时间段，在【模式】中选择相应的中心天体或场景对象；对于两个目标之间的过渡过程，单独添加一条【转向】记录。
7. 根据任务时间顺序检查各条记录，确认目标指向时段与转向时段的起止时间符合任务安排。
8. 完成设置后，点击【确定】或【应用】，并在三维视图中检查指向效果。

## 注意事项

- 模型指向设置针对模型中的可指向元素，不会直接改变对象本身的位置、轨道或整体姿态。
- 可指向元素由模型文件预先定义，其名称和数量可能因模型不同而有所差异。
- 并非所有三维模型都包含可指向元素。若列表为空，应确认当前模型是否提供了相应的指向定义。
- 直接选择中心天体或场景对象，表示为当前元素指定一个指向目标；选择【时段】，则在【模型指向间隔】窗口设置分时段的指向安排。
- 【转向】表示指向机构从前一目标转向后一目标的过渡时段，不应将其作为普通目标对象使用。通常应将其安排在两个目标指向时段之间。
- 设置间隔列表时，应检查各记录的 UTC 开始时间和结束时间，并确保时间顺序及区间衔接符合任务要求。
- 【无】表示相应时间区间不指定指向目标，不会删除模型中的可指向元素。
