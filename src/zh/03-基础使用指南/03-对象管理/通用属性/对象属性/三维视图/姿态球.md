# 姿态球

姿态球用于在三维视图中以球面网格的形式表示对象相对于指定参考坐标系的姿态方向，可辅助观察对象的姿态及其随时间的变化。姿态球的网格由经纬线构成，其中零度线用于突出显示球面的赤道和本初子午线。

姿态球属性分为【姿态球】和【投影】两个区域。【姿态球】用于设置球面网格的显示效果、比例及参考坐标系；【投影】用于将中心天体相对于当前对象的位置关系投影到姿态球表面。

## 姿态球

姿态球区域用于控制姿态球的显示状态及球面网格的外观。

| 参数       | 说明                  |
|------------|--------------------|
| 显示       | 控制是否在三维视图中显示姿态球。勾选后显示姿态球；取消勾选后隐藏姿态球。       |
| 颜色       | 设置姿态球普通网格线的显示颜色。                |
| 零度颜色   | 设置姿态球赤道线和本初子午线的显示颜色，用于突出显示零度方向。       |
| 线宽       | 设置姿态球普通网格线的显示宽度。        |
| 零度线宽   | 设置赤道线和本初子午线的显示宽度。    |
| 比例       | 设置姿态球的显示缩放比例。可在【值】文本框中输入数值，也可拖动滑块调整。该参数采用对数方式控制姿态球的显示尺寸，数值与实际显示尺寸并非线性关系。 |
| 参考坐标系 | 指定姿态球所采用的参考坐标系。点击右侧【选择】按钮，可打开参考坐标系选择窗口。姿态球的球面网格方向依据所选坐标系确定。                           |

姿态球的普通网格线用于表示球面经纬网格；零度线包括赤道线和本初子午线。通过分别设置颜色和线宽，可以区分普通网格线与零度线。

参考坐标系决定姿态球所表达的方向基准。选择不同的参考坐标系后，姿态球的方向表示也随之改变。姿态球主要用于辅助观察对象相对于所选坐标系的姿态关系，不改变对象本身的姿态数据。

## 投影

投影区域用于设置中心天体在姿态球表面上的投影显示。通过投影可以观察中心天体相对于当前对象的方向关系，并辅助判断对象与相关天体之间的空间方位。

### 投影列表

投影列表用于显示可供投影的对象，并设置各对象投影的显示属性。

| 参数     | 说明    |
|----------|-------|
| 名称     | 显示可进行投影的中心天体的名称。      |
| 显示     | 控制是否在姿态球上显示对应对象的投影。勾选后显示投影；取消勾选后隐藏该对象的投影。 |
| 显示标签 | 控制是否显示对应投影的名称标签。             |
| 颜色     | 设置对应对象投影的显示颜色。  |
| 点大小   | 设置以点标记形式显示的投影标记尺寸。             |

中心天体的投影表示的是该天体相对于当前对象的方向或视位置关系，并非对象在实际空间中的距离位置。

## 设置方法

1.  在【姿态球】区域勾选【显示】，启用姿态球显示。
2.  根据显示需求设置普通网格线的【颜色】和【线宽】。
3.  设置【零度颜色】和【零度线宽】，突出显示赤道线和本初子午线。
4.  在【比例】区域输入所需数值，或拖动滑块调整姿态球的显示尺寸。
5.  点击【参考坐标系】右侧的【选择】按钮，选择姿态球所采用的参考坐标系。
6.  在【投影】列表中选择需要显示的中心天体，勾选对应的【显示】。
7.  根据需要勾选【显示标签】，设置投影的【颜色】及【点大小】。
8.  检查三维视图中的姿态球网格及对象投影显示效果，完成姿态球配置。

**注意事项：**

- 姿态球是用于观察对象姿态和方向关系的图形辅助工具，不代表实际存在的物理球体。
- 【参考坐标系】用于确定姿态球的方向基准。更换参考坐标系后，姿态球所表达的方向关系会相应改变。
- 【比例】采用对数方式控制姿态球的显示尺寸，不应将其理解为对象的实际尺寸或物理半径。
- 【颜色】和【线宽】作用于普通网格线；【零度颜色】和【零度线宽】作用于赤道线及本初子午线。
- 【投影】用于显示中心天体相对于当前对象的方向关系，不表示这些对象的实际空间距离。
