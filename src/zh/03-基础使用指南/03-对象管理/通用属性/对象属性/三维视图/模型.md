# 模型

模型用于在三维视图中显示对象的三维外观。通过选择模型文件，并设置模型显示比例、欧拉角、标签偏移量和平移补偿，可调整模型在三维视图中的显示效果。

模型属于对象的图形显示内容。模型的缩放、旋转及平移补偿用于调整显示效果，不改变对象本身的位置、运动状态及分析计算结果。

## 模型设置

### 模型显示

模型显示区域用于加载三维模型并设置其显示参数。

| 参数     | 说明                              |
|----------|--------------------------------------------------------------------------------------------------------------------------------|
| 显示     | 控制是否在三维视图中显示对象模型。勾选后显示模型；取消勾选后隐藏模型。                                                         |
| 模型文件 | 指定用于表示对象的三维模型文件。文本框显示当前模型文件，点击右侧【...】按钮可打开文件选择窗口并加载模型。                      |
| Log比例  | 设置模型的显示缩放比例。该参数采用对数方式控制模型尺寸，数值变化与实际缩放倍数并非线性关系。可直接输入数值，也可拖动滑块调整。 |

模型文件应采用当前软件支持的三维模型格式，如：ive / 3ds / flt / fbk 等。若模型无法正常加载，可检查文件路径、文件格式是否正确。

### 欧拉角

欧拉角用于调整模型相对于对象参考坐标系的显示朝向。通过三个依次进行的轴向旋转，使模型坐标轴与对象的参考方向相匹配。

| 参数           | 说明                                     |
|----------------|------------------------------------------------|
| 欧拉角1（deg） | 设置转序中第一次旋转的角度，单位为度。                                                                                   |
| 欧拉角2（deg） | 设置转序中第二次旋转的角度，单位为度。                                                                                   |
| 欧拉角3（deg） | 设置转序中第三次旋转的角度，单位为度。                                                                                   |
| 转序           | 共12种，用于指定三个欧拉角对应的旋转轴及其先后顺序。数字 `1`、`2`、`3` 分别表示 X、Y、Z 轴。后续旋转相对于前一次旋转后的坐标轴进行。 |

例如，转序设置为 `321` 时，依次绕 Z 轴、第一次旋转后的新 Y
轴以及前两次旋转后的新 X 轴进行旋转。三个欧拉角分别对应上述三次旋转。

> 欧拉角的最终旋转结果与转序有关。调整欧拉角时，应同时检查转序设置；相同的三个角度在不同转序下可能得到不同的模型朝向。

### 标签偏移量

标签偏移量用于调整对象标签在三维视图中的显示位置，使标签与模型适当分离，避免标签与模型或其他图形元素重叠。

| 参数   | 说明                                  |
|--------|---------------------------------------|
| X（m） | 设置标签沿 X 方向的偏移量，单位为米。 |
| Y（m） | 设置标签沿 Y 方向的偏移量，单位为米。 |
| Z（m） | 设置标签沿 Z 方向的偏移量，单位为米。 |

正值和负值分别表示沿对应坐标轴的正向和负向偏移。三个方向的偏移量共同确定标签相对于对象参考位置的显示位置。

### 平移补偿

平移补偿用于调整模型相对于对象参考位置的显示位置。当模型自身的几何原点与对象参考点不重合时，可通过平移补偿修正模型的显示位置。

| 参数   | 说明                                      |
|--------|-------------------------------------------|
| X（m） | 设置模型沿 X 方向的平移补偿量，单位为米。 |
| Y（m） | 设置模型沿 Y 方向的平移补偿量，单位为米。 |
| Z（m） | 设置模型沿 Z 方向的平移补偿量，单位为米。 |

平移补偿仅调整模型在三维视图中的显示位置，不改变对象本身的位置数据。三个方向的补偿量均为`0` 时，模型不进行额外平移。

### 模型预览

预览示意图用于查看当前模型的外观及调整后的显示方向，可结合预览中的坐标轴检查模型朝向和偏移效果。

| 操作     | 说明                           |
|----------|--------------------------------|
| 关闭     | 关闭模型预览区域。             |
| 默认视点 | 将模型预览恢复为默认观察视点。 |
| 关节 | 打开【关节】设置窗口，用于查看和调整模型中定义的关节及其关联的转换参数。 |

### 关节

关节用于调整模型中预先定义的可动部分。通过选择关节及其关联的转换项目，可以调整模型中相应部分的显示状态。

点击模型设置区域中的【关节】，打开关节设置窗口。窗口包含【关节】和【转换】两个列表，以及用于调整转换参数的滑块和数值输入框。

#### 参数说明

| 参数 | 说明 |
| --- | --- |
| 关节 | 显示模型中定义的关节列表。选择某一关节后，【转换】列表显示该关节关联的转换项目。 |
| 转换 | 显示当前选中关节所包含的转换项目。选择其中一项，可调整对应的转换参数。 |
| 最小值 | 表示当前转换参数允许调整的最小值。 |
| 最大值 | 表示当前转换参数允许调整的最大值。 |
| 滑块 | 在当前转换参数允许的范围内进行调整。 |
| 数值输入框 | 显示当前转换参数的数值，也可直接输入数值进行调整。 |
| 确定 | 确认当前调整并关闭关节设置窗口。 |
| 关闭 | 关闭关节设置窗口。 |
| 应用 | 应用当前调整，窗口保持打开。 |

关节及其关联的转换项目由模型文件预先定义。不同模型所包含的关节数量、转换项目及其参数范围可能不同。

### 设置方法

1. 点击模型设置区域中的【关节】，打开关节设置窗口。
2. 在【关节】列表中选择需要调整的关节。
3. 在【转换】列表中选择需要调整的转换项目。
4. 使用滑块或数值输入框调整对应的转换参数。
5. 点击【应用】查看调整效果；确认设置后，点击【确定】关闭窗口。

## 点

点用于以点标记的形式显示对象位置，可与三维模型显示分别设置。

| 参数 | 说明                                                                           |
|------|--------------------------------------------------------------------------------|
| 显示 | 控制是否在三维视图中显示对象的点标记。勾选后显示点标记；取消勾选后隐藏点标记。 |
| 大小 | 设置点标记在三维视图中的显示尺寸。         |

模型显示与点标记显示相互独立，可根据三维视图的显示需求分别启用或关闭。

## 设置方法

1.  在模型设置区域勾选【显示】，启用对象模型显示。
2.  点击【模型文件】右侧的【...】按钮，选择需要加载的三维模型文件。
3.  根据模型在三维视图中的显示尺寸，调整【Log比例】。
4.  根据模型自身坐标方向与对象参考坐标系之间的关系，设置三个【欧拉角】及对应的【转序】，并在预览示意图中检查模型朝向。
5.  如需调整对象标签的位置，在【标签偏移量】中分别设置 X、Y、Z方向的偏移量。
6.  如需修正模型几何原点与对象参考点之间的位置偏差，在【平移补偿】中设置X、Y、Z 方向的补偿量。
7.  如需调整模型中的可动部分，点击【关节】，选择相应的关节及转换项目，设置转换参数。
8.  根据需要勾选【点】区域中的【显示】，并设置点标记的【大小】。
9.  检查三维视图中的模型、标签及点标记显示效果，完成模型配置。

**注意事项：**

- 模型缩放、欧拉角和位置补偿均用于调整三维图形显示，不改变对象本身的运动和分析数据。
- 【标签偏移量】调整的是对象标签的位置；【平移补偿】调整的是模型本身的位置，两者作用对象不同。
- 欧拉角的旋转顺序由【转序】确定。修改转序后，应重新检查模型的显示朝向。
- 模型文件应完整且符合当前软件支持的格式要求。
