# 数据显示

数据显示用于在三维视图中以文字形式显示对象相关的动态数据，便于在观察对象运动状态和场景变化的同时查看相应信息。

数据显示属性主要包括数据显示项目列表，以及文字、背景和边框的外观与位置设置。数据显示项目可以固定显示在三维视图窗口中的指定位置，也可以相对于所属对象显示。

## 数据显示项目

数据显示项目列表用于管理当前对象关联的动态数据显示内容，并设置各项目的显示状态、位置和字体颜色。

| 参数     | 说明    |
|----------|----------|
| 名称     | 显示已添加的动态数据显示项目名称。     |
| 显示     | 控制是否在三维视图中显示对应的数据内容。勾选后显示该项目；取消勾选后隐藏该项目。   |
| 显示位置 | 设置对应数据显示项目的位置，可选择【对象】或【窗口】。选择【对象】时，数据显示相对于所属对象定位；选择【窗口】时，根据设定的位置参数确定其在三维视图窗口中的初始显示位置，显示后还可以在三维窗口中手动移动。 |
| 字体颜色 | 设置对应数据显示项目的文字颜色。     |

### 项目管理

| 按钮       | 说明     |
|------------|---------------|
| 添加       | 打开动态数据显示类型列表，选择需要添加的数据显示项目，点击【确定】后将其加入当前列表。 |
| 添加自定义 | 添加自定义数据显示项目。              |
| 修改       | 修改选中的数据显示项目。              |
| 删除       | 删除选中的数据显示项目。                |
| 删除全部   | 删除当前列表中的全部数据显示项目。       |

点击【添加】后，软件弹出【添加显示数据】窗口。窗口以列表形式显示当前可用的动态数据显示类型。选择所需项目后，点击【确定】完成添加；点击【取消】则放弃本次操作。

## 文字

文字区域用于设置数据显示文字的颜色、定位方式及具体位置。

| 参数     | 说明         |
|----------|--------|
| 颜色     | 设置数据显示文字的颜色。该参数与数据显示项目列表中的【字体颜色】同步，修改其中一处后，另一处自动更新。                                   |
| 显示位置 | 设置文字在三维视图中的定位方式，可选择【对象】或【窗口】。该参数与数据显示项目列表中的【显示位置】同步，修改其中一处后，另一处自动更新。 |
| X轴原点  | 设置水平方向的位置参考原点，可选择【左】【右】或【中心】。     |
| X        | 设置文字相对于所选 X 轴原点的水平偏移量。       |
| Y轴原点  | 设置垂直方向的位置参考原点，可选择【上】【下】或【中心】。    |
| Y        | 设置文字相对于所选 Y 轴原点的垂直偏移量。        |

【X轴原点】和【Y轴原点】共同确定文字位置的参考基准；【X】和【Y】用于设置相对于该基准的偏移量。

两种显示位置的含义如下：

- **对象：** 将数据显示关联到所属对象，数据显示位置随对象在三维视图中的位置变化。
- **窗口：** 将数据显示放置在三维视图窗口中的指定初始位置，不与所属对象的位置绑定。数据显示后，可以在三维窗口中通过手动拖动调整其显示位置。

## 背景

背景区域用于设置数据显示文字区域的背景显示效果。

| 参数 | 说明           |
|------|-----------------|
| 背景 | 控制是否启用数据显示区域的背景。勾选后显示背景；取消勾选后不显示背景。 |
| 颜色 | 设置数据显示区域的背景颜色。    |

## 边框

边框区域用于设置数据显示区域边框的显示效果。

| 参数 | 说明     |
|------|--------|
| 边框 | 控制是否显示数据显示区域的边框。勾选后显示边框；取消勾选后隐藏边框。 |
| 颜色 | 设置数据显示区域边框的颜色。    |

## 设置方法

1.  在数据显示项目列表中，点击【添加】，打开【添加显示数据】窗口。
2.  在动态数据显示类型列表中选择所需项目，点击【确定】将其添加到数据显示项目列表。
3.  在列表中选择需要设置的数据显示项目，勾选【显示】启用其显示。
4.  在列表中的【显示位置】选择【对象】或【窗口】，确定数据显示的定位方式。
5.  在列表中的【字体颜色】或下方【文字】区域的【颜色】中设置文字颜色。两处设置会自动同步。
6.  在【文字】区域设置【显示位置】。该设置与列表中的【显示位置】同步。
7.  根据需要选择【X轴原点】和【Y轴原点】，并设置对应的 X、Y
    偏移量，调整文字的具体位置。
8. 当【显示位置】选择【窗口】时，可在三维视图中通过手动拖动数据显示内容，进一步调整其实际显示位置。
9.  如需显示背景，勾选【背景】，并设置背景颜色。
10.  如需显示边框，勾选【边框】，并设置边框颜色。
11. 根据需要使用【添加自定义】【修改】【删除】或【删除全部】管理数据显示项目。
12. 点击【确定】或【应用】，检查三维视图中的数据显示效果。

**注意事项：**

- 数据显示用于在三维视图中呈现动态数据，其显示内容随场景动画及相关数据变化而更新。
- 【对象】和【窗口】是两种不同的定位方式：【对象】使数据显示相对于所属对象定位；【窗口】使数据显示相对于三维视图窗口定位。窗口模式下，X、Y轴原点及偏移量用于确定初始显示位置，显示后仍可通过手动拖动调整位置。
- 列表中的【显示位置】与下方【文字】区域中的【显示位置】为同一属性，修改其中一处时，另一处会自动同步更新。
- 列表中的【字体颜色】与下方【文字】区域中的【颜色】为同一属性，修改其中一处时，另一处会自动同步更新。
- X 轴原点可选择【左】【右】【中心】；Y
  轴原点可选择【上】【下】【中心】。X、Y
  数值表示相对于所选原点的偏移量，不代表对象在空间中的坐标。
- 【背景】和【边框】分别控制数据显示区域的背景及边框，可根据显示需要独立启用。
