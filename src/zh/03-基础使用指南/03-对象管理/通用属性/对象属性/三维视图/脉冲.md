# 脉冲

## 定义

脉冲用于调制传感器在三维视图中的投影显示，使传感器投影呈现沿投影方向变化的脉冲效果。通过设置振幅、脉冲长度和频率，可以调整脉冲显示的透明度变化、空间长度以及出现速率。

脉冲属于三维视图显示效果，不改变传感器的视场定义、探测能力或约束计算结果。

## 配置项

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制是否启用传感器投影的脉冲显示。未勾选时，传感器投影以透明度均匀的单一颜色显示；勾选后，投影按照设定的脉冲参数进行调制。 |
| 振幅 | 设置脉冲显示中透明度变化的幅度，影响脉冲区域与基础投影之间的透明度对比。 |
| 脉冲长度 | 设置单个脉冲在空间中所占据的长度，单位为 km。该参数控制脉冲沿传感器投影方向所占的空间范围，不代表整个传感器投影的延伸距离。 |
| 频率 | 设置脉冲的重复频率，单位为 Hz。可通过下拉列表选择【自定义】【快速】【中速】或【慢速】模式。选择预设模式后，系统自动填入对应的频率值；选择【自定义】时，可以手动输入频率数值。 |
| 反向 | 控制脉冲的运动方向。勾选后，脉冲沿与默认设置相反的方向移动。 |
| 重置为缺省值 | 将脉冲显示参数恢复为默认设置。 |

### 频率模式

【频率】提供四种模式，不同模式对应不同的默认频率值。

| 模式 | 默认值（Hz） | 说明 |
| --- | ---: | --- |
| 自定义 | 0.0 | 用户自行输入脉冲频率。 |
| 快速 | 0.333 | 采用较高的脉冲重复频率。 |
| 中速 | 0.167 | 采用中等的脉冲重复频率。 |
| 慢速 | 0.083 | 采用较低的脉冲重复频率。 |

选择【快速】【中速】或【慢速】后，频率输入框自动显示对应的默认值。选择【自定义】后，可以在数值输入框中设置所需的频率。

## 设置方法

1. 打开传感器对象的属性设置。
2. 在【三维视图】中选择【脉冲】。
3. 勾选【显示】，启用脉冲投影效果。
4. 设置【振幅】，调整脉冲区域的透明度显示效果。
5. 设置【脉冲长度】，调整单个脉冲在空间中所占据的长度。
6. 在【频率】中选择预设频率，或根据需要设置频率数值。
7. 如果需要改变脉冲的移动方向，勾选【反向】。
8. 点击【确定】或【应用】，在三维视图中检查脉冲显示效果。
9. 如需恢复默认参数，点击【重置为缺省值】。

## 注意事项

- 本设置仅适用于**传感器**对象。
- 脉冲仅用于调制传感器三维投影的显示效果，不会改变传感器的实际视场、探测范围或约束分析结果。
- 【显示】未勾选时，脉冲效果不显示，传感器投影以透明度均匀的单一颜色显示。
- 【振幅】控制脉冲显示中透明与不透明区域的比例；【脉冲长度】控制单个脉冲占据的空间长度；【频率】控制脉冲重复出现的速率。
- 【脉冲长度】与【空间投影】中的投影延伸距离不是同一参数。前者控制单个脉冲所占据的空间长度，后者控制传感器投影的延伸范围。
