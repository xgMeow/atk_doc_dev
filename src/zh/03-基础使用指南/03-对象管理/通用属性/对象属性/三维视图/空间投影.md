# 空间投影

## 定义

空间投影用于控制传感器视场在三维空间中的投影显示及延伸距离。

该设置属于三维视图显示参数，用于调整传感器投影图形的延伸范围，不改变传感器本身的探测能力，也不直接改变可见性或覆盖分析结果。

## 配置项

| 参数 | 说明 |
| --- | --- |
| 空间投影（km） | 设置传感器空间投影的固定延伸距离，单位为 km。系统根据传感器视场轮廓最外侧点沿视轴方向的投影距离确定投影范围。 |
| 使用距离约束 | 启用后，使用传感器【约束】-【基本】中设置的距离约束确定投影范围。 |

空间投影距离用于控制传感器投影图形在三维空间中的延伸长度。未使用距离约束时，投影范围由【空间投影（km）】设置；启用【使用距离约束】后，投影范围采用基本约束中设置的距离约束。

当传感器设置了有效的距离约束时，三维视图中的传感器投影始末端会显示相应的穹顶状边界，以表示距离约束的范围。

## 设置方法

1. 打开传感器对象的属性设置。
2. 在【三维视图】中选择【空间投影】。
3. 在【空间投影（km）】输入框中设置投影延伸距离。
4. 如果需要根据传感器的距离约束确定投影范围，勾选【使用距离约束】。
5. 点击【确定】或【应用】，在三维视图中检查传感器投影的显示范围。

## 注意事项

- 本设置仅适用于**传感器**对象。
- 空间投影用于控制传感器投影图形在三维空间中的显示延伸范围，属于可视化设置，不是传感器的实际作用距离或探测距离。
- 【空间投影（km）】设置的是投影延伸距离，不应简单理解为传感器视场圆锥沿视轴方向的几何长度。其计算与视场轮廓最外侧点沿视轴方向的投影有关。
- 勾选【使用距离约束】前，应确认传感器已在【约束】-【基本】中设置相应的距离约束；否则可能无法观察到距离约束对投影范围的影响。
- 使用距离约束后，传感器投影始末端会显示穹顶状边界，用于表示距离约束范围。
