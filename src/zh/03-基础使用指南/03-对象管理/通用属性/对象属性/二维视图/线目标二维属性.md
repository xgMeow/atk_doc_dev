# 二维属性

用于设置线目标在二维地图中的显示效果。线目标的路径由**基本 → 路径**中定义的经纬度点依次连接形成。控制路径线、路径点及名称标签的显示，并设置路径线的颜色、线型和线宽，不改变路径点的坐标及锚点设置。

## 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 | 线目标图形的总显示开关。勾选后显示线目标，取消勾选后隐藏其二维图形。 |
| 显示线的点 | 勾选后，在路径线上标记构成线目标的路径点，便于检查各点的位置及路径走向；取消勾选后隐藏点标记，路径线仍可显示。 |
| 显示标签 | 勾选后，在二维地图中显示线目标的名称标签；取消勾选仅隐藏标签。 |

## 图形样式

| 参数 | 说明 |
| --- | --- |
| 颜色 | 点击颜色区域选择路径线的显示颜色，用于区分地图中的不同线目标。 |
| 线型 | 从下拉列表选择路径线的绘制样式。 |
| 线宽 | 从下拉列表选择路径线的宽度，使路径轮廓在地图中更加清晰。 |

## 设置方法

1. 在对象的**基本 → 路径**中添加路径点，完成线目标的路径定义。
2. 打开**二维视图 → 二维属性**，勾选**显示**。
3. 设置路径线的**颜色、线型和线宽**。
4. 如需检查构成路径的各个点，勾选**显示线的点**；如需在地图中识别线目标的名称，勾选**显示标签**。

需要新增、删除或修改路径点时，应返回[路径](../基本/线目标路径.md)属性进行设置。
