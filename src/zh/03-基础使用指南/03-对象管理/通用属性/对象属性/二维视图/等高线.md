# 等高线

等高线属性用于设置对象在二维视图中的仰角轮廓显示。
仰角是中心天体表面某一位置指向对象的视线与当地水平面之间的夹角；同一条仰角轮廓线上的位置，对应相同的仰角值。通过设置多个仰角分级，可以查看对象在不同仰角条件下对应的地表区域，并可单独配置指定时刻的仰角椭圆。

## 仰角轮廓线

仰角轮廓线用于表示从中心天体表面不同位置观察当前对象时，视线仰角等于指定分级值的轮廓。各分级以角度表示，单位为度（deg）。

### 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 |  勾选后，在二维地图中绘制已添加分级对应的仰角轮廓线；取消勾选后隐藏轮廓线。 |
| 填充 | 勾选后，对仰角轮廓对应的地表区域进行颜色填充；取消勾选后仅保留已启用的轮廓线，不显示填充区域。 |
| 半透明度（%） | 勾选**填充**后，可以输入数值或拖动滑块调整填充区域的透明程度。取值范围为 0%～100%；0% 表示不透明，100% 表示完全透明。 |

### 添加分级

在**添加分级**区域选择添加方式，输入角度并点击**添加**，即可将分级加入右侧的“分级属性”列表。

| 添加方式 | 参数 | 说明 |
| --- | --- | --- |
| 指定 | 分级 | 输入一个仰角值，每次点击**添加**，向分级属性列表加入一个角度等级。 |
| 起始、结束、步长 | 开始、结束、步长 | 按起始仰角、结束仰角和相邻等级的角度间隔批量生成分级。 |

### 分级属性

各仰角等级显示在**分级属性**列表中，可为不同等级分别设置颜色和线条外观，以便在地图中区分轮廓。

| 参数 | 说明 |
| --- | --- |
| 分级（deg） | 当前轮廓对应的仰角值。 |
| 颜色 | 点击对应颜色单元格，设置该仰角等级的轮廓颜色。 |
| 线型 | 设置该等级轮廓线的线条样式。 |
| 线宽 | 设置该等级轮廓线的绘制宽度。 |

选中某一分级后，点击**删除**可移除该等级；点击**删除全部**可清空整个分级列表。

## 仰角椭圆

**仰角椭圆**用于单独设置某一指定时刻、某一指定仰角对应的轮廓图形。
勾选**仰角椭圆**后，可通过列表右侧的**添加**按钮创建条目，并在表格中编辑参数。

| 参数 | 说明 |
| --- | --- |
| 时间 | 指定计算该条仰角椭圆所对应的时刻。可在时间单元格中编辑日期与时间。 |
| 分级（deg） | 指定该时刻采用的仰角值，单位为度（deg）。与时间共同确定该条目的轮廓。 |
| 颜色 | 为该条仰角椭圆设置独立的轮廓颜色。 |
| 线型 | 设置该条仰角椭圆的线条样式。 |
| 线宽 | 设置该条仰角椭圆的绘制宽度。 |
| 显示标签 | 勾选后显示该条仰角椭圆的标签；取消勾选隐藏标签。 |

点击**添加**可新增仰角椭圆条目；选中一行后点击**删除**可移除该条目；点击**删除全部**可清空列表。

## 设置方法

1. 打开对象属性中的**二维视图 → 等高线**，在**仰角轮廓线**区域勾选**显示**。
2. 在**添加分级**区域选择**指定**或**起始、结束、步长**，输入仰角值并点击**添加**。
3. 在**分级属性**列表中，为不同仰角等级设置颜色、线型和线宽。
4. 需要显示轮廓对应的地表填充区域时，勾选**填充**，再设置**半透明度（%）**。
5. 需要查看指定时刻的仰角轮廓时，勾选**仰角椭圆**，点击**添加**，为各条目设置时间、分级和显示样式。
6. 在二维地图中查看轮廓显示效果。需要调整椭圆的时间、分级或样式时，可在表格中编辑相应单元格；需要移除轮廓或条目时，使用**删除**或**删除全部**。

## 显示说明

- **仰角轮廓线与仰角椭圆分开管理。** 上方的分级列表用于统一设置仰角轮廓，下方的椭圆列表用于管理指定时刻的独立条目。两组图形可以分别启用。
- **二维视图与三维视图的设置相互关联。** 三维视图中的等高线使用本页面定义的仰角轮廓等级；轮廓锥和表面填充的三维显示方式在**三维视图 → 等高线**中设置。
