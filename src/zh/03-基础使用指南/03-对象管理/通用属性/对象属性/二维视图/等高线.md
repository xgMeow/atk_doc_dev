# 等高线

等高线属性用于设置对象在二维视图中的仰角轮廓显示。通过指定仰角分级及其图形样式，可在地图中显示不同仰角对应的轮廓，并可单独配置指定时刻的仰角椭圆。

## 仰角轮廓线

仰角轮廓线用于表示从中心天体表面不同位置观察当前对象时，视线仰角等于指定分级值的轮廓。各分级以角度表示，单位为度（deg）。

### 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 | 勾选后在二维视图中显示已配置的仰角轮廓线。 |
| 填充 | 勾选后对仰角轮廓对应的区域进行颜色填充。 |
| 半透明度（%） | 设置填充区域的透明程度。数值越大，填充越透明。 |

### 添加分级

在“添加分级”区域中选择添加方式，输入仰角值后点击 **添加**，即可将分级加入右侧的“分级属性”列表。

| 添加方式 | 参数 | 说明 |
| --- | --- | --- |
| 指定 | 分级 | 单独添加一个指定仰角值。 |
| 起始、结束、步长 | 开始、结束、步长 | 按起始角度、结束角度及角度间隔批量生成仰角分级。 |

### 分级属性

**分级属性**列表用于查看和修改已添加分级的显示样式。

| 属性 | 说明 |
| --- | --- |
| 分级（deg） | 该轮廓对应的仰角分级值。 |
| 颜色 | 设置轮廓线的显示颜色。 |
| 线型 | 设置轮廓线样式。 |
| 线宽 | 设置轮廓线宽度。 |
| 删除 | 删除列表中选中的分级。 |
| 删除全部 | 清空当前列表中的所有分级。 |

## 仰角椭圆

**仰角椭圆**用于按时间和仰角分级单独配置二维视图中的椭圆图形。勾选 **仰角椭圆** 后，可使用下方列表添加或管理条目。

| 参数 | 说明 |
| --- | --- |
| 时间 | 指定该椭圆条目对应的时刻。 |
| 分级（deg） | 设置椭圆对应的仰角分级值，单位为度（deg）。 |
| 颜色 | 设置椭圆轮廓颜色。 |
| 线型 | 设置椭圆轮廓线样式。 |
| 线宽 | 设置椭圆轮廓线宽度。 |
| 显示标签 | 勾选则显示出标签。 |
| 添加 | 在列表中新增一个仰角椭圆条目。 |
| 删除 | 删除选中的条目。 |
| 删除全部 | 清空所有仰角椭圆条目。 |

## 设置方法

1. 打开对象属性，进入 **二维视图 → 等高线**。
2. 在“仰角轮廓线”区域勾选 **显示**，根据需要设置填充及半透明度。
3. 选择 **指定** 或 **起始、结束、步长** 添加仰角分级，并在“分级属性”列表中调整颜色、线型和线宽。
4. 如需单独配置仰角椭圆，勾选 **仰角椭圆**，点击 **添加**，设置对应的时间、分级和显示样式。
