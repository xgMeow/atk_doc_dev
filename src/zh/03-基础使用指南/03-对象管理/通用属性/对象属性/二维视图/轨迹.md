# 轨迹

轨迹属性用于控制对象运动轨迹在二维视图中的显示方式。通过选择不同的轨迹类型，可按轨迹点、时间范围或完整轨迹进行显示，也可以关闭轨迹显示。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 轨迹类型 | 设置二维视图中的轨迹显示方式，可选**点、时间、所有、无**。 |

各轨迹类型说明如下：

| 轨迹类型 | 说明 |
| --- | --- |
| 点 | 按轨迹点控制显示的轨迹范围。与点数有关的具体设置以当前对象的界面为准。 |
| 时间 | 按时间范围控制显示的轨迹片段。与时间长度有关的具体设置以当前对象的界面为准。 |
| 所有 | 显示对象在有效轨迹数据覆盖范围内的完整轨迹。 |
| 无 | 不在二维视图中绘制对象的运动轨迹。 |

## 设置方法

在对象属性中选择**二维视图 → 轨迹**，通过**轨迹类型**下拉框选择所需的显示方式。选择后，二维视图按照当前轨迹类型显示对象的运动路径。
