# 轨迹

轨迹属性用于选择二维视图中绘制哪一部分运动轨迹。可通过轨迹类型在随仿真时间变化的局部轨迹、完整轨迹和不显示轨迹之间切换。

## 轨迹类型

| 类型 | 说明 |
| --- | --- |
| 点 | **以轨迹数据点为依据确定显示片段。** 随仿真时间推进，绘制的轨迹片段随对象的运动位置更新。 |
| 时间 | **以轨迹点对应的时间为依据确定显示片段。** 播放动画或拖动时间轴时，轨迹显示随当前仿真时刻更新。 |
| 所有 | 绘制对象在有效轨迹数据覆盖范围内的完整运动路径。 |
| 无 | 不绘制运动轨迹线。 |

## 设置方法

1. 打开运动对象的【二维视图 → 轨迹】属性。
2. 在【轨迹类型】下拉框中选择【点】【时间】【所有】或【无】。
3. 在二维视图中运行或拖动仿真时间，查看轨迹显示效果。需要查看整条路径时选择【所有】；需要隐藏轨迹线时选择【无】。

**说明：** 轨迹负责控制绘制范围；轨迹是否启用以及颜色、线型和线宽等外观设置，可在[显示](./显示.md)中配置。
