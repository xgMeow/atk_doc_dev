# 刈幅

刈幅用于在二维视图中显示运动对象沿轨迹经过时，在中心天体表面形成的覆盖带。
刈幅以对象的**地面轨迹**为中心，按设定的地面仰角、飞行器半锥角或地表距离确定左右两侧边界。
选择不同的刈幅类型，可分别采用地面观测仰角、对象天底锥角或地表距离作为覆盖边界的几何基准。

## 刈幅类型

在**刈幅类型**下拉列表中选择所需类型，并在右侧输入对应参数。

| 类型 | 参数 | 边界确定方式 |
| --- | --- | --- |
| 地面仰角 | 仰角 | 从地面向上观察对象，取视线仰角等于设定值的地面位置，确定轨迹两侧的边界。**0° 对应地平线方向**； |
| 飞行器半锥角 | 半锥角 | 以对象指向中心天体的**天底方向**为锥轴，将指定半锥角的锥面与中心天体表面相交，确定两侧边界。边界延伸到地平线时，以可见地表范围为限。 |
| 刈幅半幅宽 | 半幅宽 | 从地面轨迹向左右两侧各延伸指定的**地表距离**。输入的是单侧宽度。 |
| 地面仰角包络 | 仰角 | 随对象运动，跟踪指定地面仰角所对应的瞬时轮廓，以这些轮廓随时间变化形成的**包络线**确定刈幅边界。 |
| 飞行器半锥角包络 | 半锥角 | 随对象运动，跟踪指定半锥角在地表形成的瞬时轮廓，以轮廓随时间变化形成的**包络线**确定刈幅边界。 |

**三种基本类型的区别：** 

- 地面仰角从**地面观察对象**的角度确定边界。

- 飞行器半锥角从**对象朝向地面**的角度确定边界。

- 刈幅半幅宽则直接指定地面轨迹到边界的距离。

例如，将半幅宽设置为 5 km，表示地面轨迹左右两侧各取约 5 km 的地表宽度。

**刈幅与包络刈幅的区别：** **刈幅**按每一时刻轨迹两侧的几何条件求取边界点；**包络刈幅**关注同一角度轮廓随对象运动形成的外包边界。对象高度或运动方向发生变化时，两种方式得到的边界可能不同。

## 显示选项

在**选项**区域选择刈幅的绘制方式。

| 选项 | 显示效果 |
| --- | --- |
| 不显示 | 不绘制刈幅。 |
| 显示边缘 | 沿对象的地面轨迹绘制左右两侧的刈幅边界，适合查看覆盖带的宽度和走向。 |
| 显示填充 | 在左右边界之间绘制覆盖带，便于观察对象运动过程中经过的地表区域。 |

## 设置方法

1. 打开对象属性中的**二维视图 → 刈幅**。
2. 在**刈幅类型**中选择地面仰角、飞行器半锥角、刈幅半幅宽或相应的包络类型。
3. 输入角度或距离参数。
4. 在**选项**中选择**显示边缘**或**显示填充**，然后在二维视图中检查地面覆盖带。

**注意事项：**

- **刈幅半幅宽**是从地面轨迹到单侧边界的地表距离，不是飞行器到地面的斜距，也不是两侧边界之间的总宽度。
- **飞行器半锥角**以天底方向为基准，并非传感器实际指向角。此处的刈幅是由运动对象及指定几何参数形成的显示图形。
