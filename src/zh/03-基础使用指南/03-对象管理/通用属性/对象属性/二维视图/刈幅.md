# 刈幅

刈幅用于根据运动对象与中心天体表面之间的几何关系，在二维视图中显示沿运动轨迹形成的地表覆盖带。通过设置**刈幅类型、对应参数及显示选项**，可控制刈幅边界或覆盖区域的显示方式。

## 刈幅类型

选择刈幅类型后，在右侧输入对应参数。ATK 支持以下五种类型：

| 刈幅类型 | 说明 |
| --- | --- |
| 地面仰角 | 以地面位置观察运动对象时的仰角为条件，确定运动轨迹两侧的刈幅边界。 |
| 飞行器半锥角 | 以运动对象指向中心天体的天底方向为基准，按指定半锥角确定地表刈幅边界。 |
| 刈幅半幅宽 | 以地面轨迹为中心，按中心天体表面上的指定距离确定两侧刈幅边界。 |
| 地面仰角包络 | 根据指定地面仰角对应的瞬时轮廓随对象运动形成的包络，确定刈幅边界。 |
| 飞行器半锥角包络 | 根据指定飞行器半锥角对应的瞬时轮廓随对象运动形成的包络，确定刈幅边界。 |

### 地面仰角

地面仰角是地表观测位置的局部水平面与指向运动对象的视线之间的夹角。指定仰角后，系统以满足该角度条件的地面点确定沿轨迹分布的刈幅边界。

### 飞行器半锥角

飞行器半锥角是以运动对象的天底方向为轴线定义的半锥角。系统根据该锥面与中心天体表面的几何关系确定刈幅边界；接近地平线时，边界还会受到可见地表范围的限制。

### 刈幅半幅宽

刈幅半幅宽表示**从地面轨迹向一侧延伸的表面距离**，不是刈幅两侧之间的总宽度。

### 地面仰角包络与飞行器半锥角包络

包络类刈幅考虑对象运动过程中相应角度轮廓的变化，以轮廓随时间运动形成的包络确定边界。其几何意义与直接使用某一时刻的角度轮廓不同。

## 显示选项

在**选项**区域选择刈幅的显示方式。

| 选项 | 说明 |
| --- | --- |
| **不显示** | 不在二维视图中绘制刈幅图形。 |
| **显示边缘** | 绘制地面轨迹两侧的刈幅边界。 |
| **显示填充** | 显示刈幅边界之间的覆盖区域，以便直观查看刈幅范围。 |

## 设置方法

1. 在对象属性中打开 **二维视图 → 刈幅**。
2. 从下拉列表选择需要的刈幅类型。
3. 输入对应的角度或半幅宽数值。
4. 在**选项**区域选择不显示、显示边缘或显示填充。
5. 在二维视图中查看刈幅图形，并根据需要调整参数。
