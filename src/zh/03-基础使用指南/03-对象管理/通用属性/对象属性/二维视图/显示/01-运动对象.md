# 运动对象显示

运动对象显示属性用于设置飞机、卫星、火箭等对象的可见性、图形标识和运动轨迹的显示状态。各对象具有相同的基础显示参数，但轨迹选项和显示模式不完全一致。

颜色、标识类型、线型和线宽等共用参数参见[显示](../显示.md)。

## 轨迹显示选项

| 参数 | 说明 |
| --- | --- |
| 显示 | 启用或关闭该对象的整体图形显示。 |
| 显示标签 | 控制对象名称标签的显示。 |
| 显示二维地面轨迹 | 控制运动路径在中心天体表面上的二维地面轨迹显示。 |
| 显示三维地面轨迹 | 控制三维地面轨迹的显示，仅部分运动对象提供该选项。|
| 显示三维轨道 | 控制对象空间运动轨迹的显示。 |
| 保留轨迹 | 控制已绘制轨迹的保留显示，仅部分运动对象提供该选项；具体保留范围以软件显示行为为准。 |

## 飞机

飞机的 **二维视图 → 显示** 页面采用基础显示设置。

| 设置类别 | 可用选项 |
| --- | --- |
| 显示项目 | 显示、显示标签、显示二维地面轨迹、显示三维轨道、保留轨迹 |
| 图形样式 | 颜色、标识类型、线型、线宽 |

设置时，可根据需要显示飞机的二维地面轨迹和三维轨道。**保留轨迹**用于控制运动过程中已显示轨迹的保留效果。

## 卫星

卫星的 **二维视图 → 显示** 页面具有 **类型** 选项，包括 **基础** 和 **自定义** 两种模式。

### 基础

选择 **基础** 时，可直接设置下列显示项目：

| 设置类别 | 可用选项 |
| --- | --- |
| 显示项目 | 显示、显示标签、显示二维地面轨迹、显示三维地面轨迹、显示三维轨道 |
| 图形样式 | 颜色、标识类型、线型、线宽 |

### 自定义

选择 **自定义** 时，可使用时间区间表分别控制不同时段的显示状态、轨迹项目及图形样式，而不再只使用一套基础显示参数。

详细设置参见[自定义时段显示](./04-自定义时段显示.md)。

## 火箭

火箭的 **二维视图 → 显示** 页面提供以下设置：

| 设置类别 | 可用选项 |
| --- | --- |
| 显示项目 | 显示、显示标签、显示二维地面轨迹、显示三维地面轨迹、显示三维轨道、保留轨迹 |
| 图形样式 | 颜色、标识类型、线型、线宽 |

与飞机相比，火箭**增加了显示三维地面轨迹**，同时保留 **保留轨迹** 选项。用户可以分别控制二维地面轨迹、三维地面轨迹和三维轨道的显示。

## 设置说明

1. 打开运动对象属性，进入 **二维视图 → 显示**。
2. 对卫星，先选择 **基础** 或 **自定义** 类型；其他对象按实际界面设置。
3. 勾选 **显示**，再选择需要呈现的标签及轨迹项目。
4. 设置颜色、标识类型、线型和线宽。
5. 对使用自定义模式的卫星，按[自定义时段显示](./04-自定义时段显示.md)配置时间区间。
