# 区域对象显示

区域对象显示属性用于配置区域目标等对象在二维视图中的几何图形表现。与运动对象的轨迹显示不同，区域对象重点控制**中心点、边界点及区域填充**等内容。

通用图形参数参见[显示](../显示.md)。

## 显示选项

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制区域对象的整体图形显示。 |
| 显示标签 | 控制区域对象名称标签是否显示。 |
| 显示中心点 | 控制区域中心点标识的显示。中心点的具体位置由区域对象的几何定义确定。 |
| 显示边界点 | 控制构成区域边界的点位标识是否显示。 |
| 填充 | 控制区域内部是否以颜色填充。 |
| 透明度(%) | 设置区域填充的透明程度，可通过输入数值或滑块调整。仅在启用 **填充** 后可设置。 |

## 图形样式

| 参数 | 说明 |
| --- | --- |
| 颜色 | 设置区域相关图形的颜色。 |
| 线型 | 设置区域边界等线状图形的样式。 |
| 线宽 | 设置区域边界等线状图形的宽度。 |

## 设置说明

1. 打开区域目标对象属性，进入 **二维视图 → 显示**。
2. 勾选 **显示**，再选择是否显示标签、中心点和边界点。
3. 如需突出区域覆盖范围，勾选 **填充**，并调整 **透明度(%)**。
4. 根据需要设置颜色、线型和线宽。
