# 固定点对象显示

固定点对象显示属性用于设置地面站等位置固定的点状对象在二维视图中的图形可见性和标识样式。

通用图形参数参见[显示](../显示.md)。

## 地面站

地面站通过基本属性确定位置，**二维视图 → 显示** 负责配置图形呈现方式。

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制地面站对象图形是否显示。 |
| 显示标签 | 控制地面站名称标签的显示；以对象界面是否提供该选项为准。 |
| 颜色 | 设置地面站图形的显示颜色。 |
| 标识类型 | 当界面提供该选项时，选择表示地面站位置的图形符号。 |

## 设置说明

1. 进入地面站等固定点对象的 **二维视图 → 显示** 页面。
2. 根据需要勾选 **显示** 和 **显示标签** 等实际提供的项目。
3. 通过颜色和标识相关设置调整对象在地图上的外观。
4. 对未出现在当前界面中的线型、线宽等选项，无需进行额外设置。
