# 自定义时段显示

自定义时段显示用于按时间区间设置对象的显示状态、轨迹开关和图形样式。当前提供的 ATK 界面中，卫星的 **二维视图 → 显示 → 类型** 支持 **基础** 和 **自定义** 两种模式，本页说明其中的 **自定义** 模式。

运动对象的通用显示选项参见[运动对象显示](./01-运动对象.md)。

## 启用自定义模式

进入卫星对象的 **二维视图 → 显示** 页面，将 **类型** 设为 **自定义**。页面显示时间区间列表及其对应的显示属性，并提供 **添加、删除、删除全部** 操作。

## 时段与显示参数

| 参数 | 说明 |
| --- | --- |
| 默认属性 | 列表中的基础属性行，不指定具体开始与结束时间，用于呈现默认显示设置。 |
| 开始 | 自定义显示时段的开始时间。 |
| 结束 | 自定义显示时段的结束时间。 |
| 显示 | 控制该行对应时段内对象图形的显示状态。 |
| 颜色 | 设置该行对应时段的显示颜色。 |
| 二维地面轨迹 | 控制该时段二维地面轨迹的显示。 |
| 三维地面轨迹 | 控制该时段三维地面轨迹的显示。 |
| 轨道 | 控制该时段轨道图形的显示。 |
| 显示标签 | 控制该时段对象名称标签的显示。 |
| 线型 | 设置所选属性行对应的图形线型 |
| 线宽 | 设置所选属性行对应的图形线宽 |

## 时段管理

| 操作 | 说明 |
| --- | --- |
| 添加 | 新增一条自定义时间区间记录。 |
| 删除 | 删除当前选中的自定义时间区间记录。 |
| 删除全部 | 清除当前列表中可删除的自定义时间区间记录。 |

## 设置说明

1. 在卫星的 **二维视图 → 显示** 页面选择 **自定义** 类型。
2. 通过 **默认属性** 行查看并设置默认图形属性。
3. 点击 **添加**，建立需要单独设置的时间区间。
4. 为该区间配置 **开始**、**结束**、**显示**、颜色及相应的轨迹、标签选项。
5. 选中对应记录，在列表下方设置颜色、线型和线宽。
6. 需要移除时段时，选中记录后点击 **删除**；需要清空已添加的时段时使用 **删除全部**。
