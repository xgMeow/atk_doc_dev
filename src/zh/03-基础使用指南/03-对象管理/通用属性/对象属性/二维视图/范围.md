# 范围

范围属性用于在二维视图中按指定距离绘制对象的范围轮廓线，以不同距离分级表示对象周围的范围分布。用户可以设置轮廓线的显示状态、填充效果、分级距离及各分级的图形样式。

## 范围轮廓线

### 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制是否在二维视图中显示范围轮廓线。 |
| 填充 | 控制是否对范围轮廓线对应的区域进行填充显示。 |
| 半透明度（%） | 设置填充区域的透明程度，数值越大，填充效果越透明。该项在启用“填充”后可设置。 |

### 添加分级

通过**添加分级**设置需要显示的距离等级。支持以下两种添加方式：

| 添加方式 | 参数 | 说明 |
| --- | --- | --- |
| 指定 | 分级 | 输入一个距离值，点击添加后，将该距离加入分级属性列表。 |
| 起始、结束、步长 | 开始、结束、步长 | 设置距离分级的起始值、结束值与相邻分级的间隔，点击添加后批量生成距离分级。 |

### 分级属性

添加的距离分级显示在**分级属性**列表中，可以分别设置各级轮廓线的图形样式。

| 属性 | 说明 |
| --- | --- |
| 分级（km） | 当前范围轮廓线对应的距离等级。 |
| 颜色 | 设置该分级轮廓线的显示颜色。 |
| 线型 | 设置该分级轮廓线的线条样式。 |
| 线宽 | 设置该分级轮廓线的线条宽度。 |
| 显示标签 | 勾选是否显示该分级轮廓线的距离标签。 |

### 删除分级

| 操作 | 说明 |
| --- | --- |
| 删除 | 选中分级属性列表中的一项，删除该距离分级。 |
| 删除所有 | 清空分级属性列表中的全部距离分级。 |

## 设置方法

1. 在对象属性中打开**二维视图 → 范围**。
2. 勾选**显示**，启用范围轮廓线的二维显示。
3. 根据需要选择**指定**或**起始、结束、步长**，填写距离参数并点击添加。
4. 在**分级属性**列表中设置各级轮廓线的颜色、线型、线宽及标签显示。
5. 如需显示填充区域，勾选**填充**，并设置半透明度（%）。
6. 需要调整分级时，可删除指定分级或清空列表后重新添加。
