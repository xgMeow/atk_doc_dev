# 范围

范围属性用于在二维地图中绘制对象的指定距离轮廓。每个距离分级对应一条轮廓线，可通过不同颜色、线型和标签区分各级距离，便于查看对象周围的距离分布。

## 范围轮廓线

### 显示设置

| 参数 | 说明 |
| --- | --- |
| 显示 | 勾选后，根据已添加的距离分级绘制范围轮廓线；取消勾选后隐藏全部范围轮廓，已设置的分级仍保留。 |
| 填充 | 勾选后，对范围轮廓线对应的区域进行颜色填充；取消勾选后不显示填充区域，轮廓线仍可单独显示。 |
| 半透明度（%） | 启用填充后，可输入数值或拖动滑块调整填充区域的透明程度。取值为 0%～100%，0% 表示不透明，100% 表示完全透明；该设置不改变轮廓线的线条样式。 |

### 添加分级

通过**添加分级**区域选择分级的生成方式，填写参数后点击**添加**。两种方式如下：

| 添加方式 | 参数 | 说明 |
| --- | --- | --- |
| 指定 | 分级 | 输入单个距离值，每点击一次**添加**，向分级属性列表增加一个距离等级。 |
| 起始、结束、步长 | 开始、结束、步长 | 按设定的起止距离和步长批量生成等间隔距离等级，点击**添加**后批量生成距离分级。 |

### 分级属性

添加的距离分级显示在**分级属性**列表中，可以分别设置各级轮廓线的图形样式。

| 参数 | 说明 |
| --- | --- |
| 分级（km） | 显示当前轮廓线对应的距离等级。例如，`1` 表示 1 km 的范围轮廓。 |
| 颜色 | 点击颜色单元格，为当前距离等级选择颜色。 |
| 线型 | 设置当前分级轮廓线使用的线条样式。 |
| 线宽 | 设置当前分级轮廓线的绘制宽度。 |
| 显示标签 | 勾选后，在轮廓线上显示对应的距离分级标注；取消勾选仅隐藏该分级的标签，不隐藏轮廓线。 |

**删除**用于移除选中的距离分级；**删除所有**用于清空全部分级。

## 设置方法

1. 打开对象属性中的**二维视图 → 范围**，勾选**显示**。
2. 在**添加分级**区域选择**指定**或**起始、结束、步长**，输入距离值并点击**添加**。
3. 在**分级属性**列表中，为各距离等级设置颜色、线型、线宽；需要标注距离时，勾选对应行的**显示标签**。
4. 如需突出轮廓所覆盖的区域，勾选**填充**，并调整**半透明度（%）**。
5. 检查二维地图中的轮廓显示效果；需要修改分级时，可删除相应等级后重新添加。
