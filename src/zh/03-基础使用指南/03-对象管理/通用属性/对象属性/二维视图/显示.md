# 显示

显示属性用于控制对象的图形可见性、标签和显示样式。不同对象的图形特征及可用选项有所区别：运动对象可设置地面轨迹、空间轨迹等显示项目，固定点对象主要设置位置标识，区域对象则可设置边界点和区域填充。

## 通用显示参数

| 参数 | 说明 |
| --- | --- |
| 显示 | 控制对象图形的整体显示状态。取消勾选后，不显示该对象对应的图形元素。 |
| 显示标签 | 控制对象名称或标注信息是否显示。仅在提供此选项的对象中适用。 |
| 颜色 | 设置对象图形的显示颜色。 |
| 标识类型 | 选择表示对象位置的图形标识。仅在提供标识选择的对象中适用。 |
| 线型 | 设置轨迹、轮廓等线状图形的样式。 |
| 线宽 | 设置轨迹、轮廓等线状图形的宽度。 |

**说明：** 颜色、线型和线宽的具体作用对象随图形类型变化。例如，运动对象主要用于轨迹和标识，区域目标主要用于区域边界。没有对应图形元素或未提供相应选项的对象，无需设置该参数。

## 对象类型

| 类型 | 适用对象与说明 |
| --- | --- |
| [运动对象](./显示/01-运动对象.md) | 飞机、卫星、火箭等，支持二维地面轨迹、三维轨迹及对象特有显示选项。 |
| [固定点对象](./显示/02-固定点对象.md) | 地面站等位置固定的点状对象，主要设置对象标识及标签的显示。 |
| [区域对象](./显示/03-区域对象.md) | 区域目标等，支持中心点、边界点、区域填充及透明度设置。 |
| [自定义时段显示](./显示/04-自定义时段显示.md) | 用于支持自定义显示模式的对象；当前示例为卫星，可按时间区间设置显示状态及样式。 |

## 设置说明

进入相应对象的 **二维视图 → 显示** 页面，先根据需要启用 **显示**，再设置该对象提供的具体显示项目与图形样式。对具有显示模式选择的对象，应先选择模式，再进行相应设置。

该属性主要控制对象图形的呈现方式，**不改变对象的轨迹、位置、姿态数据或访问约束计算结果**。二维视图属性页中出现的三维相关选项，应按界面对应的图形类型理解，不能与运动轨迹的生成或传播计算混为一谈。
