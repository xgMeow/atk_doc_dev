# 显示

显示属性用于设置对象在场景中的图形可见性、名称标签、轨迹显示及外观样式。

## 显示内容

| 参数 | 说明 | 适用对象 |
| --- | --- | --- |
| 显示 | 对象图形的总开关。取消勾选后，隐藏该对象的标识、标签及已启用的轨迹图形；重新勾选后，按下方各显示选项绘制。 | 全部对象 |
| 显示标签 | 在对象标识附近显示名称。取消勾选仅隐藏名称。 | 全部对象 |
| 显示二维地面轨迹 | 显示运动轨迹在中心天体表面上的投影，用于查看对象经过的地面位置。 | 卫星、飞机、车辆、火箭、导弹、舰船、潜艇 |
| 显示三维地面轨迹 | 在三维场景中显示运动轨迹对应的地面路径。它与二维地面轨迹描述的是同类地面投影，不同于对象在空间中的运动轨道。 | 卫星、火箭、导弹 |
| 显示三维轨道 | 显示对象在空间中的实际运动轨迹，用于查看轨迹的空间形状及其相对于中心天体的位置。 | 卫星、飞机、车辆、火箭、导弹、舰船、潜艇 |
| 保留轨迹 | 动画推进时保留已经绘制的运动轨迹，便于观察对象经过的路径。 | 飞机、车辆、火箭、导弹、舰船、潜艇 |

## 图形样式

| 参数 | 说明 | 适用对象 |
| --- | --- | --- |
| 颜色 | 点击颜色区域选择显示颜色，用于区分场景中的不同对象及其相关轨迹。 | 全部对象 |
| 标识类型 | 从下拉列表选择对象的位置标识图案。 | 全部对象 |
| 线型 | 从下拉列表选择轨迹线条的样式，例如实线或其他可选线型。 | 卫星、飞机、车辆、火箭、导弹、舰船、潜艇 |
| 线宽 | 从下拉列表设置轨迹线条的绘制宽度，用于调整轨迹在视图中的清晰程度。 | 卫星、飞机、车辆、火箭、导弹、舰船、潜艇 |

地面站和卫星系统不提供轨迹显示、线型和线宽设置，主要通过**显示标签、颜色和标识类型**配置位置标识的外观。

## 设置方法

1. 打开对象属性中的**二维视图 → 显示**，勾选**显示**，启用该对象的图形显示。
2. 根据需要勾选**显示标签**和相应的地面轨迹、空间轨道选项。
3. 通过**颜色**和**标识类型**设置对象的外观；对于具有轨迹的对象，还可选择**线型**和**线宽**。
4. 对支持**保留轨迹**的对象，可启用该选项，观察动画运行过程中已经经过的运动路径。

## 卫星自定义时段显示

卫星在**二维视图 → 显示**中还提供**类型**选择：

- **基础**：整个显示时段采用同一组显示选项和图形样式，即本页所述的常规设置。
- **自定义**：按开始、结束时间划分显示区间，分别指定各区间的显示状态、轨迹选项和颜色等属性。

自定义模式的时间区间管理和参数设置参见[自定义时段显示](./显示/01-自定义时段显示.md)。
