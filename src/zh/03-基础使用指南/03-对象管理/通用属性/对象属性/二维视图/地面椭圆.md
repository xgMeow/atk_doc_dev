# 地面椭圆

## 功能说明

地面椭圆属性用于设置对象的地面椭圆在二维视图中的显示效果，包括名称、中心点、颜色、线型和线宽等。

## 参数说明

| 参数 | 说明 |
| --- | --- |
| 椭圆设置 | 显示已在基本属性中建立的椭圆集合。每行对应一个椭圆集合。 |
| 显示名称 | 勾选后，在二维视图中显示相应椭圆集合的名称。 |
| 显示中心点 | 勾选后，在二维视图中显示椭圆的中心点标记。 |
| 颜色 | 设置所选椭圆集合的显示颜色。 |
| 线型 | 设置椭圆轮廓线的样式。 |
| 线宽 | 设置椭圆轮廓线的宽度。 |

## 设置方法

1. 在对应对象的 **基本 → 地面椭圆** 中新建椭圆集合，并设置其椭圆数据。
2. 打开 **二维视图 → 地面椭圆**，在 **椭圆设置** 列表中找到已创建的椭圆集合。
3. 根据显示需求，勾选或取消勾选 **显示名称** 和 **显示中心点**。
4. 设置椭圆的 **颜色、线型、线宽**，调整二维视图中的轮廓显示效果。
5. 如存在多个椭圆集合，可分别配置各集合的显示属性。
