# 地面椭圆

地面椭圆属性用于设置已创建的地面椭圆在二维视图中的显示方式。椭圆的位置、尺寸等数据在**基本 → 地面椭圆中定义**。

## 椭圆显示设置

进入**二维视图 → 地面椭圆**后，**椭圆设置**列表列出基本属性中已创建的椭圆集合，如 `EllipseSet1`。选中一个集合，可单独修改其显示属性；不同集合的样式可以分别设置。

| 参数 | 说明 |
| --- | --- |
| 椭圆设置 | 列出已定义的椭圆集合。点击集合所在行，选择需要配置的对象。 |
| 显示名称 | 勾选后，在二维视图中标注所选椭圆集合的名称；取消勾选隐藏名称。 |
| 显示中心点 | 勾选后显示所选集合中椭圆的中心点标记；取消勾选隐藏中心点。 |
| 颜色 | 设置所选集合的椭圆轮廓颜色。 |
| 线型 | 设置所选集合的轮廓线样式。 |
| 线宽 | 设置所选集合的轮廓线宽度。 |

## 设置方法

1. 在对象的**基本 → 地面椭圆**中建立椭圆集合，填写椭圆数据。
2. 打开**二维视图 → 地面椭圆**，在**椭圆设置**列表中选中需要调整的集合。
3. 勾选**显示名称**或**显示中心点**，决定是否显示集合名称及椭圆中心点标记。
4. 通过**颜色、线型、线宽**设置该集合的轮廓样式。
5. 如有多个集合，依次选中其他集合分别设置，并在二维视图中查看显示效果。

**注意：** 若尚未在基本属性中建立地面椭圆集合，页面不会出现可供设置的集合。需要增加椭圆或修改其位置、尺寸时，应返回**基本 → 地面椭圆**进行编辑。
