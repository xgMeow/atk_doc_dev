# 网络浮动注册

网络浮动注册的注册码不与单台电脑绑定：注册码可供多台电脑共享，通过局域网动态分配使用权限，适用于同一局域网内多台电脑共用一套授权。

## 申请方式

网络浮动注册不支持自助申请，需直接联系官方办理，联系方式见[联系我们](../../../发布说明/联系我们.md)。

## 注册步骤

网络浮动注册通过部署 ATK 远程服务实现，由服务端持有注册码，局域网内的客户端动态获取使用权限：

1. **部署服务端**：在服务器上启动 ATK 服务端程序，首次启动时终端显示自动生成的机器码。

2. **申请注册码**：将服务端机器码提供给官方，获取注册码。

3. **完成服务端注册**：在服务端终端输入注册码，完成服务端注册。

4. **配置客户端**：局域网内各客户端在「ATK-注册」窗口选择【远程】，填写服务器 IP 与端口，点击 <kbd>注册</kbd>。

完整操作见[远程服务部署与配置](01-远程服务部署与配置.md)。

## 注意事项

- 客户端与服务端需处于同一局域网并相互可达；服务端口默认为 8090，可在服务端的 server_config.ini 中修改。

- 若服务端此前完成过本地注册，需先清理注册表残留配置，具体操作见[远程服务部署与配置](01-远程服务部署与配置.md)。

- 更换服务器或重装系统后机器码会变化，需重新申请注册码。
