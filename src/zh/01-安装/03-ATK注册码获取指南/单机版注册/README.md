# 单机版注册

单机版注册的注册码与申请时提交的机器码绑定，仅能用于该台电脑，适用于个人或单台电脑使用。

## 申请方式

单机版注册提供三种申请方式，任选其一即可：

| 申请方式 | 操作方式 | 注册码获取 |
| --- | --- | --- |
| [小程序自助申请](小程序申请.md) | 微信扫码进入小程序，填写机器码等信息后提交 | 提交后在小程序中即时查看 |
| [网页在线申请](网页在线申请.md) | 在 ATK 官网注册页面填写信息并提交 | 发送至所填邮箱 |
| [邮件申请](邮件申请.md) | 在注册界面打开 PDF 申请表，填写后发送邮件 | 回复至申请表所填邮箱 |

## 选择建议

- 可以使用微信：选择小程序自助申请，提交后即可在小程序中获得注册码，无需等待邮件回复。

- 不便使用微信，或需提交单位、团队信息：选择网页在线申请或邮件申请，注册码发送至邮箱。

## 激活

获取注册码后，在 ATK 注册机界面填入注册码并点击 <kbd>注册</kbd> 完成激活，三种申请方式的页面末尾均附有填写步骤。

::: tip 一台电脑一个注册码
注册码与机器码一一对应，多台电脑需分别为每台电脑申请。
:::
