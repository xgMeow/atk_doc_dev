# 网页在线申请

ATK 官方网站在线提供注册码申请入口，可在浏览器中直接填写并提交申请。

## 打开注册页面

访问 [ATK 生态社区](https://gitlink.org.cn/zone/atk/atksource)，在页面中找到 **下载注册** 页面。

![注册入口与申请流程](../media/网页在线申请/注册流程.png)

页面将申请流程分为四步：

1. **获取机器码**：运行 ATK 软件，在弹出的注册对话框中复制机器码。
2. **提交申请**：在表单中填写机器码与联系方式等信息后提交。
3. **获取注册码**：注册码将发送至所填邮箱。
4. **完成激活**：在软件内粘贴注册码，点击 **注册** 完成激活。

## 填写用户信息

表单提供 **单机版注册** 与 **网络浮动注册** 两个页签，本页介绍单机版注册。网络浮动注册需联系官方办理，详见[网络浮动注册](../网络浮动注册/README.md)。

![用户信息](../media/网页在线申请/用户信息.png)

用户信息中带 * 的为必填项：

- **姓名**、**团队/单位**：申请人姓名与所在单位全称。
- **联系方式**：手机号码或邮箱，用于审核过程中的沟通。
- **从何处了解到 ATK 软件**：按实际情况勾选学术会议、同行推荐、线下推广、视频平台或其他。

## 填写机器码与接收邮箱

在 **软件下载与注册** 区块填写机器码与接收注册码的邮箱。

![机器码与接收注册码的邮箱](../media/网页在线申请/机器码与注册邮箱.png)

- **机器码**：首次启动软件时，注册对话框中可直接复制机器码；ATK 版本号小于 v2.3 时，运行 Atkinput 文件夹下的 Register_2015.exe 获取。一份授权对应一台电脑，需为多台设备申请时点击 **添加机器码** 追加。
- **接收注册码的邮箱**：注册码将发送至该邮箱，请确认填写正确。

::: warning 重要提醒
请仔细核对机器码，**输入错误将导致注册码无法使用**。建议直接从注册对话框中复制粘贴。
:::

## 提交申请

点击 **提交** 后等待审核，注册码将发送至所填邮箱。收到注册码后，在软件内粘贴并点击 **注册** 完成激活。
