# ATK 注册码获取指南

ATK 采用 **免费使用模式**，首次使用需完成注册激活。注册按授权范围分为单机版注册与网络浮动注册两种方式：

- **单机版注册**：注册码与申请时提交的机器码绑定，仅该台电脑可用。可通过以下三种方式自助申请：

  - [小程序自助申请](单机版注册/小程序申请.md)
  - [网页在线申请](单机版注册/网页在线申请.md)
  - [邮件申请](单机版注册/邮件申请.md)

- **网络浮动注册**：注册码可供多台电脑共享，通过局域网动态分配使用权限，需联系官方申请，见[远程服务部署与配置](网络浮动注册/01-远程服务部署与配置.md)。

注册前请先阅读[使用须知](01-使用须知.md)，其中说明了注册机界面、机器码，以及两种注册方式的适用范围与激活位置。
