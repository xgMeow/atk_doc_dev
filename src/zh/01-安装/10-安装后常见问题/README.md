# 安装后常见问题

安装完成后遇到的启动、注册与显示问题，按遇到的现象选择对应文档：

- [提示 OpenGL 版本过低](提示OpenGL版本过低.md) — 启动即闪退、无法进入主界面，或二三维视图打不开并提示 OpenGL 版本过低
- [软件未弹出注册界面](软件未弹出注册界面.md) — 软件能够启动，但没有弹出注册激活窗口
- [高分屏显示异常](高分屏显示异常.md) — 界面文字与图标模糊、按钮重叠或窗口比例异常

以上方法均未解决问题时，可[直接联系我们](../03-ATK注册码获取指南/05-直接联系我们.md)获取技术支持。
