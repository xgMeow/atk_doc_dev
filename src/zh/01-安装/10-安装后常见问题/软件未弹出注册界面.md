# 软件未弹出注册界面

首次使用 ATK 需完成注册激活。若软件启动后未弹出注册界面，请依次检查：

## 关闭 Defender 实时保护（Windows 11）

Windows 11 自带的 Microsoft Defender 实时保护可能误删 ATK 运行所需的某个动态库，导致程序报错。请在注册前临时关闭，注册完成后再按需开启。

若文件已被隔离或删除，按下列顺序处理，避免还原后再次被删：

1. 在 Windows 安全中心 → 病毒和威胁防护 → 管理设置 → 排除项中，将 ATK 安装目录添加为排除项；
2. 在 Windows 安全中心 → 病毒和威胁防护 → 保护历史记录中找到与 ATK 相关的项目，展开后选择 <kbd>还原</kbd>；
3. 保护历史记录中没有对应项目或无法还原时，重新解压绿色版压缩包补回缺失文件；通过 deb 包安装的，重新安装 deb 包。

处理完成后重新启动 ATK，确认注册界面正常弹出。

## 以管理员身份运行

请右键点击 ATK.exe，选择 <kbd>以管理员身份运行</kbd>。若不以管理员权限启动，程序可能无法正常写入所需文件，注册流程可能失败。

## 检查安全策略与执行权限

- 检查软件是否被防火墙、安全软件（Windows）或系统安全策略（麒麟系统）拦截
- 麒麟系统：确认已正确执行 `chmod +x` 赋予可执行权限
