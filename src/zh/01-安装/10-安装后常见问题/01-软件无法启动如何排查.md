# 软件无法启动如何排查

本文档介绍 ATK 软件无法启动时的常见排查方法。请根据您遇到的具体现象，快速定位对应解决办法。

## 现象一：软件未弹出注册界面

首次使用 ATK 需完成注册激活。若软件启动后未弹出注册界面，请依次检查：

### 1. 关闭 Defender 实时保护（Windows 11）

Windows 11 自带的 Microsoft Defender 实时保护可能误删 ATK 运行所需的某个动态库，导致程序报错。请在注册前临时关闭，完成后再按需开启。

### 2. 以管理员身份运行

请右键点击 `ATK.exe`，选择"以管理员身份运行"。若不以管理员权限启动，程序可能无法正常写入所需文件，注册流程可能失败。

### 3. 检查安全策略与执行权限

- 检查软件是否被防火墙或安全软件（Windows）或系统安全策略（麒麟系统）拦截
- 麒麟系统：确认已正确执行 `chmod +x` 赋予可执行权限

## 现象二：打开软件后立即闪退，无法进入界面

这种情况很大概率是因为**显卡驱动不匹配**导致的。系统默认提供的 OpenGL 版本较低，无法支持二维、三维视图打开所需的库版本。

### 第一步：验证是否为显卡驱动问题

1. 找到 ATK 安装目录下的配置文件 `systemConfig.ini`：

   - **Windows 系统**：

     ```
     ATK-v4.0.0-windows-x64\ATK-4.0.0\config\systemConfig.ini
     ```

   - **麒麟系统**：

     ```
     /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
     ```

   ::: warning 路径注意
   实际路径可能因版本号及操作系统不同而有所变化，请根据您的安装版本调整。
   :::

2. 使用文本编辑器打开该文件：

   - Windows：可用记事本等文本编辑器打开；
   - 麒麟系统：可使用 `vim` 等文本编辑器，例如：

     ```bash
     sudo vim /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
     ```

3. 找到 `[OPEN SETTING]` 段落，将 `Open3D=true` 改为 `Open3D=false`：

   ```ini
   [OPEN SETTING]
   Open3D=false
   ```

4. 保存文件后重新启动 ATK。

::: tip 验证结论
若软件可以正常打开，则证明故障原因为**显卡驱动问题**，请继续执行第二步。
:::

### 第二步：更新显卡驱动

- **Windows 系统**：
  - NVIDIA 显卡：访问 [NVIDIA 官网](https://www.nvidia.cn/drivers/) 下载对应型号驱动
  - 其他显卡：前往显卡厂商官网获取最新驱动
- **麒麟系统**：
  - 可通过**系统设置 → 显示 → 显卡驱动**检查更新
  - 或访问显卡厂商官网（如 NVIDIA、AMD、Intel）下载 Linux 版驱动
  - 也可使用系统包管理器更新：`sudo apt update && sudo apt upgrade`

此问题十分常见，更新驱动后通常可解决。
