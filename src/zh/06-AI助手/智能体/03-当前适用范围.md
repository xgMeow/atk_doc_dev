# 当前适用范围

ATK 智能体 v1.0 支持轨道设计、可见性分析、星座与集群等 ATK v4.2.0 发布功能。智能体封装了 ATK Connect 底层命令语法的复杂细节，用户无需记忆命令格式与参数单位，即可通过对话式交互完成对象创建、轨道构型设计以及可见性与覆盖性等专业分析计算。

当前共提供 16 个分类、169 个工具，分类与数量如下。

| 分类 | 工具数量 |
|------|----------|
| 场景 | 32 |
| 卫星 | 53 |
| 传感器 | 7 |
| 地面站 | 3 |
| 恒星 | 2 |
| 链路接收器 | 4 |
| 信号发射器 | 4 |
| 飞机、船、车辆 | 3 |
| 覆盖定义 | 3 |
| 卫星集群 | 7 |
| 火箭 | 1 |
| 导弹 | 2 |
| 高级接近分析 | 2 |
| 行星 | 2 |
| 工具 | 16 |
| 机动规划 | 28 |
| 合计 | 169 |

## 场景

场景级工具用于新建与保存场景、批量创建与删除对象、重命名、设置分析时间周期、控制仿真状态，以及报告与二维、三维窗口的管理。

| 工具 | 功能 |
|------|------|
| create_scenario | 新建场景 |
| batch_create_objects | 通用创建对象工具，可创建对象或子对象，支持批量创建 |
| check_objects | 在当前场景识别所有对象路径，返回值为字符串，场景或对象之间用空格分隔 |
| delete_object | 删除一个或多个对象，用于删除部分对象的场景 |
| delete_scenario | 删除当前场景中的所有对象，即清空场景 |
| rename | 批量对象重命名，支持同时为多个对象设置新名称 |
| set_analysis_time_period | 设置分析时间周期 |
| animate | 设置场景仿真状态，包括播放、暂停、重置、单步、仿真模式、步长、倍速、实时偏移与当前时间 |
| set_animation | 操控仿真状态，包括当前时间、仿真模式、步长与实时倍率 |
| get_animation_data | 获取场景基本属性，包括时间周期、当前仿真时间与仿真步长 |
| save_scene | 保存当前场景 |
| load_scenario | 打开一个已存在的场景。已打开其他场景时不能加载，需先关闭当前场景 |
| save_as | 另存为场景或对象 |
| copy_object | 拷贝并粘贴对象到应用路径下 |
| does_obj_exist | 判断对象是否存在 |
| unload_multi | 从当前场景移除一个或多个对象及其子对象 |
| unload_sub_obj | 删除当前场景的所有对象（清空场景，场景本身保留），用于删除全部对象的场景 |
| get_directory | 返回所选目录的路径 |
| get_atk_version | 获得 ATK 版本信息 |
| units_set_connect | 设置 Connect 模式单位属性 |
| window_2d | 创建、移除二维窗口 |
| window_3d | 创建、移除三维窗口 |
| window_3d_info | 返回三维窗口信息 |
| set_object_show | 批量设置对象在窗口中的显示或隐藏，支持卫星、飞机、船 |
| vo_central_body | 设置三维中心天体或坐标系视点 |
| report_create | 创建报告，支持显示、保存与导出 |
| report_rm | 获得指定报告类型的数据，是读取分析结果的主要工具 |
| quick_report_create | 快捷报告创建 |
| quick_report_add | 添加快捷报告 |
| quick_report_rm | 获得快捷报告数据或列表 |
| exec_report_create | 创建报告并执行 |
| exec_report_rm | 获得指定报告类型的数据 |
