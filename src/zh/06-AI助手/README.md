## 场景生成智能体

用自然语言操控 ATK，无需编写代码或记忆命令格式。智能体支持自然语言文本、语音、图片、Excel 表格与 Word 文档等多种输入方式，将需求实时解析为底层 Connect 命令并执行，覆盖从对象创建、参数赋值到仿真推演与数据后处理的全流程。

当前提供 16 个分类、169 个工具，支持轨道设计、可见性分析、星座与集群等 ATK v4.2.0 发布功能。

- **对象与场景**：批量创建卫星、地面站、飞机、导弹、天体、星座等对象，支持重命名、删除与场景时段设置
- **轨道与航迹**：轨道向导、经典轨道根数、位置速度、星历导入、机动规划，以及导弹弹道、航线与星座构型
- **载荷与链路**：传感器指向与投影、地面站参数、通信收发链路配置
- **仿真与分析**：仿真状态控制、二维与三维显示调节，以及可见性与覆盖性等专业计算

## 知识问答助手

基于检索增强生成（RAG）技术的智能问答系统，整合三大知识库自动匹配回答：

| 知识库 | 数据来源 | 举例 |
|--------|----------|------|
| ATK 知识库 | 官方手册 | "如何注册 ATK？" |
| 论文知识库 | Article/ 目录中的学术论文 | "交会对接有哪些常用算法？" |
| 用户文档库 | 您上传的 PDF/DOCX/MD/TXT | "我的文档里关于轨道计算讲了什么？" |

支持本地 Ollama 部署和云端 API 调用两种模型方案，数据不出本地的同时兼顾灵活扩展。
