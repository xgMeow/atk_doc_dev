---

知识问答需要配置问答模型与嵌入模型。问答模型在主界面的「主模型」栏填写，支持兼容 OpenAI API 规范的服务，可调用云端 API，也可指向本地 Ollama；嵌入模型在「知识库嵌入模型」栏填写，由 Embedding 模式决定调用方式。

| Embedding 模式 | 需要填写的内容 |
|----------------|----------------|
| API | API Key、Base URL、模型名称 |
| 本地 Ollama | 模型名称、Base URL |

填写完成后点击「测试连接」，连接通过后再保存配置。

- [本地模型配置](./本地模型配置.md)：通过 Ollama 在本地运行，数据不外传，需下载模型文件
- [API 模型配置](./API模型配置.md)：调用云端服务，无需本地 GPU，按量付费
