# 快速入门

ATK 知识问答是一款基于 ATK 的面向航天领域的知识问答助手。

## 产品概述

基于检索增强生成技术（RAG）的智能问答系统，拥有三大知识库：

| 知识库 | 数据来源 | 适用问题举例 |
|--------|----------|-------------|
| ATK 知识库 | ATK 软件官方手册 | "ATK 如何注册？"、"怎样创建卫星场景？" |
| 用户文档库 | 您上传的 PDF/DOCX/MD/TXT | "我的文档里关于轨道计算讲了什么？" |
| 论文知识库 | Article/ 目录中的学术论文 | "交会对接有哪些常用算法？" |

系统会自动判断您的问题属于哪个知识库，也可以手动指定。

## 环境要求

### 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|---------|---------|
| CPU | 4 核 | 8 核或以上 |
| 内存 | 8 GB | 16 GB 或以上 |
| 磁盘空间 | 5 GB 可用 | 10 GB SSD |
| 操作系统 | Windows 10 64 位 | Windows 11 64 位 |

### 运行环境

- **ATK 桌面软件**：需已安装 ATK

大语言模型支持两种部署方式：

- **本地部署（推荐）**：安装 Ollama 或 LM Studio，模型运行在本地，数据不外传
- **API 远程调用**：需有可用的 API Key（如 DeepSeek、OpenAI），按量付费，无需本地 GPU

## 首次配置

首次启动时，系统会要求配置模型参数。知识问答需要配置两个模型：

- **嵌入模型**：用于生成向量库，存储文档知识
- **问答模型**：用于理解问题并生成回答

如果未配置好这两个模型，知识问答功能将无法执行。模型配置的详细步骤请参阅 [模型配置](./02-模型配置/README.md)，支持本地 Ollama 部署和 API 远程调用两种方式。

### 其他参数

参数设置中还有两个可调参数：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 检索数量 (retrieval_k) | 每次检索返回的文档块数 | 3 ~ 5（默认 5） |
| 温度 (temperature) | 生成随机性，越低越确定 | 0.3 ~ 0.5（默认 0.3） |

配置完成后，即可开始使用知识问答功能。接下来可以了解如何 [管理文档](./03-文档管理.md) 和 [管理会话](./04-会话管理.md)。
