# 通信链路性能指标

通信路径的建立与通信性能评价是两个不同层面的问题。**链路对象**用于组织对象间的连接关系并判断完整路径的访问时段；**通信性能分析**则进一步评价信号在发射、传播和接收过程中的功率、噪声与误码性能。

## 主要指标

| 环节 | 指标 | 含义 |
| --- | --- | --- |
| 发射 | $EIRP$ | 等效全向辐射功率，综合反映发射功率和发射天线增益。 |
| 传播 | $L_{\mathrm{FS}}$ | 自由空间传播损耗，与信号频率和传播距离有关。 |
| 传播 | $L_{\mathrm{RF}}$ | 大气吸收、降雨及其他传播环境引起的附加损耗。 |
| 接收 | $P_r$ | 到达接收端的信号功率，由发射条件、传播损耗和接收增益共同决定。 |
| 接收 | $G/T$ | 接收天线增益与系统噪声温度的比值，用于表征接收系统性能。 |
| 信号质量 | $C/N_0$ | 载波功率与噪声功率谱密度之比。 |
| 信号质量 | $C/N$ | 指定接收带宽内的载噪比。 |
| 信号质量 | $E_b/N_0$ | 每比特能量与噪声功率谱密度之比。 |
| 误码性能 | $BER$ | 接收数据中的误码比例，与调制编码方式及链路信噪条件有关。 |

上述指标之间并非简单的顺序替代关系。例如，$G/T$ 是接收系统性能参数，$C/N_0$ 则由发射条件、传播损耗和接收系统噪声特性共同决定。$C/N$ 与 $E_b/N_0$ 还分别与接收带宽和信息速率有关。

## 与链路对象的关系

链路中依次配置发射端、接收端和中继对象，可以表示需要分析的信号传递路径。**对象连接顺序并不代替通信设备参数或链路预算设置。** 对发射功率、天线增益、传播损耗及接收性能的计算，应在相应通信模型中完成。

多段通信路径还需要分别评价各段通信性能；即使所有相邻对象在同一时刻可访问，也不能仅据此推断端到端通信性能满足要求。
