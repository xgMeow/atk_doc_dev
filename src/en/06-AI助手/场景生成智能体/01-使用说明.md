# Usage Guide

The ATK Scenario Generation Agent is a **natural-language-driven assistant** based on large language models (LLMs), designed to lower the barrier to operating aerospace simulation systems. Acting as the front-end interaction layer of the ATK software, the agent parses the user's natural language instructions into underlying Connect secondary development commands in real time and executes them automatically, enabling code-free construction and control of simulation scenarios.

Users only need to describe the task goal (such as orbit type, payload parameters, or simulation time period), and the agent automatically completes the entire workflow, including object creation, parameter assignment, simulation, and data post-processing.

## Model Integration and Configuration

Before use, you need to complete the LLM API configuration in the **Agent Settings** panel. The system supports any model service compatible with the OpenAI API standard.

| Configuration Item | Description |
|--------|------|
| API Model Name | Specifies the model to call (e.g., DeepSeek-R1, Qwen-Max, GLM-4, etc.) |
| Base URL | The endpoint address of the model service |
| API Key | The authentication key for the interface |

## Current Scope of Application

The agent supports creating and managing various scenario objects, and provides end-to-end capabilities such as orbit settings, payload configuration, simulation control, and professional analysis.

**Scenario Object Management**

- Supports creating satellites, ground stations, aircraft, missiles, celestial bodies, satellite constellations, and more
- Supports configuring sub-objects for satellites, such as sensors and communication transmitter/receiver devices
- Supports basic management such as renaming and deleting objects, and setting the scenario time period

**Orbit and Trajectory Settings**

- Satellite orbits support five setting methods: orbit wizard, classical orbital elements, position and velocity, ephemeris file import, and maneuver planning, covering various orbit types and high-precision simulation needs
- Can quickly generate missile trajectories, plan aircraft/ship routes, and batch-create stars and constellation configurations

**Payload and Link Configuration**

- Fine-grained configuration of multiple sensor pointing modes, ground station parameters, and complete communication link parameters
- Supports automatic engineering unit conversion

**Simulation Control and Data Analysis**

- Full simulation control capabilities and 3D visualization display adjustment
- Can perform professional simulation computations such as coverage analysis and access analysis

## Notes

- **Express naturally**:
  No need to memorize any command format — just describe your needs in everyday language.

  ::: tip Example
  "Create 10 satellites", "Set the simulation time from January 1, 2026 to January 7, 2026"
  :::

- **Chinese object names are not supported yet**:
  The agent is implemented based on Connect secondary development commands, which currently do not support Chinese encoding.

  ::: warning Note
  Do not create objects with Chinese names, and do not perform operations in scenarios that contain objects with Chinese names.
  :::

- **Reset the simulation state after creation**:
  After creating objects, send the following command to the agent so the new content can be displayed correctly in the 2D and 3D views:

  ```text
  Reset the scenario simulation state
  ```

- **Features are still being improved**:
  The commands currently supported by the agent are not yet complete, and some operations may not take effect. This will be gradually enhanced with version iterations and the expansion of the Connect command library.
