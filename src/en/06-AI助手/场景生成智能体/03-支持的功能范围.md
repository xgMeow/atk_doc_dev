# Supported Capabilities

ATK Agent v1.0 supports the features released in ATK v4.2.0, including orbit design, access analysis, constellations, and clusters. The agent encapsulates the syntax details and parameter units of the underlying ATK Connect commands, so the user does not need to memorize command formats: describing the requirement in natural language is enough to create objects, design orbit configurations, and perform professional analyses such as access and coverage computation.

This version provides 16 categories and 169 tools in total, divided by object and function into scenario, satellite, sensor, facility, star, receiver, transmitter, aircraft/ship/GroundVehicle, CoverageDefinition, SatelliteCollection, LaunchVehicle, missile, AdvCat, planet, tools, and maneuver planning; the capabilities cover the following areas.

## Scenario and Object Management

- Create, save, save as, and open scenarios, and set the analysis time period; another scenario cannot be loaded while one is open, so the current scenario must be closed first
- Create satellites, facilities, aircraft, ships, GroundVehicles, missiles, LaunchVehicles, stars, planets, and SatelliteCollections in batches, along with child objects such as sensors, receivers, and transmitters
- Rename, copy, and delete objects; check whether an object exists and query object paths in the current scenario; return the selected directory path and the ATK version information
- Create and remove 2D and 3D windows, show or hide objects in the windows in batches, and set the 3D central body and the coordinate-system viewpoint

## Orbits and Routes

- Orbit definition: orbit wizard (11 types, including Circular, SunSynchronous, Molniya, and OrbitDesigner), classical orbital elements, position and velocity, spherical coordinates, two-line TLE and TLE files, and ephemeris file import
- Propagator settings: the force model, atmospheric drag, applied force model, and integration algorithm of HPOP, plus the TwoBody, J2, J4, LOP, SGP4, and Realtime propagators; batch setting is supported, and each satellite can be configured with its own orbital elements
- Satellite attributes: mass and moments of inertia, reference spacecraft, and the orbit-revolution partitioning method
- Routes and trajectories: routes and waypoints for aircraft, ships, and GroundVehicles; missile trajectories and ballistic parameters; simple vertical ascent for LaunchVehicles
- Satellite clusters: Walker parameter configuration and creation of the Walker Delta, WalkerCustom, Rosette, Flower, and AsymmetricFlower configurations; a configuration can be created from a seed satellite or independently from given orbital elements

## Payloads and Links

- Sensors: batch definition of type and parameters, pointing type, fill display, spatial projection, and pulse
- Facilities: position (Cartesian and geodetic coordinates) and label display
- Links: creation of receivers and transmitters, reading and writing of any official attribute, and constraint settings
- Constraints: set access constraints for objects such as satellites, facilities, and planets

## Attitude and Display

- Attitude: add attitude data as Euler angles or quaternions, set the attitude generation method and the standard mode, and receive real-time attitude from a client
- 2D display: number of trajectory points, trajectory duration, and display switches; colors of object labels and trajectory labels
- 3D display: model file and model display, model points, logarithmic scaling, model offset, attitude sphere, and relative trajectory reference frame

## Simulation Control

- Play, pause, reset, and single-step, plus settings for the simulation mode, step size, speed multiplier, real-time offset, and current time
- Read the scenario time period, the current simulation time, and the simulation step size

## Professional Analysis

- Access: access computation between two objects, AER line-of-sight parameter reports, access reports for a single object, and source and target configuration plus time-interval settings for batch access computation
- Coverage: the grid of a CoverageDefinition (area of interest, point granularity, point altitude), display attributes and point size, definition of assets and figures of merit, time-interval settings, single-object and batch coverage computation, and reading of figures of merit and coverage reports
- Reports: creating, displaying, saving, and exporting reports and quick reports, and reading data of a specified report type
- AdvCat: parameter settings, conjunction event computation, and target radius from an SSC file
- Vector Geometry: defining, modifying, and deleting points, and displaying vectors and coordinate systems in the 3D view

## Maneuver Planning

- Set the satellite propagator to Maneuver Planning, and insert, delete, and copy segments in the mission control sequence or a sub-sequence
- Segment configuration: Initial State Segment, Propagate Segment, Maneuver Segment, Hold Segment, Follow Segment, Lambert Segment, Sequence and Backward Sequence Segments, Stop Segment, Target Sequence Segment, RPO Segment, Return Segment, and Update Segment
- Target sequence: select design variables, configure target variables and constraints, configure and apply differential correction, reset the correction and all target sequence configurations, and read segment attribute values, control variable values, and constraint values
- Run the mission control sequence

## Relationship to Connect Commands

The tools invoked by the agent are built on ATK Connect commands and encapsulate them: one tool may correspond to a single command or to a combination of several commands, so tool names and command names do not correspond one to one, and the granularity of the tools differs from that of the command library. For the syntax, parameters, and examples of Connect commands, see [Commands by Function](../../二次开发教程/2-二次开发CONNECT模式/2-命令参考/5-Connect功能索引/README.md) and [Commands by Object](../../二次开发教程/2-二次开发CONNECT模式/2-命令参考/4-Connect对象命令库/README.md).

This version does not provide tools related to deviation analysis; such computations must be performed through Connect commands or the graphical interface.

The scope described in this section applies to the current version; capabilities that are not listed are not thereby supported, and capability changes in later versions are described in the product manual. For how typical requirements are expressed, see [Usage Examples](./04-使用示例.md).
