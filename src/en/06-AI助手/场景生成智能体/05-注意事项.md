# Notes

The following are the prerequisites that must be met and the risks that must be avoided when using the agent. If a prerequisite is not met or a risk is ignored, instructions may fail to be delivered, operations may not take effect, and results may not match expectations.

## Prerequisites

- No conversation is possible until the primary model is configured, so the primary model must be configured in settings first; for the configuration procedure, see [Quick Start](./01-快速入门.md)
- The agent operates the local ATK through Connect commands, so ATK must be started before use. When several ATK instances run at the same time, instructions may fail to be delivered or may be sent to an unintended instance
- Object names may contain only English letters, digits, and underscores. Connect commands do not support Chinese encoding; a Chinese name may prevent the object from being identified correctly, and the related operations then fail

## Operating Cautions

- After the agent creates an object, the 2D and 3D views do not display the new object immediately; the "reset scenario simulation state" instruction must be sent or the **Refresh Scenario** button clicked. This operation corresponds to the Connect command Animate Reset; see [Interface and Basic Operations](./02-界面与基本操作.md)
- Operations such as deleting objects and clearing routes first show confirmation buttons and are performed only after **Confirm Delete** is clicked; before confirming, check the object scope listed in the message
- Feedback automatically includes the chat history of the current conversation, so before submitting it the feedback content and attachments must be checked to contain no sensitive information

## Capability Limits

- The supported requirement scope is defined by [Supported Capabilities](./03-支持的功能范围.md); requirements outside that scope may not take effect. If a requirement is not executed, describe it again step by step, or accomplish it with Connect commands; for command usage, see [Commands by Function](../../二次开发教程/2-二次开发CONNECT模式/2-命令参考/5-Connect功能索引/README.md)
- When a requirement can be implemented in several ways, the agent presents the available options and confirms the orbit parameters, then executes according to the confirmed result. At the confirmation step, key inputs such as orbital elements and times must be checked
- The currently supported features are not yet complete; later versions will be improved progressively as Connect commands are extended
