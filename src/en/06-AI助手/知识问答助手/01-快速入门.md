# Quick Start

ATK Q&A is an ATK-based knowledge Q&A assistant for the aerospace field.

## Product Overview

An intelligent Q&A system built on Retrieval-Augmented Generation (RAG) technology with three knowledge bases:

| Knowledge Base | Data Source | Example Questions |
|--------|----------|-------------|
| ATK Knowledge Base | ATK software official manual | "How do I register ATK?", "How do I create a satellite scenario?" |
| User Document Library | Your uploaded PDF/DOCX/MD/TXT | "What does my document say about orbit calculation?" |
| Paper Knowledge Base | Academic papers in the Article/ directory | "What are the common algorithms for rendezvous and docking?" |

The system automatically determines which knowledge base your question belongs to; you can also specify it manually.

## Environment Requirements

### Hardware Requirements

| Item | Minimum | Recommended |
|------|---------|---------|
| CPU | 4 cores | 8 cores or more |
| Memory | 8 GB | 16 GB or more |
| Disk space | 5 GB available | 10 GB SSD |
| Operating system | Windows 10 64-bit | Windows 11 64-bit |

### Runtime Environment

- **ATK desktop software**: ATK must be installed

The large language model supports two deployment methods:

- **Local deployment (recommended)**: install Ollama or LM Studio; the model runs locally and data stays on-premises
- **Remote API calls**: requires a valid API key (e.g., DeepSeek, OpenAI), billed by usage, no local GPU required

## First-Time Configuration

On first launch, the system will ask you to configure model parameters. The Q&A feature requires two models:

- **Embedding model**: generates the vector store that holds document knowledge
- **Q&A model**: understands questions and generates answers

If these two models are not configured, the Q&A feature will not work. For detailed model configuration steps, see [Model Configuration](./02-模型配置/README.md), which supports both local Ollama deployment and remote API calls.

### Other Parameters

There are two more adjustable parameters in the settings:

| Parameter | Description | Recommended Value |
|------|------|--------|
| Retrieval K (retrieval_k) | Number of document chunks returned per retrieval | 3 ~ 5 (default 5) |
| Temperature (temperature) | Generation randomness; lower is more deterministic | 0.3 ~ 0.5 (default 0.3) |

Once configured, you can start using the Q&A feature. Next, learn how to [manage documents](./03-文档管理.md) and [manage conversations](./04-会话管理.md).
