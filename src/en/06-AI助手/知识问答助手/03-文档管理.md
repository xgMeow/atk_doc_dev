# Document Management

The Q&A Assistant supports uploading your own documents to the user knowledge base. The system automatically parses the document content and uses it to answer related questions.

## Uploading Documents

### Uploading via the Sidebar

1. Click the <kbd>+ Add Knowledge Base</kbd> button in the sidebar
2. Select one or more files in the **File Selection** dialog
3. Wait for the upload to complete

### Uploading via the Input Panel

1. Click the <kbd>📎 Files</kbd> button to the left of the input box
2. Select the files
3. They are automatically uploaded and added to the knowledge base

## Upload Limits

| Item | Limit |
|------|------|
| File size | Max 20 MB per file |
| Supported formats | PDF, DOCX, MD, TXT |
| Upload quantity | Multiple files can be selected at once; no quantity limit |

## Notes

- Uploaded documents take effect **immediately**; no restart is needed
- Images in PDFs are automatically extracted and embedded in answers
- You can upload multiple times within the same conversation; documents are merged into the same user knowledge base
- After updating the Embedding model, the user document library may need to be rebuilt and **documents will be lost** — please back up in advance
