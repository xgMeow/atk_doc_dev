# Conversation Management

## Conversation Concept

Each conversation is an independent dialogue context that includes:

- All the Q&A history between you and the assistant in that conversation
- An independent memory space (up to 10 rounds of history)
- An independent conversation ID

## Conversation Operations

| Operation | Method | Description |
|------|------|------|
| New conversation | Click the <kbd>+</kbd> button above the conversation list | Automatically creates a new conversation and switches to it |
| Switch conversation | Click a conversation in the list | Automatically restores that conversation's history context |
| Rename | Right-click the conversation → Rename | Makes it easy to distinguish conversations on different topics |
| Delete | Right-click the conversation → Delete | Deletes the conversation and all of its history |

## History Memory

- Each conversation retains up to **10 rounds of Q&A** (one user question + one assistant answer = one round)
- When the limit is exceeded, the earliest history is automatically removed
- The assistant references the latest 5 rounds of history in the current conversation when answering
- If you want to clear the history and start over, you can include a clear command with your question
