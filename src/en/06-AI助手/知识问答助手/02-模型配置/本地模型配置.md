# Local Model Configuration

Local deployment uses [Ollama](https://ollama.com/) to run models locally. The workflow for the Q&A model and the embedding model is the same: first install Ollama, then download the corresponding model, and finally fill in the configuration in **Parameter Settings**.

## Installing Ollama

Visit the [Ollama official website](https://ollama.com/) to download and install Ollama.

![Ollama official website](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-website.png)

## Q&A Model

Using DeepSeek-R1 as an example.

### Downloading the Model

Search for the required model in the [Ollama](https://ollama.com/) model library and click the model to see the download command.

![Model selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-model-select.png)

![Model download command](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-model-command.png)

Use <kbd>Win + R</kbd> to open the Run dialog, paste the command, and press Enter to start the download. For example, to download deepseek-r1:

```bash
ollama run deepseek-r1
```

![Download process](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-download-process.png)

::: tip Choosing a Different Parameter Size
When downloading, you can append a tag to the model name to select the parameter size, for example ollama run deepseek-r1:8b.

![Parameter size selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-param-size.png)
:::

### Filling in the Model Configuration

Fill in the following in the main model section of **Parameter Settings**:

| Configuration Item | Value |
|--------|------|
| Base URL | http://localhost:11434/v1 |
| Model Name | Name of the downloaded model, for example deepseek-r1:8b |
| API Key | The local service requires no authentication; this field can be left blank |

## Embedding Model

Using Qwen3-Embedding as an example.

### Downloading the Model

Search for an embedding model in the [Ollama](https://ollama.com/) model library, for example qwen3-embedding; the download method is the same as for the Q&A model.

![Embedding model selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-embedding-select.png)

![Embedding model download](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/embedding-download.png)

Run the download command on the command line:

```bash
ollama pull qwen3-embedding
```

![Embedding model download process](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/embedding-download-process.png)

### Filling in the Model Configuration

Fill in the following in the knowledge base embedding model section of **Parameter Settings**:

| Configuration Item | Value |
|--------|------|
| Embedding Mode | Local Ollama |
| Model Name | Name of the downloaded model, for example qwen3-embedding:4b |
| Base URL | http://localhost:11434 |

After filling in the fields, click **Test Connection**; save the configuration once the connection succeeds.

![Local embedding model configuration](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/local-embedding-ollama.png)
