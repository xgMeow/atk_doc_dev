# Local Model Configuration

Local deployment uses [Ollama](https://ollama.com/) to run models locally. The workflow for the large language model and the embedding model is the same: first install Ollama, then download the corresponding model, and finally fill in the configuration in ATK.

## Large Language Model Configuration

Using **DeepSeek-R1** as an example.

### Installing Ollama

Visit the [Ollama official website](https://ollama.com/) to download and install Ollama.

![Ollama official website](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-website.png)

### Downloading the Model

Search for the desired model on the [Ollama](https://ollama.com/) interface and click the model to see the download command.

![Model Selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-model-select.png)

![Model Download Command](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-model-command.png)

Use <kbd>Win + R</kbd> to open a command window, paste the command, and press Enter to start downloading. For example, to download `deepseek-r1`:

```bash
ollama run deepseek-r1
```

![Download Process](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-download-process.png)

::: tip Choosing a Different Parameter Size
To download the 7B version, replace the command with `ollama run deepseek-r1:8b`.

![Parameter Size Selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-param-size.png)
:::

### Filling in the Model Configuration

In the ATK model configuration interface:

- **Local model Name**: enter the downloaded model name, e.g., `deepseek-r1:7b`
- **Base URL**: enter `http://localhost:11434`

![Local LLM Configuration](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/local-llm-config.png)

## Embedding Model Configuration

The operation is the same as for the large language model — just search for an embedding model in Ollama. Using **Qwen3-Embedding** as an example.

### Model Selection and Download

Search for an embedding model in [Ollama](https://ollama.com/) (e.g., `qwen3-embedding`). The download method is the same as for the large language model.

![Embedding Model Selection](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/ollama-embedding-select.png)

![Embedding Model Download](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/embedding-download.png)

![Embedding Model Download Process](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/embedding-download-process.png)

### Filling in the Model Configuration

In the ATK model configuration interface:

- **Local model Name**: enter the downloaded model name, e.g., `qwen3-embedding:4b`
- **Base URL**: enter `http://localhost:11434`

![Local Embedding Model Configuration](../../../../zh/06-AI助手/知识问答助手/02-模型配置/media/本地模型配置/local-embedding-config.png)
