# Basic Constraints

This section describes the definitions, reference coordinate systems, and calculation methods for the geometric parameters used by Basic Constraints, as well as the line-of-sight constraint model for central body obstruction.

## Geometric Parameter Constraints

The geometric parameters include Azimuth ($Az$), Elevation ($El$), Range ($R$) and their rates, as well as Angular Rate, Altitude, and Propagation Delay.

### Geometric Definitions and Reference Frames

Azimuth, elevation, and range describe the spatial bearing and distance of the associated object relative to the analysis object.

Let $\boldsymbol r$ be the position vector of the associated object relative to the analysis object, and let $r_x$, $r_y$, and $r_z$ be the components of the relative position along the $OX$, $OY$, and $OZ$ axes, respectively. Their geometric relationship is shown below.

![Azimuth and elevation definitions](./media/01-基本约束/image1.png)

Let $\boldsymbol v$ be the velocity vector of the associated object relative to the analysis object, and let $v_x$, $v_y$, and $v_z$ be the three components of the relative velocity.

The reference coordinate system used for the relative position vector $\boldsymbol r$ depends on the type of analysis object. For a fixed ground object, $\boldsymbol r$ is defined in the object's local LH (Local Horizontal) coordinate system. For a moving ground object, $\boldsymbol r$ is defined in the VVLH (Vehicle Velocity Local Horizontal) coordinate system under the Central Body Fixed (CBF) frame. For a moving space object, $\boldsymbol r$ is defined in the VVLH coordinate system under the Central Body Inertial (CBI) frame.

The following table shows the correspondence between object types and reference coordinate systems.

| Reference Coordinate System | Object Type |
| --- | --- |
| LH | Facility |
| CBF-VVLH | GroundVehicle, Ship, Submarine, Aircraft |
| CBI-VVLH | Satellite, LaunchVehicle, Missile |

An attached object uses the same reference coordinate system as its parent object.

### Azimuth

Azimuth is calculated as follows:

$$
Az
=
\operatorname{arctan2}
\left(
r_y,r_x
\right)
$$

### Elevation

Elevation is calculated as follows:

$$
El
=
\arctan
\left(
\frac{r_z}
{\sqrt{r_x^2+r_y^2}}
\right)
$$

### Range

Range is calculated as follows:

$$
R
=
\sqrt{
r_x^2+r_y^2+r_z^2
}
$$

### Azimuth Rate

Azimuth Rate is calculated as follows:

$$
\frac{\mathrm dAz}{\mathrm dt}
=
\frac{
r_xv_y-r_yv_x
}{
r_x^2+r_y^2
}
$$

### Elevation Rate

Elevation Rate is calculated as follows:

$$
\frac{\mathrm dEl}{\mathrm dt}
=
\frac{
-v_z+\dfrac{r_z}{\boldsymbol r\cdot\boldsymbol v}
}{
\sqrt{
(R-r_z)(R+r_z)
}
}
$$

### Range Rate

Range Rate is calculated as follows:

$$
\frac{\mathrm dR}{\mathrm dt}
=
\frac{
r_x\omega_x+r_y\omega_y+r_z\omega_z
}{
R
}
$$

where:

$$
\boldsymbol\omega
=
\boldsymbol v
-
\boldsymbol\omega_{\mathrm{orb}}
\times
\boldsymbol v
$$

$$
\boldsymbol\omega_{\mathrm{orb}}
=
\frac{
\boldsymbol r\times\boldsymbol v
}{
R^2
}
$$

Here, $\boldsymbol\omega_{\mathrm{orb}}$ is the orbital angular velocity vector of the analysis object.

### Angular Rate

Angular Rate is calculated as follows:

$$
val
=
\frac{
\left\|
\boldsymbol r\times\boldsymbol v
\right\|
}{
R^2
}
$$

### Altitude

Altitude is calculated as follows:

$$
h
=
R_{\mathrm{obj}}
-
R_{C,\mathrm{local}}
$$

where:

- $R_{\mathrm{obj}}$ is the geocentric distance of the analysis object in the LLR coordinate system;
- $R_{C,\mathrm{local}}$ is the local radius of the central body.

### Propagation Delay

Propagation Delay is calculated as follows:

$$
val
=
\frac{R}{v_{\mathrm{light}}}
$$

where:

$$
v_{\mathrm{light}}
=
299792458.0\ \mathrm{m/s}
$$

Here, $v_{\mathrm{light}}$ represents the speed of light.

## Line-of-Sight Constraint

The calculation method for the Line of Sight constraint depends on the object type, as described below.

![Line-of-sight constraint](./media/01-基本约束/image2.png)

### Fixed Objects

If the object to which the Line of Sight constraint belongs remains fixed in the reference coordinate system, such as a Facility and its attached Sensor or Radar, the constraint output is defined as:

$$
val
=
\cos\beta-\cos\alpha
$$

The geometric relationship between $\alpha$ and $\beta$ is shown in the figure above.

### Moving Objects

If the object to which the Line of Sight constraint belongs has motion properties, such as a Satellite, Aircraft, LaunchVehicle, GroundVehicle, Ship, or Submarine, or an object attached to one of these objects, the constraint output is defined as:

$$
val
=
R_C
\left(
\cos\beta-\cos\alpha
\right)
$$

Here, $R_C$ is the longest semi-axis of the central body. This definition applies to triaxial ellipsoid, spheroid, and standard sphere central body models.

### Simplified Calculation for Objects on the Celestial Body Surface

When the start or end point of the line of sight lies on the central body surface, that is, when the object's elevation is $0$, the Line of Sight constraint model can be simplified. In this case, the constraint output is:

$$
val
=
\begin{cases}
\cos\gamma, & \text{Fixed Object} \\[4pt]
R_C\cos\gamma, & \text{Moving Object}
\end{cases}
$$

Here, $\gamma$ is the geometric angle shown in the following figure.

![Simplified line-of-sight calculation](./media/01-基本约束/image3.png)

When an object has a negative elevation, the central body model must be adjusted so that the object lies on the surface of the adjusted central body model. The Line of Sight constraint output is then calculated using the formulas above.
