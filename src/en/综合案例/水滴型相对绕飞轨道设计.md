# Teardrop-Shaped Relative Flyaround Trajectory Design

## Introduction

With the continuous development of space technology, many countries have carried out attempts and research on spacecraft on-orbit servicing technologies, such as the Restore-L on-orbit refueling demonstration project of the United States and the Robotic Refueling Mission (RRM) implemented by NASA and the Canadian Space Agency. In the execution of these missions, the "flyaround" technique is often used, that is, the periodic relative motion of one spacecraft (the companion spacecraft) around another target spacecraft (the reference spacecraft) within a certain distance range[1].

To form a closed teardrop-shaped flyaround configuration, control needs to be applied in the radial direction (the -R-bar direction) at the self-intersection point of the drift trajectory. As shown in the figure below, a schematic diagram of the trajectory of the companion spacecraft performing a single teardrop transfer flyaround directly behind the reference spacecraft (with the +V-bar direction taken as positive) is given. In the figure, the blue curve is the relative transfer trajectory of the controlled multi-impulse transfer of the companion spacecraft, and the red curve is the teardrop-shaped relative orbit of the companion spacecraft flying around the reference spacecraft.

![Schematic of the teardrop flyaround trajectory](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image01-水滴绕飞轨迹示意图.png)

A relative flyaround trajectory can be divided into a transfer phase and a flyaround phase, and its design can be transformed into a problem of solving a set of nonlinear equations, from which the impulsive maneuver magnitudes and maneuver times applied during the whole process are obtained. For a teardrop-shaped relative flyaround trajectory, given the initial relative position and relative velocity of the companion spacecraft with respect to the reference spacecraft at the mission initial time, the constraints of the multi-impulse transfer phase are the maneuver transfer time and the maximum transfer flight angle[2], and the constraints of the teardrop flyaround phase are the number of flyaround revolutions and the flyaround configuration (determined by $l$ and $h$ in the figure above).

In this case, the epoch of the simulation scenario and the orbital elements of the reference spacecraft are first set according to the requirements, and the initial relative position of the companion spacecraft at the mission initial time is given as $(-100, 0, 0)$ km and the initial relative velocity as $(0, 0, 0)$ m/s. The constraint values are set as follows: the maneuver transfer time is 86400 s, the maximum transfer flight angle is 5°, the number of flyaround revolutions is 1, and the teardrop flyaround configuration is $l = 2$ km, $h = 10$ km.

## Creating the Teardrop-Shaped Relative Flyaround Trajectory Task Scenario and Objects

[Install](https://smsat.space/) and run ATK.exe, and create a new scenario "RPOTeardropFlyaround". Set the start epoch to 2007-03-08 00:00:00.000 and the stop epoch to 2007-03-10 00:00:00.000; use the satellite orbit generation wizard to insert a geostationary-orbit satellite as the reference spacecraft, and name it "ReferenceSpacecraft"; then insert another satellite as the companion spacecraft, and name it "CompanionSpacecraft".

![Creating the satellite objects](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-1.png)

## Designing the Teardrop-Shaped Relative Flyaround Trajectory

1. **Reference spacecraft parameter configuration**

    Select "ReferenceSpacecraft" and choose <kbd>J2 Perturbation</kbd> in the propagator drop-down list.
    Then set the orbital epoch of the reference spacecraft to be the same as the scenario start epoch, and apply it.

    ![Reference spacecraft orbital epoch settings](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-2.png)

2. **Companion spacecraft initial parameter configuration**

    Select "CompanionSpacecraft" and choose <kbd>Astrogator</kbd> in the propagator drop-down list.
    Rename the "InitialState" initial segment to "Initial State", click <kbd>Reference Spacecraft</kbd>, and select "ReferenceSpacecraft" as the reference spacecraft.

    ![Companion spacecraft Astrogator propagation](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-3.png)

    In the【Initial State】panel on the right, set the【Coordinate System】to the "VVLH" coordinate system of "ReferenceSpacecraft".

    ![Initial state reference frame settings](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-4.png)

    The above steps establish the coordinate system of the companion spacecraft relative to the reference spacecraft. Among them, the X-axis points in the positive direction of the reference spacecraft velocity, the Y-axis points in the negative normal direction of the reference spacecraft orbital plane, and the positive Z-axis points toward the Earth's center. Set the initial relative position of the companion spacecraft:

    ![Initial relative position of the companion spacecraft](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-5.png)

3. **Parameter settings for the companion spacecraft teardrop flyaround trajectory**

    In the Astrogator interface, select <kbd>New - Insert RPO Segment - Formation Flying - Teardrop Flyaround Segment</kbd>, and rename it to "Orbital Maneuver and Teardrop Flyaround".
    Then set the "Reference Spacecraft" to "ReferenceSpacecraft", and set the teardrop flyaround parameters as follows:

    | Parameter                    | Value     |
    | ---------------------------- | --------- |
    | Number of revolutions        | 1         |
    | Starting point distance      | 2000      |
    | Maneuver point distance      | -10000    |
    | Wait time                    | 86400     |
    | Maximum true anomaly change  | 5         |
    | Solution algorithm           | Sequential Quadratic Programming |

    The above parameters correspond to the constraint variables in the scenario design.

## Simulation Run and Result Display of the Teardrop-Shaped Relative Flyaround Trajectory

1. **Simulation computation and display settings**

    After the parameter configuration of the companion spacecraft is complete, click <kbd>Run</kbd> in the【Astrogator】window and wait for the computation to finish:

    ![Running the Astrogator mission](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-6.png)

    After the computation finishes, click <kbd>Result Data</kbd> of the【Teardrop Flyaround Segment】to view the impulsive vectors and times applied during the trajectory transfer and flyaround process. From the data analysis it can be seen that the impulses applied at the initial point of the trajectory transfer, at the connection points between the transfer phase and the flyaround phase, and at the teardrop tip are relatively large (about 1 m/s ~ 2 m/s). The transfer phase applies a total of 64 impulses, but the magnitude of each impulse is not large (about 0.3 m/s). The specific results are shown in the figure below.

    ![Impulsive vector result data](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-7.png)

    Next, in the【Property Settings】window of the companion spacecraft, select the "Vectors" settings under【3D Graphics】and add a【Coordinate System】:

    ![Coordinate system settings 1](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-8.png)

    Select the "VVLH" coordinate system of "ReferenceSpacecraft":

    ![Coordinate system settings 2](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-9.png)

    Check <kbd>Display</kbd> and <kbd>Display Label</kbd>, and set parameters such as the relative track color and line width as needed.

    ![Coordinate system settings 3](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-10.png)

    Return to the【3D Graphics】interface, select <kbd>Local Viewpoint</kbd> in the upper-left corner, and then select <kbd>Satellite - ReferenceSpacecraft</kbd> in turn to fix the viewpoint on "ReferenceSpacecraft".

    ![Local viewpoint settings in the 3D view](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-11.png)

    Continue to select <kbd>3D Graphics Window's Central Body</kbd> in the upper-left corner, and in <kbd>Other...</kbd> select the "VVLH" coordinate system and "Reference Point" of "ReferenceSpacecraft", so that the track displayed in the window is in the "VVLH" coordinate system of the spacecraft "ReferenceSpacecraft".

    ![Relative track settings](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-12.png)

2. **Simulation scenario display**

    Click the <kbd>Start</kbd> button to observe the relative motion trajectory between the reference spacecraft and the companion spacecraft. The RPO teardrop flyaround trajectory is shown below.

    ![Display of the RPO teardrop flyaround trajectory 1](../../zh/综合案例/media/水滴型相对绕飞轨道设计/image0615-13.png)
