# Design and Analysis of a Midcourse Correction Trajectory for an Earth-Moon Transfer Considering Injection Errors

## Introduction

When a spacecraft performs an Earth-Moon transfer, a trajectory that satisfies the mission flight constraints is usually obtained through optimization design, and is generally called the nominal trajectory or reference trajectory. However, due to uncertainties such as state estimation errors, navigation errors, and control errors, the actual flight trajectory of the spacecraft usually deviates from the nominal trajectory. To ensure that the spacecraft smoothly enters the target orbit, midcourse correction is usually adopted in engineering to regulate the deviations, so as to reduce the probability of mission failure and improve mission robustness. The figure below shows a schematic of the midcourse correction trajectory for an Earth-Moon transfer.

![Schematic of the midcourse correction trajectory for an Earth-Moon transfer](../../zh/综合案例/media/考虑入轨偏差的地月转移中途修正轨道设计与分析/image01-地月转移中途修正轨道示意图.png)

The essence of midcourse correction design is, given the nominal trajectory and the initial deviations, to solve for the impulsive control vector required at the correction epoch so that the deviation between the actual trajectory position and the nominal trajectory position at the terminal time meets the preset requirements.

Based on the Astrogator module of the aerospace mission toolbox ATK (Aerospace Tool Kit), this case implements the design and analysis of a single midcourse correction trajectory with a fixed correction epoch. The initial nominal trajectory is an Earth-Moon transfer trajectory with a flight time of about 3 days, departing from the Earth and reaching the perilune. The correction epoch is set to one day after the departure time, the injection position deviations in all directions are set to 500 m, and the velocity deviations in all directions are set to 0.1 m/s. The design variables are chosen as the impulsive vector in the VVLH coordinate system, and all initial values are set to 0 m/s. The target quantity is the terminal position vector, and the terminal position convergence tolerance is set to 50 m.

## Description of the Task Control Sequence

To design an Earth-Moon transfer midcourse correction trajectory considering injection errors, we need to build the following task control sequence:

A **target sequence**, which contains an Initial State segment, a Maneuver segment, and two Propagate segments.

## Creating the Task Scenario

1. Run ATK.exe and click <kbd>New Scenario</kbd> to create a new scenario "Earth-Moon Transfer Midcourse Correction Scenario".

2. Set the simulation time: in the【ATK: New Scenario Wizard】dialog, set the "Epoch" as follows

    | Start Epoch | Stop Epoch |
    | ----------------------- | ----------------------- |
    | 2029-08-09 13:00:00.000 | 2029-08-13 10:00:00.000 |

3. Click <kbd>OK</kbd> to finish creating the scenario.

## Creating Objects

1. **Create and edit the satellite object**

   - Click <kbd>Insert</kbd> in the "Home" tab of the toolbar to create a satellite object.

   - Select【Scenario Objects】-【Satellite】and【Insertion Mode】-【Insert Default Type】, click <kbd>Insert...</kbd>, then click <kbd>Close</kbd>.

   - In the【Objects】tree on the left, right-click the satellite "Satellite1" and select <kbd>Rename</kbd> to name it "Earth-Moon Transfer Midcourse Correction Satellite".

   - In the【Objects】tree on the left, right-click the satellite "Earth-Moon Transfer Midcourse Correction Satellite" and select <kbd>Properties</kbd>. In the【Satellite Parameter Settings】interface, select【Propagator】-【Astrogator】.

## Designing the Midcourse Correction Trajectory

1. **Define the target sequence**

   - Delete the default Initial State segment.

   - Click <kbd>New</kbd> to add a "Target Sequence" and name it "Earth-Moon Transfer Midcourse Correction Design".

2. **Define the Initial State segment**

   Embed an "Initial State" segment in the "Earth-Moon Transfer Midcourse Correction Design" sequence and name it "Initial State". Set the【Orbital Epoch (UTCG)】to "9 Aug 2029 17:38:34.459". Select【Coordinate System】-【Earth J2000】and【Coordinate Type】-【Position Velocity】, and set the position and velocity as in the following table:

    | Parameter | Value |
    | ---- | ---- |
    | Position X | 6149445.506638841703534 m |
    | Position Y | 2990903.982296200003475 m |
    | Position Z | -1313542.527568900026381 m |
    | Velocity X | -2560.51127332499982 m/s |
    | Velocity Y | 9579.817819986599716 m/s |
    | Velocity Z | -3821.891658736356021 m/s |

3. **Define the Propagate segment up to the correction epoch**

   - Click <kbd>New</kbd> to insert a "Propagate" segment after the "Initial State" segment and name it "Transfer to Correction Epoch".

   - Click【Orbit Propagation】-<kbd>Advanced...</kbd>, select【Central Body】-【Earth】; in【Gravity】select【Gravity Model】-【WGS84】, with【Degree】-"20" and【Order】-"20"; uncheck【Atmospheric Drag Perturbation】; check【Solar Radiation Pressure Perturbation】; check【Third-Body Perturbation】-【Sun】and【Moon】, with the "Point Mass" model selected for the Sun and the【Gravity Field】model -【GLGM2】selected for the Moon, with【Degree】-"0" and【Order】-"0"; click <kbd>OK</kbd>.

   - In【Stopping Conditions】, click <kbd>New</kbd>, select【Duration】【CAsStopDuration】as the stopping condition, and set the【Trip Value】to "86400".

4. **Define the Maneuver segment**

   - Click <kbd>New</kbd> to insert a "Maneuver" segment after the "Transfer to Correction Epoch" segment and name it "Midcourse Correction Impulse".

   - Select【Maneuver Type】-【Impulsive】and【Thrust Axes】-【VVLH】, with the coordinate type set to【Cartesian】.

   - Set【Velocity Increment Vx】to "0 m/s",【Velocity Increment Vy】to "0 m/s", and【Velocity Increment Vz】to "0 m/s".

5. **Define the Propagate segment of the Earth-Moon transfer to perilune**

   - Click <kbd>New</kbd> to insert a "Propagate" segment after the "Midcourse Correction Impulse" segment and name it "Earth-Moon Transfer to Perilune".

   - Click【Orbit Propagation】-<kbd>Advanced...</kbd>; the settings here are the same as those of the first Propagate segment.

   - In【Stopping Conditions】, click <kbd>New</kbd>, select【Epoch】【CAsStopEpoch】as the stopping condition, and set the【Trip Value】to "2029-08-12 12:02:04.000011".

6. **Select the variables**

   - In the "Midcourse Correction Impulse" segment, click the icon <img src="../../zh/综合案例/media/考虑入轨偏差的地月转移中途修正轨道设计与分析/image0611-7.png" alt="Toggle to design variable" no-view /> behind the【Velocity Increment Vx】,【Velocity Increment Vy】, and【Velocity Increment Vz】fields to check them as **design variables** <img src="../../zh/综合案例/media/考虑入轨偏差的地月转移中途修正轨道设计与分析/image0611-6.png" alt="Design variable" no-view />.

   - Right-click the "Earth-Moon Transfer to Perilune" segment and select <kbd>Constraint Configuration...</kbd>. Double-click to select【Cartesian】-【Position X】,【Position Y】, and【Position Z】as the target variables, set the【Coordinate System】of all of them to "Earth J2000 Mean Equator", and click <kbd>OK</kbd>.

7. **Set the targeter**

   - Select the "Earth-Moon Transfer Midcourse Correction Design" segment, and in【Configuration】click <kbd>New</kbd> and select【Differential Corrector】; if a【Differential Corrector】already exists by default, there is no need to create a new one.

   - Double-click the【Differential Corrector】box to enter the【Targeter Settings】interface. Click the boxes under the "Use" column in【Control Variables】and【Constraints】respectively to check the control variables and constraints to be used.

        | Control variable | Constraint |
        | ---- | ---- |
        | ImpulseX | StateCalcX |
        | ImpulseY | StateCalcY |
        | ImpulseZ | StateCalcZ |

   -【Control Variables】keep the default options.

   - In【Constraints】-【StateCalcX】, enter -363714745.042420983314514 m in the【Desired Value】column, with a convergence tolerance of 50 m.

   - In【Constraints】-【StateCalcY】, the desired value is 59420346.345268502831459 m, with a convergence tolerance of 50 m.

   - In【Constraints】-【StateCalcZ】, the desired value is -9197117.039631770923734 m, with a convergence tolerance of 50 m.

   - After the settings are done, click <kbd>OK</kbd>, and then re-enter the【Targeter Settings】interface to see the results after the user settings.
