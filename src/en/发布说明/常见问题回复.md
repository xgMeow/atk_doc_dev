# Frequently Asked Questions

## Maneuver Planning

### Why doesn't the LEO-to-GEO rapid transfer case converge?

1. Refer to the case tutorial to check the orbit segment configuration, control variable configuration, and constraint configuration.

2. Check the solver configuration. For example, the `Maximum Step Size` in the solver may be set too small, which prevents large-scale correction of the parameters.

   Refer to the figure below to set the maximum step size to a larger value, e.g. `100`.

## Visualization

### How to use the HD map

For ATK 4.0 and earlier versions, place the HD map resource pack `ATK_Earth` under the path `AstroData\\3DDataBase\\Planets` to use the HD map feature normally.
