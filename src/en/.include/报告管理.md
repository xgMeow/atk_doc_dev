# Report Management

## Object Selection

The **left** side of the window is the object selection area:

- Use the [Object Type] drop-down to filter objects (you can select the scenario or a specific object within the scenario).
- After selecting the desired object, you can configure the report style for it on the right side.

<img src="@source/zh/.include/media/报告管理/image-20260327151520317.png" alt="Object Type">

## Report Type

The top of the **right** side of the window contains the [Report Type] drop-down, with options:

- [Dynamic Display](#dynamic-report)
- [Report](#data-report)
- [Chart](#curve-chart)

> [!NOTE]
>
> When opened from the Output menu, it will automatically switch to the corresponding report type; you can also manually switch here later.

## Style Management

The style list is located in the middle of the right side of the window, containing two types of styles:

- **Predefined styles**: Built into the system and cannot be deleted.
- **Custom styles**: Created by users and can be deleted.

<img src="@source/zh/.include/media/报告管理/image-20260327151739281.png" alt="Style Management">

### Creating a New Style

Click the <kbd>New</kbd> button to create a blank custom style.

<img src="@source/zh/.include/media/报告管理/image-20260327151843399.png" alt="New Style">

### Editing a Style

1. Select any style (predefined or custom).
2. Click the <kbd>Properties...</kbd> button on the right to enter the [Property Editor](#property-editor).

<img src="@source/zh/.include/media/报告管理/image-20260327152005996.png" alt="Editing a Style">

### Deleting a Style

Only for custom styles: select the style and click the <kbd>Delete</kbd> button on the right.

### Copying a Style

Select any style and click the <kbd>Copy</kbd> button on the right to quickly generate a new style with the same configuration (the new style will be a custom style).

> [!CAUTION]
>
> When no style is selected, the operation buttons on the right are disabled.

## Property Editor

In the [Property Editor], you can define which properties the report includes, their display order, names, and units.

<img src="@source/zh/.include/media/报告管理/image-20260327152104113_cmc.png" alt="Property Editor">

### Adding Properties

- The left side is the **list of available properties**.
- Double‑click a property, or select it and click the right arrow <img src="@source/zh/.include/media/报告管理/image-20260325083410705.png" alt="Right arrow"> to add it to the "Report Contents" column on the right.

### Removing Properties

- Double‑click a property in the "Report Contents" column.
- Select a property and click the <kbd>Delete</kbd> button on the right to remove it.
- Select a property and click the left arrow <img src="@source/zh/.include/media/报告管理/image-20260325083523647.png" alt="Left arrow"> to remove it.

### Ordering Properties

- Click to select a property in the "Report Contents" column.
- Use the up/down arrows <img src="@source/zh/.include/media/报告管理/image-20260325083607319.png" alt="Up arrow"> <img src="@source/zh/.include/media/报告管理/image-20260325083615648.png" alt="Down arrow"> to adjust the display order.

### "New Line" Feature

When generating reports with multiple properties, all data is displayed on the same line by default. The "New Line" feature allows you to split the report data into separate rows, so that properties in different rows are displayed on separate lines, improving the layout structure and readability of long reports.

- Click the <kbd>New Line</kbd> button on the right to add a "row marker" to the "Report Contents" column (displayed as "Row 1", "Row 2", etc.).
- The position of the row marker is the line break point; properties above and below the marker will be displayed on separate rows.
- Select a row marker and click the <kbd>Delete</kbd> button on the right to remove it.

### Renaming and Output Precision Settings

- Select a property in the "Report Contents" column and click the <kbd>Options...</kbd> button to rename the property and set its output precision.

<img src="@source/zh/.include/media/报告管理/image-20260327152305490_cmc.png" alt="Options">

### Global Unit Settings

- Click the <kbd>Unit Settings</kbd> button to open the [Settings Dialog].
  - Check <kbd>Use Default Units</kbd>: Restore all properties to their default units with one click.
  - Check <kbd>Show All Dimensions</kbd>: View all available dimensions.
  - Check <kbd>Set As Default</kbd>: Save the current unit settings as the default for future new reports.

<img src="@source/zh/.include/media/报告管理/image-20260327152338272_cmc.png" alt="Unit Settings">

### Report Interval Points

The report interval points is a dimensionless number indicating how many time points to skip when outputting report data from the underlying ephemeris sequence.

> [!NOTE]
>
> Example: If the propagator step size is 60 seconds and the interval points is set to 2, the actual time interval in the report will be 120 seconds.
> If you need to output directly by time interval, you can use the VGT data report feature, which supports setting the output time interval directly and automatically interpolates.

## Generating Reports

After the style configuration is complete, you can generate the corresponding report or chart in either of the following ways:

- Double‑click a style entry in the style list.
- Select a style entry and click the <kbd>Generate...</kbd> button.

The report type generated is determined by the current [Report Type] drop-down.
