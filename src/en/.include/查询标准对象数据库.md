# Query Standard Object Database

### Setting Filter Conditions

Set the query information in the window. The current filter conditions will be displayed above the results. Click the <img src="@source/zh/.include/media/查询标准对象数据库/image-20260324182029227.png" alt="" no-view /> icon to the right of each condition to **delete** that filter.

<img src="@source/zh/.include/media/查询标准对象数据库/image-20260324182705447.png" alt="Example of filter conditions">

### Performing a Search

After setting the conditions, click the <kbd>Search</kbd> button to execute the query. The results are displayed in the right panel, showing the total number of search results and the number of currently selected items, with specific objects presented in a table.

<img src="@source/zh/.include/media/查询标准对象数据库/image-20260324182836624.png" alt="Search illustration">

### Selecting Objects

- **Single selection**: Click a row in the table to select a single object.
- **Multiple selection**:
  - Hold down the <kbd>Ctrl</kbd> key and click to select multiple non‑contiguous objects.
  - Hold down the <kbd>Shift</kbd> key and click to select a contiguous range of objects.

After selection, the items will be highlighted in blue as shown below:

<img src="@source/zh/.include/media/查询标准对象数据库/image-20260324182923829.png" alt="Selecting objects">

### Configuring Colors

After selecting objects, you can configure colors in the insertion options:

- Check **Auto Select Color** to let the system automatically assign colors to the objects.
- Uncheck it, then click the color swatch to manually pick a color.

<img src="@source/zh/.include/media/查询标准对象数据库/image-20260324183046888.png" alt="Configuring colors">

### Inserting a Satellite System

When searching for **Satellites**, you can select multiple satellites and click **Insert Satellite System**. The system will automatically generate the corresponding TLE files (for easy loading) and insert a Satellite System object into the project.
