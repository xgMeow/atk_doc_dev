# Advanced Constellation Design Example

  :relative-paths="files"
/>

## Scenario Description

This example designs a constellation with orbital parameter and viewing angle constraints for coverage of a specified area. The constellation coverage area is set to global. The coverage type is simple coverage, with the onboard sensor half-angle set to 65 degrees. The Walker constellation orbital altitude is 0–2000 km, with RAAN and argument of perigee varying from 0 to 360 degrees.

## Creating the Scenario

1. Run ATK.exe and click <kbd>Create a new scenario file</kbd> to create a scenario named **AdvancedConstellation**.

2. Set the simulation time. In the **ATK: New Scenario Wizard** dialog, set the time period.

   | Start Epoch (UTCG)      | End Epoch (UTCG)        |
   | ----------------------- | ----------------------- |
   | 2024-03-19 00:00:00 | 2024-03-20 00:00:00 |

3. Click <kbd>OK</kbd> to complete scenario creation.

## Constellation Design

Click <kbd>Tools</kbd> - <kbd>Advanced Constellation Design</kbd> to open the constellation design tool window. The constellation design constraints include three categories: Coverage Performance, Orbital Constraints, and Coverage Parameters.

1. **Coverage Performance Settings**

   Set **Coverage Type** to **Continuous Coverage**, **Coverage Multiplicity** to 1, and **Region Type** to **Global**.

2. **Orbital Constraint Settings**

   Orbital constraint type settings: **Constellation Type** set to **Walker-Delta**, check Semi-major Axis, RAAN, and Argument of Perigee.

3. **Coverage Parameter Settings**

   Coverage parameter settings: **Coverage Type** set to **Simple Cone**, and **Cone Half-Angle** set to 65 degrees.

## Creating the Constellation

1. Click <kbd>Start Design…</kbd> to automatically generate a constellation that meets the above constraints.

2. In the satellite parameters area, hold down the Shift key to select all planes, then click <kbd>Insert Satellites…</kbd>. The resulting scenario is shown below.
