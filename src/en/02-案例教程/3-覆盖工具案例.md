# Coverage

<PathViewer
  :relative-paths="files"
/>

The Coverage tool enables analysis of one or more objects' coverage performance for ground targets. It generates coverage time analysis reports and allows evaluation of coverage effectiveness under different assessment criteria.

## Creating a Scenario

1. Run ATK.exe and click <kbd>Create a new scenario file</kbd>;

2. In the **New Scenario Wizard** dialog, set the scenario **Name** to **CoverageExample**;

3. Set the scenario time period as:

| Start Epoch (UTCG_MM)          | End Epoch (UTCG_MM)          |
| ------------------------------ | ---------------------------- |
| 2023-03-11 00:00:00.000 | 2023-03-12 00:00:00.000 |

4. Click <kbd>OK</kbd> to complete the scenario creation.

## Creating a Satellite Object

1. In the toolbar, click <kbd>Insert</kbd> under <kbd>Start</kbd> to create an object;

2. Select **Scenario Object** - **Satellite**, and **Insertion Method** - **Orbit Generation Wizard**;

3. Click <kbd>Insert…</kbd>;

4. Select **Orbit Type** - **Repeating Orbit**;

5. Set the orbital parameters as:

|          Parameter         | Value |
|:--------------------------:|:-----:|
|     Approx. Altitude (km)  |  500  |
|     Inclination (deg)      |  45   |
|       Repeating Cycles     |  10   |
| First Ascending Node Longitude (deg) |   0   |

6. Click <kbd>OK</kbd>.

## Adding a Sensor

1. In the toolbar, click <kbd>Insert</kbd> under <kbd>Start</kbd> to create an object;

2. Select **Attached Object** - **Sensor**;

3. Click <kbd>Insert…</kbd>;

4. Select the **CoverageExample** - **Satellite 1** object;

5. Click <kbd>OK</kbd>;

6. Right-click the **CoverageExample** - **Sensor 1** object and click <kbd>Properties</kbd>;

7. Select **Sensor Type** - **Simple Cone**;

8. Set the **Half-Cone Angle (deg)** to 50;

9. Click <kbd>OK</kbd>.

## Creating a Coverage Target

1. In the toolbar, click <kbd>Insert</kbd> under <kbd>Start</kbd> to create an object;

2. Select **Scenario Object** - **Ground Station**, and **Insertion Method** - **Insert Default Type**;

3. Click <kbd>Insert...</kbd>;

4. Right-click the **CoverageExample** - **Ground Station 1** object and click <kbd>Properties</kbd>;

5. Select **Position** - **Type** as **Geodetic Coordinates**;

6. Set the ground station position as:

|    Parameter   | Value |
|:--------------:|:-----:|
|  Latitude (deg)|  30   |
|  Longitude (deg)| 110  |
|  Altitude (km) |   0   |

7. Click <kbd>OK</kbd>.

## Viewing the 2D and 3D Views of the Scenario

1. Click the <img src="../../zh/02-案例教程/media/3.3覆盖工具案例/image27.jpeg" alt="" no-view /> button in the <kbd>Start</kbd> toolbar;

2. View the 2D and 3D results.

## Performing Coverage Analysis

1. Click <kbd>Tools</kbd> - <kbd>Coverage</kbd> <img src="../../zh/02-案例教程/media/3.3覆盖工具案例/image28.png" alt="" no-view />;

2. Click <kbd>Select Object...</kbd> to configure the **Analysis Object**;

3. Select the **Satellite 1** - **Sensor 1** object and click <kbd>OK</kbd>;

4. Set the computation time period as:

|    Start Epoch (UTCG_MM)    |     End Epoch (UTCG_MM)     |
|:---------------------------:|:---------------------------:|
| 2023-03-11 00:00:00.000 | 2023-03-12 00:00:00.000 |

5. Select **Ground Station 1**, then click <kbd>Compute</kbd> <img src="../../zh/02-案例教程/media/3.2可见性工具案例/image24.png" alt="" no-view />;

6. Click **Report** - <kbd>Coverage Periods</kbd> to view the coverage period report;

7. Click <kbd>Save</kbd> to save the coverage analysis report;

![Coverage Period Analysis Report](../../zh/02-案例教程/media/3.3覆盖工具案例/image30.png)

8. Close the **Coverage Analysis Report** page. Under **Report** - <kbd>More...</kbd>, you can choose additional report types;

![More Reports](../../zh/02-案例教程/media/3.3覆盖工具案例/image-3.3.1.png)

9. Click **Chart** - <kbd>Coverage Periods</kbd> to view the visualized coverage period chart;

![Coverage Period Analysis Visualization Report](../../zh/02-案例教程/media/3.3覆盖工具案例/image31.png)

10. Close the **Coverage Analysis Report** page. Under **Chart** - <kbd>More...</kbd>, you can choose additional chart types.

![More Charts](../../zh/02-案例教程/media/3.3覆盖工具案例/image-3.3.2.png)

## Coverage Quality Analysis

1. Click **Quality Parameters** - <kbd>Define…</kbd>;

2. Select **Type** - **Revisit Time**; **Computation** - **Average**; keep other options as default;

3. Click <kbd>OK</kbd> to get the average revisit time.

![Revisit Time Calculation Result](../../zh/02-案例教程/media/3.3覆盖工具案例/image-3.3.4.png)
