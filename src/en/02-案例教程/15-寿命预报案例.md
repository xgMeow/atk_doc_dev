## Scenario Description

This example performs orbital lifetime prediction and orbital decay calculation for a LEO satellite.

## Creating the Scenario

1. Run ATK.exe and click <kbd>Create a new scenario file</kbd> to create a scenario named **Lifetime Prediction**.

2. Set the simulation time. In the **ATK: New Scenario Wizard** dialog, set the time period.

   | Start Epoch (UTCG)      | End Epoch (UTCG)        |
   | ----------------------- | ----------------------- |
   | 2012-08-10 00:00:00 | 2015-03-06 00:00:00 |

3. Click <kbd>OK</kbd> to complete scenario creation.

## Creating the Satellite and Setting Properties

1. In the toolbar, click <kbd>Insert</kbd> under <kbd>Start</kbd> to create a satellite object. Select **Scenario Object** — **Satellite**, **Insertion Method** — **Insert Default Type**, click <kbd>Insert…</kbd>, then click <kbd>Close</kbd>.

2. Right‑click the satellite, select <kbd>Properties</kbd> to enter the satellite parameter settings interface. In **Orbit Propagator** — **Two‑Body**, set the relevant parameters:

   | Parameter                | Value               |
   | ------------------------ | ------------------- |
   | Epoch Time               | 2012-08-11 09:55:25 |
   | Semi-major Axis (m)      | 6843668             |
   | Eccentricity             | 0.000352            |
   | Inclination (deg)        | 97.248              |
   | RAAN (deg)               | 352.226             |
   | Argument of Perigee (deg)| 352.173             |
   | True Anomaly (deg)       | 64.382              |

## Orbital Lifetime Prediction

1. Select Satellite 1, then in the **Toolbar** - **Satellite** menu, select **Lifetime Prediction**.

2. Set the satellite drag area to 7.2727 m², atmospheric drag coefficient to 2.2, and mass to 1000 kg.

3. Constraint type selection: **Orbit Revolution Count** or **Time**. Prediction time limit: 67500 days; revolution count limit: 100000; re-entry altitude limit: 120 km.

4. Atmospheric density settings: **NRLMSISE00** model, check **Use Interpolation Table Lookup**.

5. Click the <kbd>Compute</kbd> button in the Orbital Lifetime Prediction tool to obtain the satellite's re-entry time (decaying to 120 km dense atmosphere), orbital lifetime, and remaining orbital revolutions.

6. Click <kbd>Report</kbd> or <kbd>Chart</kbd> to view the detailed report and chart curves of the satellite's decay.

   ![Orbital Lifetime Prediction Chart](../../zh/02-案例教程/media/3.15寿命预报案例/image0107-8.png)

## Orbital Decay Calculation

The preliminary steps are the same as those for orbital lifetime prediction. In **Lifetime Prediction** - **Decay Calculation Stop Time**, enter the desired number of days for orbital decay calculation (e.g., 30 days), then click the <kbd>Compute</kbd> button on the right side of the Orbital Decay section to obtain the cumulative decay over 30 days.
