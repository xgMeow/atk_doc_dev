# Dispersion Analysis

<PathViewer
  :relative-paths="files"
/>

## Scenario Description

This example uses the Dispersion Analysis tool, considering initial state deviations and maneuver errors of a space object, to solve the terminal state dispersion distribution characteristics and sensitivity indices using Monte Carlo and Polynomial Chaos methods.

## Creating the Scenario

1. Run ATK.exe and click <kbd>Create a new scenario file</kbd> to create a new scenario.

2. Set the simulation time. In the **ATK: New Scenario Wizard** dialog, set the time period.

   | Start Epoch (UTCG) | End Epoch (UTCG)   |
   | ------------------ | ------------------ |
   | 2025-11-09 00:00:00.000 | 2025-11-10 00:00:00.000 |

3. Select **Earth** as the central body, confirm the scenario **Name** and **Directory**, then click <kbd>OK</kbd> to complete scenario creation.

## Creating Objects and Configuring Dispersion Analysis Properties

1. Create and edit satellite objects. Click <kbd>Insert</kbd>. Select **Scenario Object** – **Satellite**, **Insertion Method** – **Insert Default Type**, click <kbd>Insert…</kbd>, then click <kbd>Close</kbd>.

2. Right‑click **Satellite 1**, select <kbd>Properties</kbd> to open the satellite parameter settings interface, and select **Orbit Propagator** – **Dispersion Analysis**.

3. Insert a Dispersion Analysis segment. Select <kbd>New</kbd> - <kbd>Dispersion Analysis Segment</kbd>.

   ::: warning Prerequisite for Using Dispersion Analysis Segment
   All dispersion evolution result analyses are performed based on the Dispersion Analysis segment. Therefore, for any orbital sequence segment that requires dispersion analysis, first insert a Dispersion Analysis segment, then insert the corresponding orbital sequence segment under it.
   :::

4. Define the initial state.

   - Select <kbd>New</kbd> - <kbd>Initial State Segment</kbd> to insert an **Initial State Segment** (drag it under the "Dispersion Analysis Segment").

   - Select the initial state segment, define the initial orbital state including orbit epoch, coordinate system, and orbital parameters, and check **Input Dispersion**. Click <kbd>Apply</kbd>.

5. Set up the propagation segment. Select <kbd>New</kbd> - <kbd>Propagation Segment</kbd> to insert a propagation segment. Set the stopping condition, select CAsStopDuration, enter the propagation time in the trigger value field, and choose 43200 sec.

6. Configure the maneuver.

   - Select <kbd>New</kbd> - <kbd>Maneuver Segment</kbd> to insert a maneuver segment.

   - Select maneuver type **Impulse** and thrust coordinate system **VVLH**.

   - Set the delta‑V parameter to 10 m/s, and check the maneuver dispersion components Vx, Vy, Vz to be analyzed.

   - Click <kbd>Apply</kbd>.

7. Set up the post‑maneuver propagation segment. The operation process and parameter values are the same as in Step 5. After inserting this propagation segment, right‑click it, select **Rename**, and name it **Post‑Maneuver Propagation Segment**.

8. Configure output parameters.

   - Select the **Post‑Maneuver Propagation Segment**, click <kbd>Constraint Configuration…</kbd> to open the **Optional Constraints** interface.

   - In **Optional Constraints**, expand the **Cartesian Coordinates** drop‑down, double‑click to select Position X, Y, Z and Velocity X, Y, Z, moving the six physical quantities to the right as constraint parameters.

   ::: warning Coordinate System Settings for Constraint Parameters
   Select the constraint parameters on the right; in the **Constraint Parameters** section at the bottom of the page, you can define the coordinate system for the output parameters.
   :::

9. Dispersion Segment interface settings.

   - Open the Dispersion Segment.

   - Use the <kbd>New Options!</kbd> button to select the dispersion evolution method, and double‑click to insert **Polynomial Chaos**.

   ::: warning Dispersion Evolution Method Activation Status
   The activation status of the inserted dispersion evolution method is enabled by default. Click the <kbd>Mode</kbd> button to select **Iterate** or **Inactive** to determine whether the module is enabled for iteration.
   :::

10. Dispersion Segment input and output settings.

    - First select **Configuration Type** - **Monte Carlo**, double‑click to open it, and set the input dispersion and output dispersion.

    - Select the distribution type for **Input Dispersion**: Gaussian Distribution.

    - Under the application column for input dispersion quantities, check the input parameters and set the corresponding mean and variance. Position deviation mean is 0m, standard deviation is 1m; velocity deviation mean is 0m/s, standard deviation is 1m/s; maneuver velocity deviation mean is 0m/s, standard deviation is 1m/s. Check the applications: **X, Y, Z**. (You can also view the initial covariance matrix via the <kbd>Initial Covariance Matrix</kbd> button.)

    - Under output dispersion quantities, check the output parameters: **X, Y, Z**.

    - Click <kbd>OK</kbd>.

    - Perform the same input/output parameter settings for **Configuration Type** - **Polynomial Chaos**.

## Viewing Dispersion Analysis Results

1. **Samples and Statistical Parameters**

   Click the <kbd>Run</kbd> button in the upper left <img src="../../zh/02-案例教程/media/3.13偏差分析案例/image17.png" alt="" no-view />. After computation, in the **Run Results Display** page, select **UncerQuanity** - **Monte Carlo** and **UncerQuanity** - **Polynomial Chaos** respectively to directly view the **Samples** and **Parameters** results.

2. **Probability Density**

   On the **Run Results Display** page, open **UncerQuanity** - **Polynomial Chaos**, set the sample size to 1,000,000 and click <kbd>Compute</kbd>. After computation, on the **Probability Density Distribution** page, select the first output parameter in the **X‑axis** field and click <kbd>Display</kbd> to obtain the probability density distribution for the first output, as shown below.

   ::: warning Prerequisite for Polynomial Chaos Computation
   You must configure the input/output parameters for **Polynomial Chaos** in the "Dispersion Segment Input and Output Settings", otherwise the computation cannot proceed.
   :::

   ![Polynomial Chaos Probability Density Distribution](../../zh/02-案例教程/media/3.13偏差分析案例/image18.png)

   On the **Run Results Display** page, open **UncerQuanity** - **Monte Carlo**, directly select **Probability Density Distribution**, choose the first output parameter in the **X‑axis** field, and click <kbd>Display</kbd> to also obtain the Monte Carlo probability density distribution.

3. **Sensitivity Analysis**

   Open **Sensitivity Analysis** and click <kbd>Display</kbd> to obtain the total effect indices, as shown below.

   ![Sensitivity Analysis](../../zh/02-案例教程/media/3.13偏差分析案例/image19.png)
