# Communication Link Budget

This example describes how to build a communication link between a Facility and a satellite in ATK, set the antenna, modulator, and filter of the transmitter, and generate a communication details report with the access tool to review the link budget parameters.

## Creating the Scenario

1. Run ATK.exe and click <kbd>New Scenario File</kbd>;

2. In the **New Scenario Wizard** dialog, set the scenario **Name** to Communication;

3. Set the scenario time period:

| Start Epoch (UTCG)          | End Epoch (UTCG)          |
| ----------------------- | ----------------------- |
| 2026-09-14 04:00:00.000 | 2026-09-15 04:00:00.000 |

4. Click <kbd>OK</kbd> to complete scenario creation.

## Creating Communication Objects

1. Insert one **Facility** and one **Satellite** into the new scenario using the default method;

> **Note**: The position of the Facility must ensure visibility to the satellite. Observe the 2D Graphics view and place the Facility at a point on the satellite's ground track.

2. Insert a **Receiver** under the **Facility** object, and a **Transmitter** under the **Satellite** object.

![Communication object structure](../../zh/02-案例教程/media/3.20通信案例/image1.png)

## Setting Transmitter Properties

1. Open the **Transmitter** properties and select **Complex Transmitter Model** in **Type**;
   
2. On the **Model Specifications** page, select the default parameters;

3. On the **Antenna** page, a different antenna type can be selected. The antenna parameters affect the computed EIRP. Set the **Antenna** parameters as follows:

    | Parameter | Value |
    | --- | --- |
    | Type | Parabolic Antenna |
    | Design Frequency (GHz) | 14.5 |
    | Efficiency (%) | 0.55 |
    | Back Lobe Gain (dB) | -30 |
    | Diameter (m) | 1 |

    Keep the remaining settings at their default values.

4. Switch to the **Modulator** page. Different modulation types can be selected as required; the modulation type mainly affects the bit error rate calculation.
This example uses the following settings:
   - Select **BPSK** for **Type**;
   - Clear **Select Signal PSD**;
   - Select **Auto-Adjust Bandwidth** under **Signal Bandwidth**.

> **Note**: The demodulator type at the receiver end must be consistent with the modulator type at the transmitter end; otherwise the bit error rate results return anomalous values.

5. Switch to the **Filter** page and select **Use** to enable the filter. The filter settings affect the EIRP value. Set the filter parameters as follows:

    | Parameter | Value |
    | --- | --- |
    | Type | Bessel |
    | High Band Cutoff Frequency (GHz) | 0.02 |
    | Low Band Cutoff Frequency (GHz) | -0.02 |
    | Bandwidth (GHz) | 0.04 |
    | Insertion Loss (dB) | 0 |
    | Order | 4 |
    | Cutoff Frequency (GHz) | 0.01 |
    | Pulse Factor (dB) | 3 |

A receiver can also enable a filter to take part in the link calculation.

## Viewing the Communication Details Report

1. After completing the transmitter property settings, click <kbd>Apply</kbd> to save the settings;

2. Right-click the **Transmitter** and select <kbd>Access</kbd>;

3. On the **Access** analysis page, select the corresponding **Receiver** object;

4. Click <kbd>Communication Details</kbd> to view the parameters and metrics computed for the communication link.

## Gaussian Antenna Usage Notes

When **Gaussian Antenna** is selected as the antenna type of the transmitter (the other transmitter parameters remain unchanged in this example), the Gaussian antenna has a narrow beamwidth and is sensitive to pointing errors. The transmitter therefore needs to be mounted on a **Sensor**, and the sensor must always point at the Facility so that the communication direction stays within the main beam of the antenna.

1. Create a **Sensor** under the satellite object, and mount the **Transmitter** under the sensor;

![Transmitter mounted to a sensor](../../zh/02-案例教程/media/3.20通信案例/image4.png)

2. Set the sensor pointing so that the transmitter points at the Facility. The related settings are shown below:

![Transmitter pointing settings](../../zh/02-案例教程/media/3.20通信案例/image5.png)
Keep the remaining parameters at their default values.

3. Perform the access analysis, and clear **Use Light Time Delay** at this point. With light time delay enabled, the link calculation direction may deviate from the current sensor pointing direction. Because the Gaussian antenna has a narrow beamwidth and is sensitive to pointing deviation, the antenna gain and EIRP results may become anomalous;

![Gaussian antenna access analysis](../../zh/02-案例教程/media/3.20通信案例/image6.png)

4. Click <kbd>Communication Details</kbd> to view the link budget results obtained with the Gaussian antenna.

![Gaussian antenna communication details report](../../zh/02-案例教程/media/3.20通信案例/image7.png)
