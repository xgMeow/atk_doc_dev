# Advanced Conjunction Analysis

Through the secondary development Connect mode, create an advanced conjunction analysis scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new satellite and setting its properties.
4. Creating a new advanced conjunction analysis object and setting its properties.
5. Viewing report data.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, Connect to ATK}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, Create the scenario}
atkConnect(conID, {S:New}, {S:/ Scenario AdvancedProximityAnalysis})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Creating a New Satellite and Setting Its Properties

```mixcode
{C:3, Insert a satellite and set its properties}
atkConnect(conID, {S:New}, {S:/ Satellite Satellite1})
atkConnect(conID, {S:SetState}, {S:*/Satellite/Satellite1 Classical HPOP "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000" 60 ICRF "13 Feb 2023 00:00:00.000" 7000137 0.01 28.5 0 0 0})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Creating a New Advanced Conjunction Analysis Object and Setting Its Properties

```mixcode
{C:4, Insert an Advanced Conjunction Analysis object and set its properties}
atkConnect(conID, {S:New}, {S:/ AdvCat AdvCat1})
{C:Set the Satellite1 object as the primary target}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Primary Add "Satellite/Satellite1" Fixed 21000.0 11000.0 6000.0 HardBodyRadius 2})
{C:Set the TLE file as the secondary target}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Secondary Add "(ATK root directory)\Help\Examples\08-二次开发案例\TLE20230212.txt" Fixed 10000.0 5000.0 3000.0})
{C:Set the filter parameters}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters OutOfDate On})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters ApogeePerigee 60000.0})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters OrbitPath Off})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters Time On})
{C:Start the computation}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Compute On})
```

::: warning Path Replacement Note
(ATK root directory) needs to be replaced with the user's actual ATK installation path.
:::

### Viewing Report Data

```mixcode
{C:5, View the report data}
atkConnect(conID, {S:Animate}, {S:* Reset})
atkConnect(conID, {S:Report_RM}, {S:*/AdvCat/AdvCat1 Style "Cat Event Message"})
```

### Saving the Scenario and Disconnecting from ATK

```mixcode
{C:6, Save the file and disconnect}
atkConnect(conID, {S:Save}, {S:/ *})
atkClose(conID)
```
