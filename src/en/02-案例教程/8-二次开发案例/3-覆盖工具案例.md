# Coverage

Through the secondary development Connect mode, create a coverage tool scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new satellite and setting its properties.
4. Starting the simulation.
5. Viewing the coverage calculation results.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

<mix-code lang="python">
# 1, Connect to ATK
conID = atkOpen()
</mix-code>

### Creating a New Scenario and Setting Its Properties

<mix-code lang="python">
# 2, Create the scenario
atkConnect(conID, 'New', '/ Scenario CoverageExample')
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Inserting a Satellite Using Orbit Generation Wizard and Setting Its Properties

<mix-code lang="python">
# 3, Insert a satellite using the Orbit Generation Wizard and set its properties
# Create a satellite
atkConnect(conID, 'New', '/ Satellite Satellite1')
# Set satellite properties with the Orbit Generation Wizard
atkConnect(conID, 'OrbitWizard', '*/Satellite/Satellite1 RepeatingGroundTrace Color Yellow TimePeriod "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000" ApproxAltitude 500000 Inclination 45 RevsToRepeat 10 LongitudeFirstAN 0')
</mix-code>

### Adding a Sensor and Setting Its Properties

<mix-code lang="python">
# 4, Add a sensor and set its properties
# Create a sensor
atkConnect(conID, 'New', '/ */Satellite/Satellite1/Sensor Sensor1')
# Set sensor properties
atkConnect(conID, 'Define', '*/Satellite/Satellite1/Sensor/Sensor1 SimpleCone 50')
</mix-code>

### Adding a Ground Station and Setting Its Properties

<mix-code lang="python">
# 5, Add a ground station and set its properties
atkConnect(conID, 'New', '/ Facility Facility1')
atkConnect(conID, 'SetPosition', '*/Facility/Facility1 Geodetic 30 110 0.0')
</mix-code>

### Starting the Simulation

<mix-code lang="python">
# 6, Start the simulation
atkConnect(conID, 'Animate', '* Start')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Computing and Viewing the Coverage Results

<mix-code lang="python">
# 7, Compute and view the coverage analysis results
# Select the coverage object
atkConnect(conID, 'Cov','*/Facility/Facility1 Asset */Satellite/Satellite1/Sensor/Sensor1 Assign')
# Compute the object coverage
atkConnect(conID, 'Cov','*/Satellite/Satellite1/Sensor/Sensor1 Access Compute "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"')
# Get the report
atkConnect(conID, 'Cov_RM', '*/Facility/Facility1 Access Compute "Coverage" "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"')
</mix-code>

### Saving the Scenario and Disconnecting from ATK

<mix-code lang="python">
# 8, Save the scenario and disconnect from ATK
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
</mix-code>
