# Coverage

Through the secondary development Connect mode, create a coverage tool scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new satellite and setting its properties.
4. Starting the simulation.
5. Viewing the coverage calculation results.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, Connect to ATK}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, Create the scenario}
atkConnect(conID, {S:New}, {S:/ Scenario CoverageExample})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Inserting a Satellite Using Orbit Generation Wizard and Setting Its Properties

```mixcode
{C:3, Insert a satellite using the Orbit Generation Wizard and set its properties}
{C:Create a satellite}
atkConnect(conID, {S:New}, {S:/ Satellite Satellite1})
{C:Set satellite properties with the Orbit Generation Wizard}
atkConnect(conID, {S:OrbitWizard}, {S:*/Satellite/Satellite1 RepeatingGroundTrace Color Yellow TimePeriod "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000" ApproxAltitude 500000 Inclination 45 RevsToRepeat 10 LongitudeFirstAN 0})
```

### Adding a Sensor and Setting Its Properties

```mixcode
{C:4, Add a sensor and set its properties}
{C:Create a sensor}
atkConnect(conID, {S:New}, {S:/ */Satellite/Satellite1/Sensor Sensor1})
{C:Set sensor properties}
atkConnect(conID, {S:Define}, {S:*/Satellite/Satellite1/Sensor/Sensor1 SimpleCone 50})
```

### Adding a Ground Station and Setting Its Properties

```mixcode
{C:5, Add a ground station and set its properties}
atkConnect(conID, {S:New}, {S:/ Facility Facility1})
atkConnect(conID, {S:SetPosition}, {S:*/Facility/Facility1 Geodetic 30 110 0.0})
```

### Starting the Simulation

```mixcode
{C:6, Start the simulation}
atkConnect(conID, {S:Animate}, {S:* Start})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Computing and Viewing the Coverage Results

```mixcode
{C:7, Compute and view the coverage analysis results}
{C:Select the coverage object}
atkConnect(conID, {S:Cov},{S:*/Facility/Facility1 Asset */Satellite/Satellite1/Sensor/Sensor1 Assign})
{C:Compute the object coverage}
atkConnect(conID, {S:Cov},{S:*/Satellite/Satellite1/Sensor/Sensor1 Access Compute "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"})
{C:Get the report}
atkConnect(conID, {S:Cov_RM}, {S:*/Facility/Facility1 Access Compute "Coverage" "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"})
```

### Saving the Scenario and Disconnecting from ATK

```mixcode
{C:8, Save the scenario and disconnect from ATK}
atkConnect(conID, {S:Save}, {S:/ *})
atkClose(conID)
```
