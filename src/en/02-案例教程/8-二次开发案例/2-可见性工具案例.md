# Access

Through the secondary development Connect mode, create an access tool scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating new satellites and setting their properties.
4. Starting the simulation.
5. Viewing the access calculation results.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

<mix-code lang="python">
# 1, Connect to ATK
conID = atkOpen()
</mix-code>

### Creating a New Scenario and Setting Its Properties

<mix-code lang="python">
# 2, Create the scenario
atkConnect(conID, 'New', '/ Scenario AccessExample')
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Creating New Satellites and Setting Their Properties

<mix-code lang="python">
# 3, Insert a satellite and set its properties
atkConnect(conID, 'New', '/ Satellite Satellite1')
atkConnect(conID, 'New', '/ Satellite Satellite2')
atkConnect(conID, 'SetState', '*/Satellite/Satellite1 Classical HPOP "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000" 60 ICRF "2023-03-11 00:00:00.000" 6878137.000 0 45 0 0 0')
atkConnect(conID, 'SetConstraint', '*/Satellite/Satellite1 AzimuthAngle Min 0 Max 180')
atkConnect(conID, 'SetConstraint', '*/Satellite/Satellite1 ElevationAngle Min -45 Max 45')
atkConnect(conID, 'SetConstraint', '*/Satellite/Satellite1 LineOfSight On')
</mix-code>

### Starting the Simulation

<mix-code lang="python">
# 4, Start the simulation
atkConnect(conID, 'Animate', '* Start')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Computing and Viewing the Access Results

<mix-code lang="python">
# 5, Compute and view the access analysis results
atkConnect(conID, 'Access','*/Satellite/Satellite1 */Satellite/Satellite2 TimePeriod "2023-03-11 00:00:00.000" "2023-03-11 11:00:00.000"')
atkConnect(conID, 'Access_RM', '*/Satellite/Satellite1 Access Compute "Access" "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"')
</mix-code>

### Saving the Scenario and Disconnecting from ATK

<mix-code lang="python">
# 6, Save the scenario and disconnect from ATK
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
</mix-code>
