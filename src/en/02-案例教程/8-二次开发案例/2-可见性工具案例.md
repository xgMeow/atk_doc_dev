# Access

Through the secondary development Connect mode, create an access tool scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating new satellites and setting their properties.
4. Starting the simulation.
5. Viewing the access calculation results.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, Connect to ATK}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, Create the scenario}
atkConnect(conID, {S:New}, {S:/ Scenario AccessExample})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Creating New Satellites and Setting Their Properties

```mixcode
{C:3, Insert a satellite and set its properties}
atkConnect(conID, {S:New}, {S:/ Satellite Satellite1})
atkConnect(conID, {S:New}, {S:/ Satellite Satellite2})
atkConnect(conID, {S:SetState}, {S:*/Satellite/Satellite1 Classical HPOP "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000" 60 ICRF "2023-03-11 00:00:00.000" 6878137.000 0 45 0 0 0})
atkConnect(conID, {S:SetConstraint}, {S:*/Satellite/Satellite1 AzimuthAngle Min 0 Max 180})
atkConnect(conID, {S:SetConstraint}, {S:*/Satellite/Satellite1 ElevationAngle Min -45 Max 45})
atkConnect(conID, {S:SetConstraint}, {S:*/Satellite/Satellite1 LineOfSight On})
```

### Starting the Simulation

```mixcode
{C:4, Start the simulation}
atkConnect(conID, {S:Animate}, {S:* Start})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Computing and Viewing the Access Results

```mixcode
{C:5, Compute and view the access analysis results}
atkConnect(conID, {S:Access},{S:*/Satellite/Satellite1 */Satellite/Satellite2 TimePeriod "2023-03-11 00:00:00.000" "2023-03-11 11:00:00.000"})
atkConnect(conID, {S:Access_RM}, {S:*/Satellite/Satellite1 Access Compute "Access" "2023-03-11 00:00:00.000" "2023-03-12 00:00:00.000"})
```

### Saving the Scenario and Disconnecting from ATK

```mixcode
{C:6, Save the scenario and disconnect from ATK}
atkConnect(conID, {S:Save}, {S:/ *})
atkClose(conID)
```
