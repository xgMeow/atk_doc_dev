# Launch Window Conjunction Analysis

Through the secondary development Connect mode, create a launch window conjunction analysis scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new launch vehicle and importing its trajectory from an ephemeris file.
4. Performing launch window conjunction analysis.
5. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, Connect to ATK}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, Create the scenario}
atkConnect(conID, {S:New}, {S:/ Scenario LaunchWindowAnalysis})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Creating a New Launch Vehicle and Importing Its Trajectory from an Ephemeris File

```mixcode
{C:3, Insert a launch vehicle and set its properties}
atkConnect(conID, {S:New}, {S:/ LaunchVehicle LaunchVehicle1})
atkConnect(conID, {S:SetState}, {S:*/LaunchVehicle/LaunchVehicle1 FromFile "(ATK root directory)\Help\Examples\08-二次开发案例\LaunchVehicle.e"})
```

::: warning Path Replacement Note
(ATK root directory) needs to be replaced with the user's actual ATK installation path.
:::
