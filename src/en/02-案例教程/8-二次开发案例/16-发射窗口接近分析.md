# 发射窗口接近分析案例

通过二次开发 Connect 模式，创建发射窗口接近分析场景，必须保持 ATK 为打开状态，具体命令分类包括：

1. 与 ATK 进行连接。
2. 新建场景并设置场景属性。
3. 新建火箭并从星历文件导入火箭弹道。
4. 进行发射窗口接近分析。
5. 保存场景后与 ATK 断开连接。

## 脚本展示

### 与 ATK 进行连接

```mixcode
{C:1, 与 ATK 进行连接}
conID = atkOpen()
```

### 新建场景并设置场景属性

```mixcode
{C:2, 创建任务场景}
atkConnect(conID, {S:New}, {S:/ Scenario LaunchWindowAnalysis})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### 新建火箭并从星历文件导入火箭弹道

```mixcode
{C:3, 插入火箭并进行属性设置}
atkConnect(conID, {S:New}, {S:/ LaunchVehicle LaunchVehicle1})
atkConnect(conID, {S:SetState}, {S:*/LaunchVehicle/LaunchVehicle1 FromFile "(ATK根目录)\Help\Examples\08-二次开发案例\LaunchVehicle.e"})
```

::: warning 路径替换说明
(ATK根目录) 需要替换为用户实际的 ATK 安装路径。
:::
