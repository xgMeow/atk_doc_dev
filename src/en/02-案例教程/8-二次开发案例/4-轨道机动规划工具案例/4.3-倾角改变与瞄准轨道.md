# Inclination Change Example

Through the secondary development Connect mode, create an inclination change scenario. The specific details are the same as "Example 3-9 - Giant Constellation Design Example". ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new satellite and setting its properties.
4. Creating a new maneuver planning mission sequence and setting its properties.
5. Running the maneuver planning sequence.
6. Viewing report data.
7. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, 与 ATK 进行连接}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, 建任务场景}
atkConnect(conID, {S:New}, {S:/ Scenario InclinationChange})
{C:设置仿真时间段}
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "2022-11-05 00:00:00.000000" "2022-11-08 00:00:00.000000"})
{C:初始化仿真}
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Creating a New Satellite and Setting Its Propagator to Maneuver Planning

```mixcode
{C:3，创建卫星对象}
atkConnect(conID, {S:New}, {S:/ Satellite SatInclinationChange})
{C:设置卫星的轨道预报器为机动规划}
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetProp})
```

### Setting Satellite Orbit Properties

atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange InsertSegment MainSequence.SegmentList.Target_Sequence2.SegmentList.- Maneuver})

{C:5，设置初始段属性}
{C:设置坐标系为 Earth J2000}
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.CoordinateSystem "CentralBody/Earth J2000"})
{C:设置坐标类型为 Keplerian}
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Initial_State.CoordinateType "Keplerian"})

{C:设置预报段的颜色}

{C:设置中心天体}
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Propagate.CentralBodyCode 2})
{C:设置轨道预报段的引力模型及摄动}
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Propagate.ForceModel.Gravity.GravModel JGM3})
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Propagate.ForceModel.Gravity.MaxDegree 20})
atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Propagate.ForceModel.Gravity.MaxOrder 20})
{C:设置大气阻力摄动模型}

atkConnect(conID, {S:Astrogator}, {S:*/Satellite/SatInclinationChange SetValue MainSequence.SegmentList.Propagate.ForceModel.Drag.AtmModel NRLMSISE00})

{C:设置停止条件的容忍度（例如0.0001秒）}

{C:设置推力坐标轴卫星 VNC(Earth)}
