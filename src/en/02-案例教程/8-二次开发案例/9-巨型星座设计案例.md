# Large Constellation Design

Through the secondary development Connect mode, create a large constellation scenario. The specific details are the same as "Example 3-9 - Large Constellation Design Example". ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Designing the large constellation.
4. Viewing report data.
5. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

```mixcode
{C:1, Connect to ATK}
conID = atkOpen()
```

### Creating a New Scenario and Setting Its Properties

```mixcode
{C:2, Create the scenario}
atkConnect(conID, {S:New}, {S:/ Scenario HugeConstellation})
{C:Set the simulation time period}
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "2024-03-18 00:00:00.000" "2024-03-19 00:00:00.000"})
{C:Initialize the simulation}
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Designing the Large Constellation

```mixcode
{C:3, Create the seed satellite}
atkConnect(conID, {S:New}, {S:/ Satellite Satellite1})
{C:Set up the Walker Delta constellation}
atkConnect(conID, {S:WalkerDelta}, {S:*/Satellite/Satellite1 Semimajoraxis 6678137 Eccentricity 0 Inclination 65 RAAN 0 ArgumentOfPerigee 180 TrueAnomaly 180 NumPlanes 30 NumSatsPerPlane 10 InterPlanePhaseIncrement 1 RAANSpread 360 ColorByPlane Yes Yes})
```

### Running the Simulation

```mixcode
{C:4, Run the simulation}
atkConnect(conID, {S:Animate}, {S:* Start})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### Saving the Scenario and Disconnecting from ATK

```mixcode
{C:5, Save the file and disconnect}
atkConnect(conID, {S:Save}, {S:/ *})
atkClose(conID)
```
