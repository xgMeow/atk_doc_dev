# Large Constellation Design

Through the secondary development Connect mode, create a large constellation scenario. The specific details are the same as "Example 3-9 - Large Constellation Design Example". ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Designing the large constellation.
4. Viewing report data.
5. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

<mix-code lang="python">
# 1, Connect to ATK
conID = atkOpen()
</mix-code>

### Creating a New Scenario and Setting Its Properties

<mix-code lang="python">
# 2, Create the scenario
atkConnect(conID, 'New', '/ Scenario HugeConstellation')
# Set the simulation time period
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2024-03-18 00:00:00.000" "2024-03-19 00:00:00.000"')
# Initialize the simulation
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Designing the Large Constellation

<mix-code lang="python">
# 3, Create the seed satellite
atkConnect(conID, 'New', '/ Satellite Satellite1')
# Set up the Walker Delta constellation
atkConnect(conID, 'WalkerDelta', '*/Satellite/Satellite1 Semimajoraxis 6678137 Eccentricity 0 Inclination 65 RAAN 0 ArgumentOfPerigee 180 TrueAnomaly 180 NumPlanes 30 NumSatsPerPlane 10 InterPlanePhaseIncrement 1 RAANSpread 360 ColorByPlane Yes Yes')
</mix-code>

### Running the Simulation

<mix-code lang="python">
# 4, Run the simulation
atkConnect(conID, 'Animate', '* Start')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Saving the Scenario and Disconnecting from ATK

<mix-code lang="python">
# 5, Save the file and disconnect
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
</mix-code>

## Complete Script

<mix-code lang="python">
# 1, Connect to ATK
conID = atkOpen()

# 2, Create the scenario
atkConnect(conID, 'New', '/ Scenario HugeConstellation')
# Set the simulation time period
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2024-03-18 00:00:00.000" "2024-03-19 00:00:00.000"')
# Initialize the simulation
atkConnect(conID, 'Animate', '* Reset')

# 3, Create the seed satellite
atkConnect(conID, 'New', '/ Satellite Satellite1')
# Set up the Walker Delta constellation
atkConnect(conID, 'WalkerDelta', '*/Satellite/Satellite1 Semimajoraxis 6678137 Eccentricity 0 Inclination 65 RAAN 0 ArgumentOfPerigee 180 TrueAnomaly 180 NumPlanes 30 NumSatsPerPlane 10 InterPlanePhaseIncrement 1 RAANSpread 360 ColorByPlane Yes Yes')

# 4, Run the scenario
atkConnect(conID, 'Animate', '* Start')
atkConnect(conID, 'Animate', '* Reset')

# 5, Save the scenario
atkConnect(conID, 'Save', '/ *')
# Disconnect from ATK
atkClose(conID)
</mix-code>
