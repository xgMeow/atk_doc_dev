# Getting Started

Through the secondary development Connect mode, create an introductory scenario. ATK must remain open. The specific command categories include:

1. Connecting to ATK.
2. Creating a new scenario and setting its properties.
3. Creating a new satellite and setting its properties.
4. Viewing 2D and 3D scenes.
5. Viewing output reports.
6. Saving the scenario and disconnecting from ATK.

## Script Demonstration

### Connecting to ATK

<mix-code lang="python">
conID = atkOpen()
</mix-code>

### Creating a New Scenario and Setting Its Properties

<mix-code lang="python">
# 2, Create the scenario and set its properties
atkConnect(conID, 'New', '/ Scenario SimpleExample')
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Creating a New Satellite and Setting Its Properties

<mix-code lang="python">
# 3, Insert a satellite and set its properties
atkConnect(conID, 'New', '/ Satellite Satellite1')
atkConnect(conID, 'SetState', '*/Satellite/Satellite1 Classical HPOP "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000" 60 ICRF "2026-03-06 00:00:00.000" 6878137.000 0 0 0 0 0')
</mix-code>

### Creating 2D and 3D Scenes

<mix-code lang="python">
# 4, Create the 2D and 3D windows
atkConnect(conID, 'Window2D','/ Create')
atkConnect(conID, 'Window3D','/ CreateWindow Normal')
atkConnect(conID, 'Animate', '* Reset')
</mix-code>

### Viewing Output Reports

<mix-code lang="python">
# 5, View the output reports
atkConnect(conID,'Report_RM', '*/Satellite/Satellite1 Style "J2000 Position Velocity"  TimePeriod "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"')
</mix-code>

### Saving the Scenario and Disconnecting from ATK

<mix-code lang="python">
# 6, Save the scenario and disconnect from ATK
atkConnect(conID, 'Save', '/ *')
atkClose(conID)
</mix-code>

## Complete Script

<mix-code lang="python">
conID = atkOpen()
# 2, Create the scenario and set its properties
atkConnect(conID, 'New', '/ Scenario SimpleExample')
atkConnect(conID, 'SetAnalysisTimePeriod', '* "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000"')
atkConnect(conID, 'Animate', '* Reset')
# 3, Insert a satellite and set its properties
atkConnect(conID, 'New', '/ Satellite Satellite1')
atkConnect(conID, 'SetState', '*/Satellite/Satellite1 Classical HPOP "2026-03-06 00:00:00.000" "2026-03-09 00:00:00.000" 60 ICRF "2026-03-06 00:00:00.000" 6878137.000 0 0 0 0 0')
# 4, Create the 2D and 3D windows
atkConnect(conID, 'Window2D','/ Create')
atkConnect(conID, 'Window3D','/ CreateWindow Normal')

# 5, View the output reports

atkConnect(conID, 'Save', '/ *')

</mix-code>
