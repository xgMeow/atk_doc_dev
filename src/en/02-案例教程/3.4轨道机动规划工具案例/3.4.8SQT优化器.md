# SQT Optimizer

## Scenario Description

This example demonstrates the use of the SQT optimizer to raise a satellite's perigee through a single finite-thrust maneuver.

## Mission Control Sequence Description

To raise a parking orbit with a radius of 6778 km to a target orbit with a perigee radius of 10000 km, we need to construct the following mission control sequence:

- An **Initial State Segment**: defines the initial parking orbit with a radius of 6778 km;
- A **Target Sequence Segment**: targets the desired orbit;
- A **Propagation Segment**: propagates the spacecraft's initial orbit to a specified true anomaly;
- A **Maneuver Segment**: an impulsive maneuver to place the spacecraft into the target orbit;
- A **Propagation Segment**: propagates the orbit until it reaches perigee.

## Creating the Scenario

1. Run ATK software, select the **Start** toolbar at the top, and click <kbd>New</kbd> to create a scenario file named "SQT".

2. In the **ATK: New Scenario Wizard** dialog, set the **Start Epoch** and **End Epoch**:

   | Start Epoch (UTCG_MM)      | End Epoch (UTCG_MM)        |
   | -------------------------- | -------------------------- |
   | 2026-04-02 00:00:00.000 | 2026-04-03 00:00:00.000 |

3. Click <kbd>OK</kbd> to complete scenario creation.

## Inserting the Satellite

1. Click <kbd>Insert</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image1.png" alt="" no-view /> under the **Start** toolbar to open the **Insert Object** dialog.

2. Select the **Satellite** object, then select **Insert Default Type** as the insertion method, and click <kbd>Insert…</kbd> to insert the object into the scenario.

## Defining the Initial Orbit Parameters

1. Double‑click the satellite object to open the **Properties** settings interface.

2. Click the **Orbit Propagator** drop‑down and select **Maneuver Planning**. If the mission control sequence already has a default initial segment, define it directly; otherwise, click <kbd>New</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image2.png" alt="" no-view /> to add an "Initial State Segment" <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image3.jpeg" alt="" no-view /> and name it "InitialState".

3. Select the "InitialState" sequence, click the <kbd>…</kbd> button to the right of **Coordinate System** to open the **Select Coordinate System** dialog, select **Earth** in the left panel and **ICRF** in the right panel, then click <kbd>OK</kbd>.

4. Click the **Coordinate Type** drop‑down and select **Orbital Elements**, then set the orbital elements as follows:

   | Orbital Element          | Value    |
   | ------------------------ | -------- |
   | Semi-major Axis          | 6778 km  |
   | Eccentricity             | 0.4      |
   | Inclination              | 45 deg   |
   | RAAN                     | 0 deg    |
   | Argument of Perigee      | 0 deg    |
   | True Anomaly             | 0 deg    |

5. Click <kbd>Apply</kbd> at the bottom right to complete the initial orbit parameter settings.

## Setting Up the Target Sequence Segment

1. **Define the Target Sequence Segment**

   - Click <kbd>New</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image2.png" alt="" no-view /> to add a **Target Sequence Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image4.jpeg" alt="" no-view />.

   - Under the Target Sequence Segment, add in order: a first **Propagation Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image5.jpeg" alt="" no-view />, a **Maneuver Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image6.jpeg" alt="" no-view />, and a second **Propagation Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image5.jpeg" alt="" no-view />.

2. **First Propagation Segment Settings**

   - Delete the existing stopping condition and create a new one: True Anomaly, with a **Trigger Value** of "170", keeping other parameters at default.

3. **Maneuver Segment Settings**

   - Right‑click the maneuver segment, select **Constraint Configuration…**, double‑click to select **Maneuver - Delta-V** as the target variable, and click <kbd>OK</kbd>.

   - Click the **Maneuver Type** drop‑down and select **Impulse**; click the <kbd>…</kbd> button to the right of **Thrust Axes** and select **VNC**; check the **Cartesian Coordinates** checkbox.

   - Click the check icon <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image7.png" alt="" no-view /> behind the **Delta-V Vx** text field to set it as a **Design Variable** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image8.png" alt="" no-view />.

4. **Second Propagation Segment Settings**

   - Right‑click this propagation segment, select **Constraint Configuration…**, double‑click to select **Spherical Elements - Radius Magnitude** as the target variable, and click <kbd>OK</kbd>.

   - Delete the existing stopping condition and create a new one: Periapsis, keeping other parameters at default.

5. **Target Sequence Segment Settings**

   Select the Target Sequence Segment, delete the existing targeter, click **Configuration** — <kbd>New</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image9.png" alt="" no-view />, select **Sequential Quadratic Programming**, and click <kbd>OK</kbd>. Double‑click the **Configuration - Sequential Quadratic Programming** entry to enter the targeter settings interface.

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used.

     | Control Variable       | Constraint        |
     | ---------------------- | ----------------- |
     | ImpulseX               | StateCalcDeltaV   |
     | TrueAnomaly.TripValue  | StateCalcRMag     |

   - Select "StateCalcDeltaV" and set the parameters as follows, keeping others at default:

     | Control Variable | Constraint                    |
     | ---------------- | ----------------------------- |
     | Minimum          | -1.10000000000000e+20 m/s     |
     | Maximum          | -1.10000000000000e+20 m/s     |
     | Expected Value   | 0                             |
     | Type             | Minimize                      |

   - Select "StateCalcRMag" and set the parameters as follows, keeping others at default:

     | Control Variable | Constraint       |
     | ---------------- | ---------------- |
     | Minimum          | 10000000 m       |
     | Maximum          | 10000000 m       |
     | Expected Value   | 0                |
     | Type             | Constraint       |

   - Click <kbd>OK</kbd>.

## Running the Mission Control Sequence

After the entire mission control sequence is constructed, click the white box <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image10.png" alt="" no-view /> to the right of each **Propagation Segment** and **Maneuver Segment** to select a color. The complete mission control sequence is shown below:

   - Click <kbd>Run</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image12.png" alt="" no-view /> to start computing the mission control sequence. Click <kbd>Display</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image13.png" alt="" no-view /> to view the run results.

   ![Run Results Display](../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image14.png)

2. **3D View Display**

   Click <kbd>3D View</kbd> <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.8SQT优化器/image15.png" alt="" no-view /> under the **Views** toolbar at the top. By operating the time slider, you can view the orbit shape.
