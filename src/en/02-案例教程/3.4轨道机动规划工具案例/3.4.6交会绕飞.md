# Rendezvous and Fly-Around

<PathViewer
  :relative-paths="files"
/>

## Scenario Description

Rendezvous and fly-around refers to the process in which a spacecraft (the servicer) approaches a target spacecraft along a predetermined trajectory and performs a fly-around mission, typically used for on-orbit observation, resupply, or docking exercises.

This example demonstrates how to use impulsive maneuvers and targeting sequence planning to achieve spacecraft approach from low Earth orbit to a target spacecraft and perform a fly-around at a specified relative position. The scenario assumes:

- The servicer spacecraft is initially in a low-Earth circular orbit with an altitude of approximately 6570 km and an inclination of approximately 98.5°;

- The target spacecraft is in a similar orbit with an altitude of approximately 6570 km, an inclination of approximately 98.5°, but with a phase offset;

- The spacecraft uses impulsive maneuvers for relative position adjustment to achieve fly-around approach, and ultimately maintains the specified relative position and velocity constraints.

## Mission Control Sequence Description

To complete the rendezvous and fly-around mission, the following mission control sequence needs to be constructed:

- An **Initial State Segment**: defines the initial orbital parameters of the servicer spacecraft;

- A **Propagation Segment**: propagates the orbit forward to provide predictive information for the maneuver segment;

- A **Target Sequence Segment**: contains one or more impulsive maneuvers to adjust the relative position with respect to the target spacecraft;

- A **Propagation Segment**: propagates the spacecraft's orbit to the periapsis position of the fly-around;

- A **Target Sequence Segment**: performs fine-tuning maneuvers for the fly-around endpoint to ensure that target constraints (relative position, relative velocity) are satisfied;

- A **Propagation Segment**: propagates the fly-around trajectory to verify that the final orbit and state meet the design requirements.

## Creating the Scenario

1. Run ATK.exe and click <kbd>Create a new scenario file</kbd> to create a scenario named "LEO_rendezvous".

2. Set the simulation time. In the **ATK: New Scenario Wizard**, set:

   | Start Epoch | End Epoch |
   | --- | --- |
   | 2018-07-01 16:00:00.000 | 2018-07-03 16:00:00.000 |

3. Click <kbd>OK</kbd> to complete scenario creation.

## Creating Satellite Objects

1. **Create and Edit Satellite Objects**

   - In the toolbar, click <kbd>Insert</kbd> under **Start** to create satellite objects;

   - Select **Scenario Object** — **Satellite** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image98.png" alt="Satellite" no-view />, **Insertion Method** — **Insert Default Type**, click <kbd>Insert…</kbd> to insert Satellite 1 and Satellite 2, then click <kbd>Close</kbd>.

## Satellite 1 Initial Orbit Parameter Settings

1. **Orbit Propagator Settings**

   In the left **Object** panel, right‑click **Satellite 1**, select **Properties** to open the satellite parameter settings interface, and select **Orbit Propagator** — **Maneuver Planning**.

2. **Define the Initial Segment**

   If the mission control sequence already has a default initial segment, define it directly; otherwise, click the <kbd>New</kbd> button to add an **Initial State Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image401.jpeg" alt="Initial Segment Icon" no-view />.

3. **Orbit Epoch Settings**

   Set the **Orbit Epoch (UTCG_MM)** — "2018-07-01 16:00:00.000".

4. **Coordinate-Related Settings**

   Select **Coordinate System** — **Earth ICRF**, **Coordinate Type** — **Orbital Elements**, and set the orbital elements as follows:

   | Parameter | Value |
   | --- | --- |
   | Apogee Altitude | 500 km |
   | Perigee Altitude | 500 km |
   | Inclination | 98.5° |
   | RAAN | 90° |
   | Argument of Perigee | 0° |
   | True Anomaly | 0° |

## Long-Term Propagation Segment Properties Settings

1. **Orbit Propagator Settings**

   - Click **Orbit Propagation** — <kbd>Advanced Settings…</kbd>;

   - Select **Central Body** — **Earth**, select **Gravity** — **Model** — **JGM3**, check **Atmospheric Drag Perturbation**, check **Solar Radiation Pressure**, check **Third-Body Gravity** — **Sun**, **Moon**, and select **Point-Mass** as the model type;

   - Click <kbd>OK</kbd>.

2. **Stopping Condition Settings**

   - In the stopping conditions section, click the <kbd>New</kbd> icon, select **CAsStopDuration** (Duration) as the stopping condition (if a default stopping condition already exists, set the parameters directly);

   - Set the **Trigger Value** to **172800 sec**, and the tolerance to 0.0001.

## First Rendezvous Targeting Sequence Settings

1. **Define the Target Sequence Segment**

   - Click the <kbd>New</kbd> button to add a **Target Sequence Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image471.jpeg" alt="Target Sequence Segment" no-view />;

   - Click the <kbd>New</kbd> button to embed a **Maneuver Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image481.jpeg" alt="Maneuver Segment Icon" no-view /> under the **Target Sequence Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image471.jpeg" alt="Target Sequence Segment" no-view />;

   - Click the <kbd>New</kbd> button to add a **Propagation Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image421.jpeg" alt="Propagation Segment Icon" no-view /> after the **Maneuver Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image481.jpeg" alt="Maneuver Segment Icon" no-view />.

2. **Select Maneuver Variables**

   - Select **Maneuver Type** — **Impulse**, **Thrust Axes** — **RIC**, and coordinate type **Cartesian**;

   - Click the check icon <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image105.png" alt="Icon" no-view /> behind the **Vx Vy Vz** text field to set them as design variables <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image106.png" alt="Design Variable Icon" no-view />.

3. **Define the Propagation Segment**

   - Click **Orbit Propagation** — <kbd>Advanced Settings…</kbd> to enter the orbit propagator;

   - Select **Central Body** — **Earth**, select **Gravity** — **Model** — **JGM3**, check **Atmospheric Drag Perturbation**, check **Solar Radiation Pressure**, check **Third-Body Gravity** — **Sun**, **Moon**, and select **Point-Mass** as the model type;

   - Click <kbd>OK</kbd>;

   - Select **CAsStopDuration** (Duration) as the stopping condition (if a default stopping condition already exists, set the parameters directly);

   - Set the **Trigger Value** to **36000 sec**, and the tolerance to 0.0001;

   - Right‑click this propagation segment, select **Constraint Configuration…**, double‑click to select **Cartesian Coordinates** — **Position X**, **Position Y**, **Position Z** as target variables; set **Constraint Parameters** - Coordinate System to **Satellite 1 RIC**. Click <kbd>OK</kbd>.

4. **Configure the Targeter**

   - Select the **Target Sequence Segment**, click **Configuration** — <kbd>New</kbd>, select **Differential Correction**, and click <kbd>OK</kbd>; repeat to create three **Differential Correction** entries;

   - Set up the **first differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseY | StateCalcY |

   - In the **Constraint** — **Expected Value** column, enter the expected value as **1000 m**, **Convergence Tolerance** as **1 m**, and keep other parameters at default;

   - Set up the **second differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseX, ImpulseY | StateCalcX, StateCalcY |

   - In the **Constraint** — **Expected Value** column, enter the expected value for StateCalcX as **0 m**, **Convergence Tolerance** as **1 m**; keep StateCalcY the same as before, and other parameters at default;

   - Set up the **third differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseX, ImpulseY, ImpulseZ | StateCalcX, StateCalcY, StateCalcZ |

   - In the **Constraint** — **Expected Value** column, enter the expected value for StateCalcZ as **0 m**, **Convergence Tolerance** as **1 m**, and keep StateCalcX and StateCalcY consistent with the previous settings.

## Fly-Around Endpoint Targeting Sequence Settings

1. **Define the Target Sequence Segment**

   - Click the <kbd>New</kbd> button to add a **Target Sequence Segment 1** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image471.jpeg" alt="Target Sequence Segment" no-view />;

   - Click the <kbd>New</kbd> button to embed a **Maneuver Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image481.jpeg" alt="Maneuver Segment Icon" no-view /> under the **Target Sequence Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image471.jpeg" alt="Target Sequence Segment" no-view />;

   - Click the <kbd>New</kbd> button to add a **Propagation Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image421.jpeg" alt="Propagation Segment Icon" no-view /> after the **Maneuver Segment** <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image481.jpeg" alt="Maneuver Segment Icon" no-view />.

2. **Select Maneuver Variables**

   - Select **Maneuver Type** — **Impulse**, **Thrust Axes** — **RIC**, and coordinate type **Cartesian**;

   - Click the check icon <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image105.png" alt="Icon" no-view /> behind the **Vx Vy Vz** text field to set them as design variables <img src="../../../zh/02-案例教程/3.4轨道机动规划工具案例/media/3.4.6交会绕飞/image106.png" alt="Design Variable Icon" no-view />;

   - Right‑click this maneuver segment, select **Constraint Configuration…**, select **Cartesian Coordinates** — **Velocity Z**, and set the coordinate system to **Satellite 1 RIC**; select **Formation** — **Relative Mean Semi-major Axis**, with reference spacecraft set to **Satellite 1** and central body set to **Earth**.

3. **Define the Propagation Segment**

   - Click **Orbit Propagation** — <kbd>Advanced Settings…</kbd> to enter the orbit propagator;

   - Select **Central Body** — **Earth**, select **Gravity** — **Model** — **JGM3**, check **Atmospheric Drag Perturbation**, check **Solar Radiation Pressure**, check **Third-Body Gravity** — **Sun**, **Moon**, and select **Point-Mass** as the model type;

   - Click <kbd>OK</kbd>;

   - Select **CAsStopYZPlaneCross** (YZ Plane Crossing) as the stopping condition;

   - Set the **Tolerance** to **1e-6**, trigger condition to **Decreasing Crossing**, **Repeat Count** to **1**, and coordinate system to **Satellite 1 RIC**;

   - Right‑click this propagation segment, select **Constraint Configuration…**, double‑click to select **Cartesian Coordinates** — **Position Y** as the target variable; set **Constraint Parameters** - Coordinate System to **Satellite 1 RIC**. Click <kbd>OK</kbd>.

4. **Configure the Targeter**

   - Select the **Target Sequence Segment**, again requiring **three differential corrections**;

   - Set up the **first differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseX, ImpulseY | CStateCalcRelMeanSemiMajorAxis, StateCalcY |

   - In the **Constraint** — **Expected Value** column, enter the expected value for **CStateCalcRelMeanSemiMajorAxis** as **0 m**, **Convergence Tolerance** as **0.01 m**; for StateCalcY, enter the expected value as **-1000 m**, **Convergence Tolerance** as **1 m**; keep other parameters at default;

   - Set up the **second differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseZ | StateCalcVz |

   - In the **Constraint** — **Expected Value** column, enter the expected value for StateCalcVz as **0 m/s**, **Convergence Tolerance** as **0.001 m/s**, and keep other parameters at default;

   - Set up the **third differential correction**: double‑click **Configuration** — **Configuration Type** — **Differential Correction** to enter the targeter settings interface;

   - Check the checkboxes under the **Applied** column in both the **Control Variables** and **Constraints** sections to select the variables and constraints to be used;

   | Control Variable | Constraint |
   | --- | --- |
   | ImpulseX, ImpulseY, ImpulseZ | StateCalcVz, CStateCalcRelMeanSemiMajorAxis, StateCalcY |

   - **Constraint** — **Expected Value** settings are the same as above.
