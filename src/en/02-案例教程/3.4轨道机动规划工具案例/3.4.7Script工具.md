# Script Tool

## Scenario Description

The Script tool allows you to perform your own calculations without using external tools.
This tutorial is based on the "Hohmann Transfer" exercise, applying the Script tool to provide initial guesses for the two impulsive maneuver magnitudes, before the propagator converges without the script tool.

## Creating the Scenario

1. Run ATK.exe and click <kbd>Open a scenario file</kbd>;

2. Open the scenario <kbd>HohmannTransfer</kbd> under the path <kbd>'Help\\Examples\\01-霍曼转移'</kbd>;

3. Create a new <kbd>Segment</kbd> before the Mission Control Sequence (MCS) initial segment, and place all existing maneuver planning segments under the <kbd>Segment</kbd>, making sure not to change the original order of the segments.

## Adding Constant Parameters

Create two constant parameters to specify the initial and final semi-major axes.

1. In the Segment interface, click <kbd>New</kbd> to create a new parameter. Name the new parameter "initial_a"; set the type to "Integer"; set the value to "6700000" to match the scenario;

2. Create a second new parameter in the same way. Name the new parameter "final_a"; set the type to "Integer"; set the value to "42164000" to match the scenario.

## Applying Parameters

"initial_a" and "final_a" are just constants. You need to set the initial semi-major axis and the desired apoapsis radius to use the values of these parameters.

1. Create a new parameter and name it "a0". Click <kbd>Edit</kbd> to set the object property, select <kbd>Inner Orbit.InitialState.Keplerian.SMajAx</kbd>, which selects the semi-major axis of the initial segment;

2. Create a new parameter and name it "a1". Click <kbd>Edit</kbd> to set the object property, select <kbd>Start Transfer.Profiles.Differential Correction 1.Results["DV1.Results.CStateCalcRadiusOfApoapsis"].Desired</kbd>, which selects the desired apoapsis radius targeted by the first differential correction.

## Adding Computed Parameters

Add two parameters to provide initial guesses for the two impulsive maneuver values.

1. Create a new parameter and name it "dv1_guess". Click <kbd>Edit</kbd> to set the object property, select <kbd>Start Transfer.DV1.Burn.Cartesian.X</kbd>, which selects the X-direction impulsive maneuver component in the "Start Transfer" targeting sequence;

2. Create a new parameter and name it "dv2_guess". Click <kbd>Edit</kbd> to set the object property, select <kbd>Final Transfer.DV2.Burn.Cartesian.X</kbd>, which selects the X-direction impulsive maneuver component in the "Final Transfer" targeting sequence.

## Comparing Guesses with Differential Correction Convergence Results

1. Run the maneuver planning mission sequence and view the guess values for "dv1_guess" and "dv2_guess" on the Segment page:

   | dv1_guess (m/s)   | dv2_guess (m/s)    |
   | ----------------- | ------------------ |
   | 2419.50136969004  | 1464.55506118262   |

2. View the converged results of the two impulse values in the targeting sequences:

   | Vx1 (m/s)             | Vx2 (m/s)             |
   | --------------------- | --------------------- |
   | 2417.849204235968955  | 1464.555061182624513  |

   The results show that the values calculated by the Script tool are essentially consistent with the differential correction convergence results.
