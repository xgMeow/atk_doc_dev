# Launch Window Conjunction Analysis

## Scenario Description

This example demonstrates conjunction analysis within a rocket launch window and presents the results.

## Creating the Scenario

1. Run ATK software, select the <kbd>Start</kbd> toolbar at the top, and click the <kbd>New</kbd> button to create a scenario file named **Rocket Launch Window Analysis**.

2. In the **ATK: New Scenario Wizard** dialog, set the **Start Epoch** and **End Epoch** as follows:

   | Start Epoch (UTCG_MM)    | End Epoch (UTCG_MM)      |
   |:------------------------:|--------------------------|
   | 2023-02-13 00:00:00.000 | 2023-02-18 00:00:00.000 |

3. Click <kbd>OK</kbd> to complete scenario creation.

## Inserting the Launch Vehicle and Setting Properties

1. Click the <kbd>Insert</kbd> button under the <kbd>Start</kbd> toolbar to open the **Insert Object** page.

2. Select the **Launch Vehicle** object, then select **Insert Default Type** as the insertion method, and click the <kbd>Insert…</kbd> button to insert the object into the scenario.

3. Double‑click the newly inserted **Launch Vehicle** object to open the **Properties** settings interface.

4. Click the **Orbit Propagator** drop‑down and select **STK Ephemeris**.

5. Click the <kbd>…</kbd> button to the right of **Ephemeris File**, select the <PathCopy :entry="launchVehicleFile" /> file in the system file manager, and click the <kbd>Open</kbd> button to load it into ATK.

6. Click the <kbd>Apply</kbd> button at the bottom right of the **Properties** page to complete the property settings.

## Launch Window Conjunction Analysis

1. In the left object view, select the **Launch Vehicle** object, then select the <kbd>Launch Vehicle</kbd> toolbar at the top and click <kbd>Launch Window Conjunction Analysis</kbd>.

2. In the **Launch Window** section, set the **Start Epoch** and **End Epoch** respectively to:

   | Start Epoch (UTCG_MM)    | End Epoch (UTCG_MM)      |
   | ------------------------ | ------------------------ |
   | 2023-02-13 00:00:00.000 | 2023-02-18 00:00:00.000 |

3. Click the <kbd>…</kbd> button under **Space Object Catalog File**, select the <PathCopy :entry="tleFile" /> file in the system file manager, and click the <kbd>Open</kbd> button to load it into ATK. Keep all other parameters at their default settings.

4. Click the <kbd>Compute</kbd> button.

## Result Analysis

After computation completes, the conjunction event results will be displayed in the **Results** section below.

![Results Display](../../zh/02-案例教程/media/3.16发射窗口接近分析案例/ima03058_cmc.png)

Click the <kbd>Detailed</kbd> button in the **Report** section to display detailed information about the conjunction events.

![Conjunction Event Results Display](../../zh/02-案例教程/media/3.16发射窗口接近分析案例/ima030510_cmc.png)

Click the <kbd>Clear Intervals</kbd> button in the **Report** section, and a file save window will appear, allowing you to save the `Clear Intervals.txt` file to the desired location.

![Saved Launch Window Clear Intervals.txt File](../../zh/02-案例教程/media/3.16发射窗口接近分析案例/ima030512_cmc.png)
