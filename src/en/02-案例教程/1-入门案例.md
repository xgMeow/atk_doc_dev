# Getting Started

This tutorial introduces how to create a mission scenario and objects, generate reports, and save your work.

## Creating a Mission Scenario

1. Run ATK.exe and click <kbd>New Scenario</kbd>;

2. In the **New Scenario Wizard** dialog, set the scenario **Name** to `SimpleExample`;

3. Set the scenario time period (you may choose any time frame, not necessarily the same as the tutorial):

| Start Epoch (UTCG)          | Stop Epoch (UTCG)           |
| --------------------------- | --------------------------- |
| 2026-03-06 00:00:00.000     | 2026-03-07 00:00:00.000     |

4. Click <kbd>OK</kbd> to create the scenario.

## Creating a Satellite Object

1. In the toolbar, click <kbd>Start</kbd> and select <img src="../../zh/02-案例教程/media/3.1入门案例/image8.png" alt="" no-view /> to create an object;

2. Select **Scenario Object** → **Satellite**, and choose **Insert Method** → **Insert Default Type**;

3. Click <kbd>Insert...</kbd> to insert a satellite;

4. Click <kbd>Close</kbd> to close the **Insert Object** dialog.

## Modifying Satellite Object Properties

1. Select **Satellite1**, right-click and choose <kbd>Properties</kbd>, or double-click to open the **Properties** page;

2. In **Basic - Orbit - Coordinate System**, select **ICRF** or **J2000**; for **Coordinate Type**, select **Classical Elements**. Modify the orbital elements to the following values:

| Classical Element      | Value        |
| ---------------------- | ------------ |
| Semi-major Axis (m)    | 6878137.000  |
| Eccentricity           | 0.0          |
| Inclination (deg)      | 45.0         |
| RAAN (deg)             | 0            |
| Arg of Perigee (deg)   | 0            |
| True Anomaly (deg)     | 0            |

3. Click <kbd>Apply</kbd> to save the changes;

4. Click **Orbit Generation Wizard**, and select **Orbit Type** as **Circular Orbit**;

5. Select **Satellite1** and click the color button <img src="../../zh/02-案例教程/media/3.1入门案例/image10.png" alt="" no-view /> next to its name to quickly change the label color.

## Viewing the 2D and 3D Scenes

1. Open the 2D and 3D view windows:

Click <kbd>View</kbd> and select <img src="../../zh/02-案例教程/media/3.1入门案例/image11.png" alt="" no-view /> to display the 2D view;

Click <kbd>View</kbd> and select <img src="../../zh/02-案例教程/media/3.1入门案例/image12.png" alt="" no-view /> to display the 3D view;

2. Click <kbd>Start</kbd> <img src="../../zh/02-案例教程/media/3.1入门案例/image13.jpeg" alt="" no-view /> to animate the orbit in both 2D and 3D views over time;

3. Drag the yellow slider in the **Time View** to inspect the orbital scenario at a specific epoch.

![3D Orbit View](../../zh/02-案例教程/media/3.1入门案例/image14_zy.jpeg)

![2D Orbit View](../../zh/02-案例教程/media/3.1入门案例/image15_zy.jpeg)

## Generating Output Reports

1. Click <kbd>Output</kbd> and select <img src="../../zh/02-案例教程/media/3.1入门案例/image16.png" alt="" no-view />. In the upper-left, set **Object Type** to **Satellite**, and from the upper-right **Report Type** dropdown, select **Data Report**. In the **Predefined** parameters below, select **Lat/Lon/Alt**, then click <kbd>Generate</kbd> to produce the report;

2. Click <kbd>Output</kbd> and select <img src="../../zh/02-案例教程/media/3.1入门案例/image17.png" alt="" no-view />. In the upper-left, set **Object Type** to **Satellite**, and from the upper-right **Report Type** dropdown, select **Curve Chart**. In the **Predefined** parameters below, select **RAAN**, then click <kbd>Generate</kbd> to produce the chart;

3. In the **Data Report** or **Curve Chart** **Variable Selection** page, click **Style** → <kbd>New</kbd> to customize report content or chart types as needed;

4. In the data report, click <kbd>Save as Text</kbd> <img src="../../zh/02-案例教程/media/3.1入门案例/image21.png" alt="" no-view /> in the upper-left to save the output report; right-click on the curve chart and select <kbd>Save Image</kbd> <img src="../../zh/02-案例教程/media/3.1入门案例/image22.png" alt="" no-view /> to save the chart;

5. Click <kbd>Close</kbd>.

## Saving the Scenario

Click <kbd>Start</kbd> → <kbd>Save</kbd> <img src="../../zh/02-案例教程/media/3.1入门案例/image19.png" alt="" no-view /> to save the current scenario; to reload an existing scenario, click <kbd>Open</kbd> <img src="../../zh/02-案例教程/media/3.1入门案例/image20.png" alt="" no-view /> and open a saved scenario file.
