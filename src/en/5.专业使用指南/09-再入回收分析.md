# Reentry and Recovery Analysis

## Functional Description

The Reentry and Recovery Analysis module is used for flight dynamics simulation analysis of the reentry phase and parachute recovery phase for spacecraft such as recoverable satellites, crewed spacecraft, and return capsules. The module can perform reentry phase flight simulation, parachute recovery phase flight simulation, and integrated reentry‑recovery flight simulation.

This module can be used to analyze key parameters including trajectory, velocity, altitude, heat flux, aerodynamic forces, and landing point position during the process from high‑altitude, high‑speed atmospheric reentry to low‑altitude parachute recovery. It provides computational support for reentry trajectory design, return safety assessment, recovery area prediction, and mission plan verification.

This module is primarily applicable to the following scenarios:

- Reentry trajectory simulation for recoverable satellites.
- Reentry and recovery process analysis for crewed spacecraft return capsules.
- Reentry heat flux and aerodynamic environment assessment.
- Analysis of bank angle control effects on reentry trajectories.
- Parachute deployment timing and landing point dispersion analysis.
- Recovery area prediction under wind field influence.

## Basic Concept Descriptions

1. **Reentry Phase**
   The reentry phase refers to the flight process during which a spacecraft enters the dense atmosphere from high altitude and decelerates under the action of aerodynamic forces, gravity, and control inputs. This phase is typically characterized by high velocity, strong heat flux, and rapidly changing aerodynamic conditions.

2. **Recovery Phase**
   The recovery phase generally refers to the process after the spacecraft completes high‑speed reentry, where it further decelerates via a parachute system at low altitude and eventually descends to a specified altitude or landing area.

3. **Integrated Reentry‑Recovery Simulation**
   Integrated reentry‑recovery simulation treats the reentry phase and the parachute recovery phase as a continuous process. The system first completes the reentry segment simulation, then uses the reentry terminal state as the initial state for the recovery segment to continue the parachute recovery process simulation.

4. **Bank Angle**
   Bank angle is an important parameter in reentry flight control, typically used to describe the rotation angle of the spacecraft's lift vector relative to the local vertical plane. By adjusting the bank angle, the lift direction can be changed, thereby affecting the reentry range, cross‑range offset, and landing point position.

   This module supports two bank angle setting modes:

   | Bank Angle Mode | Meaning |
   |---|---|
   | Constant Bank Angle | A fixed bank angle is used throughout the entire reentry process. |
   | Interpolated Bank Angle | A varying bank angle is obtained via data table interpolation based on time, altitude, or other variables. |

   Constant bank angle is suitable for rapid scheme validation, while interpolated bank angle is suitable for simulating more complex reentry control laws.

5. **Heat Flux**
   Heat flux is used to describe the aerodynamic heating intensity per unit area experienced by the spacecraft during reentry. Higher reentry velocities and greater atmospheric densities typically result in stronger heat flux.

   Heat flux analysis can be used to assess whether the spacecraft's thermal protection system design meets requirements. The heat flux calculation in the module uses an empirical model. Users can adjust the heat flux calculation characteristics by setting the **Index Coefficient** and **Empirical Coefficient**.

6. **Aerodynamic Parameters**
   Aerodynamic parameters describe the drag and lift characteristics of the spacecraft during atmospheric flight, mainly including the drag coefficient and lift coefficient.

   This module supports two aerodynamic parameter setting modes:

   | Aerodynamic Mode | Meaning | Application Scenario |
   |---|---|---|
   | Constant Aerodynamics | Drag coefficient and lift coefficient remain constant during reentry. | Rapid simulation, preliminary scheme assessment. |
   | Interpolated Aerodynamics | Drag coefficient and lift coefficient are obtained via data table interpolation. | Detailed simulation, analysis of aerodynamic variations with Mach number or angle of attack. |

   Interpolated aerodynamics mode is closer to actual flight conditions, but requires the user to provide a relatively complete aerodynamic data table.

7. **Wind Field**
   The wind field describes the wind speed and direction distribution in the atmosphere. The wind field affects the lateral drift of the spacecraft during the terminal reentry phase and the parachute recovery phase, especially having a significant impact on the landing point position during low‑altitude parachute descent.

   This module supports two wind field configuration methods:

   | Wind Field Configuration Method | Meaning |
   |---|---|
   | Wind Field File Import | Wind field data is added by replacing or loading an external wind field file. |
   | Interface Data Table Configuration | Wind field data is manually configured via the interface data table. |

## How to Use

### Reentry Phase Flight Simulation

#### Initial Parameter Settings

Configure the initial parameters for reentry flight simulation, including: spacecraft model parameters, reentry initial conditions, orbit parameters, and simulation end altitude settings. The Earth gravity model can be set to either **Sphere Model** or the higher‑precision **J2 Model**.

![Reentry Phase Flight Simulation Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-3.png)

#### Heat Flux Parameter Settings

Configure the heat flux calculation parameters for reentry flight simulation: **Index Coefficient** and **Empirical Coefficient**.

![Reentry Phase Heat Flux Calculation Model Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-4.png)

#### Aerodynamic Parameter Settings

Configure the spacecraft's aerodynamic parameters, including **Constant Aerodynamics** and **Interpolated Aerodynamics** modes. In Constant mode, the drag coefficient and lift coefficient are set to constant values during reentry, as shown below.

![Reentry Phase Constant Aerodynamics Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-5.png)

In Interpolated mode, the drag coefficient and lift coefficient are configured as interpolatable data tables, as shown below. Users can add or remove entries in the aerodynamic data table via the interface to accommodate reentry simulations for spacecraft with different aerodynamic characteristics.

![Reentry Phase Interpolated Aerodynamics Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-6.png)

#### Control Parameter Settings

Configure the spacecraft's control parameters, including **Constant Bank Angle** and **Interpolated Bank Angle** modes. In Constant mode, the bank angle is set to a constant value during reentry, as shown below.

![Reentry Phase Constant Bank Angle Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-7.png)

In Interpolated mode, the bank angle is configured as an interpolatable data table, as shown below. Users can add or remove entries in the bank angle data table via the interface to accommodate reentry simulations with varying bank angle profiles.

![Reentry Phase Interpolated Bank Angle Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-17.png)

#### Wind Field Parameter Settings

Reentry flight simulation can consider wind field effects. Wind fields can be added by replacing or loading a wind field file, or by configuring the wind field data table through the interface, as shown below.

![Wind Field Parameter Configuration Interface](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-8.png)

#### Reentry Simulation Mode Selection

After completing the reentry phase flight simulation parameter configuration, select the Reentry Phase option at the lower right of the interface and click the **Compute** button, as shown below, to complete the reentry phase simulation.

![Reentry Phase Simulation Mode Selection](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-9.png)

#### Reentry Simulation Results Display

Reentry flight computation results can be displayed by selecting different parameters from the dropdown menu. Users can also choose to display the spacecraft's final position information, as shown below.

![Reentry Phase Simulation Results Display](../../zh/5.专业使用指南/media/09-再入回收分析/image0105-10.png)

## Results

The final simulation results are displayed as curves showing the state variations during the spacecraft's reentry and recovery process, including altitude, downrange, latitude, velocity, and other parameters as functions of time, facilitating intuitive analysis of flight trajectory, deceleration process, and recovery phase characteristics.
