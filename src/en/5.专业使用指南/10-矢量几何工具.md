# Vector Geometry Tool

## Functional Description

This module enables the display of Points, Axes, Vectors, Angles, Planes, and Systems. For Vectors and Axes, vector elements can be selected.

## Function Location

This function is located in the ATK menu toolbar. The specific location is shown in the figure below.

![Vector Geometry Tool function in the toolbar](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-1.png)

## Interface Introduction

The left side is the object selection interface, and the right side is the component addition interface. Vector elements can be selected as needed.

![Vector Geometry Tool Interface](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-2.png)

## How to Use

The following example demonstrates adding a velocity vector to display it. (In other functional modules, the Vector Geometry Tool also provides flexible coordinate system selection.)

1. Click **Vector Geometry Tool**.

2. Select Satellite 1 on the left, then click the **Vector** button.

![Click Vector button](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-3.png)

3. In the "Add Geometry Component" window, select Velocity Vector and click **OK**.

![Select Velocity Vector](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-4.png)

4. Name the component: "Example Velocity".

![Name the vector](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-5.png)

5. In Satellite 1's properties, go to 3D View → Vectors, click Add, select the predefined vector (Example Velocity) under Custom Components, click Show, enable Show Label, and choose the desired display color.

![Vector visualization settings](../../zh/5.专业使用指南/media/10-矢量几何工具/image0106-6.png)
