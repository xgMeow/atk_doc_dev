# Uncertainty Quantification

## Functional Description

The current Uncertainty Quantification module supports analyzing the dispersion characteristics of spacecraft states using methods such as Monte Carlo (MC) and Polynomial Chaos Expansions (PCE). It can account for conservative and non‑conservative perturbations including atmospheric drag, Earth oblateness, solar radiation, third‑body gravity, and solar radiation pressure, enabling high‑precision perturbed orbit uncertainty propagation analysis.

### Function Location

This function is accessed via the “Propagator” dropdown menu in **Satellite → Properties → Propagator** by selecting **Uncertainty Quantification**.

### Interface Introduction

The interface consists of two areas: the Mission Sequence and the Sequence Property Settings, as shown below.

## How to Use

After creating a scenario, add a satellite to the scenario. In the satellite's Basic Properties, select **Uncertainty Quantification** as the Propagator, as shown below.

![Uncertainty Quantification Function](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-2.png)

Click **Add** below to add an **Uncertainty Quantification Segment** to the sequence, as shown below.

![Sequence Illustration](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-3.png)

Delete the existing **Initial State** segment, select the **Uncertainty Quantification Segment**, click **Add**, and add an **Initial State** and a **Propagate** segment to the sequence, as shown below.

![Sequence Illustration](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-4.png)

Configure the **Initial State** segment as shown below, and check the Position and Velocity options (check the boxes next to Position and Velocity).

![Initial State Settings](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-5.png)

In the **Propagate** segment, use the default stopping condition **CAsStopDuration** (if not present, create a new stopping condition and add **CAsStopDuration**).

![Create New Stopping Condition](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-6.png)

Set the trigger value to 86400 and the tolerance to 0.0001, as shown below.

![Stopping Condition Settings](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-7.png)

Select the **Propagate** segment, click **Constraints Configuration**, select the Position and Velocity constraints under **Cartesian**, add them to the right panel, and click **OK**, as shown below.

![Constraints Configuration](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-11.png)

Select the **Uncertainty Quantification Segment**, and under **Configure**, add **Monte Carlo** and **Polynomial Chaos**, as shown below.

![Uncertainty Quantification Settings Window](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-8.png)

The detailed settings for the two configurations are shown below.

![Monte Carlo Settings](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-9.png)

![Polynomial Chaos Settings](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-10.png)

Click the **Run** button <img src="../../zh/5.专业使用指南/media/5.12偏差分析/image-11.png" alt="" no-view />. The window shown below will appear to perform the fitting computation.

![Monte Carlo Iteration and Results Display](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-12.png)

![Polynomial Chaos Iteration and Results Display](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-13.png)

After the computation is complete, the satellite display in the scenario is shown below.

![Satellite Display in Scenario](../../zh/5.专业使用指南/media/5.12偏差分析/image0106-14.png)
