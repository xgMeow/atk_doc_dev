# Coverage Tool

## Overview

The Coverage Tool is used to calculate whether a coverage relationship exists between two objects under the current property and parameter constraints. It can be applied to tasks such as satellite-to-ground coverage analysis. The tool supports evaluation of coverage performance under different assessment criteria.

This tool can perform coverage analysis from a single object to one or multiple objects. Based on the computational results of different coverage relationships, it can generate data reports and graphical reports, for example: output coverage interval data, as well as coverage quality data under the defined coverage figure of merit. It can also generate visual graphical reports and display computational results in the 2D view.

## Accessing the Tool

### From the Object Window

Select any object in the Object Window, right-click, and the Coverage Tool can be found.

## Interface Sections

Includes the Object Operations area, Time Settings area, Figure of Merit area, Report Output area, and Data Visualization area.

![Coverage Analysis Tool Window Interface](../../../zh/5.专业使用指南/01-可见性与覆盖分析/media/02-覆盖性工具/image_zy.png)

### Object Operations Area

Used to select analysis objects, generate coverage analysis data, and update or clear coverage analysis data. Used to set the **Access Object** (initiator) and **Asset Objects** for coverage analysis. Supports simultaneous selection of multiple access objects and multiple asset objects to reduce repetitive operations for multi-object coverage analysis. **Analysis results are still stored and displayed on a per-object basis.**

|      Element      |                                   Description                                   |                                                                   Operation                                                                   |
|:-----------------:|:-------------------------------------------------------------------------------:|:---------------------------------------------------------------------------------------------------------------------------------------------:|
| **Access Object** |                        Initiator of the coverage analysis                       |                                  Click <kbd>Select Object...</kbd> to choose from the current scenario object list                             |
|   **Update**      | Synchronizes scenario configuration changes, resets time settings and step size to scenario defaults, updates the visualization view | Use after modifying scenario properties; use when resetting the coverage analysis period to the scenario default time; automatically updates after object property changes are saved—no click needed |
|   **Clear**       |                     Removes the selected asset object and its coverage data                    |                                                Select the object and click                                                                    |
| **Clear All**     |               Clears all coverage analysis data for all asset objects under the current access object              |                        Click directly; clears only the current access object's analysis results and display (does not affect other access objects)                       |
|   **Compute**     |            Executes coverage computation, generates coverage interval data, and displays in 2D/3D views           |                                    Click after configuration is complete; an `*` appears before the object name upon completion                                   |
| **Show Filter**   |                            Filters the object list by type                           |                                            Click the dropdown and select (default: All Objects)                                            |
| **Object List**   |                           Displays asset objects available for addition                          |                                                Hold `Ctrl` for multi-selection                                               |

::: warning Clear Results Promptly to Free Memory
Undeleted results will consume memory; it is recommended to clear them promptly after use.
:::

### Time Settings Area

Used to set the analysis time interval and computation step size for coverage analysis.

|      Element      |     Description     |               Operation               |
|:-----------------:|:-------------------:|:-------------------------------------:|
| Start Epoch (UTCG) | Analysis start time | Format: `YYYY-MM-DD HH:MM:SS.000` |
| Stop Epoch (UTCG)  | Analysis end time   | Format: `YYYY-MM-DD HH:MM:SS.000` |
|    Step Size       | Report time interval |      Switchable units (default: seconds)     |

::: warning Analysis Time Range Restriction
The analysis time range must be within the platform's simulation time range; otherwise, analysis will fail due to the inability to obtain the corresponding state data.
:::

### Figure of Merit Area

#### Coverage Figure of Merit Parameters

Click <kbd>Define...</kbd> to access the [Figure of Merit Parameters] settings page. On this page, you can configure the **type**, **computation** method (different types have different settings), **satisfaction condition**, **invalid data indicator**, and **value limits** properties of the coverage figure of merit.

The Coverage Analysis Tool supports 16 types of coverage figures of merit. For type definitions and statistical value descriptions, see [Figure of Merit](04-品质因子/).

Additionally, checking the **Show Contours** checkbox allows you to view the numerical distribution of the coverage figure of merit along the object's trajectory in the 2D view. Click the <kbd>Contours...</kbd> button to access the settings page, where you can configure contour display options, color levels, and line styles. Click the <kbd>Legend...</kbd> button in the **Level Attributes** area to set the contour legend's display position, background, text, and color range in the view.

::: info Figure of Merit Types Supporting Contours
The **Show Contours** checkbox is only available for the following **types** of coverage figures of merit:

- Access Duration
- N Asset Coverage
- Number of Accesses
- Response Time
- Revisit Time
- Age of Data
- System Response Time
- System Age of Data
- Dilution of Precision
- Navigation Accuracy
- Access Constraint
:::

#### Data Visualization Display

1. Click the <kbd>Graphics Displays...</kbd> button
2. Check the data to display on the left side; set text color, position, background, and border on the right side
3. Click <kbd>OK</kbd>, and the data will be displayed dynamically in the 2D/3D views

::: tip Font Display Adjustment
The font display effect is related to the scene background. Flexibly adjust font style and background/border settings to ensure legibility.
:::

### Data Visualization Area

Configures the visualization effects of coverage analysis results in the view.

|      Element     |                                                          Description                                                         |
|:----------------:|:----------------------------------------------------------------------------------------------------------------------------:|
| Show Static Track  | In the 2D view, when the access object or asset object is a movable object (e.g., satellite, vehicle), continuously displays the track projection of all its visible intervals as a **static bold line**, which does not change as time advances |
| Show Animate Line | In the 2D and 3D views, dynamically draws a **line between the access object and the asset object** during coverage intervals; the line disappears when coverage ends; reflects only the current coverage state |

::: tip Difference Between Static Track and Animate Line
- **Static Track** is suitable for quickly browsing the full-period coverage status, allowing you to see the approximate proportion of visible intervals relative to the total period
- **Animate Line** is suitable for time-sequence playback scenarios, observing the establishment and interruption of coverage relationships frame by frame
- Both can be checked simultaneously without conflict
:::

## Complete Workflow

### Set Constraints

According to actual mission requirements, set the constraints for the coverage analysis process. The specific operation is: double-click the analysis object to enter the [Properties] settings page, then configure constraints in the **Constraints - Basic**, **Constraints - Sun**, and **Constraints - Time** tabs.

### Select Access Object

In the Object Operations area, click <kbd>Select Object...</kbd> to choose the **initiator** of the coverage analysis from the current scenario object list. Supports simultaneous selection of multiple access objects.

### Add Asset Objects

Check the asset objects to be analyzed in the object list (hold `Ctrl` or click and drag the mouse for multi-selection), then click <kbd>Compute</kbd>. Supports adding multiple asset objects simultaneously; analysis results are stored on a **per-object** basis.

### Configure Analysis Period

Set the start epoch, stop epoch, and analysis step size in the Time Settings area. The analysis period must be within the scenario's simulation time range; for objects such as vehicles, ships, or missiles whose lifetime is shorter than the simulation time, the actual analysis period is the **intersection** of the object's lifetime and the set period.

### Set Figure of Merit Parameters

In the **Figure of Merit** area, click <kbd>Define...</kbd> to define the figure of merit type and related parameter settings. For certain figure of merit types, you can check the **Show Contours** checkbox to display the numerical distribution of the coverage figure of merit as contours in the view. After modifying the figure of merit parameters and clicking <kbd>OK</kbd>, coverage results will update automatically without needing to click <kbd>Compute</kbd> again.

### Execute Computation

Click <kbd>Compute</kbd>; upon completion, an `*` icon appears before the asset object name.
After object property changes are saved, coverage results will **update automatically** without needing to recompute.

### View Results

- **Data Reports**: Click the corresponding button in the report area, or select a template via <kbd>More...</kbd> and click <kbd>Create</kbd>
- **Chart Reports**: Click the corresponding button in the chart area, or select a template via <kbd>More...</kbd> and click <kbd>Create</kbd>

### Dynamically Display Data in the View

The **Figure of Merit Value** data from coverage analysis can be dynamically displayed in the **2D View** or **3D View**.

The specific operation is: click the <kbd>Graphics Displays...</kbd> button to enter the [Graphics Data Display] page. The left side of the page lists the **Figure of Merit Value** data checkboxes, which users can check according to actual needs. The right side of the page allows configuration of text color, text position, background, and border. After completing all settings, click <kbd>OK</kbd> to dynamically display the **Figure of Merit Value** data results in the view.

### Clear Results

After analysis is complete, click <kbd>Clear</kbd> to remove results for a single asset object, or click <kbd>Clear All</kbd> to clear all results under the current access object. Undeleted results will continue to consume memory.

::: tip Multi-Object Analysis Result Isolation
In batch multi-object analysis, results for different access objects are independent of each other. <kbd>Clear All</kbd> only affects the currently selected access object.
:::
