# Time Constraint

## 1. Functional Description

Time Constraint is used to limit the effective range of access analysis or coverage analysis in the time dimension. By setting the start time, stop time, duration, or specifying a time interval file, you can control the valid computation interval of the access relationship between objects, thereby filtering access results that satisfy the mission time requirements.

---

## 2. Parameter Descriptions

| Parameter | Meaning |
| :---: | --- |
| Start Time | The start instant of the access or coverage analysis. Only access results at or after this time are considered to satisfy the Time Constraint. |
| Stop Time | The stop instant of the access or coverage analysis. Only access results at or before this time are considered to satisfy the Time Constraint. |
| Minimum Duration | The lower bound of the duration of a valid access or coverage. If the access duration is less than this value, the Time Constraint is not satisfied. |
| Maximum Duration | The upper bound of the duration of a valid access or coverage. If the access duration is greater than this value, the Time Constraint is not satisfied. |
| Time Interval | One or more valid time intervals. Only access results that fall within the specified time intervals are considered to satisfy the Time Constraint. |
| Interval File | Imports valid or invalid time intervals from an external file. The system filters access results according to the time intervals defined in the file. |
