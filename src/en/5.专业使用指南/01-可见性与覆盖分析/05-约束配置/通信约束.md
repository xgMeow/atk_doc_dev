# Communication Constraints

## 1. Functional Description

Communication Constraints are used to analyze whether the communication link between a transmitter and a receiver satisfies specified conditions. This type of constraint is typically applied to scenarios such as satellite communications, inter-satellite links, ground station communications, telemetry, tracking and command links, and data transmission missions.

During access analysis, the system can determine whether the current communication link is usable based on indicators such as link frequency, received power, signal-to-noise ratio, bit error rate, link margin, and Doppler shift. If the link parameters satisfy the set minimum, maximum, or range values, the access is considered to satisfy the Communication Constraints; otherwise, it is judged as an invalid access.

::: tip Note
Communication Constraints are currently only relevant to transmitter objects and receiver objects.
:::

## 2. Parameter Descriptions

| Parameter | Meaning |
| :---: | --- |
| Frequency | The operating frequency used by the communication link. It can be set by frequency band or by a numerical range, and is used to restrict the link to operating within the specified frequency range. |
| Frequency Band | Filters links by communication frequency band, e.g., L, S, C, X, Ku, Ka, etc. The specific options are subject to the frequency band range provided by the software interface. |
| Received Isotropic Power | The power level that could be received assuming an ideal isotropic receiving antenna, used to evaluate the strength of the signal near the receiving end. |
| Flux Density | The electromagnetic power density received per unit area, describing the spatial power distribution intensity of the signal at the receiving location. |
| Link EIRP | The equivalent isotropic radiated power of the transmitting end along the link direction, usually related to transmit power and transmit antenna gain. The larger the value, the stronger the equivalent radiation capability of the transmitting end in that direction. |
| Doppler Shift | The received frequency offset caused by relative motion between the transmitter and the receiver, commonly used in communication link analysis for high-speed moving platforms. |
| C/No | The ratio of carrier power to noise power spectral density, used to measure the strength of the received signal relative to the noise background, and is an important indicator of communication link quality. |
| Receiver Input Power | The signal power entering the front end of the receiver. If this value is too low, reception may become difficult; if too high, it may cause receiver saturation or nonlinear distortion. |
| C/N | The ratio of carrier power to noise power, used to evaluate the signal-to-noise level of the received signal within a specified bandwidth. |
| Bit Error Rate | The ratio of erroneous bits to the total transmitted bits during communication. The lower the bit error rate, the better the communication quality. |
| Link Margin | The margin of the actual link performance relative to the minimum communication requirement. A positive link margin usually indicates that the link has a certain level of reliability; insufficient margin may lead to communication interruption or quality degradation. |
| Eb/No | The ratio of energy per bit to noise power spectral density, used to measure the anti-noise capability of digital communication systems, and is often used together with the bit error rate to evaluate data link performance. |
| Polarization Relative Angle | The relative angle between the polarization directions of the transmitting antenna and the receiving antenna. Polarization mismatch causes polarization loss, thereby reducing the received signal strength. |
| Antenna Figure of Merit | The overall performance of the receiving antenna system, usually related to antenna gain and system noise temperature. The higher the value, the stronger the receiving system's ability to receive weak signals. |
| Reverse Selection | Logically inverts the current constraint condition. When enabled, accesses that originally satisfied the constraint range will be excluded, and accesses that originally did not satisfy the constraint range will be retained. |
