# Sun Constraints

## 1. Functional Description

Sun Constraints are used to further filter visibility intervals or coverage intervals based on the relative geometric relationships among the Sun, the analysis object, and the associated object. By setting parameters such as Sun Elevation Angle, Sun Ground Elevation Angle, Solar Exclusion Angle, and additional central body occultation conditions, it can be determined whether the current access relationship meets illumination and sunlight avoidance requirements.

All conditions within Sun Constraints are independent. A given instant is considered to satisfy the Sun Constraints only when all enabled conditions are satisfied simultaneously.

---

## 2. Parameter Descriptions

| Parameter | Meaning |
|---|---|
| Sun Elevation Angle Minimum | When enabled, the Sun's elevation angle relative to the analysis object must be greater than or equal to the set value. |
| Sun Elevation Angle Maximum | When enabled, the Sun's elevation angle relative to the analysis object must be less than or equal to the set value. |
| Sun Ground Elevation Angle Minimum | When enabled, the Sun's elevation angle in the local horizontal coordinate system of a ground‑based object must be greater than or equal to the set value. |
| Sun Ground Elevation Angle Maximum | When enabled, the Sun's elevation angle in the local horizontal coordinate system of a ground‑based object must be less than or equal to the set value. |
| Solar Exclusion Angle | The minimum allowed angle between the line‑of‑sight direction to the associated object and the Sun direction. The current access is invalid when the actual angle is smaller than the set value. |
| Additional Central Body Occultation | Used to specify additional celestial bodies (beyond the object's default central body) that should participate in line‑of‑sight occlusion judgment. When enabled, bodies can be moved from "Available Central Bodies" to "Assigned Central Bodies." |

All angular parameters in the interface are in degrees (deg). Minimum and maximum values can be enabled independently or simultaneously. When both are enabled, the corresponding angle $\theta$ must satisfy:

$$
\theta_{\min}\leq\theta\leq\theta_{\max}
$$

## 3. Computation Methods

### 3.1 Sun Elevation Angle

The Sun Elevation Angle describes the apparent position of the Sun relative to the analysis object. Let:

- $\boldsymbol r$ be the position vector of the analysis object in the central body reference frame;
- $\boldsymbol s$ be the position vector of the Sun relative to the analysis object.

The Sun Elevation Angle can then be expressed as:

$$
E_{\mathrm{Sun}}
=
\frac{\pi}{2}
-
\operatorname{atan2}
\left(
\left\|\boldsymbol r\times\boldsymbol s\right\|,
\boldsymbol r\cdot\boldsymbol s
\right)
$$

When the Sun Elevation Angle is greater than $0^\circ$, the Sun is above the local horizontal plane of the analysis object; when it is less than $0^\circ$, the Sun is below the local horizontal plane.

When minimum and maximum constraints are enabled, the Sun Elevation Angle must satisfy the corresponding range requirements.

### 3.2 Sun Ground Elevation Angle

The Sun Ground Elevation Angle is defined in the local horizontal coordinate system of ground‑based objects (e.g., ground stations) and describes the height of the Sun direction relative to the local ground plane.

Let:

- $s_{z,\mathrm{LH}}$ be the $OZ$‑axis component of the Sun's relative position vector in the object's local LH coordinate system;
- $R_{\mathrm{Sun}}=\|\boldsymbol s\|$ be the distance between the Sun and the analysis object.

According to the axial conventions of the software's local coordinate system, the Sun Ground Elevation Angle can be expressed as:

$$
E_{\mathrm{Local}}
=
\arcsin
\left(
-\frac{s_{z,\mathrm{LH}}}{R_{\mathrm{Sun}}}
\right)
$$

The Sun Ground Elevation Angle is commonly used to set mission conditions such as daytime, nighttime, twilight, or low solar elevation. For example:

- Setting the maximum value to less than $0^\circ$ can be used to filter periods when the Sun is below the horizon;
- Setting the minimum value to greater than $0^\circ$ can be used to filter periods when the Sun is above the horizon.

> **Note**
>
> The Sun Ground Elevation Angle is primarily applicable to ground‑based objects that have a local horizontal coordinate system. Its positive/negative direction is determined by the axial convention of the software's LH coordinate system.

### 3.3 Solar Exclusion Angle

The Solar Exclusion Angle represents the angle between the line‑of‑sight direction from the analysis object to the associated object and the Sun direction.

Let:

- $\boldsymbol l$ be the line‑of‑sight vector from the analysis object to the associated object;
- $\boldsymbol s$ be the position vector of the Sun relative to the analysis object.

The Solar Exclusion Angle is then:

$$
\theta_{\mathrm{avoid}}
=
\arccos
\left(
\frac{
\boldsymbol l\cdot\boldsymbol s
}{
\|\boldsymbol l\|
\|\boldsymbol s\|
}
\right)
$$

If the specified minimum Solar Exclusion Angle is $\theta_{\min}$, then a valid access must satisfy:

$$
\theta_{\mathrm{avoid}}
\geq
\theta_{\min}
$$

When the actual angle is smaller than the set value, the target line‑of‑sight is too close to the Sun direction, and the current access is considered invalid. This constraint is commonly used in optical sensor sun avoidance, bright‑light interference mitigation, and observation safety analysis.

When the Sun direction is occluded by the central body and the Sun does not directly enter the vicinity of the target line‑of‑sight, the Solar Exclusion Angle constraint may be excluded from the validity judgment at the current time.

### 3.4 Additional Central Body Occultation

Additional Central Body Occultation is used to account for third‑body occultation beyond the object's default central body. For example, in deep‑space communications or interplanetary missions, the line of sight between analysis objects may be occluded by the Moon, Earth, or other planets.

After enabling **Use**:

1. Select the celestial bodies to be considered from the "Available Central Bodies" list;
2. Click the right arrow to move them into "Assigned Central Bodies";
3. During computation, the software will determine whether the line of sight between the analysis object and the associated object is occluded by any of the selected bodies;
4. If occlusion occurs, the current access relationship is invalid.

Click the left arrow to remove a body from "Assigned Central Bodies." Bodies not added to "Assigned Central Bodies" are not included in additional occultation judgment.
