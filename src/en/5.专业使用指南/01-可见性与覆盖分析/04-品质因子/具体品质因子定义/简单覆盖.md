# Simple Coverage

## Definition

Indicates whether the analysis object can be covered by the selected coverage resources, expressed as a 0‑1 Boolean value.

## Statistics

The Simple Coverage type does not provide configurable statistical options (such as Maximum, Minimum, Mean, etc.) in the interface. Its internal computation follows a fixed rule, with the following meanings:

- **Statistic Value** (aggregated over the analysis period)  
  Indicates whether there exists any covered interval for the analysis object during the selected analysis period.  
  - If the statistic is `0`, the object **cannot be covered at any time** during the analysis period (no covered interval exists).  
  - If the statistic is non‑zero (typically `1`), the object is **covered at least at one instant** during the analysis period.

- **Dynamic Value** (instantaneous value at a given time)  
  Indicates whether the analysis object is within a covered interval at a specified instant (i.e., has visibility to at least one coverage resource).  
  - If the dynamic value is `0`, the object is **not covered** at that instant.  
  - If the dynamic value is non‑zero, the object is **covered** at that instant.
