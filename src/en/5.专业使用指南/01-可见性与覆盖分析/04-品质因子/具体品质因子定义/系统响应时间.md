# System Response Time

## Definition

The time from when coverage of a point is requested to when data from the coverage resource is acquired.

## Specific Parameters

- **System Assets**: Command Object, Receive Object, Allow Crosslink
- **Phase Duration Parameters**: Command Prep Time, Commanding Time, Pre‑Collection Time, Collection Time, Post‑Collection Time, Downlink Time, Time Step

## Statistics

|      Name     |                          Meaning                          |
|:-------------:|:---------------------------------------------------------:|
|    **Mean**   |    The mean System Response Time over the entire analysis period.    |
|  **Maximum**  |    The maximum System Response Time over the entire analysis period.    |
|  **Minimum**  |    The minimum System Response Time over the entire analysis period.    |
