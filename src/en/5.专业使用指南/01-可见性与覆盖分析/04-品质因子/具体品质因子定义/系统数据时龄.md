# System Data Age

## Definition

The time elapsed from the end of the last data collection interval that satisfies the mission sequence requirements to the current time.

## Specific Parameters

- **System Assets**: Command Object, Receive Object, Allow Crosslink
- **Phase Duration Parameters**: Command Prep Time, Commanding Time, Pre‑Collection Time, Collection Time, Post‑Collection Time, Downlink Time, Time Step

## Statistics

|      Name     |                          Meaning                          |
|:-------------:|:---------------------------------------------------------:|
|    **Mean**   |    The mean System Data Age over the entire analysis period.    |
|  **Maximum**  |    The maximum System Data Age over the entire analysis period.    |
|  **Minimum**  |    The minimum System Data Age over the entire analysis period.    |
