# Revisit Time

## Definition

The time interval between two successive coverage events.

## Specific Parameters

- **Minimum Multiplicity**: Sets the minimum number of simultaneous coverage resources.
- **End Gap**: Specifies whether the final incomplete gap at the end of the analysis period is ignored or included.

## Statistics

|          Name          |                                             Meaning                                            |
|:----------------------:|:-----------------------------------------------------------------------------------------------:|
|       **Mean**         |        The average interval between two successive coverage events, computed as the sum of all coverage gap durations divided by the number of gaps.       |
|     **Maximum**        |                                  The maximum coverage gap within the analysis period.                                 |
|     **Minimum**        |                                  The minimum coverage gap within the analysis period.                                 |
|   **Percent Below**    |             Given a percentage X%, returns a value V such that Revisit Time is below V for X% of the analysis period.            |
| **Percent Below Gaps Only** | Given a percentage X%, returns a value V such that, considering only the time spent in coverage gaps, Revisit Time is below V for X% of that gap time. |
| **Num Percent Below**  |      Given a percentage X%, returns a value V such that X% of all coverage gaps have duration below V.     |
|   **Std Deviation**    |                                The standard deviation of all coverage gap durations.                               |
