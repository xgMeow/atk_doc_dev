# Number of Accesses

## Definition

Counts the number of times the analysis object is covered. Overlapping coverage intervals from different resources are merged; when counting the number of accesses, each merged interval is counted as a single access.

## Statistics

|        Name          |                                             Meaning                                            |
|:--------------------:|:----------------------------------------------------------------------------------------------:|
|   **Avg Per Day**    |                Total accesses divided by the number of analysis days; represents the average number of accesses per day.               |
|   **In Span**        |                The number of coverage intervals whose duration falls within the specified minimum and maximum duration range.               |
| **In Span Per Day**  | The number of intervals satisfying the duration range divided by the number of analysis days; represents the average number of qualifying accesses per day. |
|   **Max Per Day**    |                The maximum number of accesses in any single UTC day over the analysis period.               |
|   **Min Per Day**    |                The minimum number of accesses in any single UTC day over the analysis period.               |
|     **Total**        |                The total number of accesses over the entire analysis period.               |

::: tip Note
- **Total** counts all independent accesses across the entire analysis period.
- Overlapping accesses are not merged. For example, if the same analysis object is simultaneously covered by two resources, even if the two access intervals completely overlap, they are counted as two accesses.
- **Avg Per Day**, **In Span Per Day**, **Max Per Day**, and **Min Per Day** are based on the UTC days contained in the analysis period.
- **In Span** and **In Span Per Day** filter accesses by duration, counting only those that meet the specified duration range.
:::
