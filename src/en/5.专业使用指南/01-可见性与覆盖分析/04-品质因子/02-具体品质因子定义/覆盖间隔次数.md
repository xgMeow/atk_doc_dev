# Number of Coverage Gaps

## Definition

Counts the number of **uncovered intervals** (gaps) that occur for the analysis object during the analysis period.  
At each moment, the value is a logical indicator: 1 means the current moment lies within a coverage gap (i.e., no coverage resource covers the object), and 0 otherwise.

## Statistics

|        Name          |                                             Meaning                                            |
|:--------------------:|:----------------------------------------------------------------------------------------------:|
|   **Avg Per Day**    |                Total number of gaps divided by the number of analysis days; represents the average number of gaps per day.               |
|   **In Span**        |                The number of gaps whose duration falls within the specified minimum and maximum range.               |
| **In Span Per Day**  | The number of gaps satisfying the duration range divided by the number of analysis days; represents the average number of qualifying gaps per day. |
|   **Max Per Day**    |                The maximum number of gaps in any single UTC day over the analysis period.               |
|   **Min Per Day**    |                The minimum number of gaps in any single UTC day over the analysis period.               |
|     **Total**        |                The total number of gaps over the entire analysis period.               |

::: tip Note
- **Total** counts all gaps that occur during the entire analysis period.
- **Avg Per Day**, **In Span Per Day**, **Max Per Day**, and **Min Per Day** are based on UTC days.
- A UTC day runs from 00:00 UTC to the next 00:00 UTC.
- **In Span** and **In Span Per Day** filter gaps by the specified minimum and maximum duration, counting only those that satisfy the range.
:::
