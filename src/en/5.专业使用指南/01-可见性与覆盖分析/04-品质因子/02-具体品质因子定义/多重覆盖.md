# Multiple Coverage

## Definition

Counts the number of coverage resources that simultaneously cover the analysis object (coverage multiplicity).

## Statistics

|      Name       |                                       Meaning                                       |
|:---------------:|:-----------------------------------------------------------------------------------:|
|    **Mean**     |           The average number of resources simultaneously covering over the analysis period.          |
|   **Maximum**   |           The maximum number of resources simultaneously covering over the analysis period.          |
|   **Minimum**   |           The minimum number of resources simultaneously covering over the analysis period.          |
| **Percent Above** | Let the specified percentage be X. The statistic value V means that the coverage multiplicity is above V for X% of the time. |
