# Coverage Time

## Definition

Coverage Time characterizes the total duration during which the analysis object is covered. This Figure of Merit provides only statistical values.

## Statistics

|           Name           |                                             Meaning                                            |
|:------------------------:|:----------------------------------------------------------------------------------------------:|
|     **Max Per Day**      |                The maximum coverage duration within any single UTC day.               |
|  **Max Percent Per Day** |                The maximum coverage duration as a percentage of a UTC day.               |
|     **Min Per Day**      |                The minimum coverage duration within any single UTC day.               |
|  **Min Percent Per Day** |                The minimum coverage duration as a percentage of a UTC day.               |
|        **Per Day**       |                The average coverage time per day.               |
|   **Per Day Std Dev**    |                The standard deviation of the total coverage time per UTC day.               |
|       **Percent**        |                The total coverage duration as a percentage of the analysis period.               |
|    **Percent Per Day**   |                The average daily coverage duration as a percentage of a day.               |
| **Percent Per Day Std Dev** | The standard deviation of the daily coverage duration percentage.               |
|   **Percent Time Above** | Let the specified multiplicity be N. The statistic value V means that the analysis object is covered by at least N resources for V% of the analysis period. |
|        **Total**         |                The total coverage duration over the analysis period.               |
|   **Total Time Above**   |                Let the specified multiplicity be N. The total duration during which the analysis object is covered by at least N resources.               |
