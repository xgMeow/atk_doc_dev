# Batch Coordinate Transformation Tool

## Functional Description

The Batch Coordinate Transformation Tool (hereinafter referred to as Crdn) is mainly used for batch coordinate transformation of data files between different coordinate systems.

The main functions include:

(1) Batch coordinate transformation between coordinate systems including Central Body Fixed, J2000 Earth Mean Equator and Equinox, Assembled System, East‑North‑Up (ENU), Launch System, and Launch Inertial System.

(2) Flexible input format support, including spaces, commas, semicolons, and other separators, with customizable data order and content.

(3) Input and output data files can be in TXT or ephemeris format.

### Function Location

Open the main interface, click **Tools** in the menu bar, and select **Batch Coordinate Transformation Tool**. (The legacy version is also available under this menu.)

### Interface Introduction

The Batch Coordinate Transformation interface consists, from left to right, of the Time Options area, Transformation Parameters area, Source Coordinate System area, Destination Coordinate System area, Computation Mode area, Source Coordinate Data area, and Destination Coordinate Data area. The specific functions are described in the table below.

<center>Batch Coordinate Transformation Page Area Functions</center>

| Area | Function |
| ---------------- | -------------------------------------------- |
| Time Options | Selects the reference epoch for the data, including UTC and Relative Time. |
| Computation Mode | Selects the import/export file format: TXT or ephemeris file. |
| Transformation Parameters | Selects the data to be transformed, typically position, velocity, and time. |
| Source Coordinate System | Corresponds to the coordinate system of the imported batch data. |
| Source Coordinate Data | Corresponds to the imported batch data. |
| Destination Coordinate System | Corresponds to the coordinate system of the exported batch data. |
| Destination Coordinate Data | Corresponds to the exported batch data. |

## How to Use

### Select Time Mode

Based on the time information in the imported data, select the corresponding time mode in the **Time Options** area.

(1) Set the initial time. The default selection is **Epoch Time**, where the **Initial Time (UTC)** field is grayed out and not editable. In this mode, the time information in the imported TXT document should be in the format "YYYY‑MM‑DD HH‑MM‑SS".

(2) When **Relative Time** is selected, the **Initial Time (UTC)** field becomes editable. The time data in the document can be entered directly; the computation will use the initial time specified in the interface. In this mode, the time information in the TXT document is relative time in seconds. The ephemeris file defaults to Relative Time mode, with the initial time obtained directly from the ephemeris file.

![Selecting Relative Time](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170621465_zy.png)

### Import Data to Transform

(1) Select the import data type. The imported data can be a TXT or ephemeris file. The interface automatically reads the configuration from the ephemeris file, automatically checks **Epoch Time** in the Time Options, and selects the corresponding Source and Destination coordinate systems.

![Selecting Import File Type](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170051903_zy.png)

(2) Click the **…** button to browse for the original file to be transformed and import it. (Note: The time in the imported data must be consistent with the time mode selected in the software, and the units of the imported data must be consistent, either meters or kilometers.)

![Imported Transformation File](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170146472_zy.png)

(3) Locate the path of the data document to be transformed and click the **Open** button.

![Locating the batch coordinate data document](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170429270_zy.png)

(4) After import, the data is displayed in the **Source Coordinate Data** box. (Note: The document should include time, coordinate, and other relevant information.)

![Imported Data](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170448871.png)

### Select Transformation Parameters

The left side of the Transformation Parameters area lists the selectable parameter types, and the right side shows the selected parameter types. Time, Position, and Velocity are selected by default. (Note: The order of the parameter items in the right box must correspond to the format and order of the corresponding input data; otherwise, the computation will produce errors.)

![Selecting Transformation Parameters](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170650345_zy.png)

### Select Reference Systems for Coordinate Parameters

(1) The Source Coordinate System options include: Central Body Fixed, J2000 Earth Mean Equator and Equinox, Assembled System, East‑North‑Up (ENU), Launch System, and Launch Inertial System.

(2) The Destination Coordinate System options include: Central Body Fixed, J2000 Earth Mean Equator and Equinox, Assembled System, East‑North‑Up (ENU), Launch System, and Launch Inertial System.

Note: The corresponding parameter input fields appear only after both coordinate systems are selected. For example, when selecting **Launch Inertial System**:

1. The launch time should be entered according to the selected time mode.
2. Launch longitude and tracking longitude are limited to values within **±180°**; values outside this range cannot be entered.
3. Launch latitude and tracking latitude are limited to values within **±90°**; values outside this range cannot be entered.
4. Launch altitude and tracking altitude are limited to positive real numbers greater than 0.

![Entering Transformation Parameter Information](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170726301_zy.png)

### Start Transformation

After entering the data and completing the parameter and coordinate system selections, click the **Compute** button. The computed results will appear in the Destination Coordinate Data area.

If the computation is not successful, a corresponding prompt will appear. Use this information to identify the cause of the error.

### Export Results

(1) Export the data and save it in the selected file format. (The file is saved according to the selected output format: `.e` or `.txt`.)

![Setting Export File Type](../../zh/5.专业使用指南/media/04-批量坐标转换工具/image-20240426170808163_zy.png)

Note: When **Export File Type** is set to **Ephemeris File**, the imported file must also be an ephemeris file; otherwise, export is not allowed.

![Export File Type Prompt](../../zh/5.专业使用指南/media/04-批量坐标转换工具/4545_zy.png)

(2) After entering the data and completing the parameter and coordinate system selections, click **Compute**. The transformed data will be displayed in the destination data area. Then choose a location to save the exported file.
