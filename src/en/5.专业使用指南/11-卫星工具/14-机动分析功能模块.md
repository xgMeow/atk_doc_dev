## Functional Description

This module consists of two functions: "Maneuver Detection" and "Maneuver Reachable Domain". The former detects satellite maneuver activities, allowing observation of whether and what kind of maneuvers a satellite performs; the latter calculates all positions a satellite can reach given a specified maneuver capability.

### Function Location

This function is located in the ATK Tools menu. The specific opening position is shown in the figure below.

![Maneuver Analysis function in the toolbar](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-1.png)

## How to Use

### Create a Scenario

First, click <kbd>New<img src="../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image-3.png" alt="" no-view /></kbd> under the <kbd>Home</kbd> tab to create a scenario, as shown below.

![Create Scenario](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image-4.png)

### Add a Default Satellite

Add a satellite to the scenario. Click <kbd>Insert</kbd>, select **Satellite → Insert Default Type**, and click the <kbd>Insert…</kbd> button at the bottom right, as shown below.

![Create Satellite](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-3.png)

### Maneuver Detection

#### TLE‑Based Historical Maneuver Detection

Select **TLE‑Based Historical Maneuver Detection** as the Detection Type. In the **TLE Data of the Satellite** section, select the <PathCopy :entry="TLE_FILE" /> file as shown below. Keep other configuration settings at their defaults and click <kbd>Compute</kbd>. The computation results will be displayed in the data output area.

::: tip
TLE (Two‑Line Element) is a standard format for describing the orbits of space objects, widely used in satellite orbit computation and prediction.
:::

![TLE‑Based Historical Maneuver Detection Parameter Settings](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image-7.png)

![TLE‑Based Historical Maneuver Detection Results Display](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0526.png)

#### POD Data Based Maneuver Detection

Select **POD Data Based Maneuver Detection** as the Detection Type. The propagation models include: Vinti Model, Two‑Body, and J2 Mean. For this computation, choose the Vinti Model and keep other parameters at their defaults, as shown below. Click <kbd>Compute<img src="../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image-8.png" alt="" no-view /></kbd> to display the computation results in the data output area, as shown below.

![POD Data Based Maneuver Detection Parameter Settings](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-4.png)

![POD Data Based Maneuver Detection Data Results](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-5.png)

![POD Data Based Maneuver Detection Graphic Results](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-6.png)

### Maneuver Reachable Domain Computation

On this page, click **Maneuver Spacecraft → Add…**, and the **Maneuver Spacecraft** dialog will appear, as shown below.

![Maneuver Reachable Domain Parameter Settings](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-7.png)

Select **Satellite 1** from the scenario and click <kbd>OK</kbd>. Then click <kbd>Compute</kbd> to display the computation results in the data display area, as shown below.

![Maneuver Reachable Domain Computation Results](../../../zh/5.专业使用指南/11-卫星工具/media/5.14机动分析功能模块/image0105-8.png)
