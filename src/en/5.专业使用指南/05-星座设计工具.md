# Constellation Design Tool

## Functional Description

The Constellation Design module adds Walker, Rosette, and Flower constellations to the scenario based on a "seed" satellite.

## Function Location

This function is located in the ATK Tools menu. The specific location is shown in the figure below.

![Constellation Design in the toolbar](../../zh/5.专业使用指南/media/05-星座设计工具/image_zy.png)

## Interface Introduction

The interface consists of a seed satellite parameter settings area (left) and a generated constellation satellite list display area (right), as shown below.

![Constellation Design Interface](../../zh/5.专业使用指南/media/05-星座设计工具/image-1_zy.png)

## How to Use

### Create a Scenario

First, click <kbd>New<img src="../../zh/5.专业使用指南/media/05-星座设计工具/image-2.png" alt="" no-view /></kbd> under the <kbd>Home</kbd> tab to create a scenario, as shown below.

![Create Scenario](../../zh/5.专业使用指南/media/05-星座设计工具/image-3_zy.png)

### Add a Satellite to the Scenario

Add a satellite to the scenario as the "seed" satellite. Click <kbd>Insert</kbd>, select **Satellite → Insert Default Type**, and click the <kbd>Insert…</kbd> button at the bottom right, as shown below.

![Insert Satellite](../../zh/5.专业使用指南/media/05-星座设计工具/image-0311insertsat_zy.png)

The satellite appears in the scenario as shown below.

![Satellite in the Scenario](../../zh/5.专业使用指南/media/05-星座设计工具/image-5_zy.png)

### Set Constellation Parameters

Select <kbd>Constellation Design</kbd> from the <kbd>Tools</kbd> menu in the top toolbar, as shown below.

![Constellation Design Window](../../zh/5.专业使用指南/media/05-星座设计工具/image-6_zy.png)

Check **Seed Satellite** in the upper left, click <kbd>Select Object…</kbd> and choose the seed satellite inserted in the previous step, then click <kbd>OK</kbd>. The parameters of the newly created Satellite 1 will be displayed in the left area, as shown below.

![Constellation Design Window](../../zh/5.专业使用指南/media/05-星座设计工具/image-7_zy.png)

If **Seed Satellite** is not checked, you can directly set the seed satellite parameters in the left area, as shown below.

![Constellation Design Window](../../zh/5.专业使用指南/media/05-星座设计工具/image-8_zy.png)

### Create the Constellation

The available constellation configurations can be selected from the **Constellation Type** list, as shown below.

![Constellation Configuration Selection](../../zh/5.专业使用指南/media/05-星座设计工具/image-9_zy.png)

After selecting the constellation type (taking Walker as an example), enter the corresponding constellation parameters below, such as total number of satellites, number of satellites per plane, number of planes, inter‑plane phase offset, and RAAN spread. Click <kbd>Compute</kbd> to display all the satellite parameters in the right list, as shown below.

![Computed Satellites](../../zh/5.专业使用指南/media/05-星座设计工具/image-10_zy.png)

Click <kbd>Insert Satellites</kbd> to complete the constellation creation, as shown below.

![Constellation in 3D View](../../zh/5.专业使用指南/media/05-星座设计工具/image-11_zy.png)

![Constellation in 2D View](../../zh/5.专业使用指南/media/05-星座设计工具/image-12_zy.png)
