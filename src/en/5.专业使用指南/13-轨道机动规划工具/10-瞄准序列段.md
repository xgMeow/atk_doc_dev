# Target Sequence

A Target Sequence defines a sub‑mission sequence consisting of a series of Maneuver Segments and Propagate Segments to accomplish a specific target task. Implementing a Target Sequence can generally be completed in three steps.

1) Add basic segments to the Target Sequence.

2) Define the properties of the Target Sequence.

3) Configure the Target Sequence.

**(1) Add Basic Segments to the Target Sequence**

Any Mission Control Sequence segment can be nested within a Target Sequence, and one Target Sequence can also be nested within another. Users can add the basic MCS segments they need according to their mission requirements.

**(2) Define the Properties of the Target Sequence**

The iterative algorithms available in the current software version include the Differential Corrector, Sequential Quadratic Programming, and intelligent optimization algorithms. **(3) Configure the Target Sequence**

After completing the property settings, re‑enter the Target Sequence settings interface to configure the **Action** parameters for the Target Sequence. The action types include: Run active profiles, Run Nominal Sequence, and Run active profiles ONCE.

Among these, **Run active profiles** executes the target sequence until the optimization objective is achieved. During execution, the target sequence iterates repeatedly, and the selected optimization variables are updated accordingly. **Run Nominal Sequence** performs the opposite—it executes without iteration. **Run active profiles ONCE** executes the target sequence based on the variable values provided by the user, and typically does not involve optimization solving.

Users can select the appropriate **Action** parameter according to their needs. The **Apply Changes** button next to the Action parameter applies the current modified settings to the target sequence, while the **Reset** button resets the target sequence.
