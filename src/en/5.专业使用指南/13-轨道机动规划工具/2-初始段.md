# Initial State

The Initial State segment is used to define the initial state of the entire Mission Control Sequence and its subsequences. In addition to time information, the configuration of the Initial State mainly includes three parts: initial orbital elements or initial position/velocity, spacecraft parameters, and basic information. The detailed page is shown in the figure below.

![Orbit Maneuver Planning Tool - Initial State](../../../zh/5.专业使用指南/13-轨道机动规划工具/media/5.3轨道机动规划工具/image-131_zy.png)

Specifically, the main function of the Initial State segment is to define the initial conditions of the spacecraft and the characteristic parameters of the spacecraft itself. The initial state is usually given in terms of initial orbital elements, initial epoch, and orbital coordinate system. Spacecraft parameters include dry mass, fuel mass, drag coefficient, drag area, solar radiation pressure coefficient, and solar radiation pressure area. Basic information is used to describe the fundamental parameters of the Initial State, including the name and other user‑defined descriptive information.
