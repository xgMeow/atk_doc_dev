# Backward Sequence

The Backward Sequence is a composite that can be used to group multiple segments together, and can define how the resulting state is passed to the next mission sequence segment or the next sequence. Unlike the Sequence Segment, the basic segments within this sequence are run in reverse. The parameter settings for the Backward Sequence mainly concern the state transfer method. There are two transfer methods: passing the initial state of the Backward Sequence to the next segment, and passing the final state of the Backward Sequence to the next segment.
