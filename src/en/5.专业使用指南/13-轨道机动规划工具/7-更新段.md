# Update Segment

The Update Segment is used to update spacecraft configuration parameters, including six parameters: dry mass, fuel mass, solar radiation pressure area, drag area, solar radiation pressure coefficient, and drag coefficient. For each parameter, the Update Segment provides the options shown in the following table.

| Operation        | Meaning                                                       |
| ---------------- | ------------------------------------------------------------- |
| No change in value | Keeps the current value of the parameter unchanged.             |
| Add value        | Adds the value entered in the numeric field to the current value of the parameter. |
| Subtract value   | Subtracts the value entered in the numeric field from the current value of the parameter. |
| Set to new value | Replaces the current value of the parameter with the value entered in the numeric field. |
