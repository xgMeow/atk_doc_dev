# Sequence Segment

The Sequence Segment is a composite that can be used to group multiple segments together, and can define how the resulting state is passed to the next mission sequence segment or the next sequence. The parameter settings for the Sequence Segment mainly concern the state transfer method. There are two transfer methods: passing the initial state of the sequence to the next segment, and passing the final state of the sequence to the next segment. The Sequence Segment also includes a built‑in Lua client, which supports running corresponding script programs.
