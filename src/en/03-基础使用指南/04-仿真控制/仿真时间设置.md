# Simulation Time Settings

Displays the current simulation time in real time. The default value is the scenario start time, and you can manually enter a time to jump to a specific point.

![Simulation time input box](../../../zh/03-基础使用指南/04-仿真控制/media/仿真时间设置/update2601-83.png)

You can also drag the slider in the Timeline View to change the current simulation time.
