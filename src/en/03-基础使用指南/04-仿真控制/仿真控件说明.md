# Simulation Controls

## Reset

Click the ![image-20260327163938298](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327163938298.png) button to reset the simulation progress and restore the simulation time to the scenario start time.

> After the simulation data finishes playing, it will stop automatically. The progress bar will not remain at the end time. Click <kbd>Reset</kbd> to restart playback from the beginning.

## Decrease Time Step

Click the ![image-20260327163958108](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327163958108.png) button to decrease the simulation rate. The effect varies by mode:

- Step Mode: Step size is halved; the minimum step is **1**.
- Rate Mode: Speed is halved; the minimum speed is **0.0001**.
- RealTime Mode: Simulation time decreases by **1 second** directly.

## Reverse

Click the ![image-20260327164014571](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164014571.png) button to enable reverse playback. The simulation direction moves from the current time back toward the scenario start time.

> After the simulation finishes playing, click the ![image-20260327164014571](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164014571.png) reverse button to start reverse playback from the current position.

## Pause

Click the ![image-20260327164025573](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164025573.png) button to pause the currently running simulation.

> After pausing, click the ![image-20260327164046354](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164046354.png) button to resume simulation.

## Run

Click the ![image-20260327164036593](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164036593.png) button to start or resume simulation.

> After clicking, the ![image-20260327164025573](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164025573.png) pause button will become clickable.

## Increase Time Step

Click the ![image-20260327164118379](../../../zh/03-基础使用指南/04-仿真控制/media/仿真控件说明/image-20260327164118379.png) button to increase the simulation rate. The effect varies by mode:

- Step Mode: Step size is doubled; the maximum step is **100000000**.
- Rate Mode: Speed is doubled; the maximum speed is **100000000**.
- RealTime Mode: Simulation time increases by **1 second** directly.
