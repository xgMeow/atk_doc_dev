# Simulation Mode Configuration

## Supported Simulation Modes

Used to quickly select the simulation run mode. The following three modes are supported:

- **Step Mode**
  When selected, a [Step] drop-down appears on the right ![Step Mode](../../../zh/03-基础使用指南/04-仿真控制/media/仿真模式配置/update2601-86.png)
  Available values: 0.1, 1, 5, 30, 60, 180, 300, 600

- **Rate Mode**
  When selected, a [Speed] drop-down appears on the right ![Rate Mode](../../../zh/03-基础使用指南/04-仿真控制/media/仿真模式配置/update2601-87.png)
  Available values: Maximum Speed, 5-times, 10-times, 100-times, 500-times

- **RealTime Mode**
  Advances the simulation according to system real time; no additional parameter drop-down.

> The default mode is **Step Mode**.

## Simulation Step / Speed Input Box

Displays and allows manual modification of the current simulation step or speed:

![](../../../zh/03-基础使用指南/04-仿真控制/media/仿真模式配置/update2601-82-1774600410891-54.png)

- Default step: **10**
- Default speed: **128**

> [!NOTE]
>
> - Step = **1**: Each second of simulation advances the scenario by 1 minute.
> - Speed = **1**: Each second of simulation advances the scenario by 1 second.
