# Insert

The **Insert** menu options include four sub-menus: [Insert](#insert-1), [Insert Default](#insert-default), [From Database](#from-database-1), and [Constellation](#constellation).

![Insert Sub-Menu](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/update2601-28.png)

## Insert

### General Operation Instructions

Click the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image97.png" alt="" no-view /> icon to open the **Insert Object** dialog. You can insert the following two types of objects into the current scenario:

- **Scenario Objects**: Advanced Close Approach, Aircraft, Area Target, Chain, Constellation, Coverage Definition, Facility, GroundVehicle, LaunchVehicle, Missile, Planet, Satellite, SatelliteCluster, SatelliteSystem, Ship, Star, Submarine, etc.
- **Attached Objects**: Antenna, FigureOfMerit, Receiver, Sensor, Transmitter, etc.

**Operation Steps**:

1. **Select Object Type**: Choose the object to be inserted from the list.
2. **Select Central Body**: Specify the celestial body to which the object belongs (e.g., Earth, Moon, etc.).
3. **Select Insertion Method**: Choose the appropriate addition method based on the object type (see [Insertion Method Descriptions](#insertion-method-descriptions) and [Insertion Method Detailed Operations](#insertion-method-detailed-operations)).
4. **Complete Insertion**: Click the <kbd>Insert...</kbd> button.

![Insert Object](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324160345230.png)

### Insertion Method Descriptions

The system provides various insertion methods for different object types, making it easy to quickly add objects:

| Insertion Method | Description |
| ----------------- | ----------- |
| **Insert Default** | Quickly add an object using system default settings |
| **From Database** | Search and load objects from the standard object database |
| **From TLE File** | Import satellite objects via TLE ephemeris files |
| **From External Ephemeris File** | Import satellite objects via `.e` format ephemeris files |
| **Orbit Wizard** | Add satellites with wizard assistance, supporting multiple orbit types |
| **Select Countries and Regions** | Add area targets by selecting countries or regions |
| **From City Database** | Search and add facility objects from the city database |

### Insertion Method Detailed Operations

#### Insert Default
Select the `Insert Default` method and simply click the <kbd>Insert...</kbd> button to complete the addition.

#### From Database
Select the `From Database` method, click the <kbd>Insert...</kbd> button, set the search parameters in the pop-up window, and click <kbd>Search</kbd>. Select the desired object from the results, configure the color, and click <kbd>Insert</kbd>.

> For detailed operations, please refer to [From Database](#from-database-1).

![From Database Insert Example](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324200029409.png)

#### From City Database
Select the `From City Database` method, click the <kbd>Insert...</kbd> button, search and select city data as needed, configure the color, and click <kbd>Insert</kbd>. For detailed operations, please refer to the [From Database](#from-database-1) section.

![From City Database Insert Example](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324200850860.png)

#### From TLE File
Select the `From TLE File` method, choose the data source in the pop-up dialog, and configure color and start epoch as needed.

#### From External Ephemeris File
Select the `From External Ephemeris File` method and select an ephemeris file in `*.e` format in the pop-up dialog.

#### Orbit Wizard
Select the `Orbit Wizard` method, choose the orbit type and configure the corresponding parameters in the wizard interface.

![Orbit Wizard](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324201405156.png)

#### Select Countries and Regions
Select the `Select Countries and Regions` method, choose the country or region on the left side of the interface, and configure insertion options, insertion area, and visualization color on the right side.

![Select Countries and Regions](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324201546523.png)

## Insert Default

Click the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324163558318.png" alt="" no-view /> icon to open a prompt dialog where you can select the default object type to insert (such as Advanced Close Approach, Satellite, Facility, Ship, etc.).

After configuration, clicking the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324163538252.png" alt="" no-view /> icon will directly insert the selected default object, enabling quick insertion of frequently used objects.

![Insert Default Object Dialog](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/update2601-8.png)

## From Database

Click the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/update2601-31.png" alt="" no-view /> icon to open the **Query Standard Object Database** window.

### Set Filter Conditions
Configure the query information in the window. The current filter conditions will be displayed above the results. Click the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324182029227.png" alt="" no-view /> icon next to each condition to **delete** that filter condition.

![Filter Conditions Example](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324182705447.png)

### Execute Search
After setting the conditions, click the <kbd>Search</kbd> button to execute the query. The search results will be displayed in the right area, showing the total number of results and the number currently selected, with specific objects presented in a table.

![Search Example](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324182836624.png)

### Select Objects

- **Single Selection**: Click an item in the table to select a single object.
- **Multiple Selection**:
  - Hold the <kbd>Ctrl</kbd> key and click to select multiple non-contiguous objects simultaneously.
  - Hold the <kbd>Shift</kbd> key and click to select a contiguous range of objects.

After selection, the objects will be highlighted in blue as shown below:

![Select Objects](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324182923829.png)

### Configure Color
After selecting objects, you can configure colors in the insertion options:
- Check **Auto Select Color** to have the system automatically assign colors to objects.
- Uncheck and click the color block to manually select a color.

![Configure Color](../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/image-20260324183046888.png)

### Complete Operations
After completing the above settings, you can perform the following operations:
- **Export TLE**: Export the selected objects to a TLE format file.
- **Insert Satellite System**: Insert the selected objects as a satellite system.
- **Insert**: Directly insert the selected objects.
- **Close**: Close the current window.

## Constellation

Click the <img src="../../../zh/03-基础使用指南/01-主菜单栏/media/04-插入/update2601-32.png" alt="" no-view /> icon to open the **Insert Constellation** interface. Click the drop-down list to select from the following predefined constellations: BeiDou, Tianlian, Galileo, GLONASS, GPS, DSP.

After selecting the constellation to insert, click <kbd>Insert</kbd> to complete the addition.
