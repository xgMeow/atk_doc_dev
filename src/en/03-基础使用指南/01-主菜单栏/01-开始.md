## File Operations

### New

Click ![image-20260327155249154](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260327155249154.png) to open the **ATK: New Scenario Wizard** dialog.

Follow the wizard prompts to select the central body of the scenario, and quickly complete the creation of a new scenario.

![New Scenario Wizard](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/update2601-3.png)

> For more information on creating a new scenario, refer to: [Creating a New Scenario](../02-场景管理/02-创建新场景.md)

### Open

Click ![image-20260327155453897](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260327155453897.png) to open the default scenario file directory. Scenario files are saved in `.atk` format by default. Select the scenario file you wish to open to restore the previous scenario settings.

![Open Scenario Example](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260324153559805.png)

### Close

Click ![image-20260327155513508](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260327155513508.png) to close the currently active scenario.

### Save

Click ![image-20260327155540105](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260327155540105.png) to save changes to the current scenario.

### Save As

Click ![image-20260327155558046](../../../zh/03-基础使用指南/01-主菜单栏/media/01-开始/image-20260327155558046.png) to open the save directory dialog. You can enter a file name and choose a save format (`.atk`, `.xml`, `.txt` are supported), with `.atk` as the default. Save the current scenario as a new file.
