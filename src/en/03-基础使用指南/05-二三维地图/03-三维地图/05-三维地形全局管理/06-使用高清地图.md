# Using High‑Resolution Maps

## Enabling High‑Resolution Display

> [!NOTE]
> ATK includes built‑in high‑resolution Earth imagery textures. This feature is **disabled by default**.

In the [Globe Manager] interface, check the `Earth_img_Base_TDB` layer to load and display the high‑resolution TDB‑format Earth imagery.

![TDB‑format Earth imagery texture](../../../../../zh/03-基础使用指南/05-二三维地图/03-三维地图/05-三维地形全局管理/media/06-使用高清地图/GlobeManager(3).jpg)

## Restoring Basic Display

Uncheck the `Earth_img_Base_TDB` layer to disable the TDB high‑resolution imagery. The system will automatically switch to display only the next‑level TIFF‑format basic Earth imagery.

![TIFF‑format Earth imagery texture](../../../../../zh/03-基础使用指南/05-二三维地图/03-三维地图/05-三维地形全局管理/media/06-使用高清地图/GlobeManager(4).jpg)
