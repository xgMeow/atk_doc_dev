# Best Practice Recommendations

1. Add basic low‑resolution imagery/elevation layers first, then overlay high‑resolution detail layers to improve loading efficiency.
2. It is recommended that elevation layers use the same geographic coordinate system as imagery layers to avoid misalignment between terrain and texture.
3. During temporary debugging, you can quickly hide layers by unchecking them, avoiding frequent deletion and re‑addition.
4. For large amounts of tile data, it is recommended to use the `.tdb` format to improve scene loading speed and stability.
