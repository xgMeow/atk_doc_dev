# Troubleshooting Common Issues

## Layer not displaying after addition

- Verify that the layer checkbox is checked.
- Confirm that the data file path is correct and the file is not corrupted.
- Check the layer priority to see if it is completely covered by a lower‑listed layer with higher priority.

## No terrain relief effect

- Confirm that an elevation layer for the target celestial body has been added and is checked.
- Check whether the elevation data file is valid or if it is covered by a lower‑priority layer that uses flat terrain.

## Imagery appears blurry or misaligned

- Add a higher‑resolution imagery layer first, or reorder the layer list by moving the high‑resolution layer to a lower position.
- Verify that the coordinate system of the imagery data matches the celestial body model.
