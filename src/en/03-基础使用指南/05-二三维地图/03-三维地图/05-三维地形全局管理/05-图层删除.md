# Deleting a Layer

1. In the [Globe Manager] interface, select the target layer to be deleted.
2. Click the <kbd>Delete</kbd> button in the upper-left corner of the interface to completely remove the layer from the 3D scene; the associated effects will also disappear simultaneously.
