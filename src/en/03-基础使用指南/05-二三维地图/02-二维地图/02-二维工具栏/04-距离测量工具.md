# Range Measurement Tool

## Description

This tool is used to quickly measure the **geographic distance** and **bearing** between two points within the 2D map view.

## Procedure

1. Click the 「Measure」 button in the toolbar to activate the function.
2. Click the start point on the map, hold down the left mouse button, drag to the end point, and release.
3. The measurement result will be displayed directly in the status bar at the bottom of the view, including:
   - Latitude and longitude coordinates of the start and end points
   - Straight-line distance between the two points (in km)
   - Bearing between the two points (in deg)

## Result Interpretation

- Distance: The spherical distance between the two points calculated based on the Earth ellipsoid model.
- Bearing: The direction angle from the start point to the end point, ranging from 0° to 360°.

> [!TIP]
> The measurement result is an approximation under the 2D map projection. For high‑precision calculations, it is recommended to use the dedicated spatial analysis module.
