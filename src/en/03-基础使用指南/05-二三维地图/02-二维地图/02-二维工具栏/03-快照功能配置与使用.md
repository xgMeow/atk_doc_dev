# Snapshot Configuration and Usage

## Snapshot Property Configuration

Click the 「Snapshot Property」 button in the toolbar to open the [2D View Snap Property] dialog, where you can preset default parameters for screenshots to streamline subsequent operations:

- **Snapshot Target Settings**:
  - `Snap to Clipboard`: The screenshot is saved directly to the system clipboard for quick pasting into other documents.
  - `Snap to File`: The screenshot is saved directly as a local file; this requires the file format setting to be configured accordingly.
- **File Format Selection**: Supports multiple image formats such as `PNG`, `BMP`, and `JPG`; you may also select "All files" to specify a custom extension.

## Instant Snapshot Operation

After completing the property configuration, click the 「Snapshot」 button in the toolbar to capture the current 2D view:

- If set to 「Snap to Clipboard」, the screenshot is directly stored in the clipboard with no further action required.
- If set to 「Snap to File」, a [Save As] dialog will appear, allowing you to customize the save path, file name, and format, and quickly export the image according to the preset format.
