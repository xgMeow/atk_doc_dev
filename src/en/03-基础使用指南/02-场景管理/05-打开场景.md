# Opening a Scenario
This document describes the specific steps for opening an existing simulation scenario in the ATK software, supporting the loading of scenario files in various formats from local storage to quickly restore previous simulation configurations and states.

1. Click the **Home** menu at the top of the software and select the <kbd>Open</kbd> button in the ribbon. The system will display the **Open Scenario** dialog.
2. In the **Open Scenario** dialog, browse the local file directory, select the scenario file you wish to open (supported formats: `.atk` and `.xml`), and then click the <kbd>Open</kbd> button in the dialog.

   ![Opening a Scenario - Example](../../../zh/03-基础使用指南/02-场景管理/media/03-打开场景/image-20260325162956195.png)

3. After clicking, the software will automatically load the selected scenario file. Once completed, all configurations, object information, and simulation states of that scenario will be restored, allowing you to proceed directly with further editing and simulation operations.
