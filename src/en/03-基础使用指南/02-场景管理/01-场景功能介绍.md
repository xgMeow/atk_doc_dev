# Scenario Overview

A scenario is the core carrier of aerospace mission simulation in the ATK software. It serves as a unified container for managing simulation time, celestial body data, terrain information, visualization styles, and various space objects, providing a standardized runtime environment for the entire simulation workflow, including orbit computation, coverage analysis, access analysis, and mission propagation.

## Core Functional Modules

### Scenario Lifecycle Management

Scenario lifecycle management provides full-process control over simulation scenarios from creation to opening and saving, supporting rapid initialization, recovery, and persistence of simulation environments. The specific functions are as follows:

- **New Scenario**: Create a new scenario quickly from the welcome screen or the main menu, with automatic initialization of the basic simulation runtime environment.
- **Open Scenario**: Load local scenario files in `.atk` or `.xml` format, restoring the complete simulation state from the file in a single click.
- **Save Scenario**: Save all current scenario configuration and object information with a single click, with support for <kbd>Save As</kbd> to a new file. You can customize whether to save historical data, facilitating subsequent simulation review and data traceability.

> Related operations: [Creating a New Scenario](./02-创建新场景.md), [Opening a Scenario](./05-打开场景.md), [Saving a Scenario](./04-保存场景.md)

### Basic Properties Configuration

Through the **Scenario Properties** dialog, you can perform fine-grained management and customization of the underlying core parameters of the scenario to meet the requirements of aerospace mission simulations at various levels of fidelity and for different mission types. The core configuration items are as follows:

- **Analysis Period**: Supports multiple time systems including UTCG, BJT, GPS, BDT, TDT, and Julian Date, allowing precise setting of the simulation time interval and reference epoch to accommodate high-precision orbit computation needs.
- **Earth Data**: Configure Earth Orientation Parameters (EOP) to provide time-matched Earth rotation data for high-precision orbit determination and ground target positioning.
- **Terrain Management**: Supports adding/removing terrain data for celestial bodies such as Earth and the Moon, with customizable latitude/longitude ranges and resolutions for terrain occlusion analysis and surface environment simulation.
- **Save Options**: Allows manual selection of whether to save scenario history data, enabling full recording of simulation operations and data changes.

> Detailed configuration: [Scenario Properties](./03-场景属性配置/README.md)

### Visualization Styles Configuration

Visualization styles configuration supports personalized display settings for 2D and 3D views, optimizing the visual presentation and data readability of the simulation scenario. The core configuration items are as follows:

- **2D Graphics Properties**: Customize the font, size, style, and border color of the 2D window to enhance the readability of text annotations against the map background.
- **3D Graphics Properties**: Includes two major configuration dimensions: **3D Fonts** and **Data Display**
  - **3D Fonts**: Configure the display style of text in the 3D scene, precisely adapting to annotation requirements in complex 3D environments.
  - **Data Display**: Add real-time monitoring items such as spacecraft parameters and mission status, with flexible settings for text display position, alignment, background, and border styles, enabling visual real-time monitoring of critical data during simulation.
