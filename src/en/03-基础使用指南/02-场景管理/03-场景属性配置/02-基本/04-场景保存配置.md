# Save Options

Scenario Save Options is an important configuration item of ATK scenario properties, used to customize whether to save **history data** of the scenario. Through reasonable configuration, operation records and data changes during the simulation process can be preserved, providing complete data support for subsequent scenario review, data traceability, and secondary analysis.

![Scenario Save Options Interface](../../../../../zh/03-基础使用指南/02-场景管理/03-场景属性配置/02-基本/media/04-场景保存配置/image-20260325173513559.png)

## Operation Instructions

1. Open the **Scenario Properties** dialog in the software, locate the scenario save-related settings area among the configuration items, and enter the **Save Options** configuration window.
2. In the window, check the <kbd>Save History Data</kbd> option to enable the scenario history data saving function; uncheck it to disable this function, saving only the basic scenario configuration and object information.

> [!TIP]
> After enabling the **Save History Data** function, simulation data changes during scenario execution will be saved along with the scenario.
> If you only need to save the basic scenario configuration, you can uncheck this option to effectively reduce the storage size of the scenario file.
>
> For actual scenario saving operations, refer to: [Saving a Scenario](../../04-保存场景.md)
