# Terrain

## Function Overview

Terrain is an important configuration module of ATK scenario properties, used to centrally manage terrain data for different central bodies. It supports **adding** and **removing** terrain data operations. The configured terrain data files will provide realistic geographic data support for **terrain occlusion analysis** and **celestial body surface environment visualization** in aerospace mission simulations, significantly improving the realism and accuracy of the simulations.

For example, local terrain data can be customized for **Earth, the Moon, and traditional planets of the Solar System** to suit different aerospace mission simulation requirements:

- Add high-resolution terrain data for the Moon to precisely simulate terrain occlusion relationships during a lander's descent to the lunar surface.
- Add terrain data for Earth to analyze the impact of mountains, highlands, and other terrain features on the visibility intervals between low-orbit satellites and ground receiving stations.

## Basic Operation Instructions

In the **Terrain** configuration interface, first select the target celestial body from the **Central Body** drop-down list. The interface will automatically display all terrain data files currently bound to that celestial body. You can then perform management operations such as adding or removing files.

## Terrain File Information Display

After selecting the target central body, the interface will display the core information of all its terrain files in a list format, facilitating quick review of data attributes. The information fields are described as follows:

- **Enabled**: Indicates whether the terrain source is currently active in the current scenario.
- **File**: Displays the local storage path of the terrain data file for easy file location.
- **Type**: Indicates the file format type of the terrain data.
- **Lat/Lon Extents**: Displays the geographic coverage of the terrain data in the format `Min Latitude, Min Longitude, Max Latitude, Max Longitude`.
- **Resolution**: Indicates the spatial resolution of the terrain data. Higher resolution provides greater accuracy for terrain simulation and analysis.

## Terrain File Management Operations

For the terrain data files of the selected central body, both single-file and batch management operations are supported. The operation buttons and their functions are described as follows:

- **Add**: Click the <kbd>Add</kbd> button. In the **File Selection** dialog that appears, you can import **one or more** terrain data files to the current celestial body.
- **Remove**: First select the terrain file(s) to be removed in the list, then click the <kbd>Remove</kbd> button to delete the selected file(s).
- **Remove All**: Click the <kbd>Remove All</kbd> button to clear **all** terrain data files bound to the current central body in a single action.

> [!TIP]
> The **resolution** and **latitude/longitude coverage range** of terrain data directly affect the visualization accuracy of the scenario and the reliability of terrain analysis results. It is recommended to select matching terrain files based on the accuracy requirements and analysis scope of your simulation mission.
