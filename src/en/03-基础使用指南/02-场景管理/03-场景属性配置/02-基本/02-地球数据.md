# Earth Data

Earth Data is a critical configuration item of ATK scenario properties, used to set **Earth Orientation Parameters (EOP)**. These parameters precisely describe the variation of the Earth's rotation axis relative to a space-fixed reference frame, serving as the core foundation for high-precision orbit computation and precise ground target positioning, and directly impacting the computational accuracy of aerospace mission simulations.

## Earth Data Core Configuration Item Descriptions

| Configuration Item | Detailed Description |
| :----------------- | :------------------- |
| **Start Time** | The starting epoch of the Earth Orientation Parameters data. **Must match the time range of the scenario's [Analysis Period](./01-仿真时间.md)** , providing the corresponding Earth orientation data for the simulation period. |
| **Stop Time** | The ending epoch of the Earth Orientation Parameters data. **Must be consistent with the time range of the scenario's [Analysis Period](./01-仿真时间.md)** , ensuring continuity of EOP parameters throughout the entire simulation period. |
| **Data File** | Select a local Earth Orientation Parameters data file. Only `.dat` format is supported. The file must contain complete and valid EOP parameter datasets to provide data support for computations. |

> [!IMPORTANT]
> The time range of the Earth Data configuration must exactly match the [Analysis Period](./01-仿真时间.md). Any deviation in the time range will directly reduce the accuracy of orbit computation and ground target positioning, and may even cause distortion of simulation results.
