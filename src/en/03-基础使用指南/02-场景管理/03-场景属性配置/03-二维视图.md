# 2D Graphics Properties

The 2D Graphics properties page is an important module for ATK scenario visualization configuration. It is specifically designed to customize the **font display effects** in the 2D graphics window. By adjusting font and text outline related parameters, it optimizes the readability of text annotations in 2D scenarios, adapting to different map backgrounds and display requirements.

![2D Graphics Configuration Interface](../../../../zh/03-基础使用指南/02-场景管理/03-场景属性配置/media/02-二维视图/image-20260325173706343.png)

## Font Configuration
Full customization of text fonts in the 2D view is supported, including the following configuration items:
- **Font**: Freely select the desired font from the local system font library to suit different display styles.
- **Size**: Set the font display size in **points**, which can be flexibly adjusted according to the view window size.
- **Style**: Supports selecting **Bold**, **Italic**, or a combination of both for a **Bold + Italic** style.

## Text Outline Configuration
To address the issue of text being obscured or having low legibility against different map backgrounds, personalized settings for text outlines are supported, including the following configuration items:
- **Style**: Two options are available — "None" disables the text outline, while "Show" enables it. When enabled, readability against complex backgrounds is significantly improved.
- **Color**: Click the color picker in the interface to customize the display color of the text outline. It is recommended to choose a color that contrasts well with the map background.

> [!TIP]
> The font display effect in the 2D view is directly related to how well it matches the scene background. You can flexibly adjust font styles and outline settings based on the current map's colors and textures to ensure clear and readable text annotations.
