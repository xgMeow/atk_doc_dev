# Client Plotting

## Overview

- Implements the client-side plotting toolbar, including functions such as export, move, zoom in, reset, grid, data cursor, and legend.

## Usage

Run `ATKConsole.exe` located in the same directory as `ATK.exe`. The client plotting command window will appear.

Enter the following command:

```atks
 plot([4,5],[9,8])
 ```

This command creates a 2D graphics window with an X‑axis range of 4–5 and a Y‑axis range of 8–9, and draws a straight line connecting point (4,9) and point (5,8).

![Graphics 1](../../../zh/03-基础使用指南/可视化/media/客户端绘图/Image1.png)

Enter the following command:

```atks
 hold ("on")
 ```

This command allows subsequent plotting commands to be overlaid on the previous plot.

![Graphics 2](../../../zh/03-基础使用指南/可视化/media/客户端绘图/Image2.png)

Enter the following command:

```atks
 plot([7,8,9,10],[10,11,12,13])
 ```

This command creates a 2D graphics window with an X‑axis range of 7–10 and a Y‑axis range of 10–13, and draws a straight line connecting point (7,10) and point (10,13).

## Window Description

![Window Buttons](../../../zh/03-基础使用指南/可视化/media/客户端绘图/Image3.png)

| Button          | Description |
| --------------- | ----------- |
| Save            | Saves the generated window. |
| Export          | Exports a `.csv` file; supports export by row or by column. |
| Move            | After selection, allows dragging the graphics within the window with the mouse. |
| Zoom in         | Zooms in on the graphics. |
| Reset           | Restores the graphics window to its original format. |
| Show Legend     | Displays the legend. |
| Show Grid       | Displays grid lines. |
