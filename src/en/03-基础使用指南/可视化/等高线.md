# Contours

## Overview

The Contours function is used to visually display the **elevation coverage range** of a vehicle (such as a satellite, aircraft, etc.) relative to the ground in both 2D and 3D views.

- **Elevation Contours**: Closed curves connecting all points on the ground where the vehicle can be observed at the **same elevation angle**. For example, a contour line for a satellite elevation of 30° connects all locations on the ground that see the satellite at exactly 30° elevation.
- **Elevation Ellipse**: Since the Earth is approximately spherical and the vehicle's signal beam is typically conical, its intersection with the Earth's surface often appears as an ellipse on a planar map. This function supports setting elevation ellipses at specific times for precise signal coverage analysis.

## Usage

### 1. Open the Contours Settings Interface

#### Open Object Properties

Select the target object in the scene (e.g., "Satellite1") and access its properties via either method:

- Right-click the object and select **Properties**.
- Double-click the object directly.

#### Enter the Contours Settings Interface

In the navigation tree on the left side of the properties window, expand **2D Graphics** > **Contours** to enter the settings interface.

The interface mainly contains two configuration areas: **Elevation Contours** and **Elevation Ellipse**.

### 2. Configure Elevation Contours

#### Enable Display

- Check the **Show** checkbox to display the contour lines in the view.

#### Add Levels

The system provides two ways to add elevation levels:

- **Batch Add (by Start/Stop/Step)**
  Enter the start value, stop value, and step size, then click **Add**. The system will automatically generate a series of evenly spaced levels (e.g., 10°, 20°, 30°…).
- **Single Add (by Specified Value)**
  Enter a specific angle value directly and click **Add** to add a single level.

#### Configure Level Styles

After adding, all levels will appear in the list. You can customize each level individually:

- **Modify Angle Value**: Double‑click the value in the list to edit it.
- **Set Color**: Click the color swatch and select a color from the palette.
- **Adjust Line Style and Line Width**: Choose a line style (e.g., solid, dashed) from the drop‑down menu, and enter a value to adjust line width (in pixels).
- **Control Label Display**: Check or uncheck **Show Label** to toggle label visibility for each level.

#### Fill Region

To fill the area inside the contour lines, check the **Fill** checkbox.

### 3. Configure Elevation Ellipse

#### Enable Function

Check the **Elevation Ellipse** checkbox to activate the function.

#### Manage Elevation Ellipses

- **Add**: Click **Add** to insert a new row in the list. Double‑click to edit the **Time** and **Level Angle** for that ellipse; click to modify its color, line style, and line width.
- **Delete**: Select a row in the list and click **Delete** to remove that ellipse; click **Delete All** to remove all ellipses.

![Elevation Ellipse configuration at specific times illustration](../../../zh/03-基础使用指南/可视化/media/等高线/image-20260319084932788.png)

### 4. Save and Apply

- Click **OK**: Save all current settings and close the properties window.
- Click **Apply**: Apply the settings without closing the window, allowing you to continue adjusting other parameters.
