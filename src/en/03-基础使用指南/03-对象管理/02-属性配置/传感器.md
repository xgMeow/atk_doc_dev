# Sensor

Sensor properties are used to configure detection equipment mounted on various platforms, including four modules: **Basic Properties, 2D Graphics, 3D Graphics, and Constraints**.

---

## Basic Properties

Define the sensor type, geometric/physical parameters, relative position, and pointing method.

### Sensor Types and Corresponding Parameters

| Sensor Type       | Key Definition Parameters                               |
| ----------------- | ------------------------------------------------------- |
| Simple Conic      | Cone Half Angle                                         |
| Rectangular       | Vert Half Angle, Hori Half Angle                        |
| Complex Conic     | Cone Half Angle, Clock Angle                            |
| Half Power        | Frequency, Diameter                                     |
| SAR               | Elevation Angle, Exclusion Angle, Track parent altitude, Altitude |

The pointing setup includes the pointing type and the corresponding parameters for each type.

::: details Pointing Type: Fixed
| Offset Attitude Form | Parameters                           | Description                                                                                     |
| :------------------- | :----------------------------------- | :---------------------------------------------------------------------------------------------- |
| **Az-El**            | Azimuth, Elevation                   | Azimuth is the horizontal angle, Elevation is the pitch angle, in degrees.                      |
| **Quaternion**       | qx, qy, qz, qs                       | Quaternion representation, qs is the scalar part.                                               |
| **Euler Angles**     | Euler1, Euler2, Euler3, Sequence     | Three Euler angles (deg) and rotation sequence (e.g., ZYX, XYZ).                                |
| **YPR Angles**       | Yaw, Pitch, Roll, Sequence           | Three angles and sequence (e.g., YPR, YRP).                                                     |
| **Transformation Matrix** | 3×3 matrix                      | Directly enter the 9 elements of a 3×3 rotation matrix.                                        |
:::

::: details Pointing Type: Spinning
| Definition       | Description                                                                                                 |
| :--------------- | :---------------------------------------------------------------------------------------------------------- |
| **Scan Mode**    | - **Continuous**: Constant rotation; set spin rate and initial offset angle.                                |
|                   - **Unidirectional**: Scan from start angle to stop angle; set start/stop angles, spin rate, initial offset. |
|                   - **Bidirectional**: Sweep back and forth; parameters same as unidirectional.              |
| **Spin Axis**    | Options: Azimuth, Elevation, Cone Angle.                                                                    |
:::

::: details Pointing Type: Targeted
| Parameter          | Description                                                                                                 |
| :----------------- | :---------------------------------------------------------------------------------------------------------- |
| **Boresight Type** | - **Tracking (Receive/Transmit/Transpond)**: Real-time target tracking with pointing adjusted by signal type. |
|                    | - **Fixed**: Uses the same offset attitude forms as "Fixed" pointing (e.g., Az-El, Quaternion) with a fixed offset applied to the target. |
| **Option Filter**  | Filters available targets; can select from scenario objects or library targets.                             |
:::

::: details Pointing Type: Grazing Altitude
| Parameter           | Description                                 |
| :------------------ | :------------------------------------------ |
| **Azimuth Offset**  | Horizontal offset angle from reference direction. |
| **Grazing Altitude**| Altitude value of the target point (typically in km). |
:::

::: details Pointing Type: External
| Parameter        | Description                                                                 |
| :--------------- | :-------------------------------------------------------------------------- |
| **External File**| Select a file containing pointing data (format supported by software, e.g., .pattern files). |
:::

## 2D Graphics

Controls the display style of the sensor in the 2D view:

| Option               | Description                                       |
| -------------------- | ------------------------------------------------- |
| Show                 | Whether to display the sensor in the 2D view      |
| Fill                 | Whether to fill the detection area with color     |
| Color                | Fill and outline color                            |
| Show Intersections   | Options: None, Central Body, Terrain              |
| Line Width           | Outline line width                                |

---

## 3D Graphics

Used to configure the spatial representation of the sensor in the 3D view, including **Space Projection, Pulse, Vector, and Data Display**.

### Space Projection

- Space projection distance (km)
- Whether to use range constraint

### Pulse

- Show: Whether to display detection pulse animation
- Amplitude, Pulse Length, Frequency value
- Reverse: Whether to reverse the pulse direction
- <kbd>Reset to Defaults</kbd>: Restore default parameters with one click

### Vector and Data Display

For details, see the corresponding sections in [Aircraft Property Settings](./飞机.md).
