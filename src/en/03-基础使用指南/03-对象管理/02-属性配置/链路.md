# Chain

Chain properties are used to configure communication/line-of-sight connections between two or more objects, and include two sections: **Basic Properties** and **Visualization**.

---

## Basic Properties

Used to define the chain composition:

- Object option filter
- Available Objects list
- Assigned Objects (platforms/payloads that make up the chain)

![Definition settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/链路/update2601-142.png)

---

## Visualization

Supports both static and dynamic display modes:

- Overall display toggle
- **Static Visualization**: Show toggle, color, line style, line width
- **Animation Graphics**: Brightness, line display, color, line style and width, direction display
