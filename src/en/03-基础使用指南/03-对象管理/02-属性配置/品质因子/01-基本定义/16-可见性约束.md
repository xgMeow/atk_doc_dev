# Visibility Constraints

## Definition

Visibility Constraints compute geometric, kinematic, or illumination parameters between coverage resources and the analysis object during coverage intervals, and form FigureOfMerit results according to the selected statistical method.

This metric is computed only when the coverage resources satisfy the established visibility conditions. When multiple available coverage resources exist at the same time, the software first aggregates the constraint parameters of each resource according to the **Across Assets** setting, and then applies the **Compute** setting to produce statistics over the entire analysis period.

> **Note**
>
> "Available coverage resources" refers to satellites, aircraft, ships, vehicles, sensors, or links that satisfy line-of-sight occlusion, sensor field of view, operating range, and other access conditions at the current time, and can participate in the computation for the current analysis object or grid point.

---

## Specific Parameters

- **Constraint**: Selects the visibility constraint type
- **Across Assets**: Specifies how the results computed by multiple available coverage resources are aggregated
- **Compute**: Selects the statistical method for the visibility constraint
- **Step**: Specifies the analysis time step
- **Invalid Value**: When a valid result cannot be computed, specifies whether to ignore or include that sample.

### Constraint Parameter Options

#### Altitude

Represents the height of the object to which the constraint belongs above the surface of the central body:

$$
h=R_{\mathrm{obj}}-R_{\mathrm{C,local}}
$$

where:

- $R_{\mathrm{obj}}$ is the distance from the object to the center of the central body;
- $R_{\mathrm{C,local}}$ is the local radius of the central body in the direction of the object.

This parameter can be used to analyze whether the object lies within a specified minimum or maximum altitude range.

#### LOS Angular Rate

Represents the rate of change of the line-of-sight direction from the coverage resource to the analysis object, reflecting how fast the relative line of sight rotates between the two objects:

$$
\omega_{\mathrm{LOS}}
=
\frac{\left\|\boldsymbol r\times\boldsymbol v\right\|}{R^2}
$$

where:

- $\boldsymbol r$ is the position vector of the coverage resource relative to the analysis object;
- $\boldsymbol v$ is the relative velocity vector;
- $R=\|\boldsymbol r\|$ is the distance between the two objects.

A larger line-of-sight angular rate means the target moves faster across the field of view, imposing higher demands on sensor tracking or communication link pointing capabilities.

#### Azimuth Angle

Represents the horizontal direction angle of the coverage resource relative to the analysis object. In the object's local coordinate system, it usually starts from local north and increases toward the east.

If the components of the relative position in the object's reference coordinate system are $(r_x,r_y,r_z)$, the azimuth angle can be expressed as:

$$
Az=\operatorname{atan2}(r_y,r_x)
$$

The specific zero direction and positive direction are determined by the local reference coordinate system adopted by the object.

#### Azimuth Rate

Represents the time rate of change of the azimuth angle:

$$
\dot{Az}
=
\frac{r_xv_y-r_yv_x}{r_x^2+r_y^2}
$$

where $v_x$ and $v_y$ are the components of the relative velocity along the corresponding coordinate axes.

#### Elevation Angle

Represents the elevation angle of the coverage resource relative to the local horizontal plane of the analysis object. When the elevation angle is greater than $0$, the resource is above the local horizontal plane; when it is less than $0$, the resource is below the local horizontal plane.

$$
El=
\arctan
\left(
\frac{r_z}{\sqrt{r_x^2+r_y^2}}
\right)
$$

#### Elevation Rate

Represents the time rate of change of the elevation angle, reflecting the target's angular motion speed in the vertical direction. Its computation is determined jointly by the relative position and the relative velocity.

A larger absolute value of the elevation rate indicates faster vertical movement of the target within the sensor field of view.

#### LOS Lunar Exclusion

Represents the angle between the line-of-sight direction pointing to the coverage resource or target object and the Moon direction:

$$
\theta_{\mathrm{Moon}}
=
\arccos
\left(
\frac{
\boldsymbol l\cdot\boldsymbol r_{\mathrm{Moon}}
}{
\|\boldsymbol l\|
\|\boldsymbol r_{\mathrm{Moon}}\|
}
\right)
$$

where:

- $\boldsymbol l$ is the line-of-sight vector from the analysis object to the coverage resource or target object;
- $\boldsymbol r_{\mathrm{Moon}}$ is the position vector of the Moon relative to the analysis object.

This parameter can be used to determine whether the line of sight satisfies Moon avoidance requirements. When the angle is smaller than a specified threshold, the access is usually considered to fail the requirements.

#### LOS Solar Exclusion

Represents the angle between the line-of-sight direction pointing to the coverage resource or target object and the Sun direction:

$$
\theta_{\mathrm{Sun}}
=
\arccos
\left(
\frac{
\boldsymbol l\cdot\boldsymbol r_{\mathrm{Sun}}
}{
\|\boldsymbol l\|
\|\boldsymbol r_{\mathrm{Sun}}\|
}
\right)
$$

This parameter is primarily used to prevent strong sunlight from entering the sensor field of view, or to evaluate the impact of the Sun direction on observation tasks.

#### Lunar Elevation Angle

Represents the apparent elevation of the Moon relative to the analysis object. In the local horizontal coordinate system of fixed objects such as Facilities, it can be understood as the elevation angle of the Moon direction relative to the local horizontal plane.

A larger lunar elevation angle means the Moon is higher in the local sky; when the elevation angle is less than $0$, the Moon is below the local horizon.

#### Sun Elevation Angle

Represents the apparent elevation of the Sun relative to the analysis object. In the local horizontal coordinate system of ground-based objects, it can be understood as the elevation angle of the Sun direction relative to the local horizontal plane.

The Sun elevation angle can be used to determine day/night status, solar illumination conditions, and the impact of sunlight on observation tasks.

#### Propagation Delay

Represents the time required for a signal to propagate between the coverage resource and the analysis object:

$$
t_{\mathrm{delay}}=\frac{R}{c}
$$

where:

- $R$ is the spatial distance between the two objects;
- $c=299\,792\,458\ \mathrm{m/s}$ is the speed of light.

Propagation delay is usually used in communication link, command uplink, and data downlink analyses.

#### Range

Represents the spatial straight-line distance between the coverage resource and the analysis object:

$$
R=
\sqrt{r_x^2+r_y^2+r_z^2}
$$

This parameter is also referred to as slant range, and can be used to limit the sensor operating range or the communication link coverage.

#### Range Rate

Represents the time rate of change of the distance between the coverage resource and the analysis object, that is, the relative velocity along the line-of-sight direction:

$$
\dot R
=
\frac{\boldsymbol r\cdot\boldsymbol v}{R}
$$

- $\dot R>0$ indicates that the distance between the two objects is increasing;
- $\dot R<0$ indicates that the distance between the two objects is decreasing;
- $\dot R=0$ indicates that the distance is near an extremum at the current time.

### Across Assets Parameter Options

Assume that at a given time there are $m$ available coverage resources, whose selected constraint parameters are respectively:

$$
q_1(t),q_2(t),\ldots,q_m(t)
$$

According to the **Across Assets** setting, the software aggregates the results of multiple resources into the FigureOfMerit value $q(t)$ at that time.

| Across Assets Method | Computation Method | Meaning |
|---|---|---|
| Mean | $\displaystyle q(t)=\frac{1}{m}\sum_{i=1}^{m}q_i(t)$ | Takes the mean of the constraint parameters of all available resources at the current time. |
| Maximum | $\displaystyle q(t)=\max_i q_i(t)$ | Takes the maximum value among all available resources at the current time. |
| Minimum | $\displaystyle q(t)=\min_i q_i(t)$ | Takes the minimum value among all available resources at the current time. |
| Sum | $\displaystyle q(t)=\sum_{i=1}^{m}q_i(t)$ | Accumulates the constraint parameters of all available resources at the current time. |

### Compute Parameter Options

Over the analysis period, the software samples according to the **Step** and obtains the time series after across-assets processing:

$$
q(t_1),q(t_2),\ldots,q(t_n)
$$

The **Compute** parameter is used to compute statistics on this time series.

| Statistical Method | Meaning |
|---|---|
| Mean | Takes the mean of all valid samples over the analysis period. |
| Maximum | Takes the maximum value of the valid time series over the analysis period. |
| Minimum | Takes the minimum value of the valid time series over the analysis period. |
| Percent Below | With the percentage set to $X\%$, the output value $V$ means that the selected constraint parameter is no greater than $V$ for $X\%$ of the valid analysis time. |
| Percent Above | With the percentage set to $X\%$, the output value $V$ means that the selected constraint parameter is no less than $V$ for $X\%$ of the valid analysis time. |
| Sum | Accumulates the valid samples over the analysis period. This result is affected by the analysis step. |

The mean can be expressed as:

$$
\overline q
=
\frac{1}{n}
\sum_{k=1}^{n}q(t_k)
$$

The maximum and minimum are respectively:

$$
q_{\max}
=
\max_{1\leq k\leq n}q(t_k)
$$

$$
q_{\min}
=
\min_{1\leq k\leq n}q(t_k)
$$
