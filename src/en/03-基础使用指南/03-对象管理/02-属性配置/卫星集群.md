# SatelliteCollection

SatelliteCollection properties are used to build and manage homogeneous satellite constellations in batches, including three configuration modules: **Basic Properties, 3D Graphics, and Constraints**.

---

## Basic Properties

Core functionality is used to quickly generate standardized satellite constellations. Configuration items include:

- **Walker Properties**: Generate a Walker constellation configuration with one click.
- **Subsets**: Classify and manage satellites within the collection.
