# Rocket

Rocket property settings include five modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**. They are primarily used for launch trajectory and ascent phase simulation.

---

## Basic Properties

Includes three parts: **Trajectory, Attitude, and Ground Ellipses**.

### Trajectory

Supports two propagator types:

::: details Simple Ascent
- Launch Start/Stop Time, Step Size
- Launch Latitude, Longitude, Altitude
- Burnout Velocity, Latitude, Longitude, Altitude
:::

![Simple Ascent parameter settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-147.png)

::: details STK Ephemeris
- Start/Stop Epoch
- Ephemeris file loading
- Option to override file times
:::

![STK Ephemeris parameter settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-148.png)

Ephemeris Transform Tool settings: Click <kbd>Import Data</kbd> to enter the Import Data page. Here you set the epoch (UTC), source coordinate system, trajectory type, and use the <kbd>Data Column</kbd> function to map columns from the imported file to the corresponding fields (relative time, position, velocity) by specifying column indices, resolving issues with mismatched column order. Additionally, the Ephemeris Transform Tool supports automatic parameter saving, so settings persist after restart.

![Ephemeris Transform Tool settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2603-1.png)

### Attitude

Provides three attitude modes:

::: details Standard
Attitude type + Offset Attitude Form (Quaternion / Euler Angles / YPR)
:::

![Standard attitude mode parameter settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-149.png)

::: details Multi-Segment
Set multi-segment attitudes and quaternions by time intervals
:::

![Multi-Segment attitude mode parameter settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-150.png)

::: details STK File
Import external attitude files
:::

![STK File attitude mode parameter settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-151.png)

### Ground Ellipses

Settings are the same as in [Aircraft Property Settings](./飞机.md); not repeated here.

## 2D Graphics

Includes **Show, Ground Track, Contours, Range, Swath, and Ground Ellipses**.

### Swath

Select swath type and configure display:

- Ground Elevation, Vehicle Half Angle, Swath Half Width
- Ground Elevation Envelope, Vehicle Half Angle Envelope

![Swath settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-152.png)

Other items are the same as in [Aircraft Property Settings](./飞机.md).

---

## 3D Graphics

Includes **Model, Vector, Attitude Sphere, Orbit System, Proximity, Contours, Range, and Data Display**.

### Orbit System

- Select coordinate system
- Show toggle, custom color option and color settings

![Orbit System settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/火箭/update2601-153.png)

## Constraints

| Property | Description |
| --- | --- |
| [Basic](../03-约束配置/01-基本约束.md) | Geometric and line-of-sight conditions that access between the rocket and other objects must satisfy (azimuth, elevation, range, propagation delay, altitude, etc.) |
| [Sun](../03-约束配置/02-太阳约束.md) | Conditions determined by the relative positions of the Sun and the Moon that access between the rocket and other objects must satisfy (Sun/Moon elevation angle, exclusion angle, additional central body obstruction, etc.) |
| [Time](../03-约束配置/03-时间约束.md) | Time windows within which access between the rocket and other objects must fall (local time/GMT/local solar time/duration/time intervals) |

---

## RF

| Property | Description |
| --- | --- |
| [Environment](../08-RF/RF.md) | Describes the additional attenuation of RF signal propagation caused by propagation environments such as atmospheric absorption, rain, clouds, and fog, and includes it in communication or radar link performance calculations. |
| [Radar Cross Section](../08-RF/雷达散射截面.md) | Describes the equivalent scattering capability of a target under radar electromagnetic wave illumination, and provides target scattering parameters for radar echo and detection performance calculations through frequency band, RCS computation model, and Swerling fluctuation model. |
