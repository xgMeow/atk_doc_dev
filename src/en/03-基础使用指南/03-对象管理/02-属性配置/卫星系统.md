# Satellite System

Satellite System properties are used for unified configuration of a satellite system consisting of multiple satellites, and include four modules: **Basic Properties, 2D Graphics, 3D Graphics, and Constraints**.

---

## Basic Properties

Orbit settings are the core configuration item, primarily supporting:

- Loading TLE ephemeris data
- Displaying the number of satellites currently in the system

![Orbit settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/卫星系统/update2601-156.png)

---

## 2D Graphics

Controls the overall display of the satellite system in the 2D view:

- Show
- Show Label
- Color settings
- Marker Style settings

![Display settings interface](../../../../zh/03-基础使用指南/03-对象管理/02-属性配置/media/卫星系统/update2601-157.png)

---

## 3D Graphics

Includes **Model** and **Data Display** related configurations.
Specific settings are the same as those in the 3D Graphics section of [Aircraft Property Settings](./飞机.md), and are not repeated here.

---

## Constraints

Includes **Basic Constraints** and **Solar Constraints**.
Configuration methods are the same as those in the Constraints section of [Aircraft Property Settings](./飞机.md), and are not repeated here.
