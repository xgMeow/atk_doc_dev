# Vehicle

Vehicle property settings include five modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**, all of which are configured in the same way as for Aircraft.

---

## Basic Properties

- Route
- Ground Ellipses

For configuration details, see the Basic Properties section in [Aircraft Property Settings](./飞机.md).

---

## 2D Graphics

- Show
- Ground Track
- Range
- Ground Ellipses

For configuration details, see the 2D Graphics section in [Aircraft Property Settings](./飞机.md).

---

## 3D Graphics

- Model
- Vector
- Attitude Sphere
- Range

For configuration details, see the 3D Graphics section in [Aircraft Property Settings](./飞机.md).

---

## Constraints

All constraint configurations are described in the Constraints section in [Aircraft Property Settings](./飞机.md).

---

## RF

For environment settings, see the RF section in [Aircraft Property Settings](./飞机.md).
