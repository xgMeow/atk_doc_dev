# Facility

Facility properties are used to configure Earth-fixed observation/telemetry and tracking sites, and include five modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**.

---

## Basic Properties

The core is **Position Settings**:

- Select a position type and configure the corresponding coordinate parameters.
- You can check <kbd>Enable map interaction response</kbd>.

## 3D Graphics
