# Submarine

Submarine property settings include five modules: **Basic Properties, 2D Graphics, 3D Graphics, Constraints, and RF**, with the overall configuration logic highly consistent with that of Aircraft.

---

## Basic Properties

Route settings follow the same rules as those in the Basic Properties section of [Aircraft Property Settings](./飞机.md), so they are not repeated here.

---

## 2D Graphics

Includes **Show** and **Ground Track** related configurations.

For specific settings, see the 2D Graphics section in [Aircraft Property Settings](./飞机.md).

---

## 3D Graphics

Includes **Model, Vector, Attitude Sphere, Proximity, and Data Display**.

For specific settings, see the 3D Graphics section in [Aircraft Property Settings](./飞机.md).

---

## Constraints

Includes **Basic Constraints, Solar Constraints, and Temporal Constraints**.

Configuration methods are the same as those in the Constraints section of [Aircraft Property Settings](./飞机.md).

---

## RF

Includes only the **Environment** settings.

Rules are the same as those in the RF section of [Aircraft Property Settings](./飞机.md).
