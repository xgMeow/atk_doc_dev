# Figure of Merit

Figure of Merit is used to quantitatively evaluate mission performance such as coverage, access, navigation, and communications. Its property settings include two sections: **Basic Properties** and **2D Graphics**.

---

## Basic Properties

Defines the evaluation rules and calculation methods. Main configuration items:

- Definition type settings
- Satisfaction condition settings
- Invalid data indicator settings
- Valid value limits

::: details Figure of Merit Types
- Simple Coverage
- Access Duration
- Access Separation
- Coverage Time
- N Asset Coverage
- Number Of Accesses
- Number Of Gaps
- Response Time
- Revisit Time
- Time Average Gap
- Age Of Data
- System Response Time
- System Age Of Data
- Dilution of Precision
- Navigation Accuracy
- Access Constraint
:::

---

## 2D Graphics

Supports both **Animation** and **Static** display modes. Both modes include:

- Whether to display the corresponding graphics
- Grid point display settings
- Display metric settings
