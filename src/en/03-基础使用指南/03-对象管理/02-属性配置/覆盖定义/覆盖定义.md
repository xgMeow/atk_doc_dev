# Coverage Definition

Coverage Definition properties are used to configure the grid and evaluation rules for regional coverage analysis, and include three sections: **Basic Properties, Visualization, and Constraints**.

---

## Basic Properties

The core is **Grid Settings**:

- **Grid Area of Interest**: Select the type and configure the corresponding region parameters.
- **Grid Definition**: Grid type, Point Altitude, Point Locations. Point Locations can be defined by importing grid point files (`.pnt`, `.txt` formats).
- Option to use <kbd>Parallel Computing</kbd> for acceleration.

## Visualization

Controls the display of the coverage grid in the scene:

- Show
- Show Region
- Show Points
- Color
- Point Size
- Fill
