# Antenna

Antenna properties are used to configure RF transmit/receive units mounted on platforms, and include two modules: **Basic Properties** and **Constraints**.

---

## Basic Properties

Includes two parts: **Definition** and **Orientation**.

### Definition

Select the antenna type and configure the corresponding parameters:

- Gaussian Antenna
- Isotropic Antenna
- Parabolic Antenna
- External Antenna

### Orientation

Set the antenna pointing method and position offset:

- Pointing type: Azimuth-Elevation, Euler Angles, Quaternion, YPR Angles
- Position offset: X, Y, Z axis offsets can be set (in meters)

---

## Constraints

Temporal constraint configuration rules are the same as those in the Constraints section of [Aircraft Property Settings](./飞机.md) and are not repeated here.
