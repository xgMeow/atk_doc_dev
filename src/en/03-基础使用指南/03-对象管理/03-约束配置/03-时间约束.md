# Time Constraints

## Function Description

Temporal Constraints limit accesses to allowed time ranges in the time dimension, using the various local time bases of the object.

The 【Start】/【End】 settings of window-type parameters can be enabled as a pair to bound the window; 【Exclude】 removes accesses that fall within the specified window.

## Parameter Descriptions

<Entry meta="Format: HH:MM:SS.mmm" name="Local" desc="The effective window measured in the time of the object's time zone." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the local time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

For the definition and conversion, see [Local Time](../../../04-理论基础/02-约束配置/03-时间约束.md#local-time).

</Entry>

<Entry meta="Format: HH:MM:SS.mmm" name="GMT" desc="The effective window measured in the mean solar time of the prime meridian." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the Greenwich Mean Time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

For the definition, see [Greenwich Mean Time](../../../04-理论基础/02-约束配置/03-时间约束.md#gmt).

</Entry>

<Entry meta="Format: HH:MM:SS.mmm" name="Local Apparent" desc="The effective window measured in local apparent time." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

At noon the Sun and the satellite are at the same longitude, which is why this time base is also known as Local Satellite Time (LST); it is commonly used to filter access periods by the diurnal cycle.

Select this option and enter the times in the 【Start】 and 【End】 boxes to bound the local apparent time window in which accesses are allowed; enable 【Exclude】 to remove accesses that fall within that window and retain only those outside it.

For the definition, see [Local Apparent Time](../../../04-理论基础/02-约束配置/03-时间约束.md#local-apparent-time).

</Entry>

<Entry meta="Dimension: Time|Unit: s, min, h, day, cd, EarthTU, SunTU, FN, yr" name="Duration" desc="Limits the acceptable duration range of a single access." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

A minimum and a maximum value can be set separately; accesses whose duration falls outside the specified range do not satisfy the constraint.

</Entry>

<Entry name="Intervals" desc="The time intervals to be allowed (or excluded)." objects="Receiver,GroundVehicle,Sensor,Missile,Facility,Transmitter,Aircraft,CoverageDefinition,LaunchVehicle,Ship,Submarine,AreaTarget,Antenna,Satellite">

Intervals are used to manually add or load a number of time intervals. Each interval is defined by a start time and a stop time (UTC), and the 【Add】, 【Load】, 【Remove】, and 【Remove All】 operations are supported.

After enabling 【Use】 in this group, click 【Add】 to create an interval with default start and stop times, whose contents you can edit by clicking the 【Start Time (UTC)】 or 【Stop Time (UTC)】 box; click 【Load】 to load start and stop times from an external interval file (.int); select an existing entry and click 【Remove】 to delete it, or click 【Remove All】 to clear all entries.

【Exclude】 determines whether the specified periods are valid periods that satisfy the constraint or invalid periods to be removed: when enabled, accesses within all the listed periods do not satisfy the constraint; when disabled, accesses within all the listed periods satisfy the constraint.

</Entry>
