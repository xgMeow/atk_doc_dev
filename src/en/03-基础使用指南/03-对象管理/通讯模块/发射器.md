# Transmitter

Supported objects for transmitters: vehicles, satellites, sensors, submarines, ships, missiles, launch vehicles, ground stations, and aircraft.

## Functional Description

A transmitter models the transmitting end of a communication system. Parameters such as frequency, power, data rate, antenna, modulation, filters, and additional gains and losses describe the transmitted signal characteristics and provide inputs for communication link analysis.

Transmitters are divided into transmitter and transponder categories, with six models supported in total. On the **Basic - Definition** page of the transmitter properties, select the desired model using **Type** at the top.

| Category | Model Type | Function |
| --- | --- | --- |
| Transmitter | Simple Transmitter Model | Directly specifies the equivalent isotropically radiated power (EIRP) to describe the radiated power at the transmitting end. |
| Transmitter | Medium Transmitter Model | Specifies transmit power and transmit gain separately to describe the radiated power at the transmitting end. |
| Transmitter | Complex Transmitter Model | Specifies transmit power and uses an antenna model to describe antenna gain and its directionality. |
| Transponder | Simple Transponder Model | Specifies saturated EIRP and describes the transponder output through frequency conversion and power backoff. |
| Transponder | Medium Transponder Model | Specifies saturated transmit power and transmit gain separately to describe the transponder output. |
| Transponder | Complex Transponder Model | Specifies saturated transmit power and determines gain through an antenna model to describe the transponder output. |

### Simple Transmitter Model

Select **Simple Transmitter Model** under **Type** . The pages include **Model Specifications** , **Modulator** , **Filter** , and **Additional Gains and Losses** .

**Model Specifications** is used to set the transmit frequency, data rate, EIRP, and antenna polarization.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Frequency | Carrier frequency of the transmitted signal. | Enter the transmit frequency and select the corresponding frequency unit using the unit box on the right. |
| Data Rate(Mb/sec) | Number of data bits transmitted per unit time at the transmitting end. | Enter the value according to the data transmission requirements of the communication task, in Mb/sec . |
| EIRP(dBW) | Equivalent isotropically radiated power, which describes the combined radiated power resulting from transmit power and antenna gain. | Directly enter the known EIRP, in dBW . |
| Antenna Polarization | Direction of the transmitted signal's electric field and how it varies. | Select **Use** as needed and configure the polarization type and related parameters. See **Antenna Polarization** for details. |

EIRP and transmitter output power have different meanings. When feeder losses and other gains and losses are excluded, their relationship is:

$$
\mathrm{EIRP}=P_t+G_t
$$

Here, $P_t$ is the transmit power in dBW; $G_t$ is the gain relative to an ideal isotropic antenna in dBi; and EIRP is in dBW. The Simple Transmitter Model directly uses the entered EIRP, so transmit gain does not need to be entered separately.

The settings in **Filter** and **Additional Gains and Losses** also affect the transmitting-end power results in link calculations. Therefore, avoid counting the same loss in both EIRP and other settings.

### Medium Transmitter Model

Select **Medium Transmitter Model** under **Type** . The page layout is the same as that of the Simple Transmitter Model.

In **Model Specifications** , the Medium Transmitter Model replaces the **EIRP** input of the simple model with **Power** and **Transmit Gain** . All other settings are configured in the same way.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Frequency | Carrier frequency of the transmitted signal. | Enter the transmit frequency and select the corresponding unit. |
| Data Rate(Mb/sec) | Number of data bits transmitted per unit time at the transmitting end. | Enter the data rate according to the requirements of the communication task. |
| Power(dBW) | Radio-frequency output power of the transmitter. | Enter the transmit power in dBW; this value excludes the transmit gain configured separately. |
| Transmit Gain(dB) | Gain of the transmitting antenna, which combines with transmit power to determine the radiated power at the transmitting end. | Enter the antenna gain. The interface labels the unit as dB; when used in EIRP calculations, its physical reference is an ideal isotropic antenna. |
| Antenna Polarization | Polarization characteristics of the transmitted signal. | Configure in the same way as for the simple model. See **Antenna Polarization** for details. |

This model uses the specified transmit gain in calculations. Select the Complex Transmitter Model when an antenna pattern is needed to describe gain in different directions.

### Antenna Polarization

Polarization describes the direction of the electric field vector of an electromagnetic wave and how it varies over time. Polarization matching between the transmitting and receiving ends affects power reception over the communication link.

For the simple and medium models, configure polarization in **Model Specifications - Antenna Polarization** ; for the complex model, configure it in **Antenna - Polarization** .

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Use | Whether antenna polarization settings are enabled. | Select this option when polarization characteristics need to be defined, and configure the related parameters. |
| Type | Polarization type of the transmitted signal. | Select linear, horizontal, vertical, left-hand circular, or right-hand circular polarization. |
| Reference Axis | Reference coordinate axis used to define the polarization direction. | For polarization types that require a reference axis, select the X, Y, or Z axis. |
| Polarization Angle(deg) | Angle by which the linear polarization direction deviates from the selected reference direction. | Enter the polarization angle when the corresponding parameter is editable, and check the angle unit. |

| Polarization Type | Meaning |
| --- | --- |
| Linear | The electric field vector oscillates along a fixed direction, which can be defined using the reference axis and polarization angle. |
| Horizontal | The electric field oscillates in the horizontal direction under the reference definition in use. |
| Vertical | The electric field oscillates in the vertical direction under the reference definition in use. |
| Left-Hand Circular | The electric field vector rotates in the left-hand circular polarization sense. |
| Right-Hand Circular | The electric field vector rotates in the right-hand circular polarization sense. |

After selecting the polarization type, configure the parameters that are editable for that type. Interpret the horizontal and vertical directions relative to the selected reference axis; they cannot be directly equated with the horizontal and vertical directions on the screen.

#### Antenna Polarization Loss Calculation

Polarization loss results from a mismatch between the polarization states of the transmitted signal and the receiving antenna. In the following, $L_p$ denotes polarization loss in dB, with positive values consistently representing loss.

##### Linear Polarization

A polarization loss of 3-4 dB needs to be considered. For circular polarization with the same sense of rotation, consider a polarization loss of 0.5-2 dB.

##### Horizontal Polarization

Polarization loss is calculated as:

$$
L_p=-20\log_{10}|\cos\theta|
$$

Here, $\theta$ is the angle between the polarization directions of the transmitted signal and the receiving antenna in the same reference plane.

##### Vertical Polarization

Polarization loss is calculated as:

$$
L_p=-20\log_{10}|\cos\theta|
$$

Here, $\theta$ is the angle between the polarization directions of the transmitted signal and the receiving antenna.

##### Left-Hand Circular Polarization

When the axial ratio of non-ideal circular polarization is taken into account, polarization loss can be expressed as:

$$
L_p
=
-10\log_{10}
\left\{
\frac{1}{2}
\left[
1+
\frac{
\pm 4X_rX_t
+
(1-X_t^2)(1-X_r^2)\cos(2\alpha)
}{
(1+X_t^2)(1+X_r^2)
}
\right]
\right\}
$$

Here, $X_t$ is the axial ratio of the incident wave, and $X_r$ is the axial ratio of the receiving antenna polarization. The axial ratio is the ratio of the electric field amplitudes along the major and minor axes of the polarization ellipse, expressed as a linear ratio; $\alpha$ is the angle between the major axes of the two polarization ellipses.

Determine the sense of rotation using a consistent propagation-direction convention. Use "+" for the same sense of rotation and "−" for opposite senses. Ideal circular polarization has an axial ratio of 1.

##### Right-Hand Circular Polarization

Right-hand circular polarization uses the same axial-ratio loss formula as left-hand circular polarization. The sign in the formula depends on whether the transmitting and receiving polarization senses match.

| --- | --- | --- |

To configure this area, first clear **Select Signal PSD** , then adjust the editable parameters according to the automatic or manual setting method.

#### Signal Bandwidth

**Signal Bandwidth** is used to set the extent of the transmitted signal in the frequency domain.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Auto-Adjust Bandwidth | Determines the bandwidth from signal parameters such as modulation scheme and data rate. | When **Select Signal PSD** is not selected, use this option to determine bandwidth automatically; clear it when manual specification is required. |
| Symmetric Adjustment | Controls whether the spectral range is symmetric about the carrier frequency. | When setting bandwidth manually, select this option according to whether the signal spectrum is symmetric. |
| Upper Cutoff Frequency | Upper boundary of the signal spectrum relative to the carrier frequency. | When the parameter is editable, enter the upper frequency boundary and select the unit. |
| Lower Cutoff Frequency | Lower boundary of the signal spectrum relative to the carrier frequency. | When the parameter is editable, enter the lower frequency boundary and select the unit. |

The upper and lower spectral boundaries here are referenced to the carrier frequency, rather than being absolute transmit carrier frequencies. The lower boundary can be expressed as a negative frequency offset, and the bandwidth is the difference between the upper and lower boundaries. With symmetric settings, the upper and lower boundaries have equal magnitudes and opposite signs relative to the carrier frequency.

### Filter

**Filter** is used to filter the power spectral density (PSD) of the transmitter's output signal, describing the spectral changes and corresponding losses as the transmitted signal passes through the filter. All three transmitter models are configured in the same way.

Select **Use** , then choose the filter type and configure its parameters; when this option is cleared, the filter settings are not enabled. Supported types include Bessel, Butterworth, Chebyshev, Gaussian Window, and Raised Cosine.

#### Common Parameters

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Use | Whether the filter is enabled. | Select this option when filter modeling is required for the transmitted signal. |
| Type | Filter model in use. | Select a type from the drop-down list, and the page displays the corresponding parameters. |
| Upper Cutoff Frequency | Upper boundary of the filter's spectrum calculation range relative to the carrier frequency. | Enter the upper-frequency boundary and select the unit. |
| Lower Cutoff Frequency | Lower boundary of the filter's spectrum calculation range relative to the carrier frequency. | Enter the lower-frequency boundary and select the unit. |
| Bandwidth | Frequency span between the upper-frequency and lower-frequency boundaries. | Determined by the upper and lower boundaries and displayed as read-only. |
| Insertion Loss(dB) | Fixed signal power loss introduced by inserting the filter. | Enter the value according to the equipment parameters; this differs from the spectral loss caused by the filter's frequency response. |

**Upper Cutoff Frequency** and **Lower Cutoff Frequency** specify the spectral range used; the separate **Cutoff Frequency** setting available for some filters defines their frequency response characteristics. These settings have different meanings.

#### Types and Type-Specific Parameters

| Filter Type | Characteristics | Settings in Addition to Common Parameters |
| --- | --- | --- |
| Bessel | Emphasizes phase and group delay characteristics to describe filter responses with waveform fidelity requirements. | Order and cutoff frequency. |
| Butterworth | Has a flat passband magnitude response. | Order and cutoff frequency. |
| Chebyshev | Achieves a steeper frequency transition by allowing ripple in the magnitude response. | Order, cutoff frequency, and pulse factor. |
| Gaussian Window | Describes filter characteristics using a Gaussian window. | Order and sampling frequency. |
| Raised Cosine | Describes a spectral transition using a raised cosine, commonly used for communication signal shaping. | Roll-off factor and symbol rate. |

| Parameter | Applicable Types | Meaning and Usage |
| --- | --- | --- |
| Order | Bessel, Butterworth, Chebyshev, Gaussian Window | Filter order parameter. Set it according to the design requirements of the selected filter to determine the form of its response. |
| Cutoff Frequency | Bessel, Butterworth, Chebyshev | Characteristic frequency describing the transition of the filter response from the passband to the attenuation region. Enter the corresponding frequency and select the unit. |
| Pulse Factor(dB) | Chebyshev | Controls ripple in the magnitude response of the Chebyshev filter, i.e., the ripple parameter. Set the required ripple magnitude; the name follows the interface label. |
| Sampling Frequency | Gaussian Window | Sampling frequency parameter of the Gaussian Window filter. Set it according to the filter design requirements and select the corresponding unit. |
| Roll-off Factor(%) | Raised Cosine | Controls the spectral transition region and excess bandwidth of the raised cosine response. Enter the value according to the signal shaping requirements. |

Symbol rate and the data rate in **Model Specifications** have different meanings. Data rate counts bits, whereas symbol rate counts modulation symbols. Their relationship depends on the modulation and coding scheme, so they cannot be treated as the same parameter.

#### Calculation Models for the Filter Types

The following basic mathematical forms describe the response characteristics and parameter meanings of each filter type. In the formulas, $f$ represents the frequency offset relative to the carrier frequency. All frequency parameters should use consistent units.

##### Butterworth Filter

The magnitude response of an $n$th-order Butterworth filter can be expressed as:

$$
|H(f)|
=
\frac{1}
{\sqrt{1+\left(\frac{f}{f_c}\right)^{2n}}}
$$

Here, $n$ is the filter order, corresponding to **Order** ; $f_c$ is the cutoff frequency, corresponding to **Cutoff Frequency** .

##### Chebyshev Filter

The magnitude response of a Chebyshev filter can be expressed as:

$$
|H(f)|
=
\frac{1}
{\sqrt{1+E^2C_n^2\left(\frac{f}{f_c}\right)}}
$$

Here, $n$ is the filter order; $E$ is a design constant controlling passband ripple; $C_n(x)$ is the $n$th-order Chebyshev polynomial; and $f_c$ is the passband edge frequency of this prototype model.

The Chebyshev polynomials satisfy the following recurrence relation:

$$
C_n(x)
=
2xC_{n-1}(x)-C_{n-2}(x),
\qquad n\geq 2
$$

The initial conditions are:

$$
C_0(x)=1,
\qquad
C_1(x)=x
$$

##### Bessel Filter

The frequency response of a Bessel filter can be expressed in the following polynomial form:

$$
H(f)
=
\frac{K_n}
{B_n\left(\frac{f}{f_b}\right)}
$$

Here, $n$ is the filter order; $f_b$ is the cutoff frequency of this filter; $B_n(x)$ is the Bessel polynomial expressed along the imaginary frequency axis; and $K_n$ is the normalization coefficient.

The recurrence relation for the polynomials is:

$$
B_n(x)
=
(2n-1)B_{n-1}(x)-x^2B_{n-2}(x),
\qquad n\geq 2
$$

The initial conditions and normalization coefficient are:

$$
B_0(x)=1,
\qquad
B_1(x)=1+jx,
\qquad
K_n=B_n(0)
$$

Here, $j$ is the imaginary unit, and the magnitude response is $|H(f)|$.

##### Gaussian Window Filter

The Gaussian Window filter uses a Gaussian function to describe smoothly decaying weights. The standard form of the Gaussian function is:

$$
G(x,y)
=
\frac{1}{2\pi\sigma^2}
\exp\left(
-\frac{x^2+y^2}{2\sigma^2}
\right)
$$

Here, $G(x,y)$ is the Gaussian function; $\sigma$ is the standard deviation, which controls the width of the function's distribution; and $x、y$ are the two-dimensional coordinate variables.

##### Raised Cosine Filter

The Raised Cosine filter consists of a passband, a cosine transition band, and a stopband. Its frequency response is:

$$
H(f)
=
\begin{cases}
T,
&
|f|\leq \dfrac{1-\alpha}{2T},
\\[8pt]
\dfrac{T}{2}
\left[
1+
\cos\left(
\dfrac{\pi T}{\alpha}
\left(
|f|-\dfrac{1-\alpha}{2T}
\right)
\right)
\right],
&
\dfrac{1-\alpha}{2T}
<
|f|
\leq
\dfrac{1+\alpha}{2T},
\\[10pt]
0,
&
|f|>
\dfrac{1+\alpha}{2T}.
\end{cases}
$$

Here, $T$ is the symbol period and is related to the symbol rate $R_s$ by $T=1/R_s$; $\alpha$ is the roll-off factor, with a range of $0\leq\alpha\leq 1$.

### Additional Gains and Losses

**Additional Gains and Losses** supplements the description of additional gains or losses at the transmitting end. All three transmitter models are configured in the same way.

| Parameter | Meaning | Usage |
| --- | --- | --- |
| Gain/Loss(dB) | Additional net gain or loss applied to the transmitting end beyond the items already modeled separately. | Enter the signed value of the additional gain or loss; positive values represent gain, and negative values represent loss. |

### Configuration Procedure

- Open the transmitter properties and select the transmitter model type on the **Basic - Definition** page.
- Set the frequency, data rate, and corresponding EIRP or power parameters in **Model Specifications** . The medium model also requires transmit gain to be set.
- When using the complex model, open the **Antenna** page and select **Embedded** or **Linked** ; configure the antenna model and pointing for an embedded antenna, or verify the referenced antenna for a linked antenna.
- Configure polarization characteristics in **Model Specifications - Antenna Polarization** or **Antenna - Polarization** according to the selected model.
- Select the modulation type in **Modulator** , determine whether to use signal PSD, and configure the corresponding spectrum or bandwidth parameters.
- Enable **Filter** as needed and configure the common and type-specific parameters for the selected filter type.
- Set any additional gains or losses that have not yet been accounted for in **Additional Gains and Losses** .
- Check all parameters and units, then click **Apply** to save the current settings or **OK** to save and close the properties window.

### Conversion Methods

**Conversion Methods** defines the frequency and power relationships between the input signal and the transponder output signal. It contains two subpages: **Frequency** and **Power Backoff** . All three transponder models are configured in the same way.

#### Frequency

**Conversion Methods - Frequency** is used to set the coefficients of the frequency conversion polynomial, which calculates the output frequency from the input frequency:

$$
f_{\mathrm{out}}
=a_0+a_1f_{\mathrm{in}}+a_2f_{\mathrm{in}}^2+\cdots+a_nf_{\mathrm{in}}^n
$$

Here, $f_{\mathrm{in}}$ is the input frequency, $f_{\mathrm{out}}$ is the output frequency, $a_i$ is the coefficient of each polynomial term, and $n$ is the polynomial order.

Enter the coefficients according to the required frequency conversion relationship. The constant term describes a fixed frequency offset, and the linear term describes proportional changes in the input frequency; higher-order terms can be set when nonlinear conversion is required. The coefficients should be consistent with the frequency units used in the calculation.

#### Power Backoff

**Conversion Methods - Power Backoff** is used to set the conversion relationship between input power backoff and output power backoff.

Input power backoff is determined by the difference between the saturation flux density and the actual input flux density:

$$
\mathrm{IBO}=\Phi_{\mathrm{sat}}-\Phi_{\mathrm{in}}
$$

Here, $\Phi_{\mathrm{sat}}$ is the **Saturation Flux Density** , and $\Phi_{\mathrm{in}}$ is the actual input power flux density, both in dBW/m²; $\mathrm{IBO}$ is the input power backoff in dB.

Output power backoff is calculated using a polynomial:

$$
\mathrm{OBO}
=b_0+b_1\mathrm{IBO}+b_2\mathrm{IBO}^2+\cdots+b_m\mathrm{IBO}^m
$$

Here, $\mathrm{OBO}$ is the output power backoff in dB; $b_i$ is a coefficient of the power backoff polynomial; and $m$ is the polynomial order. The notation $b_i$ is used here to distinguish these coefficients from the frequency conversion coefficients $a_i$.

Enter the coefficients according to the transponder's input and output power characteristics. Output power backoff represents the reduction in output relative to saturation and is used to determine the actual transponder output power.

#### Coefficient Editing

The coefficients on the **Frequency** and **Power Backoff** pages are configured separately, using the same editing operations.

| Item | Meaning and Usage |
| --- | --- |
| Index | Sequence number of the coefficient in the list, identifying its position. |
| Coefficient | Value of the coefficient in the current conversion polynomial. Double-click the cell to modify the value. |
| Add | Add a new coefficient row and enter the required value. |
| Delete | Select the row to remove and click **Delete** . |
| Move Up | Select a row and click **Move Up** to move it one row above its current position. |
| Move Down | Select a row and click **Move Down** to move it one row below its current position. |

Set each coefficient according to the required conversion relationship, then check the coefficient values and their order after editing.

### Antenna Polarization

For the simple and medium transponder models, configure polarization in **Model Specifications - Antenna Polarization** ; for the complex transponder model, configure it in **Antenna - Polarization** .

The polarization types, reference axis, polarization angle, and usage are the same as those for transmitters. For parameter descriptions and calculation formulas, see **Antenna Polarization** under Transmitters.

### Filter

**Filter** is used to filter the power spectral density of the retransmitted signal. The page parameters and configuration methods for all three transponder models are the same as those for transmitters.

Select **Use** as needed, choose a Bessel, Butterworth, Chebyshev, Gaussian Window, or Raised Cosine filter, and configure the common and type-specific parameters for the selected type. For parameter descriptions and calculation models, see **Filter** under Transmitters.

### Additional Gains and Losses

**Additional Gains and Losses** supplements the description of additional gains or losses at the transponder output. All three transponder models are configured in the same way as transmitters.

Enter the signed value of the additional gain or loss in **Gain/Loss(dB)** . Positive values represent gain, and negative values represent loss. Losses already accounted for through power backoff, filters, or other parameters should not be counted again here.

### Configuration Procedure

- Open the transmitter properties and select the transponder model type on the **Basic - Definition** page.
- Set **Saturation Flux Density** in **Model Specifications** , and enter **Satellite EIRP** or **Power** according to the model. The medium model also requires **Transmit Gain** to be set.
- When using the complex model, select **Embedded** or **Linked** on the **Antenna** page, then configure or verify the antenna parameters.
- Configure polarization characteristics in **Model Specifications - Antenna Polarization** or **Antenna - Polarization** according to the selected model.
- Set the coefficients separately in **Conversion Methods - Frequency** and **Conversion Methods - Power Backoff** .
- Enable **Filter** as needed and set any additional gains or losses not yet accounted for in **Additional Gains and Losses** .
- Check the parameters, units, and coefficient order, then click **Apply** to save the current settings or **OK** to save and close the properties window.
