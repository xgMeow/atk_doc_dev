# From External Ephemeris File

**From External Ephemeris File** is an insertion method exclusively for Satellite objects, supporting direct import of high-precision orbital data via external `.e` format ephemeris files, suitable for scenarios using custom ephemeris or third-party orbital data.

1. In the **【Insert Object】** window, select **Satellite** and choose **「From External Ephemeris File」** as the insertion method, then click the <kbd>Insert...</kbd> button;
2. In the pop-up file dialog, select a local ephemeris file in `*.e` format;
3. The system will automatically parse the ephemeris content and preview the orbital information in the interface;
4. After confirming the information is correct, complete the satellite object import.
