# Orbit Wizard

**Orbit Wizard** is a visual creation tool exclusively for Satellite objects, adopting a step-by-step wizard mode that supports custom orbit parameters, suitable for high-precision orbit design, mission simulation, and instructional demonstration scenarios.

1. In the **【Insert Object】** window, select **Satellite** and choose **「Orbit Wizard」** as the insertion method;
2. Click the <kbd>Insert...</kbd> button to open the wizard interface;
3. In the wizard, select the desired orbit type, then sequentially set parameters such as orbital elements, time, central body, etc.;
4. Confirm the configuration to complete the satellite creation.
