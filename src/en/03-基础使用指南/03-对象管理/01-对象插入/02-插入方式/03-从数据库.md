# From Database

The **From Database** insertion method supports filtering, searching, and batch importing objects from ATK's built-in **Standard Object Database**, making it particularly suitable for batch loading of standardized objects such as satellite catalogs, stars, and planets, significantly improving scenario modeling efficiency.

## Menu Bar Quick Access

In the top **Insert** menu bar, click the <img src="../../../../../zh/03-基础使用指南/03-对象管理/01-对象插入/02-插入方式/media/03-从数据库/update2601-31-1774512293042-34.png" alt="update2601-31" no-view /> icon to directly open the **【Query Standard Object Database】** window for rapid object search and insertion.

## Select "From Database" in the Insert Object Window

1. Open the **【Insert Object】** window and select the **target object type** you wish to insert;
2. In the insertion method list, choose **「From Database」**;
3. Click the <kbd>Insert...</kbd> button, and the system will automatically open the **【Query Standard Object Database】** window.

## Database Insertion Workflow

1. In the **【Query Standard Object Database】** window, set the **filter/search parameters**;
2. Click the <kbd>Search</kbd> button to retrieve the matching object list;
3. Select the desired objects from the result list;
4. Configure the **display color** for the objects in the scenario;
5. Click <kbd>Insert</kbd> to complete the batch import of objects.
