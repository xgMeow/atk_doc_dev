# Insert Object Tool

The Insert Object Tool is the unified entry point in ATK for creating **all scenario objects and attached objects**, supporting flexible configuration by object type, central body, and insertion method to meet the rapid modeling needs of various space mission simulations.

## General Instructions
Click the <img src="../../../../zh/03-基础使用指南/03-对象管理/01-对象插入/media/01-对象插入工具/image97.png" alt="" no-view /> icon to open the **【Insert Object】** dialog.
Supports inserting two major categories of objects into the current scenario:

- **Scenario Objects**: AdvCAT, Aircraft, Area Target, Chain, Constellation, Coverage Definition, Facility, GroundVehicle, LaunchVehicle, Missile, Planet, Satellite, SatelliteCollection, SatelliteSystem, Ship, Star, Submarine, etc.
- **Attached Objects**: Antenna, FigureOfMerit, Receiver, Sensor, Transmitter, etc.

## Procedure
1. **Select Object Type**: Choose the desired object from the object list;
2. **Select Central Body**: Specify the celestial body to which the object belongs (e.g., Earth, Moon, etc.);
3. **Select Insertion Method**: Choose the appropriate method based on the object type (see details below);
4. **Complete Insertion**: Click the <kbd>Insert...</kbd> button to create the object.

## Insertion Method Description
The system provides multiple quick creation methods for different objects, including default creation, file import, database loading, etc.:

| Insertion Method       | Description |
|------------------------|--------------------------------------|
| **Insert Default**     | Create an object using system default parameters |
| **From Database**      | Retrieve and load an object from the built-in standard object database |
| **From TLE File**      | Import a satellite via a TLE two-line element file |
| **From External Ephemeris File** | Import a satellite via a `.e` format ephemeris file |
| **Orbit Wizard**       | Create a satellite through a visual wizard, supporting various types such as circular orbits, elliptical orbits, etc. |
| **Select Countries and Regions** | Quickly add an area target using administrative divisions |
| **From City Database** | Create a facility by selecting a location from the built-in city database |
