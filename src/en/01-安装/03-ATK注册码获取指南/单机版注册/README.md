# Standalone Registration

The Register Id of standalone registration is bound to the machine code submitted with the application and works only on that computer, so it suits personal use or a single computer.

## Application Methods

Standalone registration offers three application methods, any one of which is sufficient:

| Application method | How it works | How the Register Id is delivered |
| --- | --- | --- |
| [Mini Program Application](小程序申请.md) | Scan the QR code with WeChat to open the Mini Program, fill in the machine code and other information, and submit | View it in the Mini Program immediately after submission |
| [Online Application on the Website](网页在线申请.md) | Fill in and submit the form on the ATK registration page | Sent to the email address you fill in |
| [Email Application](邮件申请.md) | Open the PDF application form in the registration window, fill it in, and send it by email | Replied to the email address in the application form |

## Choosing a Method

- If WeChat is available, choose Mini Program Application: the Register Id is issued in the Mini Program right after submission, with no need to wait for an email reply.

- If WeChat is not convenient, or if organization or team information must be submitted, choose Online Application on the Website or Email Application; the Register Id is sent to your email address.

## Activation

After obtaining the Register Id, enter it in the ATK Registration window and click <kbd>Register</kbd> to activate. All three application pages end with the entry steps.

::: tip One Register Id per computer
The Register Id corresponds one-to-one with the machine code, so multiple computers require a separate application for each.
:::
