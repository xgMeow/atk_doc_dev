# Obtaining an ATK Register Id

ATK is **free to use**, but it must be registered and activated before first use. Registration is divided into two methods by license scope: standalone registration and network floating registration.

- **Standalone registration**: the Register Id is bound to the machine code submitted with the application and works only on that computer. It can be applied for in any of the following three self-service ways:

  - [Mini Program Application](单机版注册/小程序申请.md)
  - [Online Application on the Website](单机版注册/网页在线申请.md)
  - [Email Application](单机版注册/邮件申请.md)

- **Network floating registration**: the Register Id can be shared by multiple computers, with usage rights allocated dynamically over the local network. It must be applied for through the ATK development team; see [Remote Service Deployment and Configuration](网络浮动注册/01-远程服务部署与配置.md).

Before registering, read [Before You Begin](01-使用须知.md), which describes the registration window, the machine code, and the applicable scope and activation location of both registration methods.
