# Troubleshooting

The following pages cover the startup, registration, and display problems that occur after installation. Choose the page that matches the symptom you encounter:

- [OpenGL Version Too Low](提示OpenGL版本过低.md) — ATK crashes immediately on launch and cannot reach the main interface, or the 2D and 3D views fail to open and report that the OpenGL version is too low
- [No Registration Window on Startup](软件未弹出注册界面.md) — ATK starts normally but the registration window does not appear
- [High-DPI Display Issues](高分屏显示异常.md) — blurry text and icons, overlapping buttons, or abnormal window proportions

If none of the methods above solves the problem, please [Contact Us](../../发布说明/联系我们.md) for technical support.
