# No Registration Window on Startup

ATK must be registered and activated before first use. If the registration window does not appear after the software starts, check the following in order:

## Turn Off Defender Real-Time Protection (Windows 11)

Microsoft Defender real-time protection included in Windows 11 may remove a dynamic library required by ATK, causing the program to report an error. Turn it off temporarily before registering, and turn it back on as needed after registration.

If the file has already been quarantined or removed, handle it in the following order so that it is not removed again after being restored:

1. In Windows Security → Virus & threat protection → Manage settings → Exclusions, add the ATK installation directory as an exclusion;
2. In Windows Security → Virus & threat protection → Protection history, find the items related to ATK, expand them, and select <kbd>Restore</kbd>;
3. If Protection history has no matching item or the item cannot be restored, extract the portable package again to restore the missing files; if ATK was installed from the deb package, reinstall the deb package.

Restart ATK after the steps above and confirm that the registration window appears normally.

## Run as Administrator

Right-click ATK.exe and select <kbd>Run as administrator</kbd>. If the program is not started with administrator permissions, it may be unable to write the required files, and the registration process may fail.

## Check Security Policies and Executable Permissions

- Check whether the software is intercepted by a firewall, security software (Windows), or system security policies (Kylin OS)
- Kylin OS: confirm that `chmod +x` has been executed correctly to grant executable permissions

::: tip Obtaining a Register Id
The machine code shown in the registration window is used to apply for a Register Id. For the application methods, see [How to Get a Register Id](../03-ATK注册码获取指南/README.md).
:::
