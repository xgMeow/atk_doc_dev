# Startup Failures

This document describes common causes and troubleshooting steps when ATK fails to start.

## Windows

### Startup Failure Due to Missing Registration

Registration is required to activate ATK on first use. If the software does not show the registration window, check the following:

- Make sure you have obtained a Register Id (see [How to Get a Register Id](../03-ATK注册码获取指南/README.md)).
- Check whether the software is being blocked by a firewall or security software.
- Try running `ATK.exe` as an administrator.

### Crash on Launch Due to Graphics Driver Mismatch

If the software crashes immediately after opening and never reaches the main interface, the most likely cause is a **graphics driver mismatch**. The default OpenGL version provided by the system may be too low to support the library versions required for 2D and 3D views.

#### Verification

1. Locate the configuration file in the ATK installation directory:

   ```
   ATK-v4.0.0-windows-x64\ATK-4.0.0\config\systemConfig.ini
   ```

2. Open the file with a text editor such as Notepad.

3. Find the `[OPEN SETTING]` section and change `Open3D=true` to `Open3D=false`:

   ```ini
   [OPEN SETTING]
   Open3D=false
   ```

4. Save the file and restart ATK.

::: tip Verification Result
If the software opens normally after this change, it confirms that the issue is caused by the **graphics driver**.
:::

#### Solution

Update your graphics driver to the latest version:

- **NVIDIA graphics cards**: Visit the [NVIDIA official website](https://www.nvidia.cn/drivers/) and download the driver for your model.
- **Other graphics cards**: Visit the manufacturer's official website to get the latest driver.

This is a very common issue, and updating the driver usually resolves it.

## Kylin OS

### Startup Failure Due to Missing Registration

Registration is required to activate ATK on first use. If the software does not show the registration window, check the following:

- Make sure you have obtained a Register Id (see [How to Get a Register Id](../03-ATK注册码获取指南/README.md)).
- Check whether the software is being blocked by a system security policy.
- Confirm that you have granted executable permissions correctly with `chmod +x`.

### Crash on Launch Due to Graphics Driver Mismatch

If the software crashes immediately after opening and never reaches the main interface, the most likely cause is a **graphics driver mismatch**. The default OpenGL version provided by the system may be too low to support the library versions required for 2D and 3D views.

#### Verification

1. Locate the configuration file in the ATK installation directory:

   ```
   /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
   ```

   ::: warning Note
   The actual path may vary depending on the version number. Adjust the path according to your installed version.
   :::

2. Open the file using `vim` or another text editor:

   ```bash
   sudo vim /opt/ATK/ATK-v4.0.0-kylin-x86_64/ATK-4.0.0/config/systemConfig.ini
   ```

3. Find the `[OPEN SETTING]` section and change `Open3D=true` to `Open3D=false`:

   ```ini
   [OPEN SETTING]
   Open3D=false
   ```

4. Save the file and restart ATK.

::: tip Verification Result
If the software opens normally after this change, it confirms that the issue is caused by the **graphics driver**.
:::

#### Solution

Update your graphics driver to the latest version:

- On Kylin OS, go to **System Settings → Display → Graphics Driver** to check for updates.
- Or visit the graphics card manufacturer's official website (such as NVIDIA, AMD, or Intel) to download the Linux driver.
- You can also update using the system package manager: `sudo apt update && sudo apt upgrade`.

This is a very common issue, and updating the driver usually resolves it.
