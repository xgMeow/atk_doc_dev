# System Requirements

## Hardware Requirements

| Hardware | Minimum | Recommended |
|----------|---------|-------------|
| Processor | Intel Core series | Intel i5 or higher |
| CPU frequency | 2 GHz or higher | 3 GHz or higher |
| Memory | 3 GB or more | 8 GB or more |
| Disk space | 3 GB free space | 10 GB free space |
| Graphics card | NVIDIA GeForce GT 1030 or higher | NVIDIA GTX 1060 or higher |
| Display | Supports 1920×1080 resolution | 27-inch, 1920×1080 (the software is optimized for this resolution by default) |

::: warning High-DPI Displays
ATK is optimized for 27-inch 1920×1080 displays by default. Laptops with high-DPI screens may experience UI scaling issues. Refer to [Troubleshooting → High-DPI display](10-安装后常见问题/02-高分屏显示异常.md) to adjust settings.
:::

## Operating Systems

### Windows

- Windows 11
- Windows 10
- Windows 8
- Windows 7 Service Pack 1 (SP1) or later
- Windows Server 2012
- Windows Server 2008 R2

### Kylin OS (Linux)

- Kylin OS V10 or later
- Supports x86_64 and arm64 architectures

::: warning Architecture Matching
Select the installation package that matches your CPU architecture (x86_64 or arm64). An architecture mismatch will prevent the software from starting.
:::

## Software Dependencies

- **Windows version**: No additional dependencies. It is a portable package — simply extract and run.
- **Kylin deb package**: Requires the `dpkg` package manager to be installed on the system (installed by default on Kylin).
- **Kylin archive**: No additional dependencies. After extraction, grant executable permissions and run.
