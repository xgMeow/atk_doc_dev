# Choosing an Installer

Download the installation package that matches your computer's CPU architecture (`x86_64` / `arm64`).

::: warning Important
An architecture mismatch will prevent the software from starting. Make sure the installation package matches your CPU architecture.
:::

::: tip How to Check Your CPU Architecture

- **Windows**: Run `echo %PROCESSOR_ARCHITECTURE%` in the command prompt. If the output is `AMD64`, your architecture is x86_64.
- **Kylin OS**: Run `uname -m` in the terminal. The output will be `x86_64` or `aarch64` (arm64).
:::

## Download the Installation Package

Visit the [ATK official download page](https://www.osredm.com/atknudt/atk/about#/) to get the installation package for your version.

After downloading, select the installation guide for your operating system:

- [Windows (Portable)](./Windows系统安装（绿色版）.md)
- [Kylin OS — Archive](./麒麟系统安装/压缩包.md)
- [Kylin OS — deb Package](./麒麟系统安装/deb包.md)

::: tip Multiple Versions Coexistence
If you install using the Kylin archive or Windows portable version, different versions of ATK will not overwrite each other. To remove an old version, manually delete the corresponding files.
:::
