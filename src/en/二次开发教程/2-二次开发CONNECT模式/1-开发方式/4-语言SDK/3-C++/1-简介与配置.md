# 简介与配置

## 简介

C++ SDK 是 ATK 提供的 C++ 通信库，允许用户在自己的 C++ 开发环境中编写程序，通过 TCP 网络连接与 ATK 交互，实现场景搭建、参数设置、仿真运行等自动化操作。

作为 CONNECT 模式的核心开发方式之一，C++ SDK 提供了头文件（`.h`）和预编译库文件，适合需要将 ATK 功能集成到 C++ 项目、或对性能和底层控制有较高要求的场景。

| 平台 | 静态库 | 动态库 | 编译器要求 |
|------|--------|--------|-----------|
| Windows | `.lib` | `.dll` | Visual Studio 2015 / 2017 / 2019 / 2022 |
| Linux / 麒麟 | `.a` | `.so` | GCC 5.x 及以上 |

::: tip 开发方式选择
各开发方式的详细对比请参考 [CONNECT 模式概述](/二次开发教程/2-二次开发CONNECT模式/README.md#开发方式对比)。
:::

## 环境与配置

### 编译器要求

- **Windows**：Visual Studio 2015 / 2017 / 2019 / 2022，需安装 **C++ 桌面开发** 工作负载，平台工具集对应 v140 / v141 / v142 / v143
- **Linux**：GCC 5.x 及以上，支持 C++11

::: warning 注意
使用 C++ SDK 发送命令前，必须打开 ATK 软件（不需要打开场景）。若需新建场景，需将已打开的场景关闭。
:::

### 头文件选择

根据链接方式选择对应的头文件：

- **静态库**：`#include "ATKConnectorlib.h"` — 将库编译进可执行文件，无需附带额外的动态库文件
- **动态库**：`#include "ATKConnectorDll.h"` — 运行时需将对应的动态库文件放在可执行文件同目录（Windows：`.dll`；Linux：`.so`）

两种方式的 API 完全一致。示例代码使用静态库模式。

### 配置步骤

#### Windows

1. 根据电脑安装的 Visual Studio 版本，打开对应的解决方案文件：

| VS 版本 | 解决方案目录 | 平台工具集 |
|---------|-------------|-----------|
| VS 2015 | <PathCopy :entry="vs2015Sln" /> | v140 |
| VS 2017 | <PathCopy :entry="vs2017Sln" /> | v141 |
| VS 2019 | <PathCopy :entry="vs2019Sln" /> | v142 |
| VS 2022 | <PathCopy :entry="vs2022Sln" /> | v143 |

2. 打开解决方案后，Visual Studio 会提示**重定向工程**，点击确认即可（如需手动配置：右键项目 → 属性 → 配置属性 → 常规 → **Windows SDK 版本** 和 **平台工具集** 选择已安装的版本）

3. 配置修改完成后，选择 **Release x64** 配置，按 <kbd>Ctrl+Shift+B</kbd> 编译

::: tip xmake 构建（可选）
也可使用 **xmake** 跨平台构建工具代替 Visual Studio 编译：

```bash
xmake f -m release
xmake build
```
:::

#### Linux / 麒麟

C++ SDK 在 Linux（麒麟）平台下以预编译库 + 头文件的形式提供。

##### 目录结构

```
C++/
├── include/                    # ATK 连接器对外头文件目录
│   ├── ATKConnector.h
│   ├── ATKConnectorDll.h
│   └── ATKConnectorlib.h
├── lib/                        # Linux 平台预编译库文件
│   ├── libATKConnectorDll.so    # 动态共享库
│   └── libATKConnectorlib.a     # 静态归档库
├── qt/                         # Qt 可视化测试工程目录
│   └── ConnectTest/
│       ├── ConnectTest.pro
│       └── main.cpp
├── src/                        # 原生 C++ 业务示例源码目录
│   └── ex-InclinationChange.cpp
└── README.md
```

##### GCC 编译

在命令行中进入 C++ SDK 根目录，使用 GCC 编译示例代码：

**静态链接（推荐）**：

```bash
g++ -std=c++11 -I./include -L./lib \
    src/ex-InclinationChange.cpp \
    -lATKConnectorlib \
    -o ex-InclinationChange
```

**动态链接**：

```bash
g++ -std=c++11 -I./include -L./lib \
    src/ex-InclinationChange.cpp \
    -lATKConnectorDll \
    -o ex-InclinationChange
```

::: warning 注意
动态链接方式运行时，需确保 `libATKConnectorDll.so` 位于系统库搜索路径中，或将其复制到可执行文件同目录下。
:::

编译成功后运行：

```bash
./ex-InclinationChange
```

##### Qt 工程编译

如果使用 Qt Creator 开发，可参考 `qt/ConnectTest/` 目录下的 Qt 工程：

```bash
cd qt/ConnectTest
qmake ConnectTest.pro
make
```

## 使用方式

完成上述配置后，即可在代码中调用三组核心 API 操控 ATK。基本流程如下：

```cpp
#include "ATKConnectorlib.h"

int main()
{
    // 1. 建立与 ATK 的连接
    int conID = atkOpen("127.0.0.1", 6655);

    // 2. 发送命令（示例：新建一个场景）
    atkConnect(conID, "New", "/ Scenario MyScenario");

    // 3. 断开连接
    atkClose(conID);

    return 0;
}
```

详细的 API 参数说明见 [核心 API](./2-核心API.md)，完整案例见 [完整示例](./3-完整示例.md)。
