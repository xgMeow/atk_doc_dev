# Introduction and Configuration

## Introduction

The Matlab SDK is the Matlab communication library provided by ATK. It lets you write scripts in your own Matlab development environment and interact with ATK over a TCP network connection, enabling automated operations such as scenario building, parameter setting and simulation running.

As one of the core development methods in Connect mode, the Matlab SDK shares the same communication protocol and command format with the [Python Client tool](../../2-Python客户端工具/1-简介与配置.md) built into ATK. The difference is that the Matlab SDK runs in your own Matlab environment, which suits scenarios where you need to integrate ATK functionality into a Matlab project or leverage Matlab's matrix computation and visualization capabilities.

::: tip Choosing a Development Method
For a detailed comparison of the development methods, refer to the [Connect Mode Overview](../../../README.md#development-method-comparison).
:::

## Environment and Configuration

### Matlab Environment

You need to download and install Matlab yourself. The ATK communication library is developed and tested on Matlab R2015b; we recommend R2015b or later to ensure compatibility.

::: warning Note
Before sending commands with the Matlab SDK, you must open the ATK software (no scenario needs to be open). To create a new scenario, close any scenario that is already open.
:::

### Communication Library Files

The ATK Matlab communication library is shipped with the installation package and is located under `IntegratingWithATK\connect\Matlab` in the installation directory:

- **Windows**: the <PathCopy :entry="matlabDir" /> folder, based on Matlab R2015b

The following describes the file structure using the Windows version as an example:

- <PathCopy :entry="mexFile" />: a MEX executable file that acts as the bridge layer between Matlab and `ATKConnectorDll64.dll`, handling low-level data transfer.
- <PathCopy :entry="atkOpenFile" /> / <PathCopy :entry="atkConnectFile" /> / <PathCopy :entry="atkCloseFile" />: Matlab function M-files that encapsulate the calls to the MEX function, used to establish a connection, send commands and close the connection respectively.

### Configuration Steps

Add the folder path to the Matlab search path:

```matlab
addpath('<ATK installation directory>\IntegratingWithATK\connect\Matlab\Win_2015b')
```

After the configuration is complete, you can directly call the communication interface functions in a script or on the command line, for example:

```matlab
conID = atkOpen();
% ... Send commands ...
atkClose(conID);
```

## Usage

After completing the configuration above, you can call the core APIs in your code to control ATK. The basic flow is as follows:

```matlab
% 1. Add the library file path to the Matlab search path
addpath('<ATK installation directory>\IntegratingWithATK\connect\Matlab\Win_2015b')

% 2. Establish the connection to ATK
conID = atkOpen();

% 3. Send a command (example: create a new scenario)
atkConnect(conID, 'New', '/ Scenario MyScenario');

% 4. Close the connection
atkClose(conID);
```
