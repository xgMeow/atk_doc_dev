# Run the Maneuver Plan

## Description

Run the maneuver plan.

## Syntax

```atk-command
Astrogator <Satellite Object Path> RunMCS
```

::: tip Note
- This command applies only to satellites.
:::

## Examples

::: details open **Run the Maneuver Plan**
```
Astrogator */Satellite/Satellite1 RunMCS
```
:::
