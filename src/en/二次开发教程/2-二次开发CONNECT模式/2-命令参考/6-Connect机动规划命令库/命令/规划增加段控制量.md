# Add a Segment Control Variable

## Description

Add a control variable for a segment inside the target sequence.

## Syntax

```atk-command
Astrogator <Satellite Object Path> AddMCSSegmentControl <AttributePath> <Attribute>
```

## Additional Notes

- The attribute of this command is an independent variable: a numeric element of a segment in the target sequence is selected as the independent variable. For the settable numeric elements, see [maneuver planning properties - Target Sequence - Variables](../属性/瞄准序列段/Variables.md)

## Examples

::: details open **Add a Control Variable for the Maneuver Segment inside the Target Sequence**
```
Astrogator */Satellite/Satellite1 AddMCSSegmentControl MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver ImpulsiveMnvr.Cartesian.X
```
:::

::: details open **Add a Stopping Condition Control Variable for the Propagate Segment inside the Target Sequence**
```
Astrogator */Satellite/Satellite1 AddMCSSegmentControl MainSequence.SegmentList.Target_Sequence.SegmentList.Propagate StoppingConditions.Duration.TripValue
```
:::
