# Delete a Segment

## Description

Delete a segment from a mission control sequence or subsequence.

## Syntax

```atk-command
Astrogator <Satellite Object Path> DeleteSegment <Attribute Path>
```

## Additional Notes

- When deleting a segment from the mission control sequence without nesting it in a subsequence, you do not need to include the path; simply enter the name of the segment you want to delete

## Examples

::: details open **Delete a Specified Segment from the Mission Control Sequence**
```
Astrogator */Satellite/Satellite1 DeleteSegment MainSequence.SegmentList.Target_Sequence.SegmentList.Target_Sequence.SegmentList.Propagate2
```
:::

::: details open **Delete a Subsequence from the Mission Control Sequence**
```
Astrogator */Satellite/Satellite1 DeleteSegment MainSequence.SegmentList.Target_Sequence
```
:::

::: details open **Delete the Last Segment from the Mission Control Sequence**
```
Astrogator */Satellite/Satellite1 DeleteSegment MainSequence.SegmentList.Target_Sequence.SegmentList.Target_Sequence.SegmentList.-
```
:::
