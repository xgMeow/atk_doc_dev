# Maneuver Planning Commands

The CONNECT command library for Maneuver Planning (Astrogator), in two parts: [Commands](./命令/README.md) covers the commands that operate on the mission control sequence and its segments, while [Attributes](./属性/README.md) covers the properties that can be set on each segment (organized by segment type).

This page lists every command and attribute in the library in **alphabetical order**.

- If the command name is known but the library it belongs to is not, see [Command Index](../3-命令总索引.md).
:::
