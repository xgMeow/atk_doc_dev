# 单位格式

## 使用方式

在命令中使用 `{Dimension} {Unit}` 格式指定量纲和单位，其中 `{Dimension}` 为下表第一列的任意量纲名称，`{Unit}` 为对应可选单位之一。

## 量纲与单位对照表

| 量纲 | 说明 | 可选单位 |
|------|------|----------|
| Date | 日期 | `UTCG_MM`、`UTCG`、`BJT`、`BDT`、`BDTG`、`GPS`、`GPSG`、`TDTG`、`JDate`、`ModJDate`、`EpSec` |
| Distance | 距离 | `m`、`km`、`dm`、`cm`、`mm`、`in`、`kin`、`ft`、`yd`、`kyd`、`fur`、`mi`、`nm`、`Au`、`ly`、`Re` |
| Time | 时间 | `s`、`min`、`h`、`day`、`cd`、`EarthTU`、`SunTU`、`FN`、`yr` |
| Angle | 角度 | `deg`、`rad`、`arcSec`、`arcMin`、`revs` |
| Mass | 质量 | `g`、`kg`、`t` |
| Frequency | 频率 | `Hz`、`KHz`、`MHz`、`GHz`、`THz` |
| Pressure | 压力 | `Pa`、`kPa` |
| Temperature | 温度 | `degC` |

## 示例

::: details open **设置日期单位为北京时**
```
Units_SetConnect / Date BJT
```
:::

::: details open **设置距离单位为公里**
```
Units_SetConnect / Distance km
```
:::
