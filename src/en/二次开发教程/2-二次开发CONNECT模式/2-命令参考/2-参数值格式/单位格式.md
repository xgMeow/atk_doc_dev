# Unit Format

Physical quantities in ATK are organized by dimension, and one dimension may have several units to choose from. Values in Connect commands are interpreted in the current Connect units; this page covers the categories of units, the value rules, the dimensions and units that can be set, and how the units of composite quantities are determined.

## Unit Categories

ATK units are organized into four categories by module; changing one category does not affect the other three.

| Category | Scope |
|------|----------|
| GUI | Units used when data is entered in the graphical user interface |
| Report | Units used when reports are generated and displayed in the graphical user interface |
| Connect | Units used for values in Connect commands |
| ConnectReport | Units used when reports are generated and displayed in a Connect session |

For example, with the GUI distance unit set to km, distance values in Connect commands are still interpreted in the Connect distance unit.

Connect units are changed by either of two equivalent commands: [Units_SetConnect](../4-Connect对象命令库/命令/Units_SetConnect.md) affects Connect units only, while [Units_Set](../4-Connect对象命令库/命令/Units_Set.md) acts on the same range through its Connect category; each command page gives the syntax.

## Value Rules

- Without a unit suffix, a value is interpreted in the current Connect unit of its dimension: with the distance unit set to km, 1000 means 1000 km.
- A value may carry a unit suffix, in which case it is converted from that unit, so 1000 m always means 1000 m. Not every command accepts a unit suffix: only parameters whose description lists optional units may carry one.
- Date formats (UTCG, BJT, JDate, and so on) belong to the Date dimension and follow the Date unit setting; see [Date Time Format](日期时间格式.md).
- The current Connect units can be queried with [Units_Get](../4-Connect对象命令库/命令/Units_Get.md).
- Where a command specifies its own handling of units, that command's description takes precedence.

## Settable Dimensions and Units

`{Dimension}` and `{Unit}` in command syntax stand for the dimension names and unit names in the table below. All four categories can set every dimension listed.

| Dimension | Description | Optional Units |
|------|------|----------|
| Date | Date | `UTCG_MM`, `UTCG`, `BJT`, `BDT`, `BDTG`, `GPS`, `GPSG`, `TDTG`, `JDate`, `ModJDate`, `EpSec` |
| Distance | Distance | `m`, `km`, `dm`, `cm`, `mm`, `in`, `kin`, `ft`, `yd`, `kyd`, `fur`, `mi`, `nm`, `Au`, `ly`, `Re` |
| Time | Time | `s`, `min`, `h`, `day`, `cd`, `EarthTU`, `SunTU`, `FN`, `yr` |
| Angle | Angle | `deg`, `rad`, `arcSec`, `arcMin`, `revs` |
| Mass | Mass | `g`, `kg`, `t` |
| Power | Power | `W`, `kW`, `MW` |
| Frequency | Frequency | `Hz`, `KHz`, `MHz`, `GHz`, `THz` |
| Temperature | Temperature | `degC`, `degF`, `K` |
| Ratio | Ratio | `dB` |
| Force | Force | `N`, `kN`, `lbf` |
| Pressure | Pressure | `Pa`, `kPa` |

## Units of Composite Quantities

Quantities composed from these dimensions, such as velocity, acceleration, angular rate, and area, have no unit setting of their own; their units follow from the units of the dimensions involved. Common composite quantities are:

| Quantity | Unit |
|------|------|
| Velocity | The distance unit divided by the time unit; km/s with distance in km and time in s |
| Acceleration | The distance unit divided by the square of the time unit; km/s² with distance in km and time in s |
| Angular Rate | The angle unit divided by the time unit; deg/s with angle in deg and time in s |
| Area | The square of the distance unit; km² with distance in km |
