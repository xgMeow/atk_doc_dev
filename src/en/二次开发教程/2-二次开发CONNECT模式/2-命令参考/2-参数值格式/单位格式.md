# Unit Format

## Usage

In a command, use the `{Dimension} {Unit}` format to specify the dimension and its unit, where `{Dimension}` is any dimension name in the first column of the table below, and `{Unit}` is one of the corresponding optional units.

## Dimension-Unit Correspondence Table

| Dimension | Description | Optional Units |
|------|------|----------|
| Date | Date | `UTCG_MM`, `UTCG`, `BJT`, `BDT`, `BDTG`, `GPS`, `GPSG`, `TDTG`, `JDate`, `ModJDate`, `EpSec` |
| Distance | Distance | `m`, `km`, `dm`, `cm`, `mm`, `in`, `kin`, `ft`, `yd`, `kyd`, `fur`, `mi`, `nm`, `Au`, `ly`, `Re` |
| Time | Time | `s`, `min`, `h`, `day`, `cd`, `EarthTU`, `SunTU`, `FN`, `yr` |
| Angle | Angle | `deg`, `rad`, `arcSec`, `arcMin`, `revs` |
| Mass | Mass | `g`, `kg`, `t` |
| Frequency | Frequency | `Hz`, `KHz`, `MHz`, `GHz`, `THz` |
| Pressure | Pressure | `Pa`, `kPa` |
| Temperature | Temperature | `degC` |

## Examples

::: details open **Set the date unit to Beijing Time**
```
Units_SetConnect / Date BJT
```
:::

::: details open **Set the distance unit to kilometers**
```
Units_SetConnect / Distance km
```
:::
