# Date/Time Format

Time parameters in commands are divided into two categories by how they are entered: **a single time value** and **a time interval**.

## Single Time Value

When a command contains parameters such as `{TimeValue}`, `"<OrbitEpoch>"` or `"<CoordEpoch>"`, or the `"<StartTime>"` / `"<StopTime>"` of a time interval, enter an absolute date/time.

**Format**: `"DD Mon YYYY HH:MM:SS.sss"` (UTCG)

| Example | Description |
|------|------|
| `"01 Sep 2011 12:00:00.000"` | 2011-09-01 12:00:00 |
| `"1 Jul 2021 09:00:00.000"` | 2021-07-01 09:00:00 |

::: tip Switching the Date Format
UTCG is used by default. To switch to Beijing Time `BJT`, Julian Date `JDate`, and so on, use `Units_SetConnect / Date <format name>`; see the Date row in [Unit Format](单位格式.md) for the available formats.
:::

## Time Interval

When a command contains the `{TimeInterval}` parameter, enter a start time and a stop time separated by a space:

```
"<StartTime>" "<StopTime>"
```

- The start time comes first and the stop time comes last; the order **cannot be swapped**
- The two times **cannot be identical**
- Both `"<StartTime>"` and `"<StopTime>"` are entered using the single time value format

**Example**: `"01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"`

## Examples

::: details open **Single time value** — set the ECI position of Satellite1 at a specified time
```
SetPosition */Satellite/Satellite1 ECI "1 Jul 2021 09:00:00.000" 8678140.000000 0.000064 -1.837743
```
:::

::: details open **Time interval** — create a data report for Satellite1 over a specified time period
```
ReportCreate */Satellite/Satellite1 TimePeriod "01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"
```
:::
