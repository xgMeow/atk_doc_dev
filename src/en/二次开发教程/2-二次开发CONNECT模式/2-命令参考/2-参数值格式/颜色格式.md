# 颜色格式

`{Color}` 参数支持以下四种输入格式：

## 英文颜色名

直接输入英文颜色名称，支持常见颜色名。

**示例**：<ColorSwatch name="Red" />、<ColorSwatch name="Blue" />、<ColorSwatch name="Green" />、<ColorSwatch name="Yellow" />、<ColorSwatch name="White" />、<ColorSwatch name="Black" />

## 数字颜色

输入数字 `0-27` 使用预设颜色，共 28 种。若输入大于 27，颜色会循环重复。

| 数字 | 预览 | 数字 | 预览 |
|------|------|------|------|
| 0 | <ColorSwatch hex="000000" /> | 1 | <ColorSwatch hex="00FF00" /> |
| 2 | <ColorSwatch hex="00FFFF" /> | 3 | <ColorSwatch hex="FF00FF" /> |
| 4 | <ColorSwatch hex="FFFF00" /> | 5 | <ColorSwatch hex="0000FF" /> |
| 6 | <ColorSwatch hex="FF0000" /> | 7 | <ColorSwatch hex="FFFFFF" /> |
| 8 | <ColorSwatch hex="4169FF" /> | 9 | <ColorSwatch hex="87CEFA" /> |
| 10 | <ColorSwatch hex="00CED1" /> | 11 | <ColorSwatch hex="6B8E23" /> |
| 12 | <ColorSwatch hex="8FBC8F" /> | 13 | <ColorSwatch hex="FFD700" /> |
| 14 | <ColorSwatch hex="BA55D3" /> | 15 | <ColorSwatch hex="FF69B4" /> |
| 16 | <ColorSwatch hex="D2691E" /> | 17 | <ColorSwatch hex="FFF0F5" /> |
| 18 | <ColorSwatch hex="7FFF00" /> | 19 | <ColorSwatch hex="FF6A6A" /> |
| 20 | <ColorSwatch hex="9B30FF" /> | 21 | <ColorSwatch hex="FFA500" /> |
| 22 | <ColorSwatch hex="F08080" /> | 23 | <ColorSwatch hex="F0FFFF" /> |
| 24 | <ColorSwatch hex="4D4D4D" /> | 25 | <ColorSwatch hex="999999" /> |
| 26 | <ColorSwatch hex="F0E68C" /> | 27 | <ColorSwatch hex="F0DEB2" /> |

## 百分比 RGB 格式

格式：`%RRRGGGBBB`

- 每部分最大值为 255，若输入值大于 255 则默认为 255
- 若输入位数不够，则默认补 0

**示例**：<ColorSwatch rgb="255000000" />

## 十六进制 RGB 格式

格式：`#RRGGBB`

- 每部分取值 00 到 FF
- 若输入位数不够，则默认补 0

**示例**：<ColorSwatch hex="FF0000" />

## 示例

::: details open 使用英文颜色名
```
Graphics */Satellite/Satellite1 SetColor red
```
:::

::: details open 使用数字颜色
```
Graphics */Aircraft/Aircraft1 SetColor 4
```
:::

::: details open 使用十六进制 RGB
```
Graphics */Satellite/Satellite1 SetColor #00ff00
```
:::

::: details open 使用百分比 RGB
```
Graphics */Satellite/Satellite1 SetColor %255000000
```
:::
