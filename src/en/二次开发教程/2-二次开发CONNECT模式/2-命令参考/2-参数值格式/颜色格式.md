# Color Format

The `{Color}` parameter supports the following four input formats:

## English Color Names

Enter an English color name directly; common color names are supported.

**Example**: <ColorSwatch name="Red" />, <ColorSwatch name="Blue" />, <ColorSwatch name="Green" />, <ColorSwatch name="Yellow" />, <ColorSwatch name="White" />, <ColorSwatch name="Black" />

## Numeric Colors

Enter a number from `0-27` to use a preset color, 28 colors in total. If the entered number is greater than 27, the colors cycle and repeat.

| Number | Preview | Number | Preview |
|------|------|------|------|
| 0 | <ColorSwatch hex="000000" /> | 1 | <ColorSwatch hex="00FF00" /> |
| 2 | <ColorSwatch hex="00FFFF" /> | 3 | <ColorSwatch hex="FF00FF" /> |
| 4 | <ColorSwatch hex="FFFF00" /> | 5 | <ColorSwatch hex="0000FF" /> |
| 6 | <ColorSwatch hex="FF0000" /> | 7 | <ColorSwatch hex="FFFFFF" /> |
| 8 | <ColorSwatch hex="4169FF" /> | 9 | <ColorSwatch hex="87CEFA" /> |
| 10 | <ColorSwatch hex="00CED1" /> | 11 | <ColorSwatch hex="6B8E23" /> |
| 12 | <ColorSwatch hex="8FBC8F" /> | 13 | <ColorSwatch hex="FFD700" /> |
| 14 | <ColorSwatch hex="BA55D3" /> | 15 | <ColorSwatch hex="FF69B4" /> |
| 16 | <ColorSwatch hex="D2691E" /> | 17 | <ColorSwatch hex="FFF0F5" /> |
| 18 | <ColorSwatch hex="7FFF00" /> | 19 | <ColorSwatch hex="FF6A6A" /> |
| 20 | <ColorSwatch hex="9B30FF" /> | 21 | <ColorSwatch hex="FFA500" /> |
| 22 | <ColorSwatch hex="F08080" /> | 23 | <ColorSwatch hex="F0FFFF" /> |

## Percentage RGB Format

Format: `%RRRGGGBBB`

- The maximum value of each part is 255; if the entered value is greater than 255, it defaults to 255
- If fewer digits than expected are entered, the missing digits are padded with 0 by default

**Example**: <ColorSwatch rgb="255000000" />

## Hexadecimal RGB Format

Format: `#RRGGBB`

- Each part ranges from 00 to FF
- If fewer digits than expected are entered, the missing digits are padded with 0 by default

**Example**: <ColorSwatch hex="FF0000" />

## Examples

::: details open Use an English color name
```
Graphics */Satellite/Satellite1 SetColor red
```
:::

::: details open Use a numeric color
```
Graphics */Aircraft/Aircraft1 SetColor 4
```
:::

::: details open Use hexadecimal RGB
```
Graphics */Satellite/Satellite1 SetColor #00ff00
```
:::

::: details open Use percentage RGB
```
Graphics */Satellite/Satellite1 SetColor %255000000
```
:::
