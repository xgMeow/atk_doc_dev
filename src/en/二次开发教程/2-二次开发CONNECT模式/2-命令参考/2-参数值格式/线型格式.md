# Line Style Format

The `{LineStyle}` parameter supports two input methods: a keyword or a number.

| Line Style | Keyword | Number |
|------|------|------|
| Solid | `solid` | `0` |
| Dashed | `dashed` | `1` |
| Dotted | `dotted` | `2` |
| Dash-dot | `dashdot` | `3` |
| Long-medium-short dashed | `lmsdash` | `4` |

## Examples

::: details open Set the line style with a keyword
```
Graphics */Satellite/Satellite1 SetLineStyle dashed
```
:::

::: details open Set the line style with a number
```
Graphics */Satellite/Satellite1 SetLineStyle 2
```
:::
