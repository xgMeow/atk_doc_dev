# Command Syntax Conventions

ATK Connect commands use the following symbols to indicate the type and constraints of parameters. Refer to this convention when reading command syntax.

## Basic Symbols

| Symbol | Meaning | Description |
|------|------|------|
| `<parameter>` | Required parameter | Replace with the actual value when used, e.g. `<ObjectPath>` → `*/Satellite/Satellite1`. |
| `[parameter]` | Optional parameter | May be omitted as needed, e.g. `[WindowID <WinNumber>]` is optional. |
| `{choice}` | Required choice | Must **select one** from the given options, e.g. fill `{On \| Off}` with `On` or `Off`; fill `{Color}` according to the color format. |
| `\|` | Option separator | Separates mutually exclusive options inside `{ }`, meaning "or", e.g. choose one of `{Details \| Platform}`. |
| `"text"` | String literal | Enter it as-is, **keeping the double quotes**. e.g. `"<FilePath>"` → `"C:\data\file.a"`. |
| `...` | Repeatable | The preceding element may appear multiple times, e.g. `({Option} <Value>)...` allows several option-value pairs. |

## Path Symbols

| Symbol | Meaning | Description |
|------|------|------|
| `*` | Scenario wildcard | Represents the "current scenario", equivalent to `current scenario/`. e.g. `VO * CentralBody Mars` (`*` is the current scenario). |
| `/` | Root path | Represents the top level of the object tree, e.g. `AllInstanceNames /` lists all root-level objects. |

## Additional Notes

- Commands separate words with **spaces**; **spaces are not allowed** inside a parameter (except within a string literal).

- If a string literal `" "` contains spaces, wrap it as a whole in double quotes.

- The parameter order must strictly follow the syntax definition and cannot be swapped.
