# Graphics_R GetLabel

## Description

Gets the label of the object.

## Syntax

```atk-command
Graphics_R <ObjectPath> GetLabel
```

## Parameters

| Parameter | Description |
|------|------|
| `<ObjectPath>` | Full path of the object, written from the scenario root `*`, for example `*/Satellite/Satellite1` |

## Applies To

Satellite, Facility

## Examples

::: details open **Get the label of the object**
```
Graphics_R */Satellite/Satellite1 GetLabel
```
:::
