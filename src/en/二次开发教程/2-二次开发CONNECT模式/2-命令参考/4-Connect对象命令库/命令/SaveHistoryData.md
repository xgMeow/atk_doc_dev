# SaveHistoryData

## Description

Controls whether the scenario saves history data.

## Syntax

```atk-command
SaveHistoryData <ApplicationPath> {Option}
```

## Additional Notes

- `{Option}` accepts `On` / `Off`.

## Examples

::: details open **Enable history data saving for the scenario**

```
SaveHistoryData / On
```

:::

::: details open **Disable history data saving for the scenario**

```
SaveHistoryData / Off
```

:::
