# Commands by Object

To find out which commands a given object type (satellite, facility, missile, and so on) supports, open the corresponding object page from the table of contents on the left.

This page is a **complete quick-reference table**: it lists every command in the object command library in alphabetical order, so when it is unclear which object a command belongs to, the command can be looked up directly here.

::: tip Other Ways to Search
- To find a command by function module, see [Commands by Function](../5-Connect功能索引/README.md).
- If the command name is known but the library it belongs to is not, see [Command Index](../3-命令总索引.md).
:::
