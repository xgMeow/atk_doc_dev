# Run the Deviation Analysis Plan

## Description

Runs the deviation analysis plan.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> RunMCS
```

::: tip Note
- This command applies to satellites only
:::

## Examples

::: details open **Run the deviation analysis plan**
```
AstroUQ */Satellite/Satellite1 RunMCS
```
:::
