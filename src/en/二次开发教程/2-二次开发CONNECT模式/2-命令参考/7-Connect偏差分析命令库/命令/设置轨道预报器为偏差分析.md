# Set the Orbit Propagator to Deviation Analysis

## Description

Sets the orbit propagator to deviation analysis.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> SetProp
```

::: tip Note
- This command applies to satellites only
:::

## Examples

::: details open **Set the orbit propagator to deviation analysis**
```
AstroUQ */Satellite/Satellite1 SetProp
```
:::
