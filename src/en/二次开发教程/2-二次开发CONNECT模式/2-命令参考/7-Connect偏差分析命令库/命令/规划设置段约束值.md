# Set Constraint Values of a Planning Segment

## Description

Sets the constraint values of a deviation analysis planning segment.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> SetMCSConstraintValue <Attribute Path>.Profiles.<Search Profile> <ParentObjectName> <ResultName> <Attribute> <Value> [<Unit>]
```

## Additional Notes

- For the specific property settings, see the planning attributes for constraints

## Parameters

### Properties Available for Differential Correction

| Parameter | Description |
|------|------|
| `Active` | Indicates whether the constraint quantity is used; enter true or false |
| `tolerance` | Sets the convergence tolerance |
| `scale` | Sets the scaling parameter |
| `weight` | Sets the weight coefficient |
| `desired` | Sets the desired value |

### Properties Available for Sequential Quadratic Programming and Intelligent Optimization Algorithms

| Parameter | Description |
|------|------|
| `Active` | Sets or gets whether the constraint quantity is used; enter true or false |
| `tolerance` | Sets or gets the convergence tolerance |
| `scale` | Sets or gets the scaling parameter |
| `weight` | Sets or gets the weight coefficient |
| `desired` | Sets or gets the desired value |
| `Objfun{Constraint\|Minimize\|Maximize\|`<br/>`MinimizeandConstraint\|MaximizeandConstraint}` | Sets or gets the type:<br/>Constraint, Minimize, Maximize, Minimize and Constraint, or Maximize and Constraint |
| `LowerBound` | Sets or gets the minimum value |
| `UpperBound` | Sets or gets the maximum value |
| `Unit` | Gets the unit |
| `Achieved` | Gets the current value |
| `Difference` | Gets the error value |

## Examples

::: details open **Set the constraint results with SetValue**
```
AstroUQ */Satellite/FastTransfer SetValue MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver.Results "Radius Of Apoapsis"
```
:::

::: details open **Set the RAAN result of a constraint with SetValue**
```
AstroUQ */Satellite/FastTransfer SetValue MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver.Results "RAAN" "X"
```
:::

::: details open **Set the desired value of a differential correction constraint**
```
AstroUQ */Satellite/FastTransfer SetMCSConstraintValue MainSequence.SegmentList.Target_Sequence.Profiles.Differential_Corrector Maneuver "Radius Of Apoapsis" Desired 84328394 m
```
:::

::: details open **Set the convergence tolerance of a differential correction constraint**
```
AstroUQ */Satellite/FastTransfer SetMCSConstraintValue MainSequence.SegmentList.Target_Sequence.Profiles.Differential_Corrector Maneuver Rel_Mean_Mean_Anomaly tolerance 0.2
```
:::
