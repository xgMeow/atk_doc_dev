# Set an Attribute Value

## Description

Pass a value to the orbit maneuver module.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> SetValue <Attribute Path>.<Attribute> <Value> [<Unit>]
```

## Additional Notes

- For specific attribute types, see the maneuver planning properties

## Examples

::: details open **Pass a Value to the Orbit Maneuver Module**
```
AstroUQ */Satellite/Satellite1 SetValue MainSequence.SegmentList.Initial_State.CoordinateType" "Modified Keplerian"
```
:::
