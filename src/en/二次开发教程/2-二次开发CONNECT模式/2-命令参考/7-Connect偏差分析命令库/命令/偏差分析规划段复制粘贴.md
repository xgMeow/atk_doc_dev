# Paste a Deviation Analysis Planning Segment

## Description

Pastes a planning segment in deviation analysis.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> Paste CopySegmentPath PasteSegmentPath
```

::: tip Note
- This command is used with deviation analysis.
:::

## Examples

::: details open **Paste a deviation analysis planning segment**
```
AstroUQ */Satellite/Satellite1 Paste MainSequence.SegmentList.Propagate.- MainSequence.SegmentList.InitialState
```
:::
