# ClearCorrections

## Description

Reset the specified profile of the target sequence segment.

## Syntax

```atk-command
AstroUQ <Satellite Object Path> ClearCorrections <Attribute Path>
```

## Examples

::: details open **Reset the specified target sequence segment profile**
```
AstroUQ */Satellite/Satellite1 ClearCorrections MainSequence.SegmentList.Target_Sequence
```
:::
