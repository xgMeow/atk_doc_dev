# Set a Segment Constraint Value

## Description

Set the constraint values of the segments in the maneuver plan.

## Syntax

```atk-command
Astrogator <Satellite Object Path> SetMCSConstraintValue <Attribute Path>.Profiles.<Search Profile> <ParentObjectName> <ResultName> <Attribute> <Value> [<Unit>]
```

## Additional Notes

- For specific attribute settings, see the maneuver planning properties - Constraints

## Parameters

### Settable Parameter Attributes for the Differential Corrector

| Parameter | Description |
|------|------|
| `Active` | Indicates whether the constraint is used; accepts true or false |
| `tolerance` | Set the tolerance |
| `scale` | Set the normalization parameter |
| `weight` | Set the weight |
| `desired` | Set the desired value |

### Settable Parameter Attributes for Sequential Quadratic Programming and Intelligent Optimization Algorithms

| Parameter | Description |
|------|------|
| `Active` | Set or get whether the constraint is used; accepts true or false |
| `tolerance` | Set or get the tolerance |
| `scale` | Set or get the normalization parameter |
| `weight` | Set or get the weight |
| `desired` | Set or get the desired value |
| `Objfun{Constraint\|Minimize\|Maximize\|MinimizeandConstraint\|MaximizeandConstraint}` | Set or get the type {Constraint\Minimize\Maximize\Minimize and Constraint\Maximize and Constraint} |
| `LowerBound` | Set or get the minimum value |
| `UpperBound` | Set or get the maximum value |
| `Unit` | Get the unit |
| `Achieved` | Get the current value |
| `Difference` | Get the error value |

## Examples

::: details open **Set Constraint Results Using SetValue**
```
Astrogator */Satellite/FastTransfer SetValue MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver.Results "Radius Of Apoapsis"
```
:::

::: details open **Set the RAAN Result of the Constraint Using SetValue**
```
Astrogator */Satellite/FastTransfer SetValue MainSequence.SegmentList.Target_Sequence.SegmentList.Maneuver.Results "RAAN" "X"
```
:::

::: details open **Set the Desired Value of a Differential Corrector Constraint**
```
Astrogator */Satellite/FastTransfer SetMCSConstraintValue MainSequence.SegmentList.Target_Sequence.Profiles.Differential_Corrector Maneuver "Radius Of Apoapsis" Desired 84328394 m
```
:::

::: details open **Set the Tolerance of a Differential Corrector Constraint**
```
Astrogator */Satellite/FastTransfer SetMCSConstraintValue MainSequence.SegmentList.Target_Sequence.Profiles.Differential_Corrector Maneuver Rel_Mean_Mean_Anomaly tolerance 0.2
```
:::
