# Insert a Segment

## Description

Insert a segment into a mission control sequence or subsequence.

## Syntax

```atk-command
Astrogator <Satellite Object Path> InsertSegment <Attribute Path> SegmentType
```

## Additional Notes

- If `<Attribute Path>` is an existing segment path plus segment name, the new segment will be inserted before that segment; if `<Attribute Path>` is a segment path plus `-`, the new segment will be inserted after the last segment of that mission control sequence
- If `<Attribute Path>` is only `-`, the new segment will be inserted after the last segment in the first mission control sequence list
- If `<Attribute Path>` is only a segment name, the new segment will be inserted before the first segment whose name matches it

## Parameters

| Parameter | Description |
|------|------|
| `RPOFMCircumnav` | RPO forced-motion circumnavigation segment |
| `RPOFMW` | RPO straight-line approach segment |
| `RPOHop` | RPO hop segment |
| `RPOHopAndStop` | RPO hop-and-stop segment |
| `RPOPerchEqualSpacing` | RPO perch (station-keeping) segment |
| `RPOTearDrop` | RPO teardrop segment |
| `RPONMCircumnav` | RPO natural-motion circumnavigation segment |
| `RPOFollowSun` | RPO sun-following circumnavigation segment |
| `RPOExitGEO` | RPO GEO exit segment |
| `RPOGEORendezvousDrifting` | RPO GEO drifting rendezvous segment |
| `RPOGEORendezvousNolead` | RPO GEO rendezvous segment |

## Examples

::: details open **Insert a New Segment before an Existing Segment**
```
Astrogator */Satellite/Satellite1 InsertSegment MainSequence.SegmentList.Maneuver1 Propagate
```
:::

::: details open **Insert a New Segment at the End of the Mission Control Sequence**
```
Astrogator */Satellite/Satellite1 InsertSegment MainSequence.SegmentList.- Propagate
```
:::

::: details open **Insert a New Segment at the End of the First Mission Control Sequence**
```
Astrogator */Satellite/Satellite1 InsertSegment - Propagate
```
:::

::: details open **Insert a New Segment before the First Segment with a Matching Name**
```
Astrogator */Satellite/Satellite1 InsertSegment Maneuver1 Propagate
```
:::

::: details open **Insert an RPO Forced-Motion Circumnavigation Segment**
```
Astrogator */Satellite/Satellite1 InsertSegment MainSequence.SegmentList.- RPOFMCircumnav
```
:::
