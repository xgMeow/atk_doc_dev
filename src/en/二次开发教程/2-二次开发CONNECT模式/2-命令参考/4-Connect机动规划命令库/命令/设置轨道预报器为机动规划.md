# Set the Orbit Propagator to Maneuver Planning

## Description

Set the orbit propagator to maneuver planning.

## Syntax

```atk-command
Astrogator <Satellite Object Path> SetProp
```

::: tip Note
- This command applies only to satellites.
:::

## Examples

::: details open **Set the Orbit Propagator to Maneuver Planning**
```
Astrogator */Satellite/Satellite1 SetProp
```
:::
