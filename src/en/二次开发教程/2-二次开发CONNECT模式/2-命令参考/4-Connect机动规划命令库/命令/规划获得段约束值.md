# Get a Segment Constraint Value

## Description

Get the constraint value of each segment in the maneuver plan.

## Syntax

```atk-command
Astrogator_RM <Satellite Object Path> GetValue <AttributePath>.Results.<ResultName>.Value
```

## Examples

::: details open **Get the Constraint Value of Each Segment in the Maneuver Plan**
```
Astrogator_RM */Satellite/Satellite1 GetValue MainSequence.SegmentList.Propagate.Results.StateCalcX.Value
```
:::
