# VO Point

## Description

Set the aircraft **3D model point** properties.

## Syntax

```atk-command
VO <ObjectPath> Point {PointOptions}
```

## Parameters

| Parameter | Description |
|------|------|
| `Show` | `{On \| Off}`: whether to show the model point |
| `Size` | `<Value>`: model point size setting |

## Examples

::: details open **Show the model point and set the size**
```
VO */Aircraft/Aircraft Point Show On Size 7
```
:::
