# Graphics SetColor

## Description

Set the **aircraft trajectory label color**.

## Syntax

```atk-command
Graphics <ObjectPath> SetColor {Color} [{Item}]
```

## Additional Notes

- For the supported `Color` formats, see [Color Format](../../2-参数值格式/颜色格式.md).

## Examples

::: details open **Set the aircraft trajectory color**
```
Graphics */Aircraft/Aircraft1 SetColor 4
```
:::
