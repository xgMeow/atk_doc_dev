# Graphics Label

## Description

Set the **aircraft label** properties.

## Syntax

```atk-command
Graphics <ObjectPath> Label {Options}
```

## Parameters

| Parameter | Description |
|------|------|
| `Show` | `{on \| off}`: Show or hide the label |

## Examples

::: details open **Show the aircraft label**
```
Graphics */Aircraft/Aircraft1 Label Show on
```
:::
