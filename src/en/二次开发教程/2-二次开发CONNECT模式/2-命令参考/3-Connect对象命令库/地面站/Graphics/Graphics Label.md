# Graphics Label

## Description

Set the facility label properties.

## Syntax

```atk-command
Graphics <ObjectPath> Label {Options}
```

## Parameters

| Parameter | Description |
| ---------------- | -------------- |
| `Show {on \| off}` | Show or hide the label |

## Examples

::: details open **Show the label**
```
Graphics */Facility/Facility1 Label Show on
```
:::
