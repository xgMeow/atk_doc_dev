# ImportTLEFile

## Description

Adds objects using a TLE file.

## Syntax

```atk-command
ImportTLEFile <ScenarioPath> "<FilePath>"
```

## Examples

::: details open **Add Objects Using a TLE File**
```
ImportTLEFile * "C:/Users/A411-2/Desktop/ATK_B/AstroData/Database/Satellite/atkFile8.0/atkAll.tce"
```
:::
