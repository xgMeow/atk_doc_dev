# Graphics Show

## Description

Sets whether the sensor is displayed in the window.

## Syntax

```atk-command
Graphics <ObjectPath> Show {On | Off}
```

## Examples

::: details open **Set Sensor Display**
```
Graphics */Satellite/Satellite1/Sensor/Sensor1 Show Off
```
:::
