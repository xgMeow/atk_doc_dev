# Graphics Fill

## Description

Sets whether to fill.

## Syntax

```atk-command
Graphics <SensorObjectPath> Fill {On | Off}
```

## Examples

::: details open **Set Sensor Fill**
```
Graphics */Satellite/Satellite1/Sensor/Sensor1 Fill Off
```
:::
