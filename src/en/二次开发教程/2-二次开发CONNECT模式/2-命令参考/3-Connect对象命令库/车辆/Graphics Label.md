# Graphics Label

## Description

Set the ground vehicle label properties.

## Syntax

```atk-command
Graphics <ObjectPath> Label {Options}
```

## Parameters

| Parameter | Description |
| --- | --- |
| `Show {on \| off}` | Show or hide the label |

## Examples

::: details open **Show the ground vehicle label**
```
Graphics */GroundVehicle/GroundVehicle1 Label Show on
```
:::
