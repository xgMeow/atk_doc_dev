# Graphics Label

## Description

Set the **ship label** properties.

## Syntax

```atk-command
Graphics <ObjectPath> Label {Options}
```

## Parameters

| Parameter | Description |
| -- | -- |
| `Show {on \| off}` | Show or hide the label |

## Examples

::: details open **Show the ship label**
```
Graphics */Ship/Ship1 Label Show on
```
:::
