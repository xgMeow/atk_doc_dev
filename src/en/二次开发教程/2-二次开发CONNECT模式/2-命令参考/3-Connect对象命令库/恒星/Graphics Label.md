# Graphics Label

## Description

Sets the star label attributes.

## Syntax

```atk-command
Graphics <ObjectPath> Label {Options}
```

## Parameters

| Parameter | Description |
|------|------|
| `Show {on \| off}` | Shows or hides the label |

## Examples

::: details open **Show the star label**
```
Graphics */Star/Star1 Label Show on
```
:::
