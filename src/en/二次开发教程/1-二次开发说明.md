# Development Guide

## Features

The ATK Secondary Development module is a customizable module that allows users to operate ATK through different languages and different software. This module provides three ways to control ATK: Connect Mode, MBSE Mode, and Component Mode.

### Connect Mode

Connect Mode connects to the ATK software over the network, allowing users to control ATK by writing scripts and sending commands. The library file provided by Connect Mode is a collection of functions and other information that this module offers to users. The interface functions it provides serve as the recognition method for data transfer between the client and ATK, and the command scripts entered into the interface functions are the basis on which ATK parses and executes operations. In this way, scenario and property settings for the ATK software can be achieved through scripts.

::: info Supported Interfaces
This mode supports **Matlab**, **Python**, and **Client**.
:::

### MBSE Mode

MBSE Mode uses a plug-in mechanism to transfer data with the ATK software. The plug-in handles the connection, data transfer, and parsing between the MagicDraw client and ATK. Users control the ATK software by building models in the MagicDraw client, entering script commands in the models, and running the models. The script command format is the same as that of Connect Mode.

### Component Mode

Component Mode invokes ATK-related functions by loading dynamic libraries. The library file contains the operational interfaces that this module provides to users, through which ATK parameters can be modified and set. Users can load the relevant library files in their own software and write code to control ATK.

::: info Supported Languages
This mode supports **C++**, **Java**, **Python**, and **Matlab**.
:::
