# ATK 文档优化规范

## 优化目标

当用户说「优化结构」「优化文档」「整理文档」时，严格按以下规范执行。只改结构，不改内容，不要拓展。

## 格式规范

### 标题
- 标题不编号

### 按钮与对话框
- 按钮用 `【按钮名】` 格式，如 `【插入】`、`【新建】`
- 打开对话框格式：`【XXX】对话框`，如 `【插入】对话框`

### 文字与段落
- 加粗文字前后要有空格
- 段与段之间必须有空行

### 表格
- 只有一列时不用表格，改用列表或引用格式

### 图片
- 单独一行的图片：`![描述](路径)`，图片前后空行
- 行内图标图片：`<img src="./media/xxx.png" no-view>`
- 图片不加序号

## 结构优化

可以使用以下 Markdown 语法增强结构：

### 折叠
```
::: details 标题
内容
:::
```

### 提示块
```
> [!TIP]
> 提示内容

> [!WARNING]
> 警告内容

> [!NOTE]
> 注意内容
```

### 引用
```
> 引用内容
```

### 表格
复杂数据用表格展示

## 禁止事项

- **不要**改链接
- **不要**改表达的意思
- **不要**拓展内容
- **不要**改图片路径
- **不要**私自调整链接跳转

## 执行原则

- 操作要易懂、逻辑要清楚、结构要清晰
- 内容不能丢失
- 可以整体调整结构
- 可以添加正确的链接跳转（VuePress 格式）
