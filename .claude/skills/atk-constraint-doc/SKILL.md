# ATK 约束文档补充

把 `references/ATK约束/` 下新增的“对象约束原始记录”（ATK<对象>约束.md，多为对软件约束界面 Tab 的转录）落成正式文档：更新**通用约束页**（`src/zh/03-基础使用指南/03-对象管理/03-约束配置新/`）里各 `<Entry>` 卡片的适用对象，并把**对象属性页**（`…/02-属性配置/<对象>.md`）的 `## 约束` 段改为链接表。

**核心纪律：以参考为准。** 参考里没出现的字段、Tab、对象一律不加；参数名用真实的界面字段名，不自行命名。

## 目录与结构

- 参考：`references/ATK约束/ATK<对象>约束.md`（每个对象一份，可随时新增）
- 通用约束页（`03-约束配置新/`，参数说明统一用 `<Entry>` 卡片，见 `01-基本约束.md` 的写法）：
  - `01-基本约束.md` 几何参数 + 视线/视场/地形约束
  - `02-太阳约束.md` 仰角组 + `### 视线`/`### 视轴` 规避角组 + 附加中心天体遮挡
  - `03-时间约束.md` 当地时间/GMT/当地太阳时/时长/时段
  - `04-通信约束.md` 链路指标 14 项
  - `README.md` 本册说明
- 对象属性页：`…/02-属性配置/<对象>.md`，`## 约束` 直接放一张“属性 | 说明”链接表（**不加导语句**）。
- 组件与色表：
  - `src/.vuepress/components/Entry/Entry.vue`：`<Entry name unit note level objects>`；`level="4"` 用于嵌在 `###` 小节下的卡片；`OBJECT_COLORS` 的对象键以 `02-属性配置` 下的对象页为准（含 品质因子、覆盖定义；船舶键为 `舰船`）。
  - 若 `objects=` 用到色表里还没有的对象，先补色。

## 各参考 Tab → 通用页落点

参考文件里每个对象通常含以下 Tab（以该参考实际出现为准），把对象名称加入对应卡片 `objects=`：

| 参考 Tab | 通用页 | 该对象拥有的参数 → 应加 `objects` 的卡片 |
| --- | --- | --- |
| 基本 | 01 | 方位角/仰角/距离/方位角变化率/仰角变化率/距离变化率/角变化率/高度（都有）；**传播延时**仅当参考列 9 项时加；底部 视线约束、**视场约束**（仅当参考底部出现）、地形约束 |
| 太阳 | 02 | 太阳仰角/太阳地平仰角/月球仰角/附加中心天体遮挡/`### 视线`组 太阳·月球规避角；`### 视轴`组太阳·月球规避角**仅当参考有 视轴(deg) 行**才加 |
| 时间 | 03 | 当地时间/格林威治标准时间/当地太阳时/时长/时段 |
| 通信 | 04 | 频率…天线性能品质因子 共 14 项 |

要点：
- 一个对象“没有”某参数/Tab（参考未列）就**绝不**往该卡片加它。例如发射器参考无 太阳、无 传播延时、无 视场。
- 参考文件还没出现的对象，不要凭其它对象推测它的 Tab；谁有参考谁才进文档（通信约束曾因无发射器参考而删去“发射器”，参考补齐后恢复）。
- 规避角两组同叫“太阳规避角 / 月球规避角”，靠 `### 视线`、`### 视轴` 小节区分，**不要**自造“太阳视轴规避角”之类名字。

## 工作流程

1. 通读 `references/ATK约束/ATK<对象>约束.md`，列出该对象的 Tab 及每页参数（参数名、单位、是否“共 N 项”、底部约束开关）。
2. 逐 Tab 打开 `03-约束配置新` 对应族页，把对象名**追加**到它实际拥有的每张卡片 `objects` 值（保留已有对象的顺序，追加在后）；同时确保它**不**出现在它没有的参数卡上。
   - 若参考出现了族页里还没有的参数，按 `01-基本约束.md` 卡片风格新增（真实字段名、单位、描述；该字段专属某类对象时才写窄化说明）。
   - 若某卡片正文有“仅…对象”且与新加入对象矛盾，把正文改成与 `objects` 徽标一致的通用说法。
   - 卡片若放在 `###` 小节下，加 `level="4"`。
3. 编辑对象属性页 `02-属性配置/<对象>.md`：把 `## 约束` 下旧式“同 XX 对象”/“详见飞机”等改成裸链接表（列：`属性 | 说明`），行内容按对象补齐：
   - 基本行：`<对象>与其他对象间的访问需满足的几何与视线条件（方位角、仰角、距离〔、传播延时、高度〕〔、视场〕等）`
   - 太阳行：`<对象>与其他对象间的访问需满足的、按太阳与月球相对位置判定的条件（太阳/月球仰角、规避角、附加中心天体遮挡等）`
   - 时间行：`<对象>与其他对象间的访问需落入的时间窗口（当地时间/GMT/当地太阳时/时长/时段）`
   - 通信行：`<对象>的通信链路需满足的指标（频率、系统噪声温度、信噪比、误码率等）`
   - 只列该对象开放的 Tab，行内不必写“仅…开放”。
4. 新对象若还没进 `Entry.vue` 的 `OBJECT_COLORS`，补一个色键。
5. 校对（见下），完成后向用户说明对象覆盖了哪些族页与属性页、加了哪些标记。

## 校对清单

- [ ] 该对象每 Tab 的卡数与参考一致：基本“N 项 + 底部开关”、太阳/时间“共 N 项”、通信 14。
- [ ] `objects=` 快照汇总符合预期。验证命令：
  ```bash
  grep -rhoE 'objects="[^"]*"' <03-约束配置新>/*.md | sort | uniq -c
  ```
- [ ] 未给对象添加它参考里没有的参数/Tab；未发明参考里不存在的字段名。
- [ ] 对象属性页 `## 约束` 为裸链接表，未残留“同 XX / 详见飞机”旧话。
- [ ] 新增对象已在 `OBJECT_COLORS`（未在则已补色）。
- [ ] 全文未使用“族/约束族”措辞（本册用 “Tab 页 / 约束页”）。
- [ ] 卡片标题级合理：直接位于 `## 参数说明` 下的默认 h3，嵌在 `###` 小节下的用 `level="4"`。
