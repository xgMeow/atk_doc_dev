# 高级接近分析案例

通过二次开发 Connect 模式，创建高级接近分析场景，必须保持 ATK 为打开状态，具体命令分类包括：

1. 与 ATK 进行连接。
2. 新建场景并进行属性设置。
3. 新建卫星并进行属性设置。
4. 新建高级接近分析对象并进行属性设置。
5. 查看报告数据
6. 保存场景后与 ATK 断开连接。

## 脚本展示

### 与 ATK 进行连接

```mixcode
{C:1, 与 ATK 进行连接}
conID = atkOpen()
```

### 新建场景并进行属性设置

```mixcode
{C:2, 创建任务场景}
atkConnect(conID, {S:New}, {S:/ Scenario AdvancedProximityAnalysis})
atkConnect(conID, {S:SetAnalysisTimePeriod}, {S:* "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000"})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### 新建卫星并进行属性设置

```mixcode
{C:3, 插入卫星并进行属性设置}
atkConnect(conID, {S:New}, {S:/ Satellite Satellite1})
atkConnect(conID, {S:SetState}, {S:*/Satellite/Satellite1 Classical HPOP "13 Feb 2023 00:00:00.000" "18 Feb 2023 00:00:00.000" 60 ICRF "13 Feb 2023 00:00:00.000" 7000137 0.01 28.5 0 0 0})
atkConnect(conID, {S:Animate}, {S:* Reset})
```

### 新建高级接近分析对象并进行属性设置

```mixcode
{C:4, 插入高级接近分析对象并进行属性设置}
atkConnect(conID, {S:New}, {S:/ AdvCat AdvCat1})
{C:将 Satellite1 对象设置为主目标}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Primary Add "Satellite/Satellite1" Fixed 21000.0 11000.0 6000.0 HardBodyRadius 2})
{C:将 TLE 文件设置为次目标}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Secondary Add "(ATK根目录)\Help\Examples\08-二次开发案例\TLE20230212.txt" Fixed 10000.0 5000.0 3000.0})
{C:设置筛选器参数}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters OutOfDate On})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters ApogeePerigee 60000.0})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters OrbitPath Off})
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 PreFilters Time On})
{C:开始计算}
atkConnect(conID, {S:ACAT}, {S:*/AdvCat/AdvCat1 Compute On})
```

::: warning 路径替换说明
(ATK根目录) 需要替换为用户实际的 ATK 安装路径。
:::

### 查看报告数据

```mixcode
{C:5, 查看报告数据}
atkConnect(conID, {S:Animate}, {S:* Reset})
atkConnect(conID, {S:Report_RM}, {S:*/AdvCat/AdvCat1 Style "Cat Event Message"})
```

### 保存场景后与 ATK 断开连接

```mixcode
{C:6, 保存文件并断开连接}
atkConnect(conID, {S:Save}, {S:/ *})
atkClose(conID)
```
