# deb 包

## 安装

> 安装包后缀：`.deb`
>

1. 优先双击 deb 安装包，系统将自动启动安装流程；

2. 若桌面无法识别安装包，打开终端并执行：

   ```bash
   dpkg -i <deb文件路径>
   ```

3. 若提示权限不足，添加 `sudo` 以管理员权限安装：

   ```bash
   sudo dpkg -i <deb文件路径>
   ```

4. 安装完成后，软件默认部署至 `/opt/ATK` 目录，并自动在桌面生成快捷方式；

5. 若快捷方式异常，可进入 `/opt/ATK` 目录，参照「压缩包格式」运行方法启动。
