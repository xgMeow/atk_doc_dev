# 客户端说明

<PathViewer
  :relative-paths="files"
/>

Python客户端是ATK软件向用户提供的界面工具，可使用Python遍历、判断类逻辑语法，同时支持在Python代码内调用Connect命令接口和ATK建立通信。

Python客户端需用户自行下载安装；ATK提供的ATK-Python通信库文件位于安装包目录下 <PathCopy :entry="pythonDir" /> 文件夹内，使用时需将对应库、函数添加至使用目录。

![使用文件目录](media/README/image0120-1.png)

![Python界面](media/README/image0120-2.png)

Python客户端支持Connect命令，用于完成和ATK软件间的命令解析、数据传输；内置三组核心接口用于连接管理与参数配置：

1. `atkOpen`：建立和ATK的连接

2. `atkConnect`：进行属性设置

3. `atkClose`：断开与ATK的连接
