# CovMulti Assets

## 作用

覆盖性选择多个目标对象

## 语法

```atk-command
CovMulti / Assets < AssetObjectPath > < AssetObjectPath > …
```

## 示例

::: details open **选择多个目标对象进行覆盖性计算**
```
CovMulti / Assets */Satellite/Satellite1/Sensor/Sensor1 */Satellite/Satellite2/Sensor/Sensor1 */Satellite/Satellite3/Sensor/Sensor1
```
:::
