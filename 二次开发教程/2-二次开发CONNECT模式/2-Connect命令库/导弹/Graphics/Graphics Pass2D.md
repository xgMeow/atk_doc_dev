# Graphics Pass2D

作用：设置轨迹类型

::: note 用法
```
Graphics <ObjectPath> Pass2D ({LeadTrailOption} <Parameters>)
```
:::

::: info 说明

- `LeadTrailOption`:  GrndTrail

- `Parameters`: `Time <Time>`、`PointNumber <PointNumber>`、`All`、`None`

:::

::: tip 举例
```
Graphics */Missile/Missile1 Pass2D GrndTrail PointNumber 5000
```
:::
