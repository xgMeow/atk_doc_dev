# Graphics Label

作用：设置卫星标签属性

用法：
```
Graphics <ObjectPath> Label {Options}
```

说明:

- `Show {on | off}`: 显示或隐藏标签

::: note 举例
```
Graphics */Satellite/Satellite1 Label Show on
```
:::
