## VO Model

作用：设置导弹 3D 模型参数

::: note 用法
```
VO <ObjectPath> Model {Options} 
```
:::

::: info 说明

| Options          | 说明           |
| ---------------- | -------------- |
| `Show {on \| off}`            | 显示或隐藏3D模型 |
| `file {"<FilePath>"}`         | 导入模型文件     |

:::

::: tip 举例
```
VO */Missile/Missile1 Model Show on
```
:::
