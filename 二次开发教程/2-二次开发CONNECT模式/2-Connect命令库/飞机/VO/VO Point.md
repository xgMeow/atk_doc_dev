# VO Point

- 作用：设置飞机3D 模型点属性
- 用法： 
```
VO <ObjectPath> Point {PointOptions}
```

| Option       | Value         | 说明                |
| ------------ | ------------- | ------------------  |
| Show         | `{On \| Off}` | 是否显示模型点       |
| Size         | `<Value>`     | 模型点大小设置       |

::: note 举例
```
VO */Aircraft/Aircraft Point Show On Size 7
```
:::
