# 日期时间格式

命令中的时间参数按填写方式分为两类：**单个时间值**和**时间间隔**。

## 单个时间值

命令中出现 `{TimeValue}`、`"<OrbitEpoch>"`、`"<CoordEpoch>"` 等参数，或时间间隔中的 `"<StartTime>"` / `"<StopTime>"` 时，均填写绝对日期时间。

**格式**：`"DD Mon YYYY HH:MM:SS.sss"`（UTCG）

| 示例 | 说明 |
|------|------|
| `"01 Sep 2011 12:00:00.000"` | 2011-09-01 12:00:00 |
| `"1 Jul 2021 09:00:00.000"` | 2021-07-01 09:00:00 |

::: tip 切换日期格式
默认使用 UTCG，如需北京时 `BJT`、儒略日 `JDate` 等，通过 `Units_SetConnect / Date <格式名>` 切换，可选格式参见 [单位格式](/二次开发教程/2-二次开发CONNECT模式/2-命令参考/2-参数值格式/单位格式.md) 中 Date 行。
:::

## 时间间隔

命令中出现 `{TimeInterval}` 参数时，填写一个开始时间和一个结束时间，用空格分隔：

```
"<StartTime>" "<StopTime>"
```

- 开始时间在前，结束时间在后，**不可调换顺序**
- 两个时间**不能相同**
- `"<StartTime>"` 和 `"<StopTime>"` 均按单个时间值格式填写

**示例**：`"01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"`

## 示例

::: details open **单个时间值** — 设置 Satellite1 在指定时刻的 ECI 位置
```
SetPosition */Satellite/Satellite1 ECI "1 Jul 2021 09:00:00.000" 8678140.000000 0.000064 -1.837743
```
:::

::: details open **时间间隔** — 为 Satellite1 创建指定时段的数据报告
```
ReportCreate */Satellite/Satellite1 TimePeriod "01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"
```
:::
