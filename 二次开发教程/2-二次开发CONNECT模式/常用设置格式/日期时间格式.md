# 常用日期/时间格式

命令中的时间参数按填写方式分为两类：**单个时间值**和**时间间隔**（时间间隔的结束时间还支持一种 **相对时间** 简写）。

## 单个时间值

命令中出现 `{TimeValue}`、`"<OrbitEpoch>"`、`"<CoordEpoch>"` 等参数，或时间间隔中的 `"<StartTime>"` / `"<StopTime>"` 时，均填写绝对日期时间。

**格式**：`"DD Mon YYYY HH:MM:SS.sss"`（UTCG）

| 示例 | 说明 |
|------|------|
| `"01 Sep 2011 12:00:00.000"` | 2011-09-01 12:00:00 |
| `"1 Jul 2021 09:00:00.000"` | 2021-07-01 09:00:00 |

::: tip 切换日期格式
默认使用 UTCG，如需北京时 `BJT`、儒略日 `JDate` 等，通过 `Units_SetConnect / Date <格式名>` 切换，可选格式参见 [常用单位格式](/二次开发教程/2-二次开发CONNECT模式/常用设置格式/单位格式.html) 中 Date 行。
:::

## 时间间隔

命令中出现 `{TimeInterval}` 参数时，填写一个开始时间和一个结束时间，用空格分隔：

```
"<StartTime>" "<StopTime>"
```

- 开始时间在前，结束时间在后，**不可调换顺序**
- 两个时间**不能相同**
- `"<StartTime>"` 和 `"<StopTime>"` 均按单个时间值格式填写

**示例**：`"01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"`

## 相对时间

`"<StopTime>"` 除了填写绝对时间，还可用相对时间简写，省去手算结束时间。

**格式**：`"+n {Unit}"`

| `{Unit}` | 可选值 |
|----------|--------|
| 天 | `Day` / `Days` |
| 小时 | `Hour` / `Hours` / `Hr` / `Hrs` |
| 分钟 | `Min` / `Mins` / `Minute` / `Minutes` |
| 秒 | `Sec` / `Secs` / `Second` / `Seconds` |

**示例**：`"+1 Day"`、`"+2 Hrs"`

组合使用：`"01 Sep 2011 12:00:00.000" "+1 Day"` 等价于 `"01 Sep 2011 12:00:00.000" "02 Sep 2011 12:00:00.000"`

## 示例

::: details open **单个时间值**
```
SetPosition */Satellite/Satellite1 ECI "1 Jul 2021 09:00:00.000" 8678140.000000 0.000064 -1.837743
```
:::

::: details open **时间间隔**
```
ReportCreate */Satellite/Satellite1 TimePeriod "01 Sep 2011 12:00:00.000" "01 Sep 2011 12:30:00.000"
```
:::

::: details open **相对时间**
```
ReportCreate */Satellite/Satellite1 TimePeriod "01 Sep 2011 12:00:00.000" "+1 Day"
```
:::
