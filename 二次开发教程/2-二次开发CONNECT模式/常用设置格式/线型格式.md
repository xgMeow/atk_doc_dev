# 常用线型格式

`{LineStyle}` 参数支持名称或数字两种输入方式：

| 线型 | 关键字 | 编号 |
|------|------|------|
| 实线 | `solid` | `0` |
| 虚线 | `dashed` | `1` |
| 点线 | `dotted` | `2` |
| 点划线 | `dashdot` | `3` |
| 长-中-短虚线 | `lmsdash` | `4` |

## 示例

::: details open 使用关键字设置线型
```
Graphics */Satellite/Satellite1 SetLineStyle dashed
```
:::

::: details open 使用编号设置线型
```
Graphics */Satellite/Satellite1 SetLineStyle 2
```
:::
