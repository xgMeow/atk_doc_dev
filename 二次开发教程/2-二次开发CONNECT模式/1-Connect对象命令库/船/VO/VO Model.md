# VO Model

## 作用

设置**船 3D 模型**属性。

## 语法

```
VO <ObjectPath> Model {Option1} <Value1> [{Option2} <Value2>]...
```

## 参数说明

| 参数 | Value | 说明 |
| -- | -- | -- |
| `Show` | `{On \| Off}` | 是否显示模型 |
| `File` | `<ModelFile>` | 模型文件路径 |

## 示例

::: details open **隐藏船 3D 模型**
```
VO */Ship/Ship1 Model Show Off
```
:::
